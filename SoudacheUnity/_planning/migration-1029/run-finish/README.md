# 桌面局内流程补全

本目录直接执行生产 Core/Run 源码；音频和 Unity 文件系统入口由测试适配器提供。验证结果不能替代主会话的原生编辑器与真实输入验收。

## 当前实现

- 背包道具读取现行 `rules.bag.use`；地图仅执行源支持的治疗、复原、随机获取、发现，混合道具仅应用地图部分。发现候选先保存，关闭或重启保持，确认成功才消耗。
- 仓库木材/口粮/钥匙卡读取 `rules.base.material` 转入储备；材料不出售；消耗区整堆恢复按古朴/稀有/史诗/传说每张1/2/3/4钥匙收费。
- 宠物使用现行 `pets.json`：初始旺财、50币+蛋孵化未拥有伙伴、口粮2/3/4/5升级、等级安全格与伙伴起始效果。储备币保留基地，不带入局内。
- 仓库容量计入符文；当前容量达到50后扩建还需2符文。研究所获取与第二玩法保持迁移范围规定的暂缓状态。
- 地图移动、切层、补给/物资领取、休整、祭坛、献祭撤离统一复用存档事务。失败回滚内存与随机状态，原档保留。
- 祭坛三卡激活后回赠二选一：回复10生命+手选复原最多3张，或传说/装备各1且不重复；2碎片可直接换本职业能力卡并激活；一次道具献祭可复原2张。选择与余量随节点保存，前往其他节点后未领部分结束。
- 战斗保存携带 Core 入场检查点与完整入场对局副本。中场HP、金币与母卡变化不污染入场副本；恢复遵循当前源的入场重开行为。Boot负责在Core.Start前捕获入场对局、恢复Core以及结算时清除。
- 成就定义复用现行26项JSON，判定按当前`ACH_DONE`移植；宠物安全格、跨档通知、钥匙与指定卡奖励、满仓延后领取已接齐。经验阈值及撤离首探量沿当前源；进层与读档不额外增加首探量。
- `BaseData`读取与保存调用整备预设、经济卡包候选、最后一盏灯故事记录的校验接口。重置槽位在同一事务内清旧档并建立新基地。
- 当前玩法仅标准/精英，精英敌人倍率为1.35、经验倍率1.5；地图遭遇/首脑/休整/物资/身份随机流对齐当前源。独立播放器可沿进程环境`SDT_UNITY_TEST_DATA`使用隔离新档目录。

## 证据

`source-vectors.mjs`直接执行当前 `executeBagItemEffects`，并通过Acorn抽取当前 `hatchPet` 原函数，不另写参考掉落公式。当前导出有19张声明背包操作的卡；32组确定性背包向量及4个种子的完整孵化序列用于对照。

`data-20261029-155746-863/result.json`：1013条断言、20次真实文件写入故障通过。覆盖道具、发现取消/重启、材料/宠物/钥匙/符文、地图收益、祭坛与紧急撤离、战斗入场保存恢复和失败结算保留检查点；恢复后再次消费母卡和修改节点回执，再重启仍保持独立入场副本，无递归包装。

其中成就26项定义逐字段对照，8组条件状态执行当前`ACH_DONE`原函数；12组首次探索量/倍率经验执行当前`firstExploreMoves`/`extractionXp`/`addXpToProgress`。130个普通遭遇向量直接执行当前`buildEncounter`、`selectEncounterSpec`和`scaleEnemyForMode`，覆盖5种子、2模式、四层全部战斗节点，并逐项对照后3次敌人随机位置。

同批旧域回归：`../save/data-20261029-152515-572/result.json`123条断言/10次真实故障；`../container/data-20261029-152515-474/result.json`25条断言/6个当前源容器向量通过。
