# 现行照相馆与照片背签迁移冻结

当前以 `../搜打撤/game` 的真实延迟入口 `game.cardslib.js → game.cardslib.page.js` 及其 `photo-studio-*`、`card-zoom-*` 和最后级联 CSS 为源。源/资源 SHA 见 `source-receipt.json`，自有产物冻结见 `freeze.json`。本轮仅后台写入与私有托管检查；没有 Unity、浏览器或前台操作，没有共享 compile、提交或旧资源删除。冻结状态不代表实际视觉与输入验收通过。

现行源 09-24 已取消馆内固定分页，正式馆内不导入通用 `card-browser`；这里沿四列连续照片墙与视口附近挂载。`PhotoStudioWall` 负责相纸/原插画、稀有度装裱/纸夹、稳定落影、当前筛选顺序和定位；分类、搜索、稀有度、人物、排序、可移除条件与重置由 `CardLibraryScreen` 和 `PhotoStudioChoice` 管理。每个筛选上下文保留选片与滚动位置，目录排除 `tt-token-color`，已收录卡牌不再套旧 `???` 收藏遮蔽。制作坊和导入/删除写入口继续关闭。

右侧 `PhotoStudioDossier` 为高396px、宽度比7:2.6的纸质选片资料，包含真实费用/效果/说明/备注，照片留在墙和特写。`PhotoDetailScreen` 沿当前1.7:.8两栏，原画比例完整展示、纸边与独立角饰、右侧自然内容高度背签、当前筛选内左右键连续浏览且两端停止，收回后定位当前片。取片420ms、收回120ms，返回墙180ms，减少动态效果读取现行全局键。搜索120ms去抖、悬停90ms和滚动保护140ms；输入法组合期间不确认搜索/关闭。

备注继续读写现有全局键与 `BaseData.TrySavePhotoNote`，240字，输入240ms后、失焦、翻片、收回时保存；失败文本留在会话 pending，明确显示“未存档，已暂存本次会话”。空白改写回落底稿。主会负责标题未选档的共享保存守卫修复；本域没有新数据库或可消耗照相道具。

共性文案统一放在 `Sdt.Res.CurrentCardPresentation`，并由主会接入正式卡面。`Description(CardDef, Context)` 直接转译审阅原文守卫、规范化、结构化句式、战斗攻击/法伤/倍率/区间和星盘相位，`RichDescription` 统一输出 Plain/Rich 和关联卡/术语字符范围。只读 JSON 是源审阅表和术语表，不存第二份卡牌定义。photo只负责原生字符命中、术语纸签与关联照片宿主。
