# 七款简洁卡背

七款卡背沿用 `SDT.Cards.CARD_BACKS` 的编号、名称、解锁条件和当前存档装备选择。`game/css/scenes.css` 的 `.hs-back.hb-*` 规则引用本目录图片，收藏缩略图、背包卡牌背面和战斗牌堆共用这条样式链。

| 文件 | 中央主题 | 边框 |
| --- | --- | --- |
| classic.webp | 行囊粗布：扎结粗布包 | 折布角与粗缝线 |
| wolf.webp | 猎手皮纸：贯月赤箭 | 皮纸边带与箭形包角 |
| coin.webp | 富商锦缎：方孔金币 | 赤锦边带与金色折角 |
| vault.webp | 仓廪木纹：单支麦穗 | 木梁与榫接角帽 |
| boss.webp | 弑神黑曜：赤缝黑曜 | 黑曜切角与少量赤缝 |
| altar.webp | 核心星轨：单环晶核 | 金色弧角与青蓝嵌面 |
| pet.webp | 忠犬爪印：单个爪印 | 皮革边带与搭扣角饰 |

每款保留单一主意象与安静色面背景，边框采用少量主题边带和角饰，装饰集中在画面边缘。内置 ImageGen 以现行追斩、初始攻击与寻宝卡图作画法参考，只改边框并沿用宽笔块面与硬边明暗；图片统一为 512×768 WebP。来源、提示词、上一版备份与哈希见[本轮记录](../../../docs/evidence/2026-10-12-cardbacks-border-design/receipt.json)和[生成请求](../../../docs/evidence/2026-10-12-cardbacks-border-design/request.json)。本轮只查看生成画作，未测试或实页验收。
