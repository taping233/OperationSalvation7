# 庭院运行时核心

此目录保存锦鲤庭院运行时正本，由相邻 `hub.courtyard-v3.js` 相对导入。首次迁入与资产目录的审核副本逐文件 SHA256 一致；原始 MIT 许可证随代码保存。观雨使用项目自有 `courtyard.rain-tableau.js`；未被导入的旧雨模拟与渲染模块已移出运行源码，来源审核副本仍保留在资产目录。

上游固定提交、来源文件和改编内容见 [来源记录](../../../assets/vendor/base-courtyard/SOURCE.md)。`game/assets/vendor/base-courtyard/` 的 JavaScript 是保留的来源审核副本，不作为运行时模块导入。

锦鲤运行时在 MIT 改编基础上使用连续闭合曲线绘制鱼身，以随尾部递增的摆动连接克制的胸鳍和尾鳍；鱼身采用暖白、朱红、淡金与炭灰色块，池宽正常比例下鱼长约 3.6%–5.4%，矮画布另按高度收缩。阴影为浅青灰投影，不再以粗描边绘制各节鱼身。

游动由帧间时间驱动，缓慢转向并避开四周至少约 10% 的岸边区域；点击投喂点也限制在该水域。食物与涟漪分别最多 24 个，食物 16 秒消失、涟漪 2.4 秒消散，吃食产生的涟漪同样受上限约束。缩放按原位置比例重映射，静态绘制不推进模拟，销毁后接口不再重建场景。运行时只清绘透明动态前景，不绘制底图，不创建全局监听或动画循环。

鱼塘保留上游的指针水纹与避让交互：水域内移动指针每 0.18 秒最多产生一次小水纹，闲游的鱼会柔和避开指针，投喂时优先觅食。六条淡水光随同一模拟时间移动，减少动效时保持静止。划过鱼身可发现九条锦鲤，实际吃到食物后累加吃食次数；两项计数仅属于当前庭院页面，不写入存档或基地经济。关闭雨独立隐藏雨层、停止雨模拟并关闭雨声，锦鲤游动、投喂、水纹与寻找仍可使用；重新开启雨不会自动开启声音。
