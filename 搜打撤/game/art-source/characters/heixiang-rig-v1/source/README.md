# 黑像 R4-b1 可编辑拆件源

这是四关键姿势技术美术原型，不是最终动画资产。主文件为 `heixiang-rig-v1.ora`；展开图层位于 `../layers/`。

初始化制件仅运行一次：`python export_key_poses.py --init`。它会从只读身份源和补画参考切出图层，并重写 `layers/`、rig、motion 与 ORA，人工编辑后不要再运行。

正常重导出：`python export_key_poses.py --export --outdir <目录>`。该命令只读取已有 PNG 图层、`rig/heixiang-rig-v1.json` 和 `motion/key-poses.json`，不会覆盖可编辑源。另一执行者可修改一个关节或图层后导出到独立目录复核。

实际来源：原战斗图继续提供头脸、疤痕、黑手套身份参照、靴、腿、围巾、肩甲和巨剑；一次 NovelAI V5 painterly 832×1216/28步参考仅用于无遮挡胸腹和两臂内侧结构。参考请求第一次因携带参考图返回HTTP 500且没有产物，移除参考传输后固定seed单次成功；没有继续生成。中文提示词与请求摘要保存在本目录。生成前没有成功取得余额快照；生成后余额接口只返回错误状态而无数值，因此不能声称已获得前后余额，只能确认未购买或追加额度。

四姿势仍是 R4-b1 审核候选，范围已收窄为上身持剑绑定。下半身与围巾采用原图静态整层；腿IK仅保留在实验报告中，不驱动候选像素。原图黑色叠手与完整剑柄作为同一刚体关系旋转，腕目标只驱动肩肘链。补画参考只进入胸腹内部，外部上臂、肩甲、手、头脸和剪影均回到原战斗图。该候选未标为可接入运行时。
