# 常无欲：四动作战斗素材

四组已完成，当前总预览为 `index.html`。攻击只动角色自身的左手：本基准图中画面右侧、原本扶镜的那条手臂；腰前右手保留原图。五张导出帧在实装前已核对角色左右及两只手；挥手帽檐另修复手部替换区的覆盖痕迹。受击延长为约 0.8 秒，死亡最终保持侧躺。

| 动作 | 当前内容 | 时长 |
| --- | --- | --- |
| 待机 | 72 个连续呼吸采样帧，头发/袍摆无独立风动 | 3 秒循环 |
| 攻击 | 角色左手从面旁向右伸出、收回；5 个帧槽含4个不同姿态 | 500 ms |
| 受击 | 同一底图的19帧连续轻后仰、回稳 | 792 ms |
| 死亡 | 失去支撑、屈膝撑地、侧身落下；8个帧槽含7个不同姿态 | 1167 ms，尾帧停留 |

全套画布 768×512。攻击、受击的首尾 PNG 直接复制 `idle/frames/idle-000.png`，死亡首帧也复制同图；文件字节与 RGBA 像素一致。死亡最后两帧是同一躺倒图。各动作时间步约24 fps；动作停留不冒称额外独立原画。

`idle/attack/hurt/death` 各含 `sprite.json`、透明帧图、独立PNG与观看副本；GIF用于观看，游戏素材保留透明。全套连播按待机→左手挥动→受击→死亡顺序结束，单独按钮也可查看。导出数据检查见各目录 `validation.json`，输入与内置 imagegen 提示词见 `requests.json`。

攻击使用 `pack_left_attack.py` 重建。`attack/anatomical-left-source.png` 是现行局部姿态源；`left-source.png` 和旧 `source.png` 是被否定的历史候选，不用于现行动作。手臂以外像素复用基准，旧面旁手被替换，腰前右手保持逐像素一致。扶镜只是待机姿态，不作为动作人设硬锚点。`attack/review-all-poses.png` 对实际导出帧做手部局部与全身复核。旧的 `frame-05..07` 不在当前5帧清单中。

待机重建执行 `bake_idle.ps1`；受击重建执行 `bake_hurt.ps1`；死亡重建运行 `python pack_action.py death death/source.png`。使用已有FFmpeg、Pillow、NumPy、OpenCV，无新增依赖。无火球、无杖；黑雾伴生物保留，死亡时消退。
