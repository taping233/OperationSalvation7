# 无整帧攻击试绘 v8

老板同意尝试整帧攻击重绘。以当前立绘为参考，通过内置image_gen分别绘制蓄力举剑、前倾下斩、伸臂命中和收势四张完整人物图，替换四动作展示页中的攻击候选。

展示按慢蓄力、快前下斩、命中短停、缓收势安排时长，约0.76秒，前后使用当前待机基准。挥击阶段可叠加短暂模糊残影。全身姿势、肩胯与袖子直接重新绘画，不继续使用站立图的关节旋转来表现该攻击。

原PNG位于`frames/attack-01.png`至`attack-04.png`，完整提示词和原始来源见`prompts.json`，播放时序见`sprite.json`。超过1MB的原图仅保留本地，由`.gitignore`排除；路径、SHA256与获取方式见`receipt.json`。
