# 无立绘攻击 v5

当前候选保留两倍待机的原立绘与原剑纹理，修复v4腿部原剑残留，并重做举剑和前挥的手臂关键姿势。未接入正式战斗，观感仍待老板确认。

原护手及柄尾有一部分超出旧移除区域，残留在大腿上方。本版扩大遮挡还原区域，继续复用已有干净补片，脸、头发、可见服装与双脚沿用原图。没有另画角色或换回昨日简易分件。

举剑时抬肘到身体外侧并屈肘；小臂先转，大臂随后带动，前挥的终点为手臂向前伸直。肩部荷叶边覆盖移动袖根，小臂、手和剑绘在它前方。举剑、挥击、收势使用不同的肘腕位置；身体小幅后移蓄力，再向前发力。

画布832×832，原人物画布576×560放在(40,216)，人物不缩放；扩大留边容纳举剑。31帧、30帧/秒、约1.03秒。待机与攻击首尾使用同一张待机第0帧，脚底固定。页面提供循环、慢放、逐帧、关节显示与PNG导出；快速剑刃拖影可关闭。

当前Codex内置浏览器逐帧目检与源ZIP像素检查见[本轮证据](../../../../../docs/evidence/2026-10-10-wu-attack-v5/README.md)。`sprite.json`为导出清单，`receipt.json`记录源ZIP与逐文件SHA256。超过1MB的动画预览只保留本地，由`.gitignore`排除；可从PNG帧及清单重新制作。
