# 无连续受击 v1

老板认可攻击v7后制作的独立受击候选。直接复用该版当前立绘、干净底图、手臂分层、刚性剑和待机，不修改已认可攻击。

动作约0.72秒、43帧、60帧/秒。先在约57毫秒内快速后撤，肩胸后仰、膝部小幅屈曲，双手随身体回收；短暂承受冲击后缓慢恢复，并轻微回弹到待机。头发稍滞后，受击残影只出现在最初冲击阶段，可关闭。

剑始终沿用攻击v7的独立纹理，只平移旋转；脚底固定，脸、发饰和服装沿原图。画布832×832、人物偏移(40,216)、角色尺度与已认可版相同。受击首尾直接使用该版待机基准，身体运动和动作速度另行安排。

页面提供循环、正常/半速/四分之一速度、逐帧、剑长对照和透明PNG导出。`sprite.json`为43帧清单，`validation.json`为输出检查，`receipt.json`记录来源ZIP与逐文件SHA256。超过1MB的本地动画预览由`.gitignore`排除。

该候选尚未接入正式战斗，观感待老板确认。覆盖范围见[本轮记录](../../../../../docs/evidence/2026-10-10-wu-hurt-v1/README.md)。
