# 无立绘攻击 v6

继续沿用当前待机立绘、已修复的腿部底图与同一剑纹理。本版修复收势裁掉剑尖的问题，并增加实际过渡姿势。仍是独立候选，未接入战斗。

v5的脚底固定区域在移动剑绘完后整条重画，收势阶段剑尖进入该区域时被擦掉。v6先恢复脚底，再绘完整持剑臂和剑；收势手腕角度也已调整，剑的全部几何轮廓保持在脚底固定带上方。此前几何长度检查没有覆盖绘制裁切，本版增加逐导出帧剑尖像素存在检查。

本版67帧、60帧/秒、约1.12秒，挥击中增加中间姿势，主挥击约6帧。蓄力保持少量连续变化，命中只短暂停顿，然后连续收势。导出检查至少65张不同帧；重复首尾与短命中停顿为有意保留。

原画布832×832、人物偏移(40,216)、人物尺度、脚底及首尾待机图保持。页面提供慢放、逐帧、关节与剑刃拖影开关及PNG导出。`sprite.json`为导出清单，`validation.json`为像素检查，`receipt.json`记录来源ZIP与逐文件SHA256。超过1MB的动画预览仅保留本地并由`.gitignore`排除。

目检与覆盖边界见[本轮记录](../../../../../docs/evidence/2026-10-10-wu-attack-v6/README.md)。
