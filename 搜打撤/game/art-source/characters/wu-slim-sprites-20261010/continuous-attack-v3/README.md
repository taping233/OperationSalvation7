# 无快速斩击 v3

老板否决上一版，指定速度优先、免检查，由老板检查。本轮复用昨日`wu-simple-rig-v3-20261009`的9张完整分件和骨骼设置，在独立目录快速制作举剑蓄力、斩击、收势；旧方案只读保留。

候选动作约0.8秒，30帧/秒，25个可导出采样帧。肩肘共同指向持剑手目标，剑保持单独刚性部件；头发和空手延迟跟随。斩击拖影仅用于快速挥击区间，可关闭。预览默认攻击与待机循环，按钮可导出透明PNG ZIP。

参考[Spryke作者的动画制作说明](https://www.gamedeveloper.com/design/5-tips-to-make-your-game-animations-better)的短时夸张帧与拖影做法，按明显不同的蓄力、斩击、收势轮廓重新安排动作。本版不是对参考游戏素材的复制。

按老板要求，没有测试、目检、浏览器验收或构建；状态为未验收候选。没有修改正式战斗加载器或运行素材。
