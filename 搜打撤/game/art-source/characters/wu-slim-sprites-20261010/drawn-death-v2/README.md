# 无 · 逐帧绘画死亡 v2

老板否决分关节死亡后改为完整姿势逐帧重绘，允许关键帧姿势变化较大。本版使用当前立绘作唯一画风与身份参考，经内置image_gen分别绘出失衡、跪撑、侧倒和最终躺倒四张完整人物图。

人物的腿部、躯干、表情和衣褶直接随姿势重新绘画。预览只播放完整绘画帧，不再拆关节、拉伸肢体或旋转站立图。四张图均闭眼或逐渐闭眼；最终侧躺，头发在地上散开，剑在身旁。

播放包含当前站立基准与四张关键帧，约0.55秒到达最终躺倒；最后一帧持续保留。页面提供半速、逐帧和可选循环。完整帧按共同画布等比显示，并作少量整体垂直放置调整；没有生成额外的插值帧。帧间姿势、细节及透视变化是本次绘画候选的一部分，尚待老板确认。

`frames/death-01.png`至`death-04.png`是原生透明绘画资产；`sprite.json`记录播放与放置；`prompts.json`保存完整生成提示词和来源。大于1MB的图不入Git，由`.gitignore`排除，路径、SHA256和获取来源见`receipt.json`。
