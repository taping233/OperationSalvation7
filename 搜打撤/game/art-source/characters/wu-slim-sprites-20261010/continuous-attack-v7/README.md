# 无立绘攻击 v7

当前候选继续沿用已确认的待机立绘。本版把待机、攻击与攻击端点统一为同一独立刚性剑层，并重排变速斩击及模糊残影。未接入正式战斗，观感仍待老板确认。

旧版待机对整张含剑立绘做局部位移，攻击用颜色筛选后的剑图，首尾又直接绘整张待机图。这些绘制路径已统一：干净身体单独呼吸，完整剑刃像素单独保留，剑在所有姿势中只平移和旋转。剑先绘、手再覆盖握柄；源立绘脸、头发、衣服和身体比例继续沿用。

本版73帧、60帧/秒、约1.22秒。时间曲线安排慢蓄力、约100毫秒快速前挥、短停顿及缓收势，手臂和剑的历史姿势只在挥击阶段形成模糊残影。实剑保持清楚，模糊残影可以关闭；“剑长对照”可叠加护手到剑尖的等长参考线。

画布832×832，原人物偏移(40,216)，人物不缩放，双脚固定。动作首尾与本版刚性剑待机第0帧一致；`paired-idle-rest.png`为相应导出参考。原连续待机与旧候选不修改。

页面提供正常/半速/四分之一速度、逐帧与PNG导出。导出遵循模糊残影开关，不导出关节或剑长对照覆盖层。`sprite.json`、`validation.json`、`receipt.json`记录清单、检查与来源ZIP及逐文件SHA256。大于1MB的本地动画预览由`.gitignore`排除。
