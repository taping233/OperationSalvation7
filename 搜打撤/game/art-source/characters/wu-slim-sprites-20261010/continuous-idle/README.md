# 无：连续待机

同一张修腿版待机立绘生成72张连续帧，24帧/秒，3秒循环。只做胸肩轻微呼吸、双手细摆和少量发尾跟随，不再逐帧重画五官、衣褶和轮廓。本轮只完成待机这一片，攻击、受击、死亡保留原候选，未替换游戏运行素材。

源图为上级 `idle/idle-000.png` 的原样副本 `base.png`。`motion.js` 使用原生WebGL对同一张纹理施加局部连续位移，头脸、腰胯和脚底区域固定；胸肩峰值1.65像素，持剑手微动约0.65像素，空手横向微摆约1.15像素，剑的角度变化约0.10度。衣服随对应局部一起移动，头部不做整片上下平移。

`index.html` 并排播放旧六帧版和新连续版。访问项目已有Vite服务：`http://127.0.0.1:5200/art-source/characters/wu-slim-sprites-20261010/continuous-idle/index.html`。默认隐藏固定位置参考线，可勾选检查。预览以24帧/秒取样，与导出帧的相位一致。

通过内置浏览器真实点击“导出72帧”，由当前窗口的原生Canvas导出RGBA PNG；ZIP另有循环相位1.0的检查帧。`package_frames.py <下载的ZIP路径>` 只拆包、检查并打包，不重画或补间。

- `frames/`：72张PNG和无损WebP；`sprite.json`：时序与帧列表。
- `preview.webp`：实际导出帧的动画预览；`idle-atlas.png`：9列×8行帧图。
- `validation.json`：头脸、双脚、腰胯三处全程像素一致，完整循环端点与首帧像素相同；最后一帧至首帧的变化没有异常增大。
- `receipt.json`：文件大小、SHA256、下载来源。超过1MB的本地产物被本目录`.gitignore`排除；获取方式为内置浏览器导出ZIP后运行打包脚本。

此方法适用于微动作待机。大幅攻击和倒地需要关节与遮挡处理，不能只放大本位移场来代替；它们尚未按新方法制作。这里的像素稳定性通过，不代表正式战斗接入已经验证。
