# 无 · 连续攻击 v2

这版扩大举剑蓄力与前挥时的身体发力，沿用已确认的修细腿型、两倍待机、同一张角色立绘和同一把长剑。它是独立预览候选，尚未接入正式战斗，也未经老板确认。

## 动作与资产

- 768×768透明画布，原角色画布576×560放在(24,144)，不缩放人物。
- 36帧、24帧/秒、1500毫秒；导出PNG与无损WebP逐帧、图集及动画预览。
- 举剑时下沉17像素、向后移14像素并后倾；前挥时向前移30像素、前倾约13度。两姿势躯干角度相差约22度。
- 第11帧至第12帧（编号10→11）小臂先转39度，大臂暂时保持；之后3帧完成主要挥击，第15至17帧保持命中姿势，再收势与收回。
- 高速挥剑的第13、14帧保留少量剑刃拖影，可在页面关闭；脸部不加模糊。
- 双脚底固定，膝腿随重心弯曲；头发与另一只手稍滞后。攻击首尾与配套两倍待机第0帧逐像素一致。

`index.html`提供正常/半速/四分之一速度、逐帧滑杆、关节显示及导出。`idle-compatible/sprite.json`是同画布的72帧两倍待机；`sprite.json`是攻击清单。完整运行时数据仍沿用游戏现有版本，本目录未修改游戏动作加载器。

## 制作与检查

复用前一版的`base.png`、遮挡补片`body-repair.png`以及拆分逻辑，只调整动作曲线、身体位移和高速拖影。当前轮没有新增整张AI重绘。

先运行`node check-geometry.mjs`核对241个采样点的剑长、手臂长度、画布边界与首尾姿态。在内置浏览器点击“导出攻击帧”，再用项目现有Python/Pillow环境执行`package_frames.py <下载ZIP的绝对路径>`。打包检查尺寸、透明通道、脚底一致、命中停顿与待机首尾相接；打包后生成`receipt.json`记录文件及来源ZIP的SHA256。

单文件超过1MB的图集和动画预览只保留本地，`.gitignore`排除它们，路径与SHA256见`receipt.json`。

当前窗口目检与验收记录见[任务证据](../../../../../docs/evidence/2026-10-10-wu-continuous-attack-v2/README.md)。待机、受击与死亡的其他版本继续保留；受击、死亡尚未用本版身体运动方案重做。
