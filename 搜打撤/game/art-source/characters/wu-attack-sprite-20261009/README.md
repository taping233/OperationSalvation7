# 无：攻击 Sprite 候选

当前统一版为 v3/：攻击首尾直接复用已认可待机的初始 PNG，文件字节与像素一致；匹配画布、比例和脚底位置，并校正两张收势姿态的比例偏小。v3/index.html 连播真实待机帧集与攻击；详见 [统一版说明](v3/README.md)。

参考改版为 `v2/`，首版被老板否定后按 [Slynyrd 剑击拆帧](https://www.slynyrd.com/blog/2018/9/8/pixelblog-9-melee-attacks)与 [imonk 斩击教程](https://itch.io/t/2489691/pixel-tutorial-sword-slash-animation)重做。新版增加腰胯驱动、前腿承重、后脚抬跟与一张短拖影姿态；命中剑尖朝前，随后带惯性收势。8 张关键姿态按 10 个 24 fps 时间步播放，单次约 417 ms。蓄力和命中有停留，不等同于 10 张不同原画。

新版在导出时统一使用同一比例，只对齐前脚横向位置和整幅脚底基线，保留腿部的重心变化。对应 `v2/index.html`、`v2/sprite.json`、8 张独立 PNG/WebP 和 4×2 透明帧图；旧版保留供比较。参考教程借鉴动作结构，角色外观和画风继续使用本聊天的无基准。

## 首版（已被否定，保留比较）

攻击沿用本聊天认可的待机人设和自然垂落的简洁马尾。12 张关键姿态组成约 667 ms 的单次攻击，按 24 fps 时间步播放；蓄力与收势各约 250 ms，斩击约 167 ms。预览循环额外停留 900 ms，正式动作配置 `loop:false`，不会强制循环。

`index.html` 可播放一次、循环演示、暂停、逐帧与拖动进度；`sprite.json` 是动作配置和对齐参数；`wu-attack-sheet.webp` 是 4 列 × 3 行透明帧图，单格 512×512；`attack-00..11.png/webp` 是独立姿态。`wu-attack-preview.gif` 是深色底观看副本，PNG/WebP 保留透明。

姿态由内置 imagegen 生成；脚底间距与基线在导出时统一。12 张姿态按 16 个时间步播放，其中蓄力和收势有明确停顿，不宣称 16 张独立原画。未使用骨骼或光流变形。单次攻击包含姿态变化，仍须实际观看判断剑形、手部和发力是否自然；这版未接入正式战斗，也未修改待机素材。

提示词见 `request.json`，复现导出运行 `python pack_sprite.py <原始帧图路径>`，使用已有 Pillow、NumPy 和 OpenCV。超过 1 MB 的图片保留本地并排除 Git，获取方式及 SHA256 见本轮证据收据。
