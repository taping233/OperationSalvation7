# 无：战斗待机 Sprite 候选

当前候选为 `v2/`：头发收拢为自然垂落的简洁大块面，身体轻微呼吸，24 fps、72 帧、3 秒循环。上一版四关键帧保留在本目录，老板反馈其播放不够连贯、头发摆动偏大。

`v2/index.html` 为播放预览，`v2/sprite.json` 为逐帧配置，`v2/wu-idle-sheet.webp` 为 8 列 × 9 行透明帧图，单帧 768 × 512；`v2/frames/` 为 72 张透明 PNG。`v2/wu-idle-preview.gif` 为深色背景观看副本，游戏素材使用透明 PNG/WebP。

基准图通过内置 imagegen 简化马尾；呼吸使用同图的连续位移烘焙，不使用骨骼，不逐帧重新生成人设。上半身最大上移 3.5 像素，底部 147 行保持逐像素一致；头发随身体起伏，没有独立风摆。像素相同的对称呼吸相位属于循环采样，不表示 72 张独立手绘原稿。重烘焙执行 `v2/bake.ps1`，依赖已有 FFmpeg、Python 和 Pillow；生成提示词见 `v2/request.json`。

素材未接入正式战斗。超过 1 MB 的文件及中间帧只留本地，SHA256 与获取方式见本轮证据目录的收据。
