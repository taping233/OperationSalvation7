# 搜打撤（Search · Strike · Extract）

> 从桌游到电子游戏。**飞行棋式掷骰 + 卡牌战斗**的搜打撤游戏。

核心循环（已按桌游原版规则确认）：

```
四角入口进入 → 掷骰沿当前环顺时针走（三同心环：28/20/12 格 + 中央祭坛）
→ 落脚触发格子事件（币/木材/宝箱/商店/战斗/事件/火堆…全部按设计者备注实装）
→ 环间门单向向内（不可返回，已离开的环虚化）→ 祭坛挑战三 BOSS
→ 外圈门免费撤离 或 内庭紧急撤离点花 10 币走人
```

## 快速开始

### 桌面版（推荐，双击即玩）

双击仓库根目录：

```
启动搜打撤.bat
```

- 本地 Electron 程序，独立窗口，不依赖浏览器
- 存档/卡牌库/格子备注持久化在本机数据目录（`%APPDATA%\搜打撤`），随程序保存
- 「退出游戏」会真正退出程序；单实例运行（重复双击只唤起已有窗口）
- 运行时已内置于 `desktop/electron/`；若缺失（如换机器），执行一次
  `powershell -ExecutionPolicy Bypass -File desktop\setup.ps1` 自动下载

### 网页版（无需安装任何东西）

双击打开：

```
prototypes/map-system/index.html
```

（或在 prototypes/map-system 下执行 `powershell -ExecutionPolicy Bypass -File serve.ps1` 后访问 http://127.0.0.1:8137/）

> 桌面版与网页版是**同一份代码**：桌面外壳直接加载 `prototypes/map-system`，
> 改网页版源码 = 改桌面版，改完重启桌面程序即可生效。

- **空格/回车** 掷骰子；拖拽平移视角、滚轮缩放
- **G** 网格线、**N** 格子编号（编号 = 事件表的键）
- **存档**：3 个独立档位，每档的**基地与进度完全独立**（资源/仓库/职业/成就/卡背各随档位保存）；
  「开始游戏」选档进入——有未完成对局直接续打，否则先进基地再出发；档位可删除或覆盖重开；
  对局中 ☰ 可选择保存离开或**放弃对局**（带入卡牌全丢，仅安全格中局内获得的卡被宠物运回）

- **英雄卡**（第八批）设计者定版：每个职业只有 1 张对应英雄卡（觉醒形态，cls 绑定职业），**只能通过 ① 事件拼凑 ② 祭坛弃牌 ③ 彩色令牌 三种途径获得**（不进随机池，获取途径待后续版本实装）；衍生牌（tokenOf 指向所属英雄）围绕英雄效果展开，同样不进随机池
- **效果词条第二批**（设计者 2026-09-02 定版，详见 design.md §3.5）：
  **抽卡 N**（BOSS 战从牌库抽 N 张 · 普通战斗改为获得 N 张杀）·
  **注能(N)**（打出前需先选择 N 张手牌消耗，被耗的卡战后进消耗口袋、可在火堆复原；「注能(小)」=1）·
  **诅咒**：流血（每层攻击伤害 +1）/ 中毒（每层回合末 1 点固定伤害）/ 冰冻（1 回合无法行动）/
  沉默（1 回合技能无效，攻击除外）/ 破甲（2 回合无法减免伤害）/ 禁疗（2 回合无法回复）+
  **净化**（清除所有诅咒）· **发现**（随机 3 张选 1 置入手牌，战斗内临时卡）·
  **背包丢弃的牌无法取回**（丢弃需二次确认），**消耗的牌可在火堆复原**
  — 卡面类型行下新增「抽 / 注能」角标，制作坊可直接编辑词条（旧卡按描述自动回填）
- **祝福词条**（v0.20 设计者定版，详见 design.md §3.6）：附加效果分为**祝福与诅咒**，祝福有——
  **攻击力增加 / 法伤增加**（本场战斗可叠加）· **潜行**（无法成为被攻击对象，不造成伤害便不会破除，
  回合到自动失效）· **免疫伤害**（不受到任何伤害，含中毒）· **减伤**（每次受伤 -N，真实伤害无视）·
  **剑仙形态**（回合开始额外抽 1 张）· **自然形态**（回合开始额外 +1 能量）·
  **宇宙形态**（本局所有卡牌 1 费，手牌带 ⚡1 角标）；状态条上祝福绿标 / 诅咒红标
- **词条时点体系**（v0.23 设计者定版，详见 design.md §3.7）：卡牌描述按句切分，三种维度可组合——
  **回合开始时：X**（生效时刻：X 延迟到下个回合开始结算；装备卡与「每回合开始时」每回合重复触发）·
  **本局对战内 / 本场战斗：X**（持续时间：整场战斗有效，离开战斗失效；增益照常挂祝福）·
  **被注能时：X**（生效条件：只有作为注能牺牲品被消耗时才结算 X——牺牲品没有被「使用」，
  主效果与伤害都不触发）；**持续 1 回合 = 本回合结束前生效，持续 n 回合 = 从触发当回合起
  覆盖 n 个完整回合**（共享回合钟：所有计时状态在每回合结束统一递减；「持续 N 回合」可覆盖默认时长）
- **位置词条与墓地**（v0.24 设计者定版，详见 design.md §3.8）：
  **将 x 洗入牌库**（把指定卡/复制衍生/随机 N 张插入牌库并洗混，仅 BOSS 战有牌库）·
  **将 x 置入手牌**（创造衍生卡进手牌；发现=3 选 1、随机获得=直接拿，落点都是手牌）·
  **🪦 墓地**（BOSS 战打出过的牌进墓地、牌库抽空自动洗回；点击可查看消耗过哪些牌并按类型统计）·
  **虚化禁用**（资源/事件卡无法在对战中打出、普通战斗禁用牌库类词条卡、BOSS 战禁用道具卡，
  全部虚化显示并提示原因；BOSS 编组同步排除资源/事件卡）
- **卡牌引擎自测**：`prototypes/map-system/selftest.js`（命令行跑 combat 自测与词条解析抽查，
  用 `desktop\electron\electron.exe` 以 `ELECTRON_RUN_AS_NODE=1` 运行即可）
- 卡名按手写照片识别录入，如有出入在卡牌库里点「编辑」即可修正；每批只自动播一次，之后删改不受影响

## ★ 怎么填格子事件（两种方式）

**方式一：游戏里点格子写备注（推荐，不用碰代码）**
1. 在棋盘上**点击任意格子** → 弹出编辑框，输入文字说明（如"火人型兵×2 把守，战胜得中宝箱"）
2. 写过备注的格子右上角有**琥珀色折角**标记；数据自动保存在浏览器（刷新不丢）
3. 侧边栏「格子备注 → 📤 导出」生成 JSON（复制或下载），把它发回来，我就能按你的备注把事件写进正式数据表

**方式二：直接改数据文件**

打开 [src/mapData.js](prototypes/map-system/src/mapData.js)，找到每层的 `cells: {}`：

```js
cells: {
  3: { type: 'battle', name: '巡逻·火人型兵', enemy: { name: '火人型兵', hp: 30, atk: 6 } },
  5: { type: 'loot',   name: '中宝箱',        item: { name: '弹药包', value: 110, tier: 'B' } },
  9: { type: 'custom', name: '随机事件',      run(game) { game.log('…'); game.addItem({…}); } },
}
```

- 键 = 轨道编号 **0~27**（0=西北角，顺时针一圈；开 N 键在画面上直接看编号）
- 入口/撤离点、楼梯的位置与去向也在同一文件的 `entrances` / `stairs` 里改
- 详见 [docs/design.md](docs/design.md)
