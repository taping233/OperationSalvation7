# 2026-10-20 新卡规则

本批源定义在 `game/src/cards/cards.data.js` 的 TABLETOP13。启动时按新批次标记补种，不手改 cards-sync.json。现行卡面由 `npm run docs:compendium` 生成到[游戏全书](game-compendium.md)。

枪术池固定为：射击（tt2-shoot）、正午决战（tt3-noon-duel，用户所称正午决斗）、连射（tt3-double-shot）、连续射击（cc-rapid-fire）、狙杀（tt13-snipe）。

## 仍保守处理的边界

- 未指定稀有度的新卡按普通阶梯起点“古朴”，源头活水按法术落为候选定义。
- 混乱套牌遇职业／衍生／棱彩等非普通阶梯稀有度，或升级后不存在合法同类型候选时，保留原牌且不参与费用交换。没有额外推定这些稀有度的等级。
- 星辰副本保留原牌完整规则；自动施放不是免除注能、支付或目标限制。副本用过后进入消耗牌堆，不自动洗回，仅由卡牌效果取回。
- 受伤触发按实际生命损失判断；被护盾／护甲完全吸收不计伤害。护身计入己方随从与毒伤。

候选改动尚未合并或发布。冲突文件与验证记录见[本批证据](evidence/2026-10-20-requested-cards/README.md)。
