# 代号7：统一工业战术二次元美术母版

本规范是标题、场景、角色、卡牌与 UI 的共同验收基线。参考《明日方舟》官网和官方美术设定集公开样张中的高层设计语言，但所有角色、服装、标识、道具、构图和图像都必须原创，不得复刻官方素材。

## 1. 核心视觉句

**既有世界观中的搜索小队，以冷静、克制、模块化的工业终端记录每一次搜寻、交战与撤离。**

画面必须同时具备：明确的日系动画人物造型、可信的实用装备、冷峻建筑空间、黑白灰信息层，以及少量高辨识度安全色。不得再出现写实影视海报、穆夏装饰、彩绘玻璃、羊皮纸桌游或欧美奇幻 RPG 观感。

## 2. 全局色彩与材质

- 70% 中性基底：`#080B0E`、`#11171C`、`#20282E`、`#DCE3E6`。
- 20% 冷色信息：`#5CB9BC`、`#7BA7C7`，用于导航、扫描、可交互状态。
- 10% 安全色：`#E5B449`、`#D96755`，仅用于主操作、警告、生命危险。
- 面板材质：磨砂金属、半透明烟灰玻璃、细网格、印刷颗粒、轻微磨损；避免木纹、金色雕花、宝石高光、厚重发光描边。
- 同一屏幕最多一个强强调色；稀有度颜色只出现在窄条、角标或边缘，不铺满整张卡。

## 3. UI 语法

- 以直角/小圆角矩形、斜切角、非对称分栏、窄色条、编号和短横线组成层级。
- 标题使用粗黑体或窄体无衬线；辅助标签可用大写英文和数字编号，但不得生成不可读的伪文字位图。
- 信息密度来自网格和模块，不来自装饰花纹。按钮必须是扁平终端控件，不使用羊皮纸、木框、宝石按钮或浮雕金边。
- 图标使用简洁硬边轮廓或实心符号；全站不直接显示 emoji，也不使用 SVG 图像或内联 SVG。
- 卡框、弹窗、基地页、战斗 HUD、设置页必须共用同一组颜色、边框、阴影和斜切规则。

## 4. 角色与敌人

- 明确二次元角色比例和清晰面部：干净线稿、动画式五官、克制赛璐璐阴影，允许少量厚涂质感但不得写实摄影化。
- 服装与装备严格保留现有职业和世界观语义，只把造型语言统一为层次清楚、功能可信、轮廓鲜明的日系战术二次元设计；保持原创剪影。
- 每名角色用 2 个主色 + 1 个小面积识别色；职业差异靠轮廓、装备和姿态表达，不靠传统奇幻法袍、圣环、兽人铠甲等陈旧符号。
- 怪物和 Boss 的种族、身份、武器与能力语义全部保持不变：兽人仍是兽人、龙仍是龙、火/水/草元素仍是对应元素、三名 Boss 仍是将军/兽人首领/元素领主。只统一线稿、色彩、材质、光影与版式，不做世界观重写。
- 头像/卡面裁切优先胸像或 3/4 身，主体轮廓不得贴边，暗背景下仍能一眼识别。

## 5. 场景与主视觉

- 场景地点、事件内容和叙事设定严格沿用现有游戏数据；只在不改变语义的前提下统一为硬边结构、克制色彩和战术二次元概念美术。
- 画面采用动画概念美术：硬边结构、清晰透视、局部手绘笔触、冷青环境光与小面积琥珀应急灯。
- 构图为 UI 服务：标题图左侧或中左留负空间；事件图保留暗部信息区；战斗背景中央不得有抢夺角色轮廓的高对比物。
- 禁止画面内文字、Logo、水印、官方角色、罗德岛符号或可识别的官方界面复刻。

## 6. 分辨率与文件规则

- 标题/主视觉：至少 1600×900，16:9。
- 场景/战斗背景：至少 1536×864，16:9；允许运行时 cover 裁切。
- 角色/敌人立绘：建议 768×1024 或更高，透明背景优先；若无法稳定透明，使用统一深灰底并在卡槽内裁切。
- 卡牌小图：允许 384×512 或约 320×448；同屏缩略图下必须保持轮廓清晰。不同卡可共享同一视觉族模板，但每个当前可见语义必须有匹配图像，不能回退旧玻璃彩绘图标。
- UI 图标：统一使用 PNG/WebP 位图，至少 128×128；禁止 SVG 文件、内联 SVG 与 `data:image/svg+xml`。应用图标需由位图同步生成 `.ico`。
- 所有运行时资源必须落在 `prototypes/map-system/assets/`，不引用生成缓存目录；记录尺寸、SHA-256、用途和提示词。

### 位图分层（参考 PRTS 文件分类，内容全部原创）

- `portraits/classes/`：11 个职业半身像/立绘；同一张原创 PNG 可按 CSS 裁切为头像、小立绘和战斗立绘。
- `portraits/enemies/`：11 个普通/精英怪与 3 个 Boss 头像/立绘，保持原怪物与 Boss 语义。
- `cards/`：卡牌低分辨率插画或卡面视觉族；卡框、稀有度角标与正文层由 HTML/CSS 叠加，图片内不生成文字。
- `items/`：无框物品 PNG；如需带框版本，由统一 CSS 框层组合，不复制官方“带框/无框”资源。
- `ui/`：职业、技能、资源、状态、导航等 PNG/WebP 图标；黑/白/黄等状态变体优先由 CSS filter 或独立原创位图提供。
- `scenes/`：标题、事件与战斗环境图。

PRTS 页面显示的常见尺寸层级为大立绘约 2048²、小立绘约 1024²，并把头像、半身像、立绘、敌人、技能、道具、职业和地图分开管理。本项目沿用这种“用途分层 + 小图复用”方法，但不下载、改造或再分发 PRTS/官方图片。

## 7. 一票否决项

- 仍可见穆夏拱框、彩绘玻璃铅线、羊皮纸、木框、金币浮雕式大面积装饰。
- 主视觉是写实照片/影视概念图，人物没有明确二次元线稿与动画面部。
- 同一屏角色来自不同画风，或场景、卡面、UI 各用一套互不相关的色彩。
- 擅自改变怪物种族、职业身份、事件含义、地点设定或任何既有世界观内容。
- 任何 emoji、缺图、破图、生成伪文字、水印、官方 Logo/角色或未接入的“候选资源”。
- 任何可见 SVG 文件、内联 SVG 或 SVG data URL；生图失败必须定位并重试，不能用 SVG 降级替代。

## 8. 最终验收

1. 扫描 HTML/JS/CSS 与资产目录，所有旧美术引用均已替换或明确删除。
2. 标题、基地、地图、事件、普通战斗、Boss 战、卡牌库和设置页逐屏截图。
3. 控制台无资源 404、脚本错误；卡牌与场景在离线桌面版可加载。
4. 自测全部通过；图片尺寸、透明度（如适用）与 SHA-256 清单完整。
5. 主任务统一目检，不符合本母版的分支必须返工后再合并。
