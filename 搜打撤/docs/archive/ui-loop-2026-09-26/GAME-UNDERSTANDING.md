## 玩法核心一句话
**牌是弹药，打出去就没：搜刮、深入，活着撤离带回才算赚。**
（与同类卡牌肉鸽的本质区别＝牌库方向相反（消耗 vs 成长）＋价值结算点后移到撤离。战斗被刻意做薄：随身直出、无需掷牌、点选即指敌——这是设计决定，不是缺陷。）

## 玩家旅程骨架
T0 标题 → T1 选档 → T2 hub → T3 整备 → T4 选人（高光）→ T5 入局钩子（启程补给）→ T6 层内循环（遭遇战/物资/火堆/商店/事件）→ T7 环间门 → T6'…（L1→L2→L3→L4）→ T8 三出口（祭坛撤离/判负撤离/死亡）→ T9 结算 → T10 回基地元循环（XP/成就/照相馆/钥匙门）。
机制链 T0-T10 实测完整；**情绪链在 T8→T10 断裂**（theory-B）。

## 本游戏最独特的三件事
1. **弹药化牌库 + 撤离即银行**（同一设计决定的三张脸：打出即消散、安全格、1/3 带回）——系统级差异，一切呈现要放大它而非掩盖它
2. **环间门单向不可逆下潜**——「只向深处放行」是紧张感的引擎，目前呈现却让玩家迷路绕圈（导航零方位信号；W1 已补方向播报与定位钮回屏，W7 复测验证）
3. **跨局见闻线索网**——事件两段式「下一次探索可继续这条线索」，是局外回访的钩子，但入口深、可见性弱
