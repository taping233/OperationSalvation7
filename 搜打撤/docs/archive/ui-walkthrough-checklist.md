# UI 走查清单（条 31：安全区 / 极端宽高比 · 人工执行）

执行方式：`npm run dev` 或桌面版，用 Electron/浏览器窗口拖成下列比例逐屏核对。
检查点：**四角元素不裁切、文字不重叠、关键操作可达**。

| 开宝箱浮层 | ☐ | ☐ | ☐ | ☐ |

## 重点元素

- 右上：静音齿轮、资源 HUD chip（超宽屏是否贴边过远/竖窗是否挤压换行）
- 底部：操作提示条（`sdt-hintbar`）与掷骰按钮（竖窗是否被裁）
- 左侧：格子备注/侧栏（16:10 下是否遮住内环结点）
- 弹窗卡片：21:9 下 max-width 是否失效导致过宽
