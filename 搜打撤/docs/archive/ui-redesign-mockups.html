方案 B · 像素混搭（推荐：像素角色/图标 × 保留终端面板）

UI 骨架保持终端石墨风不动，只把「角色卡面、职业图标、敌人肖像、道具图标」换成 32/64px 像素风位图 —— 素材可从 itch.io 免费像素包或 CC0 像素包获取，也可本地生成。改造成本集中在素材替换，代码几乎不动，且与现有琥珀/青色对色完全兼容。
