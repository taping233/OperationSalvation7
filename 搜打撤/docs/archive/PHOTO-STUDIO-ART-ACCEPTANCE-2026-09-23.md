# 照相馆美术与观看流程验收

本轮不以 CSS 生效、测试数量或无横向溢出代替美术验收。此前第六步只验证了部分 1280 画面，不能作为全馆体验通过的依据。

## 验收口径

| 项目 | 必须在真实页面检查的内容 | 通过依据 |
| --- | --- | --- |
| 字体与排版 | 1920、1280、390 下的标题、分类、筛选、说明和备注；长名称与长说明 | 正文可读，标题—内容—辅助信息层级清楚；不截字、不重叠；低优先级文字不抢主图 |
| 色彩 | 展墙、选片台、大图和背签的同屏关系 | 深绿与木色作为环境，暖白承载照片，灰青表示操作状态，黄铜只用于工艺与重点；不再混用无含义的多色高光 |
| 材质 | 相纸、木框、金属转角、皮面、背签 | 每种材质有具体用途；同一照片在选片台和大图使用同一装裱；边框不挡原图，不拉伸转角 |
| 光影 | 展墙与选片台、放大弹层的亮度和阴影 | 主图最突出；光源方向一致；背景和装饰不抢眼；无持续闪光或无意义泛光 |
| 按钮和筛选 | 默认、悬停、选中、焦点、不可用、清空、空结果 | 操作优先级明确，字号和命中范围够用；状态不只依赖色差；筛选结果与选片同步 |
| 页面衔接 | 进入→筛选→选片→展开→备注→收回 | 原位置展开，整张带框照片一起运动；侧栏跟随；收回指向来源；保留筛选、滚动和选中项；快速反复开关不留下遮罩 |

## 测试方式

- 使用 `game/dev/studio-review.html` 的独立 iframe 切换 1920×1080、1280×720、390×844，不改变老板当前游戏页的视口。
- 不修改真实备注来制造验收样例；备注保存、单例和关闭生命周期由相关自动化用例补充。
- 动效检查实际浏览器连续采样的 computed transform、opacity 和 transition-duration，并检查完成后状态；静态截图不能证明动画通过。当前浏览器只读接口不提供 `getAnimations()`。
- 战斗与背包继续使用默认卡牌展示，通过默认分支回归验证隔离。
