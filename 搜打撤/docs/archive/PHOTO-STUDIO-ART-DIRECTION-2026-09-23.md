# 照相馆与炉石参考的美术差距及执行计划

> 最新决策（2026-09-23，覆盖下方历史方案中的扣件/徽章/装裱标签建议）：稀有度主要由不同边框表达；夹子全部使用统一相片夹造型，但保留稀有度金属色与棱彩渐变。取消皇冠、菱形、盾形扣件和额外装裱名称。馆名“照相馆”只用纯白字；照片名称原有等级色仍保留。高阶增加实体框厚、雕花、镶嵌，不使用全墙持续发光。老板接管验收后，代理停止浏览器操作和测试，后续改动由老板验收。

比较依据：老板提供的炉石卡牌库截图、当前 Vite 照相馆实际画面，以及 game.cardslib.js / ui.js / expedition-library.css。炉石截图大量展示金色卡，不能凭这张图断言它的每个稀有度都有不同外框；这里提炼其物件塑造和视觉层级，采用照相馆自己的装裱语言。

## 1. 核心判断

当前照相馆已经有统一色调和操作布局，但主要是“照片网格 + 控件面板”，尚未形成完整的收藏品展示体系。字色和小夹子告诉玩家类别，却没有充分改变照片作为物件的轮廓、结构、材质和工艺。普通照片与高阶藏品的待遇差异不够，收藏满足感因此偏弱。

| 维度 | 参考截图中的可见优势 | 当前差距 | 改造原则 |
| --- | --- | --- | --- |
| 清晰度 | 卡框、画幅、名称承托和数值锚点构成稳定结构；缩小仍有不同外轮廓 | 画面主体清楚，但等级主要靠彩字和顶端小夹子；看图时容易略过 | 等级至少同时由轮廓/角件、框层数、身份标记三者中的两者表达；文字颜色是补充 |
| 满足感 | 边框有可触摸的厚度，华丽部件有明确制作工艺；卡牌像可被持有的物件 | 多数相纸同形同厚；选片台所有照片套同一张金框，普通与典藏待遇接近 | 为高阶藏品保留更多雕花、台阶和专属标记；低阶仍精致，但不提前用完所有装饰 |
| 统一画风 | 木、金属、纸张都服从同一种夸张而厚实的绘制语言 | 生成的工艺框、CSS 平面控件、照片纸边来自不同制作尺度，细节密度不一致 | 以档案照相馆为母题；同一家族的纸、护角、框槽和馆印，不能照搬龙头/宝石/法力图标 |
| 字体与排版 | 名称不是浮在空白上，而是被卷轴/铭牌承托；主次与卡牌结构吻合 | 宋体已恢复，但标题、卡名、类型、编号仍缺少完整的承托关系；多种字色同时出现会争抢 | 卡名落在统一题签区域，稀有度有独立工艺标记；规则正文保持无衬线；不靠越来越大的字表现等级 |
| 色彩 | 暗木外壳、亮纸内容、局部金属高光形成可读层次 | 当前色彩总体统一，但仅改变字色不足以分级；高饱和来源插画可能盖过小标记 | 主图保持优先，稀有度限定到框槽、馆印和名称；不可整卡染色或给所有卡加霓虹 |
| 材质 | 边缘倒角、遮挡、接触影、转角连接能解释部件如何组成卡牌 | 当前皮面有纹理但常被暗化；很多细线缺少边缘体积，角花缩小后不再可读 | 先做粗尺度框槽和实体角件，再补细线；高阶不能仅叠更多 box-shadow |
| 光影 | 可见亮边和暗槽有稳定方向，卡面与外壳有空间分层 | 同类照片阴影随机差异与等级无关；大图和墙面框形差异打断物件身份 | 装裱统一左上受光、右下落影；阴影服务厚度，不通过持续发光表达价值 |
| 按钮/筛选 | 功能控件像同一套实体部件，选中状态属于界面结构 | 当前检索栏已集中，边框和字体也补齐，但整体仍偏表单式，重置/下拉/页签的工艺关系不足 | 后续用同一套压边、刻线、扣件和内嵌面统一；保留刚整理的布局与原生控件可用性 |
| 观看连续性 | 卡牌在图鉴和相关容器中仍能保持身份 | 墙上低阶/高阶仅夹子不同，选片台一律金框，大图也一律金框 | 同一装裱标识贯穿缩略图、选片台、大图；只随展示尺寸改变线宽，不临时升级/降级 |

## 2. 稀有度与身份分开设计

不能把 RARITIES 数组下标当成美术豪华程度。初始、古朴、稀有、史诗、传说可以形成收藏工艺的递进；职业是人物归属，衍生是附属来源，棱彩是特殊工艺。职业与衍生不自动比传说更豪华。

| 实际稀有度 | 装裱身份 | 灰度下可见的结构差异 | 材质与颜色辅助 | 不允许 |
| --- | --- | --- | --- | --- |
| 初始 | 初印 | 薄纸、简洁裁切边、小型圆形印记 | 暖灰纸色 | 金框、皇冠、全卡光效 |
| 古朴 | 相纸 | 双层纸边、平整压线、窄矩形夹片 | 象牙白，轻微纸纤维 | 做成粗糙低清的劣质卡 |
| 稀有 | 银边装裱 | 窄双框、三角护角、单菱形扣件 | 银，蓝字 | 仅把古朴改蓝 |
| 史诗 | 雕花装裱 | 两级凹槽、扇形雕花角、双菱形扣件 | 暗木/银件，紫字 | 仅加发光阴影 |
| 传说 | 典藏装裱 | 三层台阶、较宽边、叶冠角件、凸起典藏章 | 胡桃木/黄铜，金字 | 借用炉石龙头或所有照片都使用此框 |
| 衍生 | 附页 | 文件附签、错层纸边、连页标记 | 纸与青绿标记 | 用豪华度冒充等级提升 |
| 职业 | 人物档案 | 对称档案护角、纵向身份带、盾形馆印 | 深色护角/红印 | 虚构人物独有徽章，未经人设依据替代角色标志 |
| 棱彩 | 棱镜装裱 | 切角/多面结构、分段金属边、棱镜形扣件 | 银质、局部干涉色和彩字 | 用整条软彩虹渐变代替分面结构、持续扫光 |

图像区域不遮挡、不拉伸；所有同排照片保持相同网格占位。边框厚度的差异从原有纸边空间分配，不能把低阶照片缩小来抬高高阶价值。选中态用统一外缘定位线，与稀有度装饰分开。

- 子代理 studio_mount_assets_luna：制作 5 张独立 SVG 工艺框（相纸、稀有、史诗、传说、棱彩）；viewBox 320×320，48px 九宫格切片，中央透明，角件不随边长拉伸；只写约定资产。
- Friday：负责 CSS 分级尺度、初始/衍生/职业身份变体、移除本轮已被替代的统一夹子/框覆盖、接入三种尺寸表面，以及实际浏览器检查。
- 禁止改战斗/背包默认 cardHTML、卡牌数值、稀有度语义、排序、存档/撤离模块。大图底部文字继续隐藏；点击照片外收回；备注/词条正常操作；保持懒加载、分批和滚动根节点。

### P1：馆内控件与题签同一家族

- 名称题签、索引框、选片台铭牌采用同源边缘处理和字体层级，统一普通/悬停/选中/按下。
- 减少检索栏大片高亮面对白色相纸的竞争；保留字段完整性、字号、触控范围和现有布局。
- 以 1920 / 1280 / 390 的实际画面决定密度，不能再凭 CSS 已写就认定完成。
- P0 通过后再派实现任务，避免多个代理同时堆叠同一份 CSS。

### P2：光照与观看节奏

- 校正相纸、角件、画框和背签的主光方向与接触阴影；高阶的亮边有更清楚的材质变化，不提高整页亮度。
- 展开/收回保持同一个物件与同一套装裱，信息侧栏晚于照片出现；避免各级都用同一种夸张闪光。
- 定向复核连续滚动、组合筛选、选片、开关、来源不可见、缩放/窄屏，记录未覆盖部分。

### P3：来源插画的专题校准（不在本轮重绘）

- 独立列出主体大小不一致、低清缩略图、脸部被裁、背景过空/过繁、明暗/笔触不同等来源问题。
- 只在具体图片被选定后修图；UI 边框不能掩盖插画本身的差异。本轮不批量重绘、不改人设。

## 4. 验收门槛

1. 缩略图实际尺寸下，古朴/稀有/史诗/传说有至少两项可见的非色彩区别；必须查看去色对照，不能只在大图里看得出。
2. 不看字色也能区分职业档案、衍生附页与收藏等级；棱彩有独立分面轮廓。
3. 同一照片在墙、选片台、大图使用相同装裱身份；三者之间不突然换成通用金框。
4. 主体区域、名称和类型可读；角件不遮脸、框不压字；三种屏幕尺寸无新增横向溢出。
5. 选中标记不覆盖/冒充稀有度标记；普通照片有完整工艺，不被故意做糊做脏。
6. 不引入全墙常驻动画、滤镜或全量原图解码；保持分批渲染。去色仅在开发验收页开启。
7. 修改完成后集中运行相关映射/照片生命周期/图库启动检查，再做实际浏览；不把测试数量或代理自评当作美术满意度。
