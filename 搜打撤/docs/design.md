# 设计入口

代号7的核心体验是：玩家在风险不断升高的三环地图中搜集资源、管理有限背包，通过卡牌战斗决定继续深入还是携带战利品撤离。

## 当前设计原则

- 越靠近中央，奖励和战斗风险越高，并提供更昂贵但更灵活的撤离机会。
- 背包、安全格和消耗口袋共同制造“带走什么、牺牲什么”的选择。
- 普通战斗强调随身资源消耗，BOSS 战强调编组和牌库循环。
- 卡牌自然语言必须能映射到明确的伤害类型、目标、时点、持续时间与位置变化。
- 表现层可以演进，但玩法数值、存档和领域逻辑必须通过稳定接口隔离。
