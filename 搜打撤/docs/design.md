# 设计文档 v0.4 —— 从桌游到电子游戏

## 1. 核心玩法（桌游原版规则，已确认）

**飞行棋式掷骰 + 卡牌战斗**的搜打撤：

1. **棋盘**：8×8 一张图，**三个同心环 + 中央祭坛区**：
   - 第一环（外圈）28 格，四角为出生入口
   - 第二环（中圈）20 格
   - 第三环（内圈）12 格
   - 中央 2×2：祭坛 + 三只 BOSS（将军 550 / 元素领主 400 / 兽人首领 320）
2. **进入**：开局从外圈四角入口之一进入。
3. **移动**：掷骰子（1d6），沿**当前环**顺时针移动；落脚才触发格子事件。
4. **环间门（双向）**：内外环可自由往返；**当前所在环的字体加粗发光，
   其他环的字体虚化**，提醒玩家当前在哪一层。
   - 外圈 1/8/15/22 号格 ⇄ 第二环（这四格同时是撤离出口）
   - 第二环 (3,6)/(1,3) ⇄ 第三环（这两格同时是商店）
   - 第三环 (3,2)/(2,3) → 祭坛（(3,2) 自带 +4 币，(2,3) 是商店）
5. **撤离**（搜打撤的"撤"）：
   - 外圈四个门格：免费撤离（趁还在外圈，走或留自己权衡）
   - 内庭 (2,4) 紧急撤离点：花 10 币立即撤离（深入后的唯一退路）
6. **经济**：币（货币）/ 木材·口粮·钥匙（资源物品）/ 宝箱与事件（战利品）。
   商店可花币购物资。

### 1.1 三环风险梯度与事件节奏（v0.25）

三环仍是固定棋盘与掷骰移动的身份核心，但每环承担不同的决策职责：第一环为低风险整备（补给、火堆和少量试探战）；第二环为中风险分岔（战斗、钥匙、商店交错，进入下一环意味着放弃部分安全路线）；第三环为高风险冲刺（元素多敌人、25% 精英预警、紧急撤离与祭坛入口）。战斗格在开战前展示环层风险和敌人策略摘要，玩家可以用已发现的门或撤离点调整路线。

事件格优先提供二选一或三选一：`金矿` 为稳定 3 币或损失 3 血换 6 币；`空中补给` 在木材、口粮、回复 3 血中三选一；`宝箱` 在小宝箱（低风险）与中宝箱（三选一高回报）中二选一。选择只调用已有资源、治疗和宝箱结算，其他事件卡保持旧的单按钮效果，旧存档和自定义事件卡不受影响。

## 2. 数字化框架（v0.3 已实现）

### 1.2 场景与战斗表现契约（v0.26）

所有落点先进入独立场景容器，再进入节点/战斗逻辑。容器保留 `data-scene-id` 与 `data-asset-key`，并使用 `scene-*` class，供绘画层和 CSS 接入。标准节点 sceneId 为 `battle/shop/fire/chest/door/altar/extract`，普通拾取为 `pickup-coin/wood/rations/key`；10 张事件卡分别为 `event-timeskip`、`event-demondeal`、`event-bandits`、`event-mystery`、`event-goldmine`、`event-goldhammer`、`event-relief`、`event-airdrop`、`event-chestdraw`、`event-systemsupply`，assetKey 与 sceneId 同名。事件 DOM 可承载 `.scene-glow`、`.scene-foes`/`.scene-art`、`.scene-title`、`.scene-line`、`.evt-choices`、`.scene-gain` 与 `data-act="sceneGo"`。

战斗保留 `.bt-foes`、`.bt-hand`、能量/抽牌堆/弃牌堆/墓地和 Pointer Events 拖牌入口；`.bt-intent[data-intent]` 显示下一回合意图。普通敌人、龙精英和三名 BOSS 分别使用 `strike/dragon/general|orc_boss|element_boss` 预告模式，结算仍走现有状态引擎。11 个职业（刺客、剑客、术士、法师、牧师、授印者、降临者、召唤师、守卫、游侠、战士）沿用 `.scene-art`/`.bt-self` 立绘挂点；全部 10 种普通敌人与 3 个 Boss 通过 `data-foe-id`（由渲染层消费）保持稳定身份。

```

  └─ 节点弹窗：环间门（撤离/进入下一环/逛商店/留下）

              紧急撤离（花币/留下）· 商店
```
- 踩过的门/祭坛入口记入侧边栏，可快捷"前往"（仍受单向限制）。
- 空格/回车掷骰；拖拽平移、滚轮缩放；G 网格线、N 格子编号；点格子写备注。

### 2.5 商店出售卡牌（设计者 2026-09-01 定版）
- **所有卡牌默认不可出售**；只有描述带「可出售」特殊备注的卡
  （桌游卡：铜币 / 银币 / 金币 / 钻石 / 石榴石弹珠）或制作坊勾选「可出售」的卡
  才能卖给商店

  其次看描述——「不可出售」优先于「可出售」（如经济卡包）
- 收购价 = 卡面币值 ◉（`SDT.Cards.sellPrice`）；无币值的可出售卡按稀有度半价（至少 1 币）
- 商店界面在购买栏下方新增「出售卡牌」区：列出持有的可出售卡牌，
  点「出售」按钮换成币并入存档

## 3. M1 战斗规则：四类伤害体系（v2 定版，设计者 2026-09-01 两批确认）

所有卡牌能够造成的伤害分为 **4 种类型**，由卡面**分类词条**区分：

| 类型 | 卡面记号 | 数值来源 | 受伤害加成 | 受防御手段 | 流血互动 |
|---|---|---|---|---|---|
| **攻击伤害** | **攻（+n）** | n + 人物攻击力 | ✅ 攻击力 / 攻⁺ | ✅ 护甲/护盾等 | **可附加流血**；目标每 1 层流血，每次受攻击伤害 **+1** |
| **法术伤害** | `n'` | n + 法伤加成 | ✅ 法伤加成 | ✅ 护甲/护盾等 | 否 |
| **固定伤害** | 纯数字 n（无「攻」无角标） | 卡面值 | ❌ 一律不加成 | ✅ 护甲/护盾等 | 否 |
| **真实伤害** | `n''` | 卡面值 | ❌ 一律不加成 | ❌ **无视一切防御手段** | 否 |

- **写成攻（+n）的才是攻击伤害**；纯数字一律是固定伤害
  （设计者定版：「射击」的 2 点是**固定伤害**，不是攻击伤害）。
- **流血**：叠层状态。**不会自动掉血**（不按回合结算），**层数无上限、不衰减**；
  只与攻击伤害互动——目标每有 1 层流血，**每次**受到攻击伤害时该次伤害 +1 点
  （多段攻击如「连射」按每次攻击分别结算）。
- **防御手段**：护甲、护盾、**格挡（「本回合所受伤害降为 1」）**、结界等；
  只有真实伤害全部无视——**格挡对真实伤害无效**。
  吸收顺序约定：**护盾 → 护甲 → 生命**；格挡在吸收前把非真实伤害降为 1。
- **记号约定**：卡面文字中 `n'` = n 点法术伤害，`n''` = n 点真实伤害，
  攻（+n）= 攻击伤害，纯数字 = 固定伤害。

### 3.1 实现约定（`src/combat.js` + 卡牌库词条）
- 攻击伤害结算 = 卡面攻击值 n（攻（+n））+ 当前攻击力(`atk`) + 目标流血层数 × 1
- 法术伤害结算 = 卡面法术值 n（n'）+ 法伤加成(`spellPower`)
- 固定 / 真实伤害 = 卡面值，不吃任何加成
- 格挡 = `defense.guard`，非真实伤害每次结算降为 1；真实伤害无视
- 属性挂载（玩家与敌人通用）：攻击力 `atk`、法伤加成 `spellPower`、
  流血 `status.bleed`、防御 `defense.shield / armor / guard`
- **卡牌库词条**：卡牌数据新增 `dmgType` 字段（attack/spell/fixed/true），
  制作坊可选伤害类型，卡面伤害宝石按类型显示（⚔+n / ✨n' / ◈n / ⚡n''）；
  旧卡由 `ensureDmgTypes()` 按描述与类型自动回填（只补缺失，不覆盖玩家标注）
- 开发者工具「⚔ 伤害自测」：内置用例覆盖上述全部规则

### 3.2 定版记录（2026-09-01 第二批，此前开放问题已全部裁定）
- 流血不自动掉血，层数无上限、不衰减。✅
- 「射击」= 2 点固定伤害；纯数字 = 固定，攻（+n）= 攻击。✅
- 格挡对真实伤害无效。✅

### 3.3 两类战斗（v0.17，`src/battle.js`；每回合固定 2 费）

**指向目标规则（v0.22 设计者定版：使用卡牌必须拖动到目标上）**：

- **伤害 / 诅咒类卡（🎯）**：必须**拖到某个敌人身上**松手才打出（点击敌人只提示、不结算）；
  拖拽悬停时保留伤害预览（v0.21）。群体伤害（描述含「所有敌人/群体/全体」）直接点击生效。
- **治疗 / 净化 / 护甲 / 护盾 / 格挡类卡（💚）**：必须**拖到战斗界面左侧「你」的玩家立绘上**
  才能打出。战斗界面新增玩家立绘卡（职业立绘 + 血条 + 攻/盾/甲），即自身目标的拖放区。
- 其余无指向效果（抽牌 / 发现 / 能量…）直接点击打出。
- 点卡只进入「锁定提示条」（说明该卡应拖到哪个目标），点目标只给纠正提示——
  保证玩家始终明确「这张卡打在谁身上」。

**普通战斗（小怪/遭遇战）——无需抽牌：**
- 随身全部可用卡（含道具卡）直接作为手牌打出，打出的卡本场不可再用
- 每回合固定 2 费（`rules.battleEnergy`）
- 「抽 N 张牌」效果改为**获得 N 张杀**（初始牌「杀」的临时复制：
  1 费 · 攻（+0）随攻击力结算 · 只存在于本场，战后消散、不进背包）
- 战后：打出过的卡进消耗口袋，没打出的完好保留

**BOSS 战——编组牌库：**
- 开战前从背包选 **15 张非道具卡牌**（`rules.bossDeckSize`；杀与道具卡不可选），
  与 **5 张杀**（`rules.starterSha`）组成牌库；
  杀不足 5 张或非道具卡不足 15 张时，有多少带多少（不硬性卡门）
- 开局抽 **5** 张（`rules.battleStartDraw`），每回合开始抽 **1** 张（`rules.battleTurnDraw`），
  手牌上限 8（`rules.battleHandMax`）；每回合固定 2 费
- 牌库抽空时弃牌堆自动洗回；「抽 N 张牌」正常从牌库抽
- 战后卡牌全部完好保留；编组会被记住，连续挑战 BOSS 时自动预选上次的 15 张

**两类通用：**
- 敌人意图固定为 ⚔ 攻击（卡面攻值），界面有意图提示
- 词条引擎（首批）：四类伤害 / 附加流血 / 回复生命 / 护甲 / 护盾 /
  格挡（在敌人下一次行动中生效）/ 抽 N 张牌（按上面两类规则生效）/
  获得 N 点能量 / 能量上限 +N（本场每回合固定费用提升）；其余词条仍为占位（M1 后续补全）

### 3.4 战斗胜利宝箱掉落（v0.18，设计者 2026-09-02 定版；`src/chests.js`）
战胜怪物 **100% 掉落宝箱**，掉哪几种由**所在环层**决定（`MAP.layerChests`，
多组组合时等概率随机一组）：

| 环层 | 掉落 |
|---|---|
| 外层（第一环） | 小宝箱 1-2 个 |
| 中层（第二环） | 中宝箱 ×2 **或** 大宝箱 ×1 |
| 内层（第三环） | 大宝箱+小宝箱 **或** 大宝箱+中宝箱 |
| BOSS（祭坛） | BOSS宝箱 ×1 |

宝箱规格（`MAP.chestKinds`，每个宝箱都含币）：

| 宝箱 | 卡牌 | 内含币 |
|---|---|---|
| 小宝箱 📦 | 1 张随机卡 | 1-2 币 |
| 中宝箱 🎁 | 随机 3 张**选 1 张** | 2-3 币 |
| 大宝箱 🧰 | 3 张随机卡 | 3-4 币 |
| BOSS宝箱 👑 | 5 张随机卡 + 金币/银币/铜币卡其一 + 30% 概率金色令牌 | —（币即币卡） |

- 随机卡池与商店随机槽同源：排除衍生卡与**传说特例卡**（`unrandom`，
  `SDT.Cards.isRandomObtainable`），稀有度按 `SHOP_WEIGHTS` 加权；同一宝箱内尽量不重复
- 开箱为逐个弹窗结算：中宝箱点卡三选一，其余「全部收下」；
  全部开完后才继续战后流程（BOSS 战回祭坛 / 普通战回待机），发卡走背包容量判定（同名可并入）
- 事件奖励同步接入：**盗匪横行**战胜奖励改为开 2 个真中宝箱；
  **宝箱格**（如外圈 17 号）改为开 1 个真小宝箱；事件卡**宝箱**（tt6-chestdraw）
  从小/中宝箱中抽 1 个开

### 3.5 效果词条第二批：抽卡 / 注能 / 诅咒 / 发现 / 净化（v0.19，设计者 2026-09-02 定版）

**抽卡 draw N**（卡面结构化词条，`cards.js`；描述「抽 N 张牌」会自动回填，制作坊可改）：
- 对战 **BOSS**：从牌库抽 N 张（照常进牌库循环）
- 对战 **普通敌人**：改为**获得 N 张杀**（临时复制，战后消散、不进背包）

**注能 infuse N**（描述「注能(N)」自动回填，「注能(小)」按 1 计；制作坊可改）：
- 打出这张卡时需先**选择 N 张手牌消耗**才能发动（手牌不足时无法发动）
- 被消耗的牌移出本场战斗、战后进**消耗口袋**——BOSS 战也不例外（可在火堆/基地复原）

**诅咒状态**（引擎 `src/combat.js`，双方通用；状态在战斗界面上有角标）：

| 诅咒 | 效果 | 计时 |
|---|---|---|
| 🩸 流血（叠层） | 每层使目标受到**攻击伤害**时伤害 +1 | 层数无上限、不衰减、不自动掉血 |
| ☠️ 中毒（叠层） | 每层在**目标回合结束时**受到 1 点固定伤害 | 层数不衰减 |
| ❄️ 冰冻 | 目标 1 回合**无法行动**（轮到时跳过反击） | 共享回合钟递减 |
| 🤐 沉默 | 目标 1 回合**技能无法生效**（主动与被动，**攻击除外**） | 同上 |
| 🔨 破甲 | 目标 2 回合内**无法减免伤害**（格挡/护盾/护甲全部失效） | 同上 |
| 🚑 禁疗 | 目标 2 回合内**无法回复生命** | 同上 |

- **净化**：清除身上**所有**诅咒类型与效果（净化箭、圣水等描述带「净化」的卡）
- **共享回合钟**（v0.23 精确化）：所有计时状态在**每回合结束**（双方各行动一次）统一递减 1。
  **持续 1 回合 = 本回合结束前生效；持续 n 回合 = 从触发的当回合起覆盖 n 个完整回合**
  （破甲=2 → 从挂上的当回合起，覆盖 2 个完整回合；描述写「持续 N 回合」可覆盖默认时长）
- 描述结算自动识别：附加流血/中毒/冰冻/沉默/破甲/禁疗（「免疫冰冻」「对冰冻角色」
  这类被动描述不会误挂诅咒）

**发现**：从 **3 张随机卡牌**中选择 1 张**置入手牌**（卡池与商店随机槽同源：
排除衍生卡与传说特例卡；「发现 1 张传说卡」只在传说里三选一）。
发现的卡是战斗内临时卡，战后消散、不进背包。

**随机获得**：「获得/随机获取 N 张随机卡牌」直接把 N 张随机卡置入手牌（同样战斗内临时）。

**卡牌取舍规则（设计者 2026-09-02 定版）**：
- 从背包**丢弃**的牌**无法取回**（背包卡牌格新增 🗑 丢弃按钮，需二次确认；安全格不受影响）
- **消耗**的牌（消耗口袋）可以在**火堆**复原（火堆每次可复原 2 张；基地免费复原不变）

### 3.6 附加效果分类：祝福（v0.20，设计者 2026-09-02 定版）

附加效果分为**祝福**与**诅咒**两类：诅咒见 §3.5，祝福如下（引擎 `src/combat.js`
BUFFS/BUFF_META；状态条上以绿色角标显示，诅咒为红色角标）：

| 祝福 | 效果 | 计时 |
|---|---|---|
| ⚔️ 攻击力增加 | 攻击伤害 +N（可叠加） | 本场战斗 |
| 🔮 法伤增加 | 法术伤害 +N（可叠加） | 本场战斗 |
| 👻 潜行 | **无法成为被攻击对象**；**不造成伤害便不会破除**潜行，造成伤害立即破除 | 一般标回合持续时间，回合到自动失效 |
| 🌟 免疫伤害 | 不受到任何伤害（攻击/法术/固定/真实/中毒全部无效，中毒层数保留） | 共享回合钟递减 |
| 🪨 减伤 | 每次受到的伤害 -N（真实伤害无视，同格挡/护盾） | 本场战斗 |
| 🗡️ 剑仙形态 | 回合开始时额外抽 1 张（普通战斗照旧改为获得 1 张杀） | 本局对战 |
| 🌿 自然形态 | 回合开始时额外获得 1 点能量 | 本局对战 |
| 🌌 宇宙形态 | 本局对战内，**所有卡牌变为 1 费**（手牌上有 ⚡1 费用角标） | 本局对战 |

- 净化同时归入祝福类动作：清除自己所有诅咒（§3.5）
- 潜行细则：潜行中对手的伤害卡无法命中（多敌人战里拖拽预览会提示「潜行中——伤害无法命中」）；
  附加诅咒、挂增益等非伤害效果不受潜行影响；**任何一方**造成伤害都会破除自己身上的潜行
- 祝福由卡牌描述结算：「潜行/潜行状态 N 回合」「攻击 +N / +N 攻 / 获得 N 点攻击力」
  「法伤 +N / 法术伤害 +N」「免疫伤害 / 无敌（N 回合内）」「减伤 N」「剑仙形态 / 每回合额外抽 N 张」
  「自然形态」「宇宙形态」；「诅咒状态下，攻 +2…」这类条件词条不会被误挂
- 沉默封印的是技能效果：祝福/诅咒/治疗/抽牌等在沉默中全部无效，只有攻击伤害照常结算

### 3.7 词条时点体系：生效时刻 / 持续时间 / 生效条件（v0.23，设计者 2026-09-02 定版）

卡牌描述按句切分（。；；换行），每句按**前缀关键词**归入一种生效方式——
三个维度彼此独立，可组合使用（例如「本局对战内，每回合开始时…」）：

| 维度 | 关键词 | 语义 |
|---|---|---|
| **生效时刻** | 「回合开始时：X」「下回合开始(时)：X」 | X 不立即触发，延迟到**下个回合开始**时结算；装备卡是战斗内持续物件，其延迟段**每回合开始重复触发**；「每回合开始时」同理 |
| **持续时间** | 「本局对战内 / 本场战斗(中)：X」 | X 在使用后的**整场战斗内永久有效**，离开战斗失效（增益照常挂祝福；「所有法术均为 1 费」= 银河之旅持续规则） |
| **生效条件** | 「被注能时：X」 | 只有这张卡**作为注能牺牲品被消耗**时才结算 X——牺牲品没有被「使用」，主效果与伤害都不触发；未来会有更多条件词 |

- 生效时刻的实现：`battle.js` 的 `delayed` 队列，出牌时注册、每回合开始（`processDelayed`）
  结算并移除非重复段；沉默中不结算（一次性段被吞掉，重复段保留）
- 注能规则重申（设计者定版）：对战普通敌人时**使用**卡牌会将卡牌消耗（进消耗口袋），
  而注能会**额外**消耗卡牌——注能消耗的卡牌并没有被使用，所以没有使用效果，
  只结算「被注能时」的条件效果（被牺牲的卡战后同样进消耗口袋，可在火堆复原）
- 计时规则（共享回合钟，见 §3.5）：持续 1 回合 = 本回合结束前生效；持续 n 回合 =
  从触发的当回合起到第 n 回合结束前都生效；诅咒/祝福默认时长
  （冰冻/沉默 1，破甲/禁疗 2，潜行/免疫由描述给出）可被「持续 N 回合」覆盖
- 「下回合无法抽牌」（破浪斩）也是延迟生效的持续标记：在下个回合开始时消耗掉，
  当回合的常规抽牌被跳过

### 3.8 位置词条与墓地（v0.24，设计者 2026-09-02 定版）

**位置词条**——描述"获取到的卡放进哪"（可与其余效果词条组合）：

| 词条 | 语义 | 实装 |
|---|---|---|
| **将 x 洗入牌库** | 把卡牌 x 插入自己**准备的牌库**中，并把牌库顺序**洗混**；x 可以是指定卡（含「流光斩复制」这类复制衍生，自动剥「复制」找本体）也可以是「洗入 N 张随机卡牌」 | 仅对战 BOSS（有牌库概念）；洗入的牌是战斗内临时卡，战后随战斗消散 |
| **将 x 置入手牌** | 创造衍生卡 x 放进手牌（战斗内临时卡，战后消散） | 两类战斗均可 |
| **发现** | 随机 3 张**选 1** → **置入手牌** | §3.5 |
| **随机获得** | 随机 N 张**直接拿** → **置入手牌** | §3.5 |

- 发现 / 随机获得本质上是"拿哪张"的区别，**落点都是手牌**——与「将 x 置入手牌」共用同一落点

**墓地（BOSS 战专属）**：
- 打出过的牌进入**墓地**（即原弃牌堆），牌库抽空时墓地自动洗回牌库循环
- 战斗中点击「🪦 墓地」可查看**自己消耗过哪些牌**（按卡牌聚合计数），并**统计各卡牌类型数量**
  （武术/法术/装备……）；注能消耗的牌不进墓地（战后进消耗口袋，可在火堆复原）
- **对战普通敌人时没有牌库与墓地概念**——墓地按钮不出现，牌库类词条无法使用

**虚化禁用（无法使用的卡）**：手牌中不可打出的卡**虚化显示、无法触发**，悬浮提示原因，
点击时日志提示「无法打出」：
- **资源卡**：任何战斗都无法打出（资源在背包中使用或出售）——BOSS 编组也不再可选
- **事件卡**：只能在棋盘事件格触发——BOSS 编组也不再可选
- **牌库类词条卡**（描述含洗入/置入牌库/放入牌库/牌库底/牌库上限）：普通战斗中禁用
  （没有牌库），对战 BOSS 正常可用
- **道具卡**：BOSS 战中禁用（发现的道具也如此），只能在普通战斗中使用

## 4. 基地系统（v0.15 定版，设计者 2026-09-01；`src/base.js` + 基地页面）

局外营盘（**v0.21 起按存档档位隔离**：每个档位独立的木材/口粮/仓库/口袋/熟练度/成就/卡背，
localStorage `sdt-base-v2-slot{1..3}`；旧全局键 `sdt-base-v1` 启动时自动迁入已有对局存档的档位）：

1. **背包扩建**：初始 16 格，每消耗 **木材 ×2** 扩建 1 格，**上限 30 格**。
2. **宠物安全格**：初始 2 格，每消耗 **口粮 ×2** 升级 1 格，**上限 6 格**。
   宠物「阿七」看守安全格；**撤离失败（死亡）时安全格里的卡牌安全运回基地**，其余全丢。
3. **初始牌「杀」**：每局开始固定携带 **5 张**（1 费 · 攻（+0）＝造成等同于攻击力的伤害，
   走 combat.js 攻击伤害结算，吃攻击力与流血加成）；同名堆叠**只占 1 格背包**。
4. **背包三区**（`showBackpack`）：
   - **物资+卡牌格**：混占容量格；同名物资/同名卡牌各堆叠 1 格（买卡/拾取按容量拒绝）
   - **安全格**：独立容量（2→6），卡牌整堆存入/取出，死亡时保护
   - **消耗口袋**：**容量无限**；对小怪（非 BOSS）使用过的卡牌存放于此，
     **未复原不能继续使用**。复原途径：基地免费复原 / 道具卡「能源水晶」就地复原 3 张
5. **战斗消耗规则**（专门战斗系统 `src/battle.js` v0.16）：
   - 小怪战（非 BOSS）：**打出过的卡**战后进入消耗口袋
     （手牌/牌库/弃牌堆里未打出的完好保留）
   - BOSS 战：卡牌全部完好保留（可撤退，撤退同样不消耗）
6. **运回结算**：
   - 撤离成功：背包木材/口粮 → 基地仓库；卡牌 → 卡牌仓库；口袋卡 → 基地口袋（仍待复原）
   - 撤离失败：仅安全格卡牌运回基地
   - 开新局：固定发放 5 张「杀」+ 卡牌仓库自动带入背包（需占新格时容量不够的留在基地）
7. 基地初始附赠 木材×4 / 口粮×2，首局结束即可体验一次升级。

### 4.1 存档档位与对局循环（v0.21，设计者 2026-09-02 定版）

**档位模型**：三个档位互相完全独立——每档保存「基地（`sdt-base-v2-slotN`）+
进行中的对局（`sdt-save-v2-slotN`）」。选档界面同时展示两行信息。

- **进入流程**：标题「开始游戏」→ 选择存档 →
  - 该档**有未完成对局** → 直接续打那一局（含未做完的职业补选）；
  - **没有对局** → 先进基地，从基地「出发」页选玩法开局。
  - 主菜单「🏠 基地」走同一选档器（`base` 模式）：该档有对局进行中时不开放，避免误覆盖。
- **runActive 门控**：只有真正出发后（newRun/loadGame）才写对局存档；
  在基地/标题界面不会产生空对局档（修复旧版在基地退出会留下空白对局的隐患）。
- **放弃对局**（对局中 ☰ → 「放弃对局」，两步确认）：
  - **带入本局的卡牌全部丢失**（开局 5 张杀 / 仓库自动带入 / 开局职业卡，标记 `brought`，
    即使已放入安全格也不保护）；
  - 对局中**获得**的卡牌：只有存入**宠物安全格**的会被运回基地仓库，其余全部失去；
  - 物资、金币、消耗口袋全部散失；职业熟练度与成就进度照常保留。
  - 对照：**死亡**时安全格里的卡牌（无论带入还是获得）都会被宠物运回。
- **背包拖拽整理**：卡牌堆可**按住拖动**重新排序（拖到某堆上=插到它前面；
  拖到空格/物资格=移到卡牌区末尾；拖入/拖出安全格=整堆存取）。
  顺序存于对局档 `cardOrder`，随存档持久化。拖拽浮影是真实卡面并带速度感应的
  3D 倾转（`perspective` + `rotateX/rotateY`）；悬停卡牌格也会随指针轻微倾斜。
- **卡背系统**（`Cards.CARD_BACKS` + 基地成就页「卡背图鉴」）：
  - 共 7 款：默认「行囊粗布」恒解锁；**猎手皮纸/弑神黑曜/祭坛星轨/富商锦缎/仓廪木纹/忠犬爪印**
    分别由对应成就的**领取奖励**解锁（成就定义带 `back` 字段，随该档基地保存）；
  - 基地成就页点击即可装备（`Base.setBack`），牌库/弃牌堆缩略图与背包翻面即刻生效；
  - 背包里**双击卡牌**可 3D 翻面查看当前卡背；升级老存档时已领取的带卡背成就自动补发（`syncBackUnlocks`）。
