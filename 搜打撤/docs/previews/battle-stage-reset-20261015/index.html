BATTLE / DESIGN DIRECTION

把战场还给角色

先看敌人准备做什么，再看手上能做什么。角色、敌方意图、生命和手牌形成一条阅读路径。

01 / 舞台

宽阔视野、同一站脚线。后景、地板、前景分别绘制和挂载，前景只出现在边缘。

02 / 决策

职业技能独立突出；手牌放大并横向叠放，常态下沉时露出费用和标题，悬停或键盘聚焦时展开整卡。

03 / 反馈

现有 Pixi 序列帧原样调用；卡框、插画、费用、名称与规则直接来自共用卡牌渲染接口。

这是独立设计稿，不连接存档或正式战斗规则。卡面调用cardHTML、正式插画映射与共用样式，预览只控制手牌位置和交互。旧战斗样式清退清单见任务说明，正式替换待老板确认。
