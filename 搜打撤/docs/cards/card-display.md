# 卡牌显示

仓库、战斗手牌、发现选择、背包、商店、悬停预览与卡牌放大使用共用的蔷薇全包边框，购买和出牌飞行中的卡牌沿用同一外观。边框从全幅画面外侧扩出，以完整框体、倒角、内槽和侧面表达厚度；费用在左上，稀有度宝石与文字在右上，卡名与效果说明位于下部。五档正式卡面采用第九稿厚涂素材，稀有仅顶部中央一朵花，史诗保留顶部中央与右上两朵花。

稀有度沿用 `SDT.Cards.rarityOf` 的现行判定，由渲染模板的 `rv*` 标记选择框体。古朴灰钢素框，稀有蓝色花苞包边，史诗紫色双层花叶，传说金色蔷薇雕框，棱彩使用幻彩花冕与晶体镶嵌。五档外扩尺寸按各透明素材的画窗边界计算，映射见 `game/css/card-frames/rose/frames.css`，源像素边界见 `game/css/card-frames/rose-painterly-1012/geometry.json`。初始、职业以及未继承其他等级的衍生使用对应标签色的基础框，不另设高阶。能力卡及其衍生仍显示为棱彩。

框体图层位于原画和阅读渐变上方、费用与文字下方，不接收输入。普通框保留完整护角，高阶框逐档加入花叶纹章、双框、花冠与切面镶件。卡面内部的原画布局继续使用272/406比例；宿主容器为外扩框体留出空间，卡牌放大复用相同无损WebP素材。

字号和费用徽章随卡片宽度缩放。名称、说明与效果提示在下部连续排布，说明不按行数截断。额外的攻击、伤害类型和币值角标不显示；抽牌、注能、回复和护甲等效果提示继续显示。五档边框使用静态透明无损WebP，初始、职业和普通衍生保留基础SVG；原银墨饰纹、薄边流光和金光变体已从正式样式移除。

卡面数字与术语沿用正文同字号，数字加粗，带讲解的术语以直立字重强调。独立全文规则栏使用共用的24设计像素字号和1.55行距，支持文字选择；卡内正文仍随卡宽缩放。短规则在大卡中阅读，长规则由独立全文栏承接。展示文案从现行ID与原文映射取得，对原文分词后逐段转义，保留自定义文字的字面内容，不改变卡牌规则或存储。

战斗手牌常态下沉，只露出费用、名称和部分卡面；悬停或键盘聚焦时单张上浮并轻微放大，移开回落。短、中长度规则在悬停时完整呈现，密集规则可由“完整规则”入口查看全文；这是手牌收纳交互，不改变其他页面的完整卡面排版。

持有数量继续放在卡外的名称栏，避免遮住右上品质标签。照片展示与照片大图使用照相馆自己的装裱规则，不属于卡牌包框。

金蝉脱壳的横幅插画按卡面内部宽度的 130% 居中、靠上显示，下部以深色底承接文字，以保留人物和草替身；其他卡牌继续使用各自的现行裁切方式。

样式入口是 `game/css/card-layout-selected.css`，由 `game/index.html` 在其他卡面及页面样式后加载。现行卡牌模板、缓存、实际费用修正与交互命令仍由 `game/src/cards/cards.view.js` 及各调用方维护；样式不改变卡牌字段或出牌规则。费用变化保留降费绿、升费红的语义色。

厚涂蔷薇框体位于 `game/css/card-frames/rose-painterly-1012/`，`game/css/card-frames/rose/frames.css` 维护有效稀有度到素材及外扩尺寸的映射，并由共用样式导入。旧版银墨素材保留作历史来源，正式卡面不再引用。各页面继续维护卡牌尺寸、排布和交互。

厚涂素材与实装验证见[厚涂蔷薇边框记录](../evidence/2026-10-12-rose-painterly/README.md)。
