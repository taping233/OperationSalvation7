# 卡牌显示

所有游戏卡面统一由 `SDT.Cards.cardHTML(card, size, options)` 输出。仓库、收藏、人物卡池、出征整备、背包、商店、奖励、战斗手牌、悬停预览、放大详情和飞行克隆复用同一接口与布局；宿主只维护卡宽、排列、选中状态和交互。兼容商店的卡牌商品也使用该接口，基地物资图标继续按物资语义展示。

卡牌正文、搜索与提示使用`displayCardDescription(原始说明,id,当前卡快照)`；富文本使用`descRich`或说明renderer的`render`接收原始说明。已经生成并裁剪的说明使用`renderResolved`，沿同一链接、高亮和缓存流程排版，数值只解析一次。装备提示保留实例uid及战斗快照，药水栏从有效库存条目的card读取规则，预览直接使用本次已生成说明。交易中的木材/口粮继续使用基地物资提示。

简单句式从执行声明取数：`amountField`读取当前卡字段，道具显式`amount`及能量/上限的`n`沿声明。满月形态同时说明本场上限增加与即时能量获得；精神药水沿战斗抽牌声明，地图可用性仍由原使用入口判断。照片与大卡根据解析后的说明决定显示正文，保留动态状态产生的说明。当前增量见[说明入口统一](../evidence/2026-10-26-flow-goals-round11/README.md)，待老板统一验收。

卡牌根盒包含完整框体，统一2:3外形；透明开口内上方53%展示卡图，下方47%为浅色手绘纸面阅读区。类型与职业/品质以纸签置于图文分割处，卡名和牌效位于下方。费用纸签置于独立上层，显示在左上靠框位置，使用Oxanium粗体数字；资源卡始终不显示费用，其他类型沿原费用显隐规则。费用显示当前实际值，与原有费用相同为黑色，高于原有费用为红色，低于原有费用为绿色；手牌与放大详情随状态更新。数量放在卡外，不覆盖类型、名称和费用。

本场临时牌显示青色边光与「临时」标记；会随操作变化的牌显示紫色边光与「随动变形」标记，变形后保留来源提示。两种状态可同时显示，减少动态偏好下停止呼吸动画。临时来源、变形状态和实际费用不同的牌不合并为同一手牌叠。

双相星盘及使用同类交替回能规则的装备，简介说明装备后首回合的相位与逐回合切换顺序。战斗中的卡面与已装备图标提示按该实例的装备回合显示本回合相位、回能是否已触发和下回合相位；未装备时预览本回合装备后的首相位。该展示读取当前结算状态，不改变触发或回能规则。

有效稀有度仍由 `SDT.Cards.rarityOf` 判定；能力卡及其衍生沿用棱彩，普通衍生继承来源品级。类型与职业不另改稀有度。卡名在浅纸面上采用深色油墨：初始灰、古朴褐、稀有蓝、史诗紫、传说金褐渐变、衍生灰青、职业按人物框配色、棱彩多色渐变。

公共卡面右下角显示金币图标与币值，数值沿用 `sellPrice`（已有币值优先，否则按现有品质收购价计算）；显示币值不改变不可出售卡的出售限制。背包不叠加第二份。局内商店货架与商品详情通过 `options.hideValue` 隐藏该角标，购买价格以货架标价和购买按钮为准；收购台与其他通用卡面保留币值。

运行映射包含13款框：七档品质、五位人物与职业素框；[职业框映射](career-frames.md)维护人物口径。品质从裸纸、单胶带、对角拼贴递进到史诗多层角饰、传说折纸装裱、棱彩彩纸星轨。职业框减少杂饰，以概括块面绘制人物锚点。所有框按原图宽高比等比显示；棱彩带沿框轮廓的边缘光、扫光和卡名渐变，减少动态偏好下保留静态效果。

传说卡保留低强度金色轮廓呼吸和缓慢扫光，棱彩使用更丰富的彩光；减少动态偏好下传说保留静态边光并停止扫光。

运行框体位于 `game/assets/ui/card-frames/paper-1015/`，是按原比例缩小后的512×768透明无损WebP；同目录interior.webp提供手绘纸面。原始制作稿与当前来源指针在 `game/art-source/card-paper-rarity-20261015/`。映射与透明开口由 `game/data/card-frame-layout.json` 提供，`game/src/cards/card-frame-presentation.js`统一选择框体与自然比例位置。

稀有品质使用蓝色对角胶带与宽笔扫痕；职业锚点和人物主色按职业框映射维护。

样式唯一入口是 `game/css/card-layout-selected.css`，主入口与开发入口均加载。旧全幅渐变、右上稀有度宝石、倾斜费用牌及各页面的卡内排版覆盖已从运行样式移除；旧框源文件不再由正式卡面导入。逐卡构图修正与照片装裱各自保留。

卡内字号随卡宽缩放。正文、数字和术语使用同等字级，数字与有讲解的术语以字重和颜色强调，保留术语交互、卡牌引用与自定义文本转义。规则数据不截字；超过卡内阅读区的内容可滚动，长文本区域支持键盘聚焦。独立全文阅读栏继续使用24设计像素和1.55行距，放大与详情仍走各宿主的原有交互。

战斗手牌保留收纳、聚焦上浮、拖拽出牌、数量与快捷键；面内费用和卡名直接来自共用卡面，独立旧身份遮罩已移除。背包格为外扩框留出空间，保持卡片比例而不裁掉框边。框图与光效不接收指针输入。

本轮素材来源与接入范围见[纸边实装记录](../evidence/2026-10-15-paper-production/README.md)；共用卡面首次接入的历史证据见[全游戏卡牌接入记录](../evidence/2026-10-15-card-face-integration/README.md)。

## 战斗牌堆与发现

普通战与首脑战都显示可点击的“本场消耗”徽标，0张也能打开；查看器统一标题为“本场消耗牌堆”，同卡合并数量，点击查看完整规则，返回原战斗。普通战读取快照 `consumed`，首脑战读取 `grave`；这是共同呈现，不是合并结算区域。普通战仍没有循环牌库，查看消耗记录不启用卡牌中的牌库/墓地专属效果。战后“消耗区”是另一生命周期位置，不改为本场牌堆的别名。

“灵能召唤”的发现展示候选供玩家选择，动作说明为“选择1张置入手牌，使其无需注能”。确认前不授予候选；仅选中临时实例携带免注能标记，候选模板与全局卡定义保持不变，正常费用和其他出牌条件仍适用。

### 自身持续效果状态条

战斗自身名牌在既有祝福/诅咒旁显示已生效的规则效果：诅咒免疫、招式费用规则、下一张法术额外施放、招式视为已注能、发现候选增加、流血附加伤害翻倍、抵挡致命伤害次数与待触发额外回合。状态项显示作用范围或剩余次数/回合；指针悬停、触屏按住、键盘聚焦均使用既有词条说明。费用规则仍以手牌实际费用为准。

这些项目来自运行时已生效状态的白名单投影，随快照更新消失，不从待选卡文案预测。诅咒免疫合并临时、本场与圣洁符文来源；临时窗口显示到下回合开始，已有本场来源不错误降为临时。原伤害免疫祝福独立显示，不与诅咒免疫混为一项。单牌限回合费用仍由手牌费用显示，内部队列、记账标志及尚未生效的候选效果不进入自身状态条。
