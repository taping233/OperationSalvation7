# 职业卡人物框

有效稀有度为职业的卡牌（rv6）使用对应人物专属包框。外轮廓与无的已确认候选一致，人物纹章与点缀色各异；费用、卡名、说明、原画和交互仍由现有卡牌模板维护。

| 人物 | 现行职业 | 模板标记 | 框体 |
| --- | --- | --- | --- |
| 无 | 侠客 | cf1 | 黑蔷薇、蓝缎带、蓝星 |
| 黑像 | 战士 | cf0 | 赤铁剑盾、刃形护边 |
| 白塔 | 法师 | cf2 | 银白塔尖、冰蓝晶体 |
| 星月 | 牧师 | cf3 | 青银月牙、星与枝叶 |
| 常无欲 | 降临者 | cf4 | 紫色虚空眼、菱形晶核 |

无人物标记的职业卡回退石墨素框。职业所属不改变有效稀有度：能力卡、棱彩及其他品质保留原五档厚涂蔷薇框。

入口：card-layout-selected.css 在蔷薇映射后导入 card-frames/career/frames.css；已有公共伪元素根据 --rose-frame 绘制，覆盖仓库、招式、战斗、发现、背包、商店、特写及复用卡面克隆。SVG共享336×486外框画布、272×406内部画窗，外扩量见同目录geometry.json；全框静态且不接收点击。

本页维护人物职业框的现行口径。card-display.md 的原职业素框描述由其他活跃会话维护，本轮未写入该占用文档；本页以独立映射覆盖原职业基础SVG。

实施与验证边界见[职业框记录](../evidence/2026-10-12-wu-career-frame/README.md)。
