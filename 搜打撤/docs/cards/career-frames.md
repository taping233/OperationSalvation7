# 职业卡人物框

有效稀有度为职业的卡牌（rv6）使用对应人物专属纸边框。框体采用统一概括块面画法，保留人物锚点与主色，减少重复角饰；费用、卡名、说明、原画和交互由共用卡面维护。

| 人物 | 现行职业 | 模板标记 | 框体 |
| --- | --- | --- | --- |
| 无 | 侠客 | cf1 | 小黑蔷薇、短蓝丝带 |
| 黑像 | 战士 | cf0 | 黑红纸边；最右侧巨剑、顶部盾牌 |
| 白塔 | 法师 | cf2 | 黄绿纸边；概括魔法书、短书签 |
| 星月 | 牧师 | cf3 | 黑黄纸边；满月、残月 |
| 常无欲 | 降临者 | cf4 | 紫黑纸边；单枚眼形 |

无人物标记的职业卡回退无人物纹章的素纸框。职业所属不改变有效稀有度：能力卡、棱彩及其他品质使用对应品质纸框。

入口：共用cardHTML按有效稀有度与cls调用card-frame-presentation.js，读取game/data/card-frame-layout.json，输出同一hsc-frame图层。五位角色与职业素框均使用game/assets/ui/card-frames/paper-1015/下的透明WebP；按自然比例显示，覆盖仓库、招式、战斗、发现、背包、商店、特写及飞行克隆，框图不接收输入。

本页维护人物职业框的现行口径；布局、费用、卡名颜色和阅读方式见[卡牌显示](card-display.md)。旧SVG仅保留来源，正式卡面不再导入其样式映射。

当前素材来源与接入范围见[纸边实装记录](../evidence/2026-10-15-paper-production/README.md)；共用卡面的历史证据见[统一卡牌接入记录](../evidence/2026-10-15-card-face-integration/README.md)。
