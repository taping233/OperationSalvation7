# R7-b 本地试玩反馈契约（待R7-a根验收后实施）

## 玩家可见变化

在任意游戏页面右键记录问题，正文为必填，复现步骤/期望/实际为可选。保存到当前浏览器后，从设置的既有留言库主动导出单条JSON交给制作者。所有文字明确本地保存、不自动发送；版本和中文页面位置随记录提供。不新增网络收件箱或第二套入口。

## 输入输出

- 输入：玩家填写文本、当前可见`#gameVersion`（缺失则未知）、`describeCurrentPage()`中文页名与稳定标识、右键位置的可读名称和百分比坐标；不自动采集完整档案或机器路径。
- 保存：沿用`sdt-suggestions-v1`裸数组。保留已有条目和字段，新条目可增加version/steps/expected/actual字段。旧条目缺新增字段可读可导出，不为了迁移重写全部数据。
- 失败：坏JSON或非数组视为读取失败，展示可重试错误并保留原串；不能把错误装成空留言库再覆盖。写失败保持所有输入和当前弹层；busy防双击，完成后可重试。退出/迟到回调不能关闭后来打开的页面或恢复过时game.state。
- 导出：单条白名单对象，仅记录格式版本、时间、游戏版本、中文页面/位置、百分比坐标与填写内容。排除selector、完整URL、原localStorage、玩家存档、任意未知字段。文件名使用安全时间/固定前缀。下载触发后回收Blob URL；不调用网络发送。
- Electron已有IPC兼容分支不改桌面文件/构建；本次验收仅浏览器路径，不恢复EXE维护。

## 文件范围

`game/index.html`既有`sugLayer`，`game/src/game.menu.js`既有反馈控制器，`game/css/overlays.css`反馈局部样式，可新增纯`feedback`模块与必要测试。保留既有全局右键、设置入口、留言done展示与删除语义，不顺手重构菜单/经济/战斗。

## 验收

- 正常：真实右键游戏界面→填写→保存→留言库可读→刷新仍在→单条导出内容正确；版本来自当前游戏。1280×720及窄屏下表单可滚动、保存/返回可达，有label、键盘焦点可见。
- 失败：真实Storage.setItem故障测试中输入保留且不自动关闭；坏存储原串不变且可见错误；恶意HTML按文本显示。导出不混入记录的任意未知字段。
- 重试：一次失败后恢复存储可保存一次；保存双击不重复。仅有ts/page/target/at/text的旧留言仍可读可导出，缺版本明确未知。刷新不自动发送或丢记录。
- 自动测试须通过真实`createGameMenuController`绑定的DOM事件证明失败/重试/busy/旧留言链路，不能只有纯序列化单测或源码字符串断言。IAB不篡改真实浏览器存储造错误，故障测试与实机正常路径分别记证据。
