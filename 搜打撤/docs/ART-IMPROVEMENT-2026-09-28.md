4. **已试：[UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)**。在系统临时目录稀疏克隆官方仓库，实际运行其 Python 风格/产品/配色检索，再对基地商店做一轮空间结构试验，见 A04。没有安装技能、改项目或全局配置。
5. **已试：[Magic UI](https://github.com/magicuidesign/magicui)**。A05 判定其 Magic Card 光效不适合卡背图鉴；A07 将官方 [Magic Card](https://magicui.design/docs/components/magic-card) 的“指针聚光强调悬停边缘”思路转到出发整备的可带卡，用项目原生 CSS 与事件委托实现，不复制 React 组件或安装依赖。

本轮战斗设计方向：玩家需要在数秒内认出敌方意图并选择手牌。第一焦点是敌人与意图，第二焦点是手牌/能量；保留老板提供的废墟背景作为险境叙事。局部审美试验是用废墟的余烬暖光把敌阵连接成一个战术目标区，而不替换背景或人物立绘。
