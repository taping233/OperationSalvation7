  1. 素材批量下载：从 open-duelyst 仓库按需拉取 6 阵营立绘 + 精选单位精灵 + 2~3 张地图背景层，入 _planning/assets-inbox/ 筛选。

  5. 登记审计：全部素材写入 asset-manifest.json（来源=CC0 / SHA-256 / prompt=无），跑 npm run assets:audit。
