壹定调五支柱

一 · 统一竖版 0.71废弃 2.3 扁横卡；手牌/商店/牌库/悬停全场景一套竖卡比例，插画永远完整（彻底消灭"战斗卡只露 43% 画面/人物切头"问题）
二 · 框色即职业战士红 / 侠客绿 / 法师蓝 / 牧师金 / 降临者紫 / 无职业中性灰——抽到手牌 0.5 秒可辨来源
三 · 横幅色即稀有度卡名丝带底色承载稀有度（灰/铜/银/蓝/紫/金），横幅比"框角小宝石"信息量更大且省一个部件
四 · 费用球浮出左上角不占卡内空间，蓝晶球+白字，压角构图是 STS 最强识别符号
五 · 描述区深底金字插画与文字物理分层；数字加大一号（Georgia）、关键字金色、伤害/冰冻等术语用冰蓝

实施切分（保速度，两步走）

第一步 · 换皮（1 批次）cards.view.js 卡 DOM 换新结构 + winter.css 新增卡框样式块；牌库/商店/悬停/制作坊全部走新竖卡。2.3 扁横布局暂保留给战斗手牌（先让玩家看到卡变好看）

配套 · 卡面重裁现有 896 方图在 0.79 插画窗下只裁上下 ~21%，比现状 2.3 裁 57% 好得多，可直接上线；后续按上轮审计清单逐批补图/重构图
风险点战斗手牌点击判定/飘字锚点跟随卡片变换；旧存档实例卡无 cls 时回退中性灰框（art.js 已有找回逻辑可复用）
