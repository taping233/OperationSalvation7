# 注能材料操作

注能材料按同类卡分组，计数显示“已选 / 持有”。加号始终增加一张，减号始终减少一张。

卡面和对应数字键采用相同规则：还有名额和可用材料时增加一张；材料已经选满，或该组没有更多可选材料时，减少该组已选的一张。卡面操作名称随当前动作切换，选中高亮与已选数量保持同步。选满后卡面仍可用于减选，无须先返回战斗。

加号不可用时，材料下方和加号提示说明原因：材料已齐、该组已全选、该组没有更多可选材料，或具体的材料限制。没有选中过的材料组在总数量已满时不能增加，需先减选。

这些交互仅调整待确认材料。确认按钮在数量不足时禁用；减选后立即回到未齐状态。材料、能量与目标合法性仍由战斗命令验证；选择过程不消耗资源。
