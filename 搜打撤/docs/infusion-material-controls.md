# 注能与消耗材料操作

注能在原战场的手牌层内选择材料，主卡常显；后景虚化压暗，当前数量以“已选 / 所需”显示。候选逐张对应实际卡牌，同名副本分别操作。

出牌前支付手牌代价、效果中选择手牌消耗，也使用这套窗口。候选按当前词条筛选，例如快意恩仇只列初始攻击、铸甲只列装备；支付材料不套用注能材料的限制。

点击候选卡将其移入已选区，点击已选卡将其撤回手牌；数字键选择当前前九张候选。选满后仍可撤回重选，手牌区和已选区不重复显示同一张卡。

候选区按当前窗口可完整容纳的卡牌数分页，常显“上一页 / 当前页数 / 下一页”，页首与页尾禁用对应按钮；鼠标滚轮也可切页。选择或撤回材料时保留当前页，页数减少时收回最后一页。点击判定直接对应当前显示的卡牌，不沿用普通扇形手牌的位置。主卡常显，不另设放大镜按钮。

确认材料后沿公共目标选择流程打出；返回选材保留原材料，取消返回战斗不消耗。可选注能可明确选择直接打出，纯注能仍须选足材料。

消耗选择在确认前只保存本次草稿，撤回不会消耗卡牌。确认后按原支付或消耗流程执行；强制支付不能跳过，允许跳过的效果保留返回入口。过期选择及旧战斗的按钮不能影响新的选择。

这些交互仅调整待确认材料。确认按钮在数量不足时禁用；减选后立即回到未齐状态。材料、能量与目标合法性仍由战斗命令验证；选择过程不消耗资源。

新增材料时，只有新选卡牌上移、放大回弹并落位，已选卡牌保留金色描边；撤回卡牌向下回弹。数量变化有短促放大反馈，材料选足时确认按钮亮起一次。减少动态效果时直接显示最终状态，不等待动画结束才能操作。
