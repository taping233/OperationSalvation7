# 奖励领取

搜刮点节点直接收下当前组金币并展示卡牌，不播放开箱动画、不等待开箱图片解码。多组卡牌奖励逐组展示，当前组处理完成后自动展示下一组，下一组内容仍到展示时确定；最后一组处理完成后继续探索。每组的卡牌、金币、已领与放弃状态随节点保存，重进和读档不重抽、不重复发放。旧存档停在开箱阶段时直接恢复卡牌页。

搜刮点、固定奖励与入城补给共用 rewardSceneHTML 和 rewardCardUnitHTML：左侧来源与标题，右侧卡牌，底部容量、整理和继续操作。单卡和多卡使用相同卡面尺寸与布局；领取按钮跟随对应卡面，卡区独立滚动。卡名只在卡面出现，不另列名称、×1、查看提示或领完后的数量回报。三选一保留永久放弃其余候选的提示，附赠卡单独领取；已领或已放弃的卡保留简短状态。

点击卡面打开详情，收下或选择这张才提交领取；详情复用同一动作。满包可整理后继续，旧页回调不重复发牌。返回地图保留未领内容；放弃剩余卡牌收在其他操作中，仍须确认。左右键切换焦点，Enter执行聚焦按钮，Esc退出最上层界面。

非战后普通或职业小箱只有一张可全领卡、一个箱子且金币已收下时，收牌成功后直接完成并返回原续流。未成功入包或保存明确失败时不自动结束。短暂回执只显示已收下，不重复卡名；回执不抢焦点、不挡操作，1.8秒后消失，打开其他浮层时清除。

战后奖励保留独立结算和额外传说准备边界，不触发地图小箱的自动完成。多箱、三选一、有宠物蛋或独立附赠时继续处理未领内容。入城补给可以全部收下，全部领取后才放行探索。

奖励界面只负责呈现和导航，不改变数量、随机池、奖励UID或存档字段。公共视口维持 min-height:0 和 overflow:clip，只有各页面自己的内容区滚动。
