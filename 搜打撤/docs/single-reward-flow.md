# 单牌奖励领取

非战后结算的普通或职业小箱只有一张可全领卡牌、只有一个箱子且全部金币已收下时，成功收牌后直接完成本批奖励并返回原续流。玩家从「开箱并收金币 → 收下 → 继续探索」变为「开箱并收金币 → 收下」。开箱动作与揭晓动画保留；卡牌未成功进入背包时不结束；写盘明确失败时保留原奖励处理路径，不自动收尾。完成后用短暂、不抢焦点也不挡操作的文字回执确认卡名与“已入背包”，不再要求关闭收据。

单牌非选择奖励复用 `rewardSceneHTML` 的显式紧凑布局：标题在上、卡牌居中、容量与整理在下。普通/职业小箱和无金币固定事件单牌入口使用同一布局；三选一、多卡、混合金币等入口保留既有布局。实际单牌picker只保留顶部“返回奖励”作为非破坏出口；放弃入口收在“其他操作”中，仍须原来的永久放弃确认。

多箱、三选一、有宠物蛋或领卡附赠、仍有金币待领时，不使用自动收尾。满包时保留原奖励、容量说明和整理入口；整理后仍由玩家点击领取，旧回调不会重复发牌。暂离、读档、放弃和结算继续沿原有奖励事务；此组件不改变数量、随机池、奖励UID或存档字段。

最终单牌使用轻量回执替代原总览上的卡牌反馈；其他领取继续使用原入包飞行动画。回执最多一条，1.8秒后消失，打开其他浮层时清除；开启减少动态效果时不会新增动画。

本批为源码与jsdom定向验证，真实窗口视觉待验：1180×757单牌尺寸、短窗口可滚动性、关闭/返回与整理流程均须当前平台内置浏览器核对，不能据源码断言已经变大或无裁切。

战后奖励带有独立结算与额外传说准备边界，即使普通箱只有一张卡，也保留明确继续操作，不触发地图小箱的自动完成。

紧凑单牌的领取或腾位按钮固定在底部操作区，卡面滚动不带走主操作；容量、整理和其他操作保留。游戏视口始终采用禁止滚动的裁切（内部奖励、背包等各自滚动区不变），避免隐藏视口遗留焦点滚动使整个面板上移。
