# 成就陈列室渲染

成就陈列室入场只创建奖章列表、统计和空详情容器；点击某枚奖章后才创建该奖章的详情。列表保存详情所需的编号与奖励文本，名称、条件和解锁状态沿用当前列表快照，详情继续使用本次开页选择的奖章画风。

关闭详情不会销毁当前详情节点。再次打开同一枚奖章时复用节点；切换另一枚时替换详情内容，因此最多保留一份详情树。重新打开整个陈列室会使用新存档快照，不跨页面缓存领取状态。详情文字按文本转义，不参与解锁判定或奖励领取。

筛选、分类、搜索、详情焦点圈定、关闭后焦点回到原奖章等行为由原有控制器负责。验证见 `tests/achievement-gallery.test.js` 和 `tests/achievement-gallery-entry.test.js`；工作量证据见 [入场测量](evidence/2026-10-20-achievement-entry-work/README.md)。

详情顶部提供固定可见的“收回奖章”按钮，接入页面的关闭回调和公共取消语义路由。Esc优先关闭详情并将焦点还给来源奖章，不退出整个陈列室；详情独立挂载时也有相同的Esc处理，输入法组合及重复按键不会误关。背景遮罩同样调用详情关闭回调。
