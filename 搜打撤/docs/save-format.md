# 存档兼容契约

## localStorage 键

| 键 | 作用 |
|---|---|
| `sdt-save-v2-slot1..3` | 三个档位的进行中对局 |
| `sdt-base-v2-slot1..3` | 三个档位的基地与局外成长 |
| `sdt-save-v1` | 旧单档对局；启动时迁入档位 1 后删除 |
| `sdt-base-v1` | 旧全局基地；启动时复制到尚无基地数据的档位后删除 |

设置项、卡牌库和格子备注仍使用各自已有键，不与档位存档合并。

每个进行中对局保存顶层 `seed`，并在 `rngState` 中保存各命名随机流的当前位置。读档会恢复该状态，确保继续游戏不会从 seed 起点重新抽取；旧档缺少这些字段时会自动生成 seed，并在下次保存时补齐。

## 兼容要求

- 缺失字段使用当前默认值补齐；未知附加字段应忽略而不是令读档失败。
- 迁移必须先成功写入目标键，再删除旧键。
- 删除档位只删除对应对局与基地数据，不影响其他档位。
- 重构允许移动函数和模块，不允许静默更改字段含义、资源数量、卡牌归属或安全格规则。

固定兼容样本位于 `tests/fixtures/`，由 `tests/save-compat.test.js` 覆盖 v1、v2、跨档隔离、未完成对局、基地、职业、成就和卡背。任何存档格式变更都必须同步更新样本与迁移测试。
