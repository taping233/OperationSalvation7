# 设置最终结构一次性挂载

## 依据和范围

2026-10-20真实浏览器三次设置入口阶段样本：overlay-sync 51.5/38.6/57ms，navigation-sync 26.8/26.8/33.3ms，分别与96/92/115ms longtask区间重叠。冷module-wait 212.5ms；资源等待单独统计，不能计作同步CPU。该样本支持优先检查同步挂载路径，但不证明某次DOM操作独占长任务。

一次性挂载负责设置模板及导航初始化；设置值由各自的保存、音频和输入模块管理。入口阶段诊断默认关闭，不调整帧率或加载阈值。

## 变化

- 每次打开即时读取游戏、存储、音频和输入状态，生成设置HTML。
- `settingsLayoutHTML` 在字符串层组合左侧竖排4页签和右侧4面板：通用、画面与反馈、音频、输入。首次挂载只有通用面板可见；数据与档案、危险操作、致谢与来源折叠在通用面板内。checkbox的文案包装和switch语义直接写入最终HTML。
- `initSettingsNavigation` 不创建/搬移设置组DOM或重新包装checkbox；只查询最终节点、设置入场顺序、绑定事件和测量marker。
- 初始aria/hidden/selected状态已在HTML中，不再在首次select时重复改写。每个新页面独立初始化，WeakSet只防同一节点重复绑定，不保存设置值。
- 竖排选中条随分类滑动；切页marker的offsetTop/offsetHeight先读完再写两个CSS变量。页签用上下方向键循环切换、Home/End到首尾；内容区按分类记住本次打开期间的滚动位置。
