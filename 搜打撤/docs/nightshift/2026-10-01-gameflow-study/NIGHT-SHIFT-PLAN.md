# 夜班任务书：游戏制作流程对照研究（WF-nightshift-gameflow-study）

> 时间窗：2026-10-01 00:45 → 07:00。调度：cron 每 50 分钟接力一轮（01:36、02:26、03:16、04:06、04:56、05:46、06:36、07:26…）。
> 收官没有独立的 07:00 任务（平台限制：一会话只能挂一个调度）：由本地时间 ≥07:10 的首个接力轮（预计 07:26）按本文件「收官协议」收官并 CronDelete 删除周期任务自身。
> 最高依据：同目录 `BOSS-BRIEF.md`（老板指令 + 18 节流程全文）。本文件是执行协议，每轮开工必读。

## 任务目标

按老板 18 节游戏制作流程，对搜打撤 Vite 版做一轮**研究+代码工具**（01:20 老板追加：要动一些代码项目层面的东西）：

1. 阶段盘点——18 节逐条对照项目现状，判定哪些有基础、哪些缺失；
2. 外部调研——撤离类玩法与卡牌构筑游戏的成熟做法（允许联网，鼓励外部信息源）；
3. 设计假设——把发现蒸馏成可验证的设计假设；
4. 创新提案——3 个以上可小步验证的创新方向；
5. **代码交付物**——自有目录内的 Node 数据分析工具（只读游戏数据，产出数值/卡牌分布报告）与自包含静态原型页（file:// 直开，不依赖 dev server）；
6. 晨报——老板早上醒来读一份文件就能掌握全部成果。

## 代码交付物边界（01:20 老板指令后新增）

- **只新增**，目录限定 `docs/nightshift/2026-10-01-gameflow-study/tools/` 与 `prototype/`；不修改、不运行任何现有 game/、scripts/、tests/ 文件。
- 分析工具只**读取**游戏数据（如 game/data/cards-sync.json、game/src/core/rule-config.js），不改写任何项目文件；输出报告写回自有目录。
- 原型页必须自包含（单 HTML 或 HTML+本地 JS），file:// 打开可用，不起服务、不进构建。
- 不给自有脚本添加进 package.json、不新增依赖（只用 Node 内置模块）。

## 属地与铁律（每轮开工先默读）

**只能写**：`docs/nightshift/2026-10-01-gameflow-study/` 目录内文件。
**唯一例外**：收官轮可编辑 `docs/PARALLEL-REGISTRY.md`——只移动本任务自有那一行（活跃登记→近期已释放），不碰规则节、不碰其他行。

**绝对不碰**：game/、scripts/、tests/、package.json、根 AGENTS.md、docs/PENDING.md、docs/quality-gates.md、docs/README.md、docs/WORKFLOW-TOOLS.md、docs/agent-protocol.md，以及 REGISTRY 活跃表里三个在班会话（WF-acceptance-scenes / WF-workflow-simplify / WF-full-audit-fix-perf）的一切属地。

**行为禁令**：不 build、不起 dev server、不改代码、不提交、不回滚、不删除任何现有文件、不 push、不外部写入。

**研究守则**：
- 允许并鼓励 WebSearch / WebFetch；单条查询失败最多重试 1 次，连续失败就记「未查明」换下一主题，不钻牛角尖。
- 读项目文档只读需要的片段（先 `rg` 定位再读）；大文件不整读。
- 每轮只做一个主题，产出一个文件，≤350 行；结论必须绑定来源（文件路径 / 行号 / URL）。
- 遇配额/限流错误：立即停止本轮，在 PROGRESS.md 记 `quota-block`，不重试轰炸。
- 中文产出。

## 每轮执行协议（严格按序）

1. 读本文件 + `PROGRESS.md`。
2. 从 PROGRESS.md 的「下一轮」字段确定本轮主题；若该轮产出文件已存在且非空，顺延到下一个未完成轮；**若 R1-R9 全部完成且未到收官时间，本轮直接结束**（在接力日志写一行「全部完成,待收官」即可——不为干活而干活，不空转烧额度）。
3. **锁检查**：PROGRESS.md 的 `running_since` 距当前时间 <55 分钟 → 说明上一轮仍在跑，本轮**直接结束**（写一行说明即可，不抢跑）。
4. 把 `running_since` 改为当前时间+轮号，然后开始工作。
5. 完成产出文件后，更新 PROGRESS.md：轮次状态、一行摘要、「下一轮」推进。
6. **时间检查**：本地时间 ≥06:50 且 R6 未完成 → 本轮直接改做 R6 晨报（宁可其他轮缺，晨报必须有）；本地时间 ≥07:10 → 按「收官协议」执行。
