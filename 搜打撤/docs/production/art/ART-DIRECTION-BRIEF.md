# 《代号柒》美术方向简报 v0.1

日期：2026-10-09。来源：老板在本会话的直接确认。用途：指导初版美术 Demo 的情绪板、风格小样和后续样板制作。此文件整理方向；具体画面、配色与跨素材执行方式仍通过样板确认。[现行视觉规范](VISUAL-BIBLE.md)继续记录运行素材与接入要求。

## 核心方向

作品包含一些严肃元素，整体玩起来轻松、简单；老板以对《明日方舟》的感受作参考。画面好看，轮廓完整、结构清楚，内部用简略色块表现，通过色彩搭配与大块光影建立风格。

当前目标是初版美术 Demo，先确认可用的视觉方向，再逐步提高作品完整度。

游戏默认画风采用 2026-10-18老板恢复的10-16双图块面厚涂，画法与可复用提示词统一见[游戏默认画风](ART-STYLE-V1.md)。个人技能后续版本与 NAI 配方版本不自动覆盖项目默认；无当前立绘 `game/assets/portraits/full/wu.webp` 用于核对身份与比例，其他主体不套用她的身份、服装或站姿。皮肤重绘保留当次指定图的构图、动作、服装和道具，再叠加默认画法。世界是未来科幻城市，科技感通过现代合成材料、模块化城市构件、自动设施与立体交通表达，避免古城石柱、城堡、旧木门和中世纪装饰成为主题。宝箱不因冬境氛围而强制带雪。已单独确认的商店背景保持原图。

2026-10-11老板补充天气为冬天：新室外场景使用冷天光、屋顶与道路边缘积雪、稀疏枯枝，保留清楚可踏足的战斗带。独立透明宝箱不强制积雪；已确认室内商店图冻结。

## 已确认的视觉要求

| 维度 | 方向 |
| --- | --- |
| 完成度 | 主体轮廓完整、结构可读；内部刻画简略。老板选择此方式，未选择可见草稿线或未填满边缘作为主要特征。 |
| 色彩 | 偏好明亮、舒服的色彩；可以丰富，但颜色之间协调。 |
| 光影与色块 | 以大块明暗和色面表现形体与氛围，减少对细节的依赖。 |
| 线条与细节 | 沿[默认画法](ART-STYLE-V1.md)保留结构性笔触、材质区别与硬软边，细节密度随焦点和形体分配。 |
| 构图 | 画面好看、主体清楚；参考 C1 的人物与环境组织。 |
| 人物画法 | 当前默认画法以[2026-10-16双图块面厚涂](ART-STYLE-V1.md)为准；D1 作为既有认可记录与运行形象参考。 |

## 情绪方向

**已确认：严肃元素与轻松、简单的整体体验并存。**“轻松、简单”是老板对游玩体验的目标；美术需辅助这种感受，具体表现由情绪板和游戏内样板确认。

2026-10-09，老板在[情绪板](../../evidence/2026-10-09-art-mood-board/mood-board.html)中明确选择 M1（首页原图），作为本轮情绪基准：冷静、安静、有故事感，严肃元素较明显。此选择针对氛围；完整轮廓、内部简略色块的画法要求继续沿用。各场景情绪强度和分配尚未确定。

## 已指定的小样基准

老板指定首页原图 [hub-wallpaper.webp](../../../game/assets/scenes/hub-wallpaper.webp)：无拿红玫瑰坐在散落书页上，背景为雪地、树木与倾斜书架。

这张图是当前对照小样的内容与构图基准；D1 是人物画风参考。首页坐姿图与 D1 的服装、道具存在差异，按当前选定基准保留，不在风格小样中擅自统一人设版本。

已制作[两张对照小样](../../evidence/2026-10-09-art-style-samples/README.md)：A 冷灰块面、B 明亮冬日。两张均待老板选择，尚未定稿或接入游戏。小样采用内置生图；后续工具选择按老板当轮指令执行。

## Demo 审阅依据

后续样板按以下问题审阅：

1. 主体轮廓和结构是否完整、清楚？
2. 色彩是否舒服、丰富且协调？
3. 简略色块和光影是否足以表达形体，是否还有多余碎线、纹理和细节？
4. 人物是否符合认可画风，构图是否协调？
5. 情绪是否符合当前场景，并支持轻松、简单的整体体验？

每轮记录老板的“保留／修改／通过”反馈，确认后再固化基准。人物、场景、卡面、UI、动画与特效的具体规格尚未定下；通过跨素材与游戏内样板后补入正式美术规范。
