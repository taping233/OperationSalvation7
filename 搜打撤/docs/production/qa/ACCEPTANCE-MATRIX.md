# Vite 整局与 Agent 验收矩阵

制定时点：2026-09-28。本矩阵是未来验收脚本，不是本次实测结果。实际规则以[现行规则](../../rules.md)为准；质量检查入口见[质量门](../../quality-gates.md)，Agent 动作与实验口径见[接口协议](../../agent-protocol.md)及[迭代手册](../../agent-iteration-playbook.md)。

## 使用方式

一次验收先固定代码状态、浏览器当前窗口、档位和随机种子（若可设置），再选覆盖范围。小改只跑受影响场景；公共架构或阶段收尾跑整局矩阵和项目规定的全量质量门。测试、静态检查、真实页面、Agent 批跑是不同证据，不相互替代。游戏实页只使用当前平台（Codex / ZCode）内置浏览器当前窗口；多尺寸另经老板明确要求。共享工作区有其他会话未提交修改时，不运行构建。

每个场景记录：通过、失败、未执行、受阻四种状态之一；失败写复现入口和实际现象；未执行保留空白，不从历史报告推定通过。当前所有场景状态均为“未执行”。

## 玩家整局路径

| ID | 场景与操作 | 最低可观察结果 | 本轮状态 |
| --- | --- | --- | --- |
| P01 | 新档进入基地，检查模式、职业、仓库与初始资源 | 页面可操作；档位隔离；玩家能识别出征入口 | 未执行 |
| P02 | 整备并出征，经过选角、带卡和地图入口 | 随身卡与基地资源变化一致；刷新后可恢复到约定检查点 | 未执行 |
| P03 | 在相邻节点探索，经过事件、搜刮、商店、火堆或祭坛中的实际可达节点 | 节点只触发一次；行动、背包占用和奖励反馈与现行规则一致 | 未执行 |
| P04 | 完成普通战斗并收取奖励 | 出牌、目标、敌方回合和战利品顺畅；结算或刷新不重复发奖 | 未执行 |
| P05 | 从可用撤离点结束一局，再回到基地查看资源 | 撤离条件、带出预估与实际结算采用同一规则；档位保留正确结果 | 未执行 |
| P06 | 触发死亡或放弃，再进入同一档位 | 资源损失与安全格规则正确；没有残留的进行中战斗或重复结算 | 未执行 |
| P07 | 在地图、战斗和结算的稳定检查点刷新或关闭后继续 | 能恢复的状态继续，不能恢复的状态明确报告且原存档受保护 | 未执行 |
| P08 | 深入第四层，击败首脑并从终局撤离 | 出现清晰的通关结算与简短收束；档位状态和奖励不重复，形成四层主地图的明确结局 | 未执行 |

完整人工跑局不要求一局同时命中所有随机节点；用真实可达路径与补充档位覆盖分支。开发工具可以帮助复现单点问题，但不能把由工具直接跳入的页面称为新玩家整局通过。研究所第二地图暂缓，不列入本阶段验收矩阵。

## Agent 路径

| ID | 场景 | 最低可观察结果 | 本轮状态 |
| --- | --- | --- | --- |
| A01 | 同一档位或固定种子上的观察、动作、完成确认 | observe 给出的可行动作可由 step 执行；拒绝与超时有明确停因 | 未执行 |
| A02 | Agent 从开档到撤离、死亡或终局的自动跑局 | 每局留存 seed、策略、停因、错误和结果；异常路径可重放定位 | 未执行 |
| A03 | 策略 A/B | 同一代码状态、种子集合和探针设置配对；对照与候选同轮运行，按现行手册判定 | 未执行 |
| A04 | 人工流程与 Agent 流程对照 | 对照同一游戏规则和命令边界；批跑快进结果不充当真实页面体验证明 | 未执行 |
