## 概念与体验承诺

玩家进入逐层深入的地图搜集物资、使用卡牌应对战斗，并在风险升高时决定继续探索还是带着战利品撤离。背包空间、生命与可用资源让“多拿一些”伴随损失风险。当前正式规则记录四层相邻节点地图、基地整备、普通战斗和首脑战等流程；具体限制与奖励见规则文档。

**完整版本范围：**四层主地图形成完整旅程，击败首脑后经终局撤离进入清晰的通关结算与简短收束。研究所第二地图当前阶段暂缓，不纳入本轮规划与完整版本验收。结局的具体文案和美术留待实现设计；未有依据的细节不在本 GDD 中补造。

## 玩家旅程

1. **基地整备：**选择对局模式与职业，管理存档、物资和携带内容。
2. **进入地图：**从外层节点开始，在相邻节点间选择路线；探索资源点、事件、战斗、商店或休整点。
3. **应对遭遇：**普通战斗使用随身可用卡；首脑战按规则从背包编组牌库。胜负、耗材与剩余空间影响后续路线。
4. **承担风险或撤离：**权衡进一步深入的奖励、当前状态及撤离机会。部分撤离或层间行动受规则限制。
5. **结算回基地：**按对局结果处理带回物资、卡牌与局外进度，再进行下一次整备。

上述旅程是体验概括，节点配置、结算细节与例外以[现行规则](../../rules.md)为准。

## 核心循环与系统关系

```text
基地整备 → 选路线并探索 → 遭遇/搜刮 → 消耗与获得资源
    ↑                                  ↓
局外整理 ← 撤离或失败结算 ← 选择继续深入或寻找撤离
```

| 系统 | 对循环的作用 | 权威入口 |
| --- | --- | --- |
| 地图与节点 | 提供路线选择、遭遇和风险递进 | [规则](../../rules.md)、[路线图](../../roadmap.md) |
| 战斗与卡牌 | 以资源消耗和效果组合处理遭遇；普通战斗与首脑战采用不同卡牌组织方式 | [规则](../../rules.md)、[卡牌规格入口](../../cards/README.md) |
| 背包与安全格 | 让空间、携带价值与失败损失进入路线决策 | [规则](../../rules.md)、[游戏全书](../../game-compendium.md)（自动生成） |
| 基地与局外成长 | 承接撤离所得并提供后续整备和成长 | [规则](../../rules.md)、[游戏全书](../../game-compendium.md)（自动生成） |
| Agent | 用结构化观察和动作接口驱动流程，并支持策略实验 | [接口协议](../../agent-protocol.md)、[迭代手册](../../agent-iteration-playbook.md) |

## 核心取舍

- 深入可获得更高层级的内容与奖励，也延长暴露于失败风险的时间；撤离把已有收获转换成局外收益。
- 背包空间有限，拾取、保留、消耗或舍弃需要围绕本局目标取舍。
- 普通战斗与首脑战在卡牌使用方式上不同，玩家需分别管理即时可用资源和首脑战编组。
- 地图路线、战斗资源和撤离选择彼此影响；避免把它们写成互不相关的奖励菜单。

## 体验支柱与待验证问题

| 体验支柱 | 设计时应保护的选择 | 后续试玩要观察什么 |
| --- | --- | --- |
| 深入与撤离的风险 | 每次继续深入都可能提高收益，也增加失去已有收获的机会 | 玩家能否说出继续或撤离的理由；是否看得懂当前带出价值与风险 |
| 有限携带资源 | 背包、安全格与消耗口袋让拾取、使用和保留相互牵制 | 玩家是否真的需要取舍；损失和回收规则是否能从界面理解 |
| 两种战斗准备 | 普通战侧重随身资源，首脑战侧重编组牌库 | 玩家能否理解何时保存关键卡、何时需要为首脑战准备 |

这些是根据[现行设计原则](../../design.md)整理的评估问题，不是已经完成的外部试玩结论。新手引导、难度曲线和整局节奏应结合实际玩家路径验证后再定具体改法。

- 项目是爱好作品，不以盈利为目标；游戏体验与 Agent 工程并重。
- 仅 Vite 网页版是当前开发范围；Godot、Unity 与桌面 EXE 冻结。
- 视觉基准是当前 Vite 实页和已定角色图；角色设定遵从[人设库](../../character-bible/README.md)中的定稿与待定标记。
- 详细玩家规则只维护在[现行规则](../../rules.md)；代码、存档与数据真源按规则页说明核对。
- 下一轮工作以代码为核心，夯实底层、达到足够好的性能、提升可修改性，并为后续人类与 Agent 制作者提供详细明确的制作文档；长期仍保持体验与 Agent 工程并重。
- 完整版本以四层主地图有明确结局为准。
- 结局路径是首脑胜利、终局撤离、清晰通关结算与简短收束；具体文案和美术在实现时另定。
- 研究所第二地图当前阶段暂缓，不纳入本轮规划与完整版本验收。
- 性能以 120 FPS 为努力目标，先测当前 Vite 实页基线与回归；不设未经证实的硬门槛。
