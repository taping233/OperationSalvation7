## 三、可疑热点登记（只有数据和现象，不下结论、不开方）

1. **照相馆目录连续滚动**：rAF 中位 48.4ms（约 20.5 帧/秒），P95 66.6ms，>20ms 慢帧占比 99.2%；滚动沿途窗口挂载把已挂载 DOM 从 24 张追到 271 张（`scrollHeight` 2094→23083），LoAF 47 次最大 78.2ms。三轮高度一致（48.4/48.5/48.4）。历史留言（09-06「库页滑动很卡」、09-24「全量渲染 271 张打开冻结 ~1.4s」）与本次数字同域。
2. **标题页出现一次 366.3ms 的 long-animation-frame**；选档页 P95 12.2ms（非 6.2）且有一次 175.5ms LoAF。两页均有常驻 CSS 动画层（标题演出/选档 bokeh 粒子），现象仅在页面打开初期出现，稳态轮次恢复 6.1/6.2。
3. **基地·仓库页一次 157.2ms LoAF**（成就页 72.6、出发页 77.3 同类）。均为切页后单次，静置轮次为 0。
4. **地图稳态的「到达重绘」**：刚到达节点的一轮 draw 可达 61–118 次，随后归零（事件驱动静态帧，与 `docs/performance.md` 的 idleFps=0 口径一致）；三轮中位因此对 draw 次数不敏感（中位=1）。属于机制确认，不是问题登记。
5. **普通战斗战场静止时 Renderer.draw 为 0 次**：战斗画面在不出牌、无演出时没有 Canvas 渲染调用（战斗为 DOM 场景）。出牌/受击瞬间的峰值未在账本口径内（见遗留 4）。
