# 地图移动与抵达

地图移动由 `game.run.flow.js` 持有整条路线事务，`map-travel-motion.js` 按曲线弧长采样。整条路线只在出发和终点加减速，中间节点连续通过；穿过节点时仍逐格更新位置、探索、回合和稳定存档，最终节点内容只结算一次。

相邻节点的移动时长按屏幕距离限制在350–450ms；多段路线按总屏幕距离安排500–2400ms。路线光痕沿用地图渲染器，推进位置与角色使用同一曲线进度。

移动期间镜头保持缩放，使用65ms方向预判，只在位置接近舒适视区边缘时平移。手动拖动或缩放取消本次自动镜头控制；原主循环不会再次抢回路线镜头。抵达后，自动路线视图仅在下一步节点超出视区时重新取景，不逐节点放大；手动视图与总览保持各自模式。

最终抵达先显示当前位置高亮和100ms扩散淡出光环，再进入节点内容。装饰光环不接收输入，随镜头坐标定位，抵达完成或上下文失效时清理。减少动态和急速模式跳过新增过渡，直接抵达并结算。后台帧暂停由事务兜底完成，失效事务回到最近提交的稳定位置。

普通战斗与已解封首脑节点在抵达反馈后直接进入战斗，不再展示接敌或决战确认页。首脑自动编组，规则见[战斗规则](rules.md#3-战斗)。祭坛尚未激活时提示封印并留在地图，不打开二级页面；已击败首脑和已结算普通战斗节点继续按安全节点收尾。
