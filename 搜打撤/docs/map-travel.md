# 地图移动与抵达

新局使用7/9探索地图：第一层至少一个非入口/出口的单路尽头，后面各层至少两个；每层至少一个尽头承载宝箱、物资或事件，所有地点可达且可原路返回，每层至多一个回环。相邻网格不自动连路。已有3/9至6/9地图按原快照和恢复契约保持拓扑。

未知区域在背景与路线之间叠加静态雾层，已揭示地点周围逐渐透开，形成不规则软边和冷灰远雾层次；雾层只读取已揭示地点坐标，不使用未揭示地点的位置、类型或连边。雾层随世界坐标平移，按揭示集和采样尺度缓存；全层已揭示时退去，不另起常驻动画。画法继续沿用低对比模糊剪影。

跨层使用独立闸口插画入场：图像就绪后约3.6秒缓慢推进，层数和当前区域名称延后浮现，再用700毫秒淡出露出地图。返回浅层显示“返回上层”；减少动态或急速模式直接跳过。图像失败保留暗底，异常准备最多6.5秒释放输入；演出不修改跨层位置和存档结算。

已揭示的同层路线按稳定散列稀疏选取，在移动曲线中段下方叠加低对比、软边的岸坡与路基剪影；长度、宽度与左右分布有差异，两端为节点和名称留白，随镜头移动与缩放并缓存。地形不表示新增通路，未揭示连接不绘制地形，节点交互与地图生成规则不变。

地图移动由 `game.run.flow.js` 持有整条路线事务，`map-travel-motion.js` 按曲线弧长采样。整条路线只在出发和终点加减速，中间节点连续通过；穿过节点时仍逐格更新位置、探索、回合和稳定存档，最终节点内容只结算一次。

多段寻路选择最短合法路线，中途可经过已知空白、已领完补给的入口和已完成的普通内容节点；尚有补给/奖励/复原待处理的地点不能自动穿过，门、祭坛、首脑及跨层关系继续使用原有边界。没有迷雾记录的旧档沿用全可见显示，对应普通中途节点也按已知处理。确认前往时以当前预览目的地重新判断可达性，打开预览后结算奖励或改变探索范围不会继续沿用旧的不可达标记。鼠标只对实际命中的图标/文字候选查询路线，按距离优先选取最近可达点；当前地点可重新进入，键盘相邻点循环读取当前连线内容并去重。

节点世界间距为180，入口初始取景以入口居中；后续定位以当前节点居中，并给四周至少一个节点间距的环境视野和额外留白，相邻地点仍保留在HUD安全区域内。边缘节点也可居中，四周允许更宽的拖拽留白。地图节点不绘制额外边框，沿用既有主体与暗色承托；空白地点保留空壳，迷雾地点不显示类型。连接路径使用三种宽笔灰色手绘素材，按连线稳定分配变体，沿实际移动曲线铺设。当前位置使用青色常驻光晕，可前往地点使用浅绿常驻光晕，选中可达点仍保留可达提示。地图不再展示操作图例和本地可达地点文字列表。

已揭示节点在名称下独立显示内容状态：未完成、待领奖、已完成、营业中或已离店。未领取的宝箱、物资候选、入口补给、祭坛回赠和剩余复原优先显示待领奖；整批奖励已处理但尚未确认收尾时，详情提示返回节点确认。纯通行节点和迷雾不显示这些标签，位置/可达光晕继续独立表达行进状态。

画布标签、节点详情与悬停说明统一使用 `mapNodeStatus`。待领奖地点提供“继续领奖”或“前往领奖”，商店提供进店入口；已完成的当前一次性内容不再提供重复进入按钮。门旁商店离店后仍可查看并使用闸门。名称与状态文字区均可用于选择同一节点，不扩大迷雾内的可交互范围；地图拓扑、移动和交易规则保持原有实现。

相邻节点的移动时长按屏幕距离限制在350–450ms；多段路线按总屏幕距离安排500–2400ms。路线光痕沿用地图渲染器，推进位置与角色使用同一曲线进度。

每段移动的32个弧长样本和逐帧位置共用该段曲线控制点；累计距离按二分查找定位样本。10-25寻路修正和模糊查询的实现范围与未核项见[本轮记录](evidence/2026-10-25-fuzzy-search-map-travel/README.md)。

地点预览开关保留当前镜头位置与缩放，只登记侧栏预留宽度，供后续显式定位或总览取景使用；预览不提供关闭×。显式进层先刷新目的地预览占位，再按新层入口取景；穿门的镜头补间不会被随后清除旧预览的刷新取消。确认前往时直接交给移动事务，不先刷新一帧关闭预览，保持侧栏inset连续。移动期间镜头保持缩放，侧栏变化不修改inset、不重新取景或覆盖travel模式。镜头使用65ms方向预判，只在位置接近舒适视区边缘时平移。手动拖动或缩放取消本次自动镜头控制；原主循环不会再次抢回路线镜头。抵达后，自动路线视图仅在下一步节点超出视区时重新取景，不逐节点放大；手动视图与总览保持各自模式。

手动拖动超过8px后按指针位移直接平移地图，不在拖动途中追加补间。松手后按最近100ms的速度减速；拖住停稳再松手时不续滑。拖动边界按当前层全部节点的包围盒、缩放、窗口及详情侧栏计算，为图标、标签和上下HUD保留留白；边缘额外保留80px拖动余量（以1280px画布宽度为基准，最多为可用轴长的12%）。整层能完整显示的轴只允许在居中位置附近有限移动。边缘拉动增加阻力，松手回弹至该边界。释放阶段复用项目已安装的 Motion 惯性发生器，不增加依赖。新拖动、缩放、程序取景、失焦或打开页面会中止惯性；减少动态时直接停止。节点点击仍以按下时锁定的世界位置判断，拖动不触发节点选择。

节点图标、文字、道路与当前位置标记沿用原有按倍率调节细节大小和屏幕尺寸补偿的绘制方式。手动滚轮每次按1.12倍或其倒数缩放，倍率范围为0.08至2.45；探索自动定位最高3.4倍。鼠标锚点在合法拖动边界内保持稳定，到达边缘时按边界钳位。

最终抵达先显示当前位置高亮和100ms扩散淡出光环，再进入节点内容。装饰光环不接收输入，随镜头坐标定位，抵达完成或上下文失效时清理。减少动态和急速模式跳过新增过渡，直接抵达并结算。后台帧暂停由事务兜底完成，失效事务回到最近提交的稳定位置。

事件等整页返回地图时，在原场景淡出前准备地图画面，复用同一跑局的背景缓存；保留220ms退出窗口，场景与共享顶栏一同收尾后再恢复地图归属。透明输入层仅保护首帧准备，不另加黑幕。减少动态与显式立即关闭仍同步收场。

普通战斗在抵达反馈后直接开战。已解封首脑节点先显示独立牌库与迎战说明，可整理或返回地图，确认后进入手动牌库编组，选满所需张数再开战；规则见[战斗规则](rules.md#3-战斗)。祭坛尚未激活时提示封印并留在地图，不打开二级页面；已击败首脑和已结算普通战斗节点继续按安全节点收尾。
