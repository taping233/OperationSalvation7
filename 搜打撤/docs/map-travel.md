# 地图移动与抵达

地图移动由 `game.run.flow.js` 持有整条路线事务，`map-travel-motion.js` 按曲线弧长采样。整条路线只在出发和终点加减速，中间节点连续通过；穿过节点时仍逐格更新位置、探索、回合和稳定存档，最终节点内容只结算一次。

节点世界间距为180，自动取景围绕当前与相邻地点保留较宽的屏幕间距。地图节点不绘制额外边框，沿用既有主体与暗色承托；空白地点保留空壳，迷雾地点不显示类型。连接路径使用三种宽笔灰色手绘素材，按连线稳定分配变体，沿实际移动曲线铺设。当前位置使用青色常驻光晕，可前往地点使用浅绿常驻光晕，选中可达点仍保留可达提示。地图不再展示操作图例和本地可达地点文字列表。

已揭示节点在名称下独立显示内容状态：未完成、待领奖、已完成、营业中或已离店。未领取的宝箱、物资候选、入口补给、祭坛回赠和剩余复原优先显示待领奖；整批奖励已处理但尚未确认收尾时，详情提示返回节点确认。纯通行节点和迷雾不显示这些标签，位置/可达光晕继续独立表达行进状态。

画布标签、节点详情与悬停说明统一使用 `mapNodeStatus`。待领奖地点提供“继续领奖”或“前往领奖”，商店提供进店入口；已完成的当前一次性内容不再提供重复进入按钮。门旁商店离店后仍可查看并使用闸门。名称与状态文字区均可用于选择同一节点，不扩大迷雾内的可交互范围；地图拓扑、移动和交易规则保持原有实现。

相邻节点的移动时长按屏幕距离限制在350–450ms；多段路线按总屏幕距离安排500–2400ms。路线光痕沿用地图渲染器，推进位置与角色使用同一曲线进度。

移动期间镜头保持缩放，侧栏变化不修改inset、不重新取景或覆盖travel模式；抵达后的侧栏变化使用平滑取景。镜头使用65ms方向预判，只在位置接近舒适视区边缘时平移。手动拖动或缩放取消本次自动镜头控制；原主循环不会再次抢回路线镜头。抵达后，自动路线视图仅在下一步节点超出视区时重新取景，不逐节点放大；手动视图与总览保持各自模式。

最终抵达先显示当前位置高亮和100ms扩散淡出光环，再进入节点内容。装饰光环不接收输入，随镜头坐标定位，抵达完成或上下文失效时清理。减少动态和急速模式跳过新增过渡，直接抵达并结算。后台帧暂停由事务兜底完成，失效事务回到最近提交的稳定位置。

普通战斗在抵达反馈后直接开战。已解封首脑节点先显示独立牌库与迎战说明，可整理或返回地图，确认后进入手动牌库编组，选满所需张数再开战；规则见[战斗规则](rules.md#3-战斗)。祭坛尚未激活时提示封印并留在地图，不打开二级页面；已击败首脑和已结算普通战斗节点继续按安全节点收尾。
