# 共用结算重试控件反馈

死亡与放弃入口均复用 terminal-settlement。此前等待重试请求时，按钮仍显示可点击的「重试结算」，只由内部 busy 防止重复提交；玩家看不到请求是否开始。现补原生 disabled、按钮 aria-busy 与「正在结算…」，独立 status 播报「正在保存结算，请稍候…」。失败后原失败页重建恢复重试，成功仍由原 finish 接管。

只修改公共组件一次，沿用 .ov-btn 已有禁用/悬停样式。不调整布局样式、主题、事务、防重复或玩法；不增加订阅和计时器。

## 选择依据

从已有二级token规范与 quality:styles 五份样式审计开始：0错误、5条字号warning。分别是翻页箭头25px、卡面比例30px、容量数字38px，以及两个14px英文标注。它们不是已确认设计错误，没有为清空报告改字号。按钮焦点已有2px/4px token，原生disabled已普遍接通，故转查动态反馈未接入处。保存退出与入库已有等待反馈，终局公共重试缺失属明确差异。

## 验证

- 修改前新增两个入口断言均失败：点击后 disabled 仍为 false；原幂等项通过。
- 修改后4文件15项通过：terminal-settlement、terminal-retry-copy、terminal-persistence、terminal-death。覆盖死亡/放弃请求中提示、重复动作不增加提交、失败恢复可用按钮、沿同attempt成功及原有持久化/文案约束。
- 相关ESLint、生产文件语法与8个类型配置通过。自有diff确认只有反馈DOM/状态与可选UI元素类型扩展，没有资源消费者/路径变化，不刷新素材指纹。
- 未运行全量/build，未提交或推送。当前平台内置浏览器连接限制沿用，视觉和屏幕阅读器实际播报尚未验；DOM断言不替代这些实页检查。范围不涉及发布会话预算脚本或其performance文档段落。
