## 来源与恢复
内置image_gen制作；首轮提示词见[request](request.json)，当前提示词、画风及结构参考见[request-v2](request-v2.json)。图像以同一张元素爆裂为输入参考，生成稿不是原画像素级复制。二进制PNG由预览目录.gitignore排除，复制来源、相对路径、字节数、尺寸与SHA256由receipt.json维护；同机器从source复制到path后校验哈希，跨机器需取得同一PNG。
