# 界面操作、文字与颜色层级

2026-10-25，Friday，`WF-interface-hierarchy-1025`。老板授权继续落实上一轮建议；本轮完成优先的操作主次、文字层级和颜色语义，复用此前官网拆解，没有重新联网研究。

## 实现

- `secondary-ui-tokens.css` 增加明确命名的普通界面字级、操作与状态变量；原有战斗/交易等局部变量保持原定义。
- `public-controls.css` 统一显式 `.ui-control[data-ui-action]`：主操作浅冷色实底，次操作低对比描边，轻操作透明，危险操作红色。照片查看、留言保存、预设应用及危险确认从原始标记接入，原事件标识和业务守卫保持。
- 收藏页头、成就、照片操作/详情、预设、设置和确认/留言引用字级变量。页面标题30、对象名26、正文22、控件20、辅助18、注释16、强调数值24，沿既有设计画布缩放；数据计数沿用等宽数值。
- 成就筛选/选中与设置分类统一冷色标记；预设就绪为绿、待处理为琥珀色，文字同时说明状态。保留照片稀有度、奖章原图、奖励进度金色、纸面和场景材质。
- 删除旧确认按钮私有配色、留言保存金色规则、预设金色应用规则、照片查看按钮的重复底色/悬停规则，以及设置各分类重复色值。原定义修改，没有增加末尾纠正层或新的 `!important`。

现行接口见[公共界面组件](../../ui/shared-interface-components.md)。原字节基线在本机 `.tmp/interface-hierarchy-baseline/`，源码归属与SHA256见 `source-manifest.json`，本轮相对快照的增量见 `source-delta.patch`。
