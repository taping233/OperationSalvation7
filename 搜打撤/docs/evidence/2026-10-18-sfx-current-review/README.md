## 播放失败修复

老板反馈全部无法播放。定位时直接读取Vite返回的模块：动态 `new URL('../../${file}', import.meta.url)` 被转换为只覆盖根目录项的glob映射，未包含深层音源，导致读取内容无法作为音频解码。直接读取原创点击WAV返回HTTP200和audio/wav，文件存在。现改用游戏现有 `assetUrl(file)`；服务返回的模块已使用该方法，且不再产生这组glob导入。具体记录见 [地址修复](playback-fix.json)。仅修资源地址，不改音效/音量、选择标记或游戏映射；未运行测试、构建、浏览器及听感验收。
