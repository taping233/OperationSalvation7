## 素材与入口

本轮未新增生图。保留原始资产与兼容URL导出，仅减少高频入口对插画的实际使用；只有 `renderer:'image'` 才生成图片节点，短切使用简单原生遮罩、光幕和线迹。旧素材未删除，资产来源仍见前轮 `2026-10-25-departure-cinematic/`、`2026-10-25-unified-silent-transitions/`。

`cinematic-profiles.js` 维护 renderer、主演出和退场方式；`silent-node-film.js` 根据 renderer 生成整幅图片或程序化舞台，支持无图片入口的准备契约；`silent-node-film.css` 分别实现光学显影、相机推进、遮幕穿越和短切。

`departure-cinematic-review.html` 将完整演出与日常短切分开陈列。程序化短切自动播放结束，避免将已经消失的线迹误当作可定格插画。预览使用私有内存Storage，不读写真实存档。本轮未打开该页验收。
