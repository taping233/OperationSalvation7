# 游戏性能优化 · 2026-10-16

本轮改善地图 CPU 热路径、连续缩放的纹理烘焙与画布分配，以及后台美术预取。玩法、素材、预热清单与渲染分辨率沿用现行实现。工作树起点 HEAD `63c4309060`，包含其他会话已完成未提交增量；未构建、暂存、提交或推送。

## 改动与归属

- `map-node-state.js` / `node-restore-state.js`：任意节点复原查询直接接受坐标，停止在每次查询中展开整个游戏对象；原单参数 API 和记录校验沿用。
- `renderer.js` / `node-info.js`：每次绘制只求一次几何、路线和各节点状态，标签与道路裁剪复用本帧结果。投影不跨帧缓存，奖励记录原地变化不会滞后一帧以上。既有标签命中、节点状态与相关未提交实现保留。
- `renderer.js` / `map-brush-art.js`：道路拓扑与画布在同一几何缓存内复用；离屏道路不裁剪、不烘焙，移回视口按当前缩放、选中和内容状态补齐。透明纹理外缘也纳入保守包围盒，曲线两端在屏外但中段穿屏时保留。
- `map-brush-art.js`：按曲线二阶导数选择 8–40 个纹理切片，短曲线中心线弦误差目标不超过缓存像素 1/8；达到旧40片上限时保持旧精度。素材与缓存像素密度不变，切片重采样会产生少量像素差异。
- `art.js`：预取响应流式消费，不拼接完整 ArrayBuffer；页面隐藏、移动或存在待处理输入时暂停下一批，恢复后继续原清单。不支持流的环境回退旧路径；失败释放读取器并保留重试能力。

只编辑上述文件的性能增量、自有测试和本证据；相关节点状态/复原文件的既有未提交内容仍属原任务。最终源码指纹见 [source-fingerprints.json](source-fingerprints.json)。

## 同窗口热点基准

Codex 内置浏览器 tab1，复用 `http://127.0.0.1:5200/?perfProbe=1`，当前窗口 1523×956、DPR 1.25；没有覆盖视口尺寸。使用同一份 [benchmark.js](benchmark.js)，在脱离页面的 Canvas 上绘制48个已知节点，并额外设置300个运行态字段；这是一项放大热路径开销的受控微基准，实际测试局游戏对象观察为91个字段。每项5轮，表中为每轮单次平均耗时的中位数，不是玩家屏幕 FPS 或全流程收益。

| 指标 | 优化前 ms | 优化后 ms | 降幅 |
| --- | ---: | ---: | ---: |
| 48节点状态+完成度投影 | 4.886 | 0.016 | 99.7% |
| 稳定地图绘制 | 10.647 | 0.510 | 95.2% |
| 每次改变缩放后的绘制 | 39.245 | 10.080 | 74.3% |

原始五轮：[优化前](benchmark-before.json)、[优化后](benchmark-after.json)。缩放包含同步纹理烘焙和分配，仍会受浏览器栅格化和回收调度影响；本数据不保证稳定120 FPS。中间方案曾只做离屏裁剪与减少切片，连续分配使后段采样升高，最终通过固定每条道路画布消除这一主要分配来源。

## 实页与输入范围

- `SDT.Agent.scenes.run('shop')` 构造无档位测试局：4项断言通过，10步收口，`errors=[]`，最终回地图，生命30。属于构造场景，不代表真实新档完整流程或战斗试玩。
- 地图探针6秒受控平移：绘制中位0.4ms、p95 0.6ms、最大0.9ms，长任务0；[原始报告](map-pan.json)。探针主动使绘制失效，报告约144Hz是 rAF/绘制调用率，不等于屏幕 FPS，也不是正常移动调度器交付帧率。
- 原生滚轮与拖动输入：缩放从3.07875变为2.1875；拖动后镜头中心从(264.2434,792.8351)变为(332.8148,769.9779)。观察到道路随视口更新、节点标签/状态保留，无浏览器 error。
- 交互结束后6秒静止地图：draw 0次、主循环24次、长任务0；[原始报告](map-idle.json)。这验证现有空闲停绘行为得到保留。
- [纹理对照脚本](visual-compare.js) 使用原40片[基线实现](brush-baseline.js)和新实现绘制四条道路。[左右对照截图](roads-ab.png)目视纹理和曲线保持；320000像素的alpha平均绝对差0.122/255，有笔触像素平均差2.016/255，最大71/255，1208像素差值>10。该对照只验证四种道路，不等同全图逐像素一致。
