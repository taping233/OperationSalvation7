采用重新取得的 [Spec Kit 官方规格模板](https://github.com/github/spec-kit/blob/main/templates/spec-template.md) 的用户旅程、验收场景、需求、边界与可测结果结构。此前试用工作区丢失，本文件是本次新规格，不是恢复的旧 CLI 产物；没有运行或冒称执行 Spec Kit CLI。官方文件 blob 见 official-reference-manifest.json。

## 用户旅程

P1：玩家关闭弹层后继续游戏，连续按返回或旧回调抵达时，关闭只生效一次。
- 已隐藏时再次关闭：不广播关闭、不改变返回令牌、不打断其他反馈。
- 正在淡出时再次关闭：保持原收尾时间，不重复事件、清理或声音。

P1：离场跳转要求立即结束淡出，随后打开下一页。
- 淡出中立即关闭：完成现有收尾一次，清除旧定时器。
- 淡出中重开：旧收尾不能清空新页内容，也不能隐藏新页。

P2：键盘和辅助技术使用者保持可辨认的页面与返回入口。
- 页面有对话框名称、按钮名称、稳定焦点返回；重复关闭不重复影响焦点或背景隔离。

## 功能需求

FR-01：真实“开→关”才推进一次关闭令牌和关闭事件。
FR-02：隐藏态/关闭态重复普通关闭是无副作用操作。
FR-03：立即升级复用原收尾，不重放关闭初始化。
FR-04：新的打开取消旧关闭尾巴。
FR-05：可选背景、提示、大卡处理器缺失时仍可安全关闭。
FR-06：遵守既有房间瞬隐、减少动态效果、淡出时长；不引入新的动效系统。

## 边界和可测结果

隐藏→关；开→关→关；开→关→立即；开→关→开→时钟推进；处理器为空；完整时间结束。通过固定 seed 的200条随机动作序列与确定性例子检验状态/事件/令牌；测试应能杀死关键守卫变异。DOM 可访问性检查限定标签和 ARIA，不声称覆盖像素、对比度或真实操作体验。

## 设计指南实际审查

[Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)：用于审查焦点管理、可中断动效与减少动态效果。选择修补同一弹层公共关闭入口，保留既有时间及返回焦点机制；不逐页面复制关闭逻辑。真实窗口的焦点可见性、视觉动效尚未验收。

[Impeccable 官方源](https://github.com/pbakaus/impeccable/blob/main/skill/SKILL.src.md)：采用操作型界面的可预期与一致性、边界加固和组件复用原则。此次不改视觉风格，不安装其全局 hook、浏览器扩展或执行类技能；这是对官方设计原则的代码/规格审查，不是其 CLI 扫描或渲染审美通过证明。
