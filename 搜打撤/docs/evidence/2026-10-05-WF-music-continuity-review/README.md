# 三首连贯性复核与重写 · 2026-10-05

老板反馈探索／战斗V4仍不连贯、听感很累，要求检查并实际参考别人的工程和经验标准。范围确认后为标题、探索、战斗各重写一版，共三首；不是每首三个候选。

交付为《霜窗回声》V9（91.43秒／84BPM）、《灰线行军》V5（102.86秒／112BPM）、《黑脉交锋》V5（92.90秒／124BPM）。同名MP3供试听，WAV／OGG／冻结分轨MMP保留。旧标题V8、探索／战斗V4及其工程、音源和游戏没有覆盖。

## 找到的问题

重新读取三份最新WAV，在250ms声能曲线上检查段落边界前后各2秒的中位数。探索V4从空地回到主段的落差约9.84dB，战斗V4释放后反击约13.97dB；这两个结果不受整体固定音量影响。原编排同时撤掉／加入多条声部，CC11每拍直接改整数值，段落起点的表情数值也阶梯变化。**上一版在增加配器时，没有充分保护主线和底层的连续性，转场过猛。** 不把LRA增大继续当作改善。

谱面还显示探索V4主线有35个音短于350ms，战斗有81个，后者中位音长约340ms、连续相邻跳进至少七半音28次。全轨音符触发密度分别5.88／8.55次每秒；此数是谱面触发事件，不是音频算法起音数，更不是人味指标。

单音测试直接使用当前GeneralUser GS／FluidSynth：A4、力度60，10ms RMS首次达到0.5–1.2秒持续段中位数的一半，快弦乐program48约130ms，慢弦program49约210ms，小提琴program40约80ms，双簧管／单簧管约50／40ms。这提示340ms的弦乐音符容易主要停留在起音阶段。测试只覆盖一个音高和力度，不是所有音区的固定延迟，不据此断言每个短音都错误。

标题V8的同类段落落差最大约2.98dB，没有探索／战斗那么严重；其250ms相邻强弱变化P95仍为7.38dB，较密的钢琴起音及句尾衰减可作为听感疲劳的检查方向。未经人工试听，不将这些数据当作听觉疲劳的唯一原因。

证据见 [audio-diagnosis.json](audio-diagnosis.json)、[score-diagnosis.json](score-diagnosis.json)、[attack-probes.json](attack-probes.json)。

## 实际读取的工程与经验

实际从 [LMMS Sharing Platform 项目9365](https://lmms.io/lsp/?action=show&file=9365)下载并解压了 VortexSupernova 的《Spring Wind》工程，原生项目说明写明A大调及作者。解析得到背景在第4小节、Melody在第6小节、Harp及合唱背景在第9小节进入，另有更长的保持声部；借鉴的是分阶段进入、旋律／伴奏职责及持续背景思路，没有复制其音符、旋律、音频或预置。该工程并非纯管弦录音，风格差异保留，不把它当作本项目的审美标准。

还实际解压了现有LMMS随附的 Ashore、Impulslogik-Zen、Skiessi-TurningPoint 三份工程，检查pattern进入位置、音符长度及编排分层。它们偏电子，只作工程组织参照，未渲染或借用它们的音色。四份工程来源与SHA256、解析结果见 [project-audit.json](project-audit.json)。下载的压缩项目仅本地忽略保存，未运行其插件或项目脚本，不作为可分发的游戏素材；共享页失败／下载URL HTML转义错误的早期记录保留，最终成功读取以project-audit及指纹为准。

经验依据是 Spitfire 对[音源起音／MIDI offset](https://support.spitfireaudio.com/en/articles/11816103-what-is-a-midi-offset-and-how-can-i-use-it)和[管弦声部预延迟调整](https://support.spitfireaudio.com/en/articles/11816101-how-to-clean-up-your-orchestral-scores-with-pre-delay)的说明，以及前轮已读的[力度、表情与颤音区分](https://support.spitfireaudio.com/en/articles/11816091-what-is-the-difference-between-dynamics-vibrato-and-expression)。采用“按实际音源起音安排时值、给长声部接续、保留自然起音”的原则；未安装或使用Spitfire采样。此次40ms的部分弦乐提前量是候选制作选择，不宣称所有音高已精准对齐。

## 三首具体重写

标题V9将主旋律改为更长的歌唱式乐句，从约100余音的原写法收为52音，首段主题轮廓保留，伴奏更疏。钢琴主线中位时长1.47秒；单簧管从句尾跨到下一句，返回A第一音放轻。保留第一拍的管弦支撑、真实钢琴CC64、古典配器方向，使用8条分轨。

探索V5把速度116降至112，保留连续钢琴、低音和弦乐桥；空地段由双簧管在两小节范围内逐渐接管，钢琴没有骤然消失。拨奏承担短音脉冲，木管只在乐句空隙回答，减少同时在前景活动的声部；11条分轨。主线中位时长1.05秒，谱面总触发密度5.88→3.36次／秒。

战斗V5把速度132降至124，主线交给较合适的长小提琴音，短脉冲由拨奏和低部承担。释放段保留低音、弦乐桥及主线，铜管逐渐接续，不再整组骤入骤出；13条分轨。主线中位时长1.02秒，触发密度8.55→5.68次／秒。重叠同音改为保持音，避免MIDI旧note-off释放刚刚重触发的同音；连续背景的共同音也作接续。

表情处理不再每拍阶梯切换段落CC11：保留实际MIDI expression的稳定值和钢琴CC64，把渐进交接／乐句呼吸写成逐样本线性增益。另有缓慢的整体音量平衡，允许范围±2.5dB，保留瞬态，不用瞬态限制器强行压峰；实际范围在各render report中。三首统一−18.50LUFS，便于相互试听，不把“更小声”当成连贯性证据。

未人工试听，无法保证“听感疲劳已消除”；技术证据支持已处理若干明确原因，最终由老板听感决定。没有游戏全量／构建、没有改游戏或全局配置、没有提交。没有新服务，离线演奏已结束。
