# 背包关闭重开浏览连续性

同一对局里，关闭再打开背包、安全格或消耗区会恢复列表双轴滚动以及卡牌/工具焦点。分区、筛选和排序沿用既有状态。实现复用容器与丢弃确认的 `captureBackpackPosition` / `restoreBackpackPosition`，不新增存档字段或玩法规则。

## 复现与修复

1. 打开背包，选「招式」，滚动列表并聚焦一张牌。
2. 按背包切换键关闭，然后再次打开。
3. 旧实现保留筛选却把列表滚动重置为 0；安全格和消耗区同样丢失位置。原独立副本的 `baseline.log` 中三个新增场景失败，其余 11 项通过。
4. 修复后复用原位置快照；工具按钮通过动作及其筛选、帮助页、分区标识找回对应节点，防止安全格/消耗区导航误聚焦第一个背包按钮。

来源页返回钩子保持一次性消费。换局、替换卡牌数组或进入不同分区不恢复旧位置。容器返回与丢弃取消/确认继续共用相同逻辑。
