## 本轮实现

对 `game/assets/scenes/battle/platform-painterly-1025-v3/` 四层分别使用内置imagegen编辑，每次均输入现行图层及同一组默认画法参考：双图 `reference-full.png` / `reference-detail.png`、九图07与09。双图控制结构性块面和笔触尺度，07/09控制彩色灰、冷暖覆色和有轻重的边缘；只借画法，不复制人物、服装、文字和水印。

- `far.webp`：远桥和城市的位置沿现行构图，天空、云层及远雪改用冷蓝/灰紫的覆色和有方向的笔触，远桥保留大形与低细节。
- `mid.webp`：保留右侧候车棚和开窗，重新组织雪顶厚薄、钢架暗面和局部反光；暖窗以成组色块表现。
- `ground.webp`：保留原雪面与三块站台立面，雪面增加暖白、蓝紫的叠压切面，钢板增加方向性笔触与克制磨损，左侧保留灯光映色。
- `foreground.webp`：保留棚架、两柱和工业灯，金属由平滑暗面改为冷暖灰块面、选定接缝与受光边；暖光集中于灯附近。

四张均保留1659×948全画布，远景RGB、其余三层RGBA透明；仅常规WebP质量94编码，没有裁切、缩放、像素滤镜或合成加工。运行文件总计508350字节。消费者源码与URL沿用，manifest仅更新这四条字节数/SHA256/来源说明。
