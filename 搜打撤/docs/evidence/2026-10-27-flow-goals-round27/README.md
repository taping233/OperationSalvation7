## 实施结果

- 应急药品站与转运军需候选页退出`bt-hand/event-choice-hand`网格，接入顶层正式领奖页、卡片单元、列表/放大领取和返回控件，状态变化使用局部更新。满包提示、列表与放大共用可接收判断；Apollo保留原主卡/附赠待领奖交接。候选、付款、领取互斥、保存和异步退出沿原业务。
- 地图、背包与腾位返回沿节点记录保存浏览状态；公共领奖焦点允许声明领取/返回动作组，入口补给、物资及事件页共用下一可用动作恢复。
- 奖励腾位删除原同名全量合并逻辑，改用正式背包叠查询；同名六张普通卡拆成两叠，移动安全格只传所选叠的UID，丢弃仍按所选叠中的一张处理。容量和支付规则沿原命令。
- 撤离整理把仓容总数单位改为格，说明卡牌每张、符文每块各占一格；剩余能入库的卡牌数量仍以张表示，扩建帮助同步单位。
- 已核对其余事件网格消费者，本批保留仍在使用的CSS，现行二级界面说明同步。

源代码与相关差异用于集成核对；本批未运行测试、lint、构建、检查脚本或实页验收。没有新增服务、删除文件、暂存、提交或推送。
