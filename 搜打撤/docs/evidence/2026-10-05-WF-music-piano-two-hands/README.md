# 双手钢琴修订 · 2026-10-05

老板反馈钢琴像只有一只手。检查确认：探索V5只有单条钢琴主线，标题V9钢琴和声每两小节仅两个音、标定活动声能比主线低9dB；战斗V5钢琴间奏只有4个单音。

本轮三首仅改钢琴相关部分，交付标题V10、探索V6、战斗V6。三首的右手音符、节奏、长度与力度均保留；新增独立左手，战斗限定于原有钢琴间奏，不改管弦主体。非钢琴冻结分轨按原SHA256逐字复用，最终整体混音增益重新匹配到原来−18.50LUFS。旧版本保留。

左手每两小节四次动作：低音、双音和弦、上方低音、较轻的和弦回应。使用和弦音及开放排列，避免连续八分音符增加疲劳；同时按右手音区下移左手声部。各次左手同时按键的跨度不超过八度，破开的低音／和弦动作可分别移动；保留实际CC64延音踏板。左手偏左、右手偏右安排，低频仍受原混音口径控制。

同名MP3供试听，WAV／OGG／MMP保留，另有 `*-piano.mid`。MIDI为Standard MIDI File格式1：tempo轨、右手轨、左手轨，左右手分别使用channel 1/2，包含原始音符、力度、声像及CC64，方便明确查看两只手。三份score JSON也明确标记hand。冻结MMP依赖本会话与前轮ignored临时分轨，属于母带处理前混音工程，未另外以LMMS再渲染；移机需带分轨或重生成。

40项必要检查通过，见 [verification.json](verification.json)：右手源音符精确保留、左手有低音与和弦、同时按键跨度、四次动作限额、双手实际声能、非钢琴分轨一致、文件指纹、独立解析MIDI音符数／踏板／时长、48k双声道、有限值／无削波、同响度、MP3／OGG解码及循环接缝。没有人工试听，不宣称两个声部出现就等于好听；左手是否够清楚、整体是否保持舒适，由老板试听判断。
