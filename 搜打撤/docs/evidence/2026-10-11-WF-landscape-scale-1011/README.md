# 固定横屏比例缩放

游戏统一使用 1920×1080（16:9）布局，按窗口宽高比例的较小值缩放，布局原点在窗口左上；多余区域留边。旧竖屏、窄窗重排、基地逆缩放和退出键局部补偿规则已从运行样式移除。

老板原指令为「缩放只能基于同一个横屏比例缩放，不用适配竖屏」，追加「把旧有规则删掉」；发现战斗、地图、选人 CSS 仍被他会话占用后，老板明确允许保留其他改动、仅移除旧尺寸适配规则。

## 改动与来源

- `ui-scale.js` 固定逻辑画面尺寸，并提供不含留边的显示尺寸；`ui-scale.css` 固定布局及 fixed 弹层边界。
- 从实际 HTML、模块导入、动态导入、URL 样式入口及 CSS import 追踪 78 个运行样式；45 个文件发生尺寸相关修订。移除 90 个尺寸适配分支，将 3 个基准下生效的桌面分支并入常规样式；251 处窗口单位改用固定游戏尺寸变量。原有减少动画等设置保留。未加载的旧展示样式与独立工具页不在本轮范围。
- 词条浮框、战斗拖牌和照相馆筛选框改用游戏画面的边界。照相馆筛选计算先换算到布局坐标，避免缩放后的显示坐标混入 CSS 尺寸。
- 现行说明仅更新 `docs/development.md` 对应缩放和旧补偿描述；他会话现有未提交内容保留。
- CSS 路径、修改前后 SHA256 与数量见 [迁移清单](css-migration.json)；收官源码指纹见 [最终指纹](final-fingerprints.json)。修改前副本及一次性迁移脚本留在 git 忽略的 `.tmp/fixed-landscape-1011/`。
