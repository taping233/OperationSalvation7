# 锦鲤动态前景修订

本轮只修改锦鲤运行时、来源说明与专项测试。新底图和庭院控制器由根会话维护；本子任务没有启动服务、构建产物或使用浏览器。

## 可见变化

- 每条鱼从多节粗描边改为一个闭合二次曲线轮廓；头部更宽、尾柄收窄，尾部摆幅沿身体递增，转弯时身体顺势弯曲。
- 暖白、朱红、淡金与炭灰以少量不规则色块叠在完整鱼身上；胸鳍和尾鳍缩小并半透明，粗黑阴影改成浅青灰投影。
- 鱼长为池宽约 3.6%–5.4%，矮画布另按高度限制；缓慢巡游，点击投喂后平滑转向并略加速趋近。
- 鱼体和投喂位置保留四周约 10% 的岸边安全域，缩放按原位置比例重新映射。引擎只清绘透明动态前景。
