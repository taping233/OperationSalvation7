本轮按老板最新优先级完成页面职责、跳转和返回，再修当前窗口看到的比例、配色、线条与动效。状态：完成未提交。接续上一轮 `WF-base-iterate-1011`；壁纸继续暂缓。

## 已实施

- 后勤直接展示仓库，补给和扩建按需进入；待复原只在有数量时出现入口，保留出征清空警示。
- 队员默认人物培养，招式、外观、伙伴为独立页；孵化再进入单独页，先返回伙伴。取消常驻双行页签和重复眉题。
- 收藏室只展示已收藏记录；奖励页合并可领取的成就和收藏奖励，成就目标及收藏里程碑另页查看。卡背解锁目标返回卡背。
- 返回键与Esc统一父级；培养仓库经补给返回保留人物及筛选；主页后勤快捷入口清理旧筛选；空态区分没有候选与搜索无匹配；主页待领取数量合计两类奖励。
- 共用冷灰纸面、深色标题与克制金色操作线。人物横图按原比例收束展示，补给原画保持比例；当前窄面板按阅读顺序换行，修复人物被挤出与返回键过小。
- 庭院合并观鱼、观雨；环境设置收纳声音、暂停、雨势与三组配色。浅水池底采用自有生成画面，透明锦鲤前景保持互动；雨景自写透视雨台、细雨线和投影水圈。一个循环管理暂停、减少动效、隐藏和销毁。

层级与研究依据见 [hierarchy.md](hierarchy.md)。NN/g渐进披露、游戏可用性和视觉层级用于职责与主次；星铁图鉴/成就、方舟主入口/仓库/商店复用上一轮实机记录；两份小红书视频本轮实际目检。GitHub候选只作比较，未复制无清楚许可的代码或安装三维依赖。
