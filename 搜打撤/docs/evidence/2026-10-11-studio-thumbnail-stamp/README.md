小图相纸名称下增加类别印章，与类型底注共用一行，不覆盖图片。全部分类显示类型和印章；具体分类继续隐藏重复类型，印章保留。名称保持完整可用宽度，过长名称沿原省略样式，悬停提示包含全名与类别，无障碍名称同步包含类别。窗口化和缓存仍复用原照片HTML。
