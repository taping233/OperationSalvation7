# 十个独立声音设计试样 v6

- 老板明确允许重新制作旧认可样音，要求查询资料经验、提高辨识度，先做十个。v5 整库的整体听感已被否定，不能继续作为已通过候选。
- 仅本目录、独立试听页自有文件及 game/assets/sfx/winter-v6-ten/；沿用 5391 / exec 26494 试听服务，不安装软件、不 build、不接游戏调用、不提交、不删除。
- 第一批十个：点击、确认、出牌、斩击、格挡、破盾、治疗、进入事件、开箱、首脑登场。每个独立设计材料与动作，停止用同一频带模板批量扩套。
- 阅读依据：[UI 声音设计语义与层级](https://uisfx.com/ui-sound-design)、[Google 交互声音访谈](https://design.google/library/ux-sound-haptic-material-design)、[Faust 模态共振模型](https://faustlibraries.grame.fr/libs/physmodels/#modalmodel)、[Kenney Casino Audio](https://kenney.nl/assets/casino-audio)。
- 应用方式：先分清动作；将起音、材料主体、反馈落点分开。金属使用非整数共振模式，破盾使用分散碎片，治疗使用调制/共振声部，卡牌用纸张层；这些是本轮设计推论，不把网页描述当作方舟实际听感结论。
- 追加方舟攻击/命中/治疗候选参考五个，来源见 reference-sources.json，仅用于结构研究，未接入成品。
- 原创方案：独立合成各声音，出牌使用从 Kenney 官方重新取得的 CC0 纸张操作录音作为素材层，重新剪辑、变速与分层；不使用方舟原音频采样，不复制其音高/节奏/包络。材料与许可见 materials/source.json。
- 当前工具仍不能代替人工听感评价。本轮以十个少量试样供老板判断，不宣称已完成专业听感验收。
- 状态：研究与制作中。服务/编辑占用归 WF-sfx-listening 的自有登记行。
