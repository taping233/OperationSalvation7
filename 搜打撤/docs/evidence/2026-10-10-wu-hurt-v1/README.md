# 无连续受击制作

老板表示攻击v7“这版还可以”，随后要求制作受击。本版按认可的当前立绘、刚性剑、干净底图与待机制作，攻击v7源码及资产只读。

新增受击曲线：快速后撤与肩胸后仰，双手回收，头发滞后，脚底固定；短暂冲击停留后缓慢恢复并小幅回弹。约0.72秒、43帧、60帧/秒，冲击阶段少量模糊残影可关闭。

当前Codex内置浏览器、当前窗口通过真实按钮和滑杆查看受击冲击、关闭残影后的姿势、恢复和首尾；截图保存于本目录。301点检查剑刃护手到剑尖约320.34源像素，长度与画布边界通过。输出帧还检查已认可版待机端点、脚底、不同帧数和逐帧剑尖像素，实际结果见资产目录`validation.json`。

独立候选未接入战斗，受击观感待老板确认；没有修改攻击、玩法或运行帧。复用5200，无新服务、build或提交；没有多窗口尺寸检查。
