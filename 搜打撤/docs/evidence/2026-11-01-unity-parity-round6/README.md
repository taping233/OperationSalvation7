# 第六轮对照、精简与验收

本轮修正发现与献祭的完整流程、当前卡库读取、基地派生数据与成功音、音乐失败重试、隐藏页更新和整档依赖检查。全部实施集中冻结后统一验收；正常播放器逻辑通过后，人工看图发现真实越屏问题，修正共同容器并补验后才列为通过。持续目标仍为active，本页只结算本轮。

## 改动与有意改进

- 发现使用当前战斗及选择轮次身份，拒绝旧页面回调；取消保留已结算部分，牌库底实体按原序归还。迷匣按真实Source两次确认与费用交换实现，8个实际JavaScript来源场景对照随机流及候选。
- 纯发现先展示候选再支付；取消不消耗来源或能量，同回合重开复用候选。首次确认重新核对资格并支付一次。原版道具amount为0却发1份奖励的行为改为不取样、不发奖励，正常消耗规则保留；这是明确改进，不列为等价证明。
- 献祭展示正式卡面和费用变体，按UID保留选择控件与滚动位置；返回时重核资格和所属状态，失败回滚重建Map后拒绝陈旧页面。紧急献祭真实消耗所选三张并进入撤离整理。
- 地图道具与事件使用当前CardLibrary，重开已有发现回执只读；已保存金币回执返回不重复整档写入。金币当前不是自然地图生成路径，此项收益限于保留命令及受控场景。
- 基地按实际页面需要汇总收藏与里程碑，单人物直接查询；已全领奖的主页不扫描收藏。仓库/背包升级、两处孵化成功各播放一次对应音，失败不播放成功声。
- 音乐切换失败保留上一有效曲并提示，手动重试只尝试一次；无有效曲的首次失败仍静音。关闭/旧分类按钮不再影响现页。
- 隐藏或覆盖的顶部状态条提前退出，避免无用场景扫描与重复可见性写入；没有按键捕获者时跳过全键枚举，删除无调用诊断代码；整档导入核对待发现回执中的卡牌依赖。
- 实看修正发现/墓地共同容器默认尺寸导致的越屏，发现页补安全内边距；混合候选可能含道具，提示使用“获得”，按其真实去向核验。
