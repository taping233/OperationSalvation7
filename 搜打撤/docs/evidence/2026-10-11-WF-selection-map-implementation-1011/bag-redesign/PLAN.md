# 局内背包整改

2026-10-11，老板授权，根将局内背包转交map_battle_art；展示markup和expedition-inventory.css，drag/rules/bridge只读。战斗背包由节点代理写，统一冷灰信息分组、计数/状态位置和卡面身份。

核心：随身、安全格、消耗口袋是三个不同用途的库存；列表负责识别与整理，既有特写负责规则与动作。卡面已经有卡名，不在外面加第二套名字；不将安全格/口袋合为同一种普通库存。

| 实际区块 | 用途/规则 | 增删合并与依据 |
| --- | --- | --- |
| 随身背包 | 物资/卡牌混占容量；堆叠、珍珠盒扩格、拖动/排序沿原逻辑 | 大主目录，标题近旁容量；空格保持实际数量，扩格仍区别。1999用途网格/HSR对象列表 |
| 安全格 | 与随身互移，初始牌不能移入；失败返还规则保留 | 右侧独立保护区，容量与规则就近；移除头部再重复安全格数字/图标。G1/G2 |
| 消耗口袋 | 用过的卡暂不可用，无限容量；火堆/道具复原规则保留 | 右侧独立暂不可用区，卡面身份保留；只在区块标不可用，格格“无法使用”重复标签降为静态区域说明。G2/HSR列表与详情 |
| 详情/使用 | 点击原卡面特写，道具/容器/移入移出按钮沿原UI.act | 不新造第二详情系统；卡名/完整规则沿原卡面，按来源条件显示动作 |
| 物资估值/金币 | 原total仅物资inventory价值，不含所有卡牌 | 将含糊“总值”标为物资估值，头部持续金币；不改任何价格/容量算法 |
| 仓库 | 此界面不是基地仓库；撤离、容器业务各有来源 | 不新增跨局仓库访问/转移入口，保持授权局内边界 |
| 帮助/退出 | B/特写优先关闭、来源恢复、搜刮挂起恢复沿现状 | 顶部稳定返回与帮助，拖动说明只保留一条；开发/重复装饰编码不加 |
