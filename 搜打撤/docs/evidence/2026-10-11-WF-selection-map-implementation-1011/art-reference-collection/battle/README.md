## 版本与画法

截图馆网页本身未标版本，但已下载图内右上明确可读：STS2四图 **v0.98.2**，HUD图日期2026-03-15、卡页日期2026-03-14；STS1两图 **V2.0 / 01-21-2020**。这是画内版本标记，不能写为2026-10最新版。官方press-kit图未标版本，1999明确为CBT。

这些图用于控件布局和辨识分工。可见STS2图标/框章采用较完整的轮廓、少量明暗面、强数值对比；STS1标题卷轴和框件偏奇幻，本项目现代城市不复制题材。1999低文字技能卡的图形辨识可借，但不替换本项目卡面正文。没有取视频结论，也没有把这些截图切出局部后冒称官方独立素材。

## 明确缺口

- 本轮未取得可核实的真实支付/消耗多选确认状态、注能专属状态或编组确认计数原图；B-N06是牌堆置顶选择，不能冒充这三项。
- 职业常驻技能按钮的费用与中央完整手牌并存状态未找到直接对应的高分辨率实图；B-R02只提供技能牌身份分组。
- 目前得到的是合成截图，未取得官方独立的能量图标、结束按钮、牌堆/消耗牌标记或框件原纹理；不能以截图裁片充当授权可接入资产。

六份新增已覆盖本轮最有用的可观察状态，收集到此停止，不用旧版本普通战斗图填缺口。
