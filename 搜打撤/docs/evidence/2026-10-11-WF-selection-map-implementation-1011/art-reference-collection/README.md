当前缺口：真实支付/消耗多选确认、注能与编组确认的直接高分辨率状态图，官方独立游戏框件/按钮原纹理，安全格直接实页，现代透明箱原资源，以及city-cut连续帧。现有普通选牌图不冒充付款，图鉴不冒充编组，GIF取样不冒充完整实时播放。
