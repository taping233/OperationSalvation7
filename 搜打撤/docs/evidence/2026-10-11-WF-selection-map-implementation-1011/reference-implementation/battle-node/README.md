## 稳定源码范围

- game/src/battle/view/battle.view.js：手选动作真实展示映射、已选数量、操作分组无障碍标签。
- game/src/battle/view/battle.overlays.js：展示分类与固定任务摘要，原focus/scroll保持逻辑保留。
- game/src/run/game.run.shop.js：购买价签模板分层；不改交易条件/随机/容量/支付/保存。
- game/css/expedition-battle.css、expedition-shop.css、expedition-rewards.css：新增本域展示规则。

没有修改battle frames/catalog/lifecycle/core/effects/cards、主背包、entry/events、地图业务、批准商店原图与WebP、五族箱帧文件或景图。未改抽取权重/授予/保存/容量。
