# 背包：对照用途网格和列表/详情分工实施

本轮由root负责，只修改showBackpack展示模板与背包专属CSS。老板自行查看，未运行测试、lint、验证、build或浏览器检查，结果待人审。

依据art-reference-collection/shop-reward-bag：1999仓库提供用途分区、数量单点与低对比空格；星铁列表/详情页提供对象识别与就近详情动作分工。这两图没有安全格、撤离保护或消耗口袋机制，只用于本项目既有三库存展示的原创适配。

| 症状与判断 | 实施 |
| --- | --- |
| 随身卡、保护卡与已消耗卡的优先级不够明确 | 左侧随身背包；右侧先安全格、再消耗口袋。保护区冷绿上缘，消耗区灰蓝上缘；容量/数量贴各区标题 |
| 旧随身卡格最小156px，空槽和卡面同等抢眼 | 本域网格最小184px，沿既有容器卡比例随槽放大；空槽降低背景/边线对比，不删除DOM或缩掉拖动目标 |
| 标题“随身档案”与实际背包用途距离较远，装饰多 | 标题直接“背包”，金币/物资估值集中同一头区；返回固定；完整卡名与规则留卡面，数量保留唯一角标 |
| 安全格/消耗区只靠上下位置区分 | 新语义section与专属区域class；安全格保护信息、消耗暂不可用状态就近，各区继续独立滚动 |
| 旧槽hover大光晕与完整卡面争焦点 | 普通hover只提边线，无新增大光晕；排序/返回键保局部焦点。珍珠盒扩格继续独立色边 |
