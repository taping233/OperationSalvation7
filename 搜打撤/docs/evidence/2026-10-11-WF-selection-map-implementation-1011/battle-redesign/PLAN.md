# 战斗整体重做：主场景与附加界面

状态：根已核对并授权三个view源码与expedition-battle.css；主场景/决策附加壳首版已实施，最终由老板统一审阅。老板已明确授权能量/技能/下方手牌与战斗触发额外界面全部重做。商店反馈到来先修商店。

**主场景按“战场上、决策下”重组；附加界面按同一场战斗的局部决策组织。** 不改变普通战全随身卡与首脑编组牌库的规则，不把阶段性附加界面留为未来。保留牌面、目标高亮、拖放、意图、实际消耗/发现/奖励和角色播放器生命周期。

## 两轮以上有假设的比较与验收

1. 第一轮：主战場/下方操作骨架与附加壳；根真实普通战截图对照B01/B03与本轮旧图，检查角色地面、能量/技能/卡牌/结束信息层级；不以测试通过当美术通过。
2. 第二轮：针对第一轮明确画面问题定向改构图/尺度/文字/明度；根复看同普通战，再看首脑编组/战斗与真实消耗/发现/目标场景。背景若有对象禁入区缺陷交生成代理定向编辑，UI不靠堆描边解决。
3. 有新明确缺陷继续第三轮；无变化/无失败不盲跑。每轮记录来源→问题→修改→实页证据→剩余。

源码按quality-gates定向测试与哨兵；减少动态、快速取消/返回、重复发现、能量不足/燃料不足、满候选/空候选、长文和首脑不同规则均列实际覆盖。未走到的状态写未覆盖，不使用外部/headless替代Codex当前窗口真实操作，不build混合树、不提交。
