- 人物：定位/机制关键词、代表卡查看、成长折叠、独立头像；切换保留页面。五人重复机制简介从首屏移除，原数据保留。立绘与白塔坐姿保留。

- 入图/地图：直接入图后揭晓实际职业卡；路线方向/已探索状态刷新；节点保留类型剪影；火堆显示实际变化；普通战恢复冬境环境。
- 节点：奖励滚动内容与固定操作分开，真实入口袋/消散/保留结果按需展开；商店查看与购买分开。各业务结算和存档契约保持原规则。
