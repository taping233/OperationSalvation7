已实际查看珍珠盒、红锦囊卡面，方舟技术调查补给真实截图与旧00/04开盖帧。保留白橙现代合成材料身份，箱身从每帧重绘改为一份独立透明绘画素材。内置imagegen以旧04为编辑目标、两张实际卡面为画法参照，生成完整无盖下箱身；另以旧00与珍珠盒生成正交顶面盖纹理。NAI阶段沿用 `art-calibration/modern-chest/nai-request.json` 已完成的主箱文本结构输入，本次拆件没有再请求NAI。没有读取或输出凭据。

`rig_chest.py`只做纹理整流、透视变换、透明合成与编码，不重画箱身、箱盖或卡面。内盖取旧04既有绘画区域整流。闭合接缝第一轮宽度不足，联系板比较后改为与箱口四角对应的投影，第二轮联系板见 `small-rig-contact.jpg`。下箱身像素在每帧完全相同，后轴两端固定在1254²画布的 `(376,560)` 与 `(1153,734)`，盖面绕轴从0°到105°，18帧/24fps。固定轴证明来自几何定义与每帧回执，不能把旧帧的RGB块匹配误称机械测量。

源帧URL在 `small-rig-receipt.json` 的 `sourceFrames`，格式 `/assets/scenes/chests/small-rig-v1/frame-00.webp` 至 `frame-17.webp`。接入使用同收据 `frames` 的640px运行组，建议 `configureFrameArt('small',{frames,fps:24})`。18张无损WebP均RGBA，alpha极值0–255；源绘画PNG留 `source/` 并精确忽略，未替换或删除旧箱候选。

五族绘画已分别制作：small浅匣；medium双竖肋运输箱；large双扣件/侧提握/底座货箱；class宽切角与集成前握专用器材箱；boss梯形正面、外扩底脚与阶梯肩部保险箱。各自下箱身和正交盖面均为独立imagegen绘画，非染色变体。内盖沿用共同灰蓝内衬纹理，但按各族盖面的alpha轮廓裁取，固定轴坐标逐族校准。完整内置提示词在 `builtin-prompts.json`，源SHA在 `source-sha256.json`。
