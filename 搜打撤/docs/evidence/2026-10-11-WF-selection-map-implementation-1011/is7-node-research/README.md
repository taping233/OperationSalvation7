# 黑流树海节点原图研究

2026-10-11，老板要求按每类高清节点资源具体研究，不使用泛泛的小场景描述。本轮只研究公开资源，没有修改游戏或生成新图。

来源：黑蓑影语集地图工具 https://arkrog.com/tool/blackflowmap ，实际公开模块 https://arkrog.com/assets-v2/index-C-GScw2O.js 中列明节点ID、名称及260×260图集坐标，并提供 /images/map/<id>.webp 独立文件。

已获取22张260×260透明节点图，另有45×45林间空地与176×176定位标记。保留原始字节及alpha，逐图SHA/URL/尺寸在assets.json。此为攻略站公开提供尺寸；未取得更高分辨率官方美术源，不能称4K或官方原始工程。特殊首脑和final的名称尚未完整核实，参考板按资源ID限定标注。

浏览原RGBA时透明像素中的RGB会显示横向彩色拖边，不能据此判断正式画面有大色带。本轮通过内置浏览器将原文件叠在黑底上逐张观察，native-black-gallery.png为实际合成截图，gallery.html为可重复查看的原尺寸参考板。

核心纠正：IS7节点以象征性主体为核心，非商店、街口等写实微缩景观。单图结构为亮色主体、低对比黑圆盘、不对称局部色晕、细颗粒/纵向拖痕、少量点线标记。多数主体约占完整画布一半；外光效渐隐到透明，不用统一粗硬环或等强全周发光。

逐类观察：作战为浅紫白兽头骨与数根肋骨，紧急作战同骨形配红光，居民据点为开合兽颅；诡意行商为青绿卷曲触须，秘境行商为金白耳廓与小环；安全角落为蜷缩人体形体，事件为粉白四足动物，愿望为伞状菌群，失与得为上下相对的两手，先行一步为横向手臂/飞鸟/扭转线，狭路相逢为明暗两条对向曲线；密道为脑状白团与耳廓组合；奇境为跳跃鹿形；险路小径为两侧手/枝条围拢通口；助力为掌与前臂；羽瞰点为不等大的圆/直线/光点；命运为类似花盘或细胞的双圆形体；未知凶戾为紫色肺状主体，未知诡秘为青白蜷缩胚胎状主体。这是图像形体观察，不是节点业务含义的官方解释。

本项目转译：学构图、主体尺度、有限色面、边缘颗粒和局部辉光，主体换成项目原创象征性形体或道具。实际卡面控制不透明大色块与选择性细化；方舟资源控制黑底、孤立主体与光效位置。不复制其器官/动物图案，不以常规店铺街景替代这种图标画法。地图背景遵老板最新要求为近黑底+稀疏光点/低亮光晕，不回到复杂城市壁纸。
