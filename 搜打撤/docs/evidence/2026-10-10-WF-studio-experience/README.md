# 照相馆体验改造（2026-10-10）

**最新决定**：老板认为新样板不如原版，要求退回原版，仅认可点击照片放大的动画。本轮前的界面代码、样式与启动测试已按原始指纹恢复；正式照相馆仅接入420ms来源放大与背签延后入场，收回沿原时序。见[还原与接入记录](revert/README.md)。此前改版和原型记录保留为历史，不代表现行界面。

老板要求增加趣味动画，并让 UI 更符合直觉、层次丰富清晰。本轮沿用现行相纸、夹子及各等级框；检索面板、照片陈列底与选片台使用不同明度和材质层级，主阅读区域增加字号和留白。原画、人设、数值与存档规则不在改造范围。
