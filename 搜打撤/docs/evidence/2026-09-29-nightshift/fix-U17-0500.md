## 一、三层键摸底（改动前实况）

| 键 | 职责 | 写侧 | 读侧 |
|---|---|---|---|
| `sdt-save-v2-slot{N}`（RUN_KEY） | 主档 | `write()` 基线比对后覆盖 | `reader.parse`：指纹缓存→JSON.parse→形状（拒数组顶层）→版本门（E5 严格整数、过新拒读）→逐版迁移→migrateRunCharacter→出口克隆 |
| `sdt-run-{N}-corrupt`（CORRUPT_KEY） | **坏档原串取证备份**：主档解析/形状/版本形状失败时由 `markCorrupt` 尽力转存原串，主键不动，玩家决定是否覆盖重开 | markCorrupt / write 成功清除 | 无消费者 |
| `sdt-run-{N}-prev`（PREV_KEY） | **上一版好档原串**（bb2e122）：write 覆盖主档前尽力转存，防「序列化成功但内容错」直接丢唯一好档 | write 前转存 / remove 清理 | **无消费者（本单元补上）** |
| `sdt-tx-v1-slot{N}`（TX_KEY） | 两键事务恢复日志 | recovery.commands 两键事务 | `txPending()` 探测；恢复流程直读原串 + `parseVersioned`，**不经过 reader.parse** |

**CORRUPT_KEY 与 PREV 回退的关系：分工并存，不冲突。**
- corrupt 键 = 「坏档原串」取证留存：回退发生后坏串**仍保留**（玩家可导出分析），语义不变；
- prev 键 = 「上一版好档」恢复源：读档失败时唯一被启用的备份。
- 一次失败读档的完整轨迹：主档坏 → markCorrupt 存证 + 告警 → 读 prev 校验 → 有效则自愈回退。

**校验链口径澄清**：任务书所述「reader 校验链：JSON.parse→version→_r2 身份」中，`_r2` 身份校验实际不在 reader.parse 内，而在 `readIdentity()`（R6 只读窄口，明确「不迁移、不写回」）。回退采用**与主键读路径完全相同的链**（reader.parse 全链，不含 _r2 强校验）——主键缺 _r2 时主路径本就不判坏，prev 同口径；身份连续性另由「原串逐字节写回」保真（见下）。`readIdentity` 保持只读不回退（契约红线），装载链 `preflightRunMap` 对 RUN_UNREADABLE 本就放行到 `readForPreflight`，回退在彼处生效。

## 二、修法（diff 摘要）

1. `readRaw` 拆为 `readRun(index, raw) -> { run, raw }` + 薄壳 `readRaw`；回退只住 `readRun` 失败分支：
   - 主键 parse 成功 → 原样返回（**零改动**）；raw 为 null（空档）→ 原样返回；
   - parse 失败且 `txPending(index)` → 直接维持失败（事务恢复中不插手，recovery.commands.js 全程 `storage.getItem`+`parseVersioned`，rg 核对无交叉）；
   - 读 PREV_KEY → prev 为空或与坏主档同串 → 维持失败；否则用 reader.parse（同链）校验 prev：
     - prev 也无效 → `invalidate` 清 prev 残留 + `markIssue` 还原主键失败口径（corrupt 不被 prev 的 tooNew 污染），维持既有失败路径；
     - prev 有效 → `setItem(RUN_KEY, prevRaw)` 逐字节自愈（**不走 write()**：不涨 revision、不重盖章，_r2 身份/version 原样保真；走 write 反而会因 publicRun 剥离 _r2 导致坏主档解析不出身份时换新 runId）+ `writeBaseline.set` 推进写基线（采纳/写入链与自愈后主档一致）+ `console.warn('[save] …已回退到上一版存档…')`（reader 既有诊断通道，markCorrupt 同款；UI.log 在 game.session.js，越红线不改）。自愈 setItem 失败（配额）则不假称已回退，维持失败。
2. `readForPreflight` 候选记账改用**生效原串**：回退后主档已换成 prev 原串，若仍记坏串，`acceptLoad` 的 `raw !== candidate.raw` 会误报 STALE_SLOT 断装载链。
