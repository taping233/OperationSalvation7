## 对照参考标准的差距

依据为[美术方向](../../production/art/ART-DIRECTION-BRIEF.md)、[视觉规范](../../production/art/VISUAL-BIBLE.md)和[绝区零基地参考](../2026-10-12-zzz-base-reference/reference-notes.md)；参考板中的动画参数和操作建议不是绝区零实测事实。

| 维度 | 当前值得保留 | 主要差距与具体方向 |
| --- | --- | --- |
| 美术 | 现代高架交通、冷天光、积雪边缘、清楚战斗带；五人物脸与武器完整 | 人物块面、光滑法术图标、线性节点符号及偏写实基地背景质感差异大；减少碎纹理并按素材类别校准，不扩大到冻结商店重绘 |
| 战斗UI | 敌我分区、意图入口、状态、完整规则、分栏与结算中禁用 | 决策数字和规则太小，扇形遮挡加大读牌成本；先提升关键HUD，别靠继续缩字留装饰空间 |
| 地图 | 相邻连线、当前位置、定位和底部工具位置稳定 | 已完成地点都叫空白节点，商店/营火身份丢失；紧急撤离点未实际到达前看不到后续门，找路成本高 |
| 奖励 | 预览与执行分开、已入/已散落与金币到账状态明确 | 卡面、框上、框下与详情重复稀有度/规则；容量和口袋的计数口径需要解释，保留真实去向 |
| 事件 | 有人物/地点画面与独立阅读面，取消成交不扣血 | 黑箱“获得箱→启封→搜索→选择→继续”无选择步骤太多；事件结束后必须清返回状态 |
| 基地 | 边缘七入口、室内空间、明确出征主动作、扩建前后对照与庭院反馈 | 房间身份多依靠同一底图上换面板；材料卡和可消费材料关系、缺资源的补充入口不够容易发现 |
| 动效/加载 | 攻击、装备、获得、移动和雨圈都有状态反馈 | 弹层动效已实证影响动作生命周期；没有逐帧/帧率/计时数据，不能将单次淡出/黑帧写成持续卡顿或旧皮肤闪回 |
