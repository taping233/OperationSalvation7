## 改版终态（已实页验收）
- 点仓库卡格 → `UI.showCardZoom` 大卡特写，页脚操作台：
  - 信息行：卡名·类型·稀有度 + `×n 张 · 收购价 X 币/张 · 全部卖出 +Y 币`；
  - 普通卡：收藏（已收藏显示「取消收藏」）/ 卖出 1 张（+X 币）/ 全部卖出 ×n；
  - 职业卡/能力卡：收藏 1 张（+经验·卡牌用掉）/ 全部收藏（convertCollection 命令链保留）；
  - 材料卡：使用 1 张 / 全部使用（不可卖出口径保留）；宠物蛋：孵化（-1 蛋 -50 币）；经济卡包：使用。
  - 已收藏保护：提示行 + 卖出按钮 disabled，取消收藏后就地解禁。
- 不可回退操作（高价≥5 / 最后一张 / 整堆 / 收藏用掉 / 最后材料 / 最后卡包）用 **armOrRun 就地二次确认**（按钮变红「确认？」2.6s），不再跳确认页。
- 动作前按**卡名**重读仓库堆（freshStack，防索引串位）；卖出/取消收藏等只改数量的动作**就地刷新页脚**（refreshZoom），特写不关不闪；堆卖空自动收回特写。
- 旧 `openStashItem` 函数、其 stash-shell 弹窗、`stashManage` 中转入口全部删除。

## 引导失败事故的最终定因（纠正此前误判）
- 现象：00:52 起游戏页静默引导失败（按钮全死）。中间两个干扰因素：
  1. **5200 双 vite 实例**（22196=无登记他会话 strictPort 残留占 IPv4；24792=本会话 web-up 落 IPv6）→ 已停双实例、重起单实例（PID 15512）。
  2. 排查中我用错路径（`/game/src/main.js`——该路径在 root=game 的 dev server 下本应 SPA 回退 index.html），误判为「IAB 模块通道卡死」。**内置浏览器自始至终正常**，此前「重启内置浏览器」的建议作废。
- **最终根因（属本轮改动）**：splice 删除 openStashItem 函数时，`game.hub.pages.js` 导出列表仍残留 `openStashItem` → 导出不存在的绑定 → 该模块求值即抛 `Export 'openStashItem' is not defined` → main.js 整条模块图挂掉、页面静默无按钮。移除该导出名后引导即刻恢复（window.SDT 就位）。
- 教训：删导出符号必须同轮 rg 全仓引用（含导出列表本身）；「页面静默全死」优先 `import('/src/main.js')` 抓链上首个错误。
