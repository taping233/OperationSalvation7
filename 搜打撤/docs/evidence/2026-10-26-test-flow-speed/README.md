## 使用

`npm run test:changed -- --plan` 先预览当前项目改动；`npm run test:changed` 按原选择器执行。共享工作树优先指定本轮路径，例如 `npm run test:changed -- --paths game/src/battle/view/battle.hover.js`。公共边界、配置变化与原阈值仍可升级full；零改动明确skip。已有明确测试列表继续用test:target；完整门仍用 `node scripts/acceptance-gate.mjs --full --run`。

默认入口的控制台给出耗时报告路径，原文件位于node_modules/.cache/test-reports/，包含各文件耗时、前10个慢项、失败文件、未完成及逐项跳过说明；显式其他reporter覆盖默认报告。见[本轮完整测试报告](full-tests.json)。
