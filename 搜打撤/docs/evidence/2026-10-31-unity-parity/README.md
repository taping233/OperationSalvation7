## 多余代码与性能

- 已移除旧三环生成/布局、无消费者的旧事件/过场/祭坛界面、旧Web迁移空壳、关闭制作坊的无入口UI、旧合成音与采样/美术路径回退，以及仓库额外出售和免消费职业保护。源码文件与`.meta`原位保留，没有删除目录或素材文件。
- 地图批量可达从逐目标重复BFS收拢为一次遍历；常用节点用字典查找。容量查询单次计数，去掉两次展开卡堆和临时对象。
- 移除战斗单字段查询重复构造整场快照/forecast、空闲每帧列表与重复组件查询；缓存描边和分组索引。
- HUD按数值变化更新；同值文字复用解析与图标；性能设置按存储修订号缓存；全局字符串读取不深复制JValue。进度查询不反复重建人物字典，基地列表和庭院计数减少重复扫描与文字分配。
- 节点布局只在尺寸/内容变化时强制重建；不先构建伪地图再销毁；不创建始终隐藏的旧提示条。新arena滤镜限定半采样、双轴卷积、帧限与显式释放。
- 生产运行C#（排除Editor和命令行门控的NativeDisplayReview验收代码）由2914906减至2829807字节，净减85099字节。全部343份C#指纹与77份本轮变更见最终源码清单；删减字节不等同于性能收益。

性能结论限于已查证的调用/分配/复杂度变化及等价断言，没有编造帧率或内存提升比例。
