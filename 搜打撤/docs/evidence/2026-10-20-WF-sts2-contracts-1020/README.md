## 行为与边界

- 选牌由领域生成 `candidateUids/canCancel`，UI与Agent共用；Agent提交前复检过期、非法和强制取消，领域最终支付复检保留。候选查询不触发旧卡修复写入。
- 卡牌实例在商店、事件收牌、旧复原分支和定义刷新深拷贝。已知短期字段清除；锦囊、未知历史扩展保留，孤儿自定义牌不改。没有全库替换每个收牌入口。
- 自然法杖使用明确目标回合的费用记录，旧数字Map恢复兼容；费用优先级、目标回合内多次生效语义不变。本轮没有新增未使用的费用生命周期。
- 敌人意图、预测和实际行动共用纯计划，保持原蓄力/冰冻顺序与狂乱攻击次数。显示层按当前状态重算意图，快照旧缓存预告未改成实时存档数据。
- 伤害与完成出牌事实存值、不存可变对象引用。护身的伤害条件与出牌计数实际消费事实，保持原完成点及“其他牌不含当前牌”的结算口径。它不是覆盖全部战斗行为的事件溯源系统。
- 唯一 `consumedPile` 合并旧四账本并排除手牌、牌库和正结算源；查看、取回、折费和增伤同源。取回移动原UID、清重影；不自动洗回。未取回牌的战后已打出/被消耗类别保留，99临时牌仍不入永久消耗区。
- 挖宝真实牌库底最多三张选一，余牌原序返回，旧n=1兼容；选中原实例入手，按其价格加甲，空库不随机补足。
- 全功能设置和战斗齿轮设置均提供重新开始本场战斗，复用既有开战检查点、保留首脑编组、取消旧队列；不走战后结算、清档或重开整局。
