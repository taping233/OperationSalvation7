## 实施

- 背景光分为左上暖主光、左下冷环境补光与右下相机桌面暖反光。主光散射可见度降低，保留暗部空间。
- 相纸漫反射：暖亮面与轻微冷暗部独立叠层，减整面泛黄。相纸纹理120px逻辑尺度，档案纸220px；大图同漫反射层次。
- 金属夹子：减少重复宽高光，收为窄亮边与冷色暗侧，沿用原金属身份色，稀有蓝色保留。
- 照片表面：去整面暖洗与底部统一黑罩，改窄幅、低强度玻璃反光；小图/大图同一规则，透明衬底和alpha修复保留。
- 无结果时隐藏顶部重复重置按钮，保留照片区的主重置入口；未另拍空态。
