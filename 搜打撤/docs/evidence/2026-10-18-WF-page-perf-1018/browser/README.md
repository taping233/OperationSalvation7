## 六秒静止地图采样

原始公开面板结果见 [idle.json](idle.json)。当前窗口CSS地图1523×767.85，backing1904×960，DPR1.25；6,000.4ms内地图重绘0次、长任务0、循环巡检23次（约3.83Hz），rAF回调853次，间隔p95为7.1ms。rAF回调率142.16Hz不等于屏幕FPS；该采样只统计 `SDT.Renderer.draw`，不包含Pixi合成、RSS/GPU内存，也不是优化前后的整机对照。

本轮自然战斗来源没有捕获error日志。初开5318时曾有Howler的“HTML5 Audio pool exhausted”警告；随后公开音乐快照显示board正在播放、进度推进、音量0.45，无错误。本轮没有耳听或音频池专项诊断，不能据此声称警告消除或code9根因修复。

文件字节数与SHA256见 [manifest.json](manifest.json)，真实动作摘要见 [interactions.json](interactions.json)。未跑长局、所有随机事件、拖拽/多尺寸或旧存档迁移；当前节点语义的其他会话后续改动不由该冻结副本证明。
