# 基地与收藏页面性能核查

本轮修改两处现行页面热路径：仓库筛选与点卡改为线性库存查询；背包散装物资在单次渲染内共享资源目录。保留原工作树的页面、材料单击使用、卡牌特写和存取规则；按老板追加授权同步两份既有测试的五个过期 UI 断言。未提交，未运行构建。

## 可复现收益

`tests/page-perf-hub.test.js` 对 `baseline/*.txt` 原字节与当前源码执行相同 DOM/渲染操作。展示端口固定，不替换库存查询逻辑；该结果衡量操作次数，不能当作实机帧率或内存测量。

| 受控输入 | 改前 | 改后 | 口径 |
| --- | ---: | ---: | --- |
| 200 堆仓库，输入一次空搜索 | 20,103 | 203 | 稳定堆键读取，减少 99.0% |
| 200 堆仓库，单击最后一堆普通卡 | 41,602 | 1,001 | 稳定堆键读取，减少 97.6% |
| 同一次普通卡单击 | 2 | 1 | 完整更新及 tick 次数；仍只打开一次原操作台 |
| 仓库图片完成、布局数值未变化 | 1 | 0 | 浏览区属性写入；原布局仍读取一次 |
| 300 张目录、30 格散装物资 | 30 | 1 | `Cards.all()` 和资源筛选次数 |
| 同一背包输入 | 9,000 | 300 | 目录 `type` 读取；整页 HTML 逐字相同 |
| 卡牌构成的主背包/安全格/消耗区 | 0 | 0 | 资源目录读取；三个区域 HTML 分别逐字相同 |

仓库索引在每次操作重建，并保留同键第一条的展示查找口径；动作仍拒绝重复稳定键。背包资源列表只在当前 `pageHTML()` 内复用，不跨次保留。专项覆盖原地改名/改数量/改稳定键、目录原地改类型/新增资源、原有模糊匹配、重复堆拒绝、材料使用一次及待复原费用守卫。

复现：

```powershell
node node_modules/vitest/vitest.mjs run tests/page-perf-hub.test.js
```

## 定向验证与基线失败

初始仓库/基地集合：5 文件、76 项通过。背包修改前：6 文件、116 项中 111 通过、5 失败。性能改后原测试集合：20 文件、269 项中 264 通过、5 失败；失败集合与背包改前完全相同，机器输出在 `final-targeted-tests.json`。

随后老板授权按现行行为完成既有改动。依据 `docs/architecture.md:94` 与 `docs/evidence/2026-10-18-feedback-13/README.md` 第 2、5 项，同步 `backpack-layout.test.js` 和 `bag-page-lifecycle-review.test.js` 中这五个过期断言：主层保留真实计数和帮助入口；伙伴押运、火堆/结晶/撤离规则在已登记帮助中验证；物资与生物在全部分类保留，招式/资源过滤仍隔离散装物资，装备空态仍能回全部。没有恢复已移除的 UI。

当前有效覆盖为 20 文件、269 项全通过：变动的两文件与性能专项共 71 项复验通过（`ui-contract-retest.json`），其余 17 文件 198 项输入未变，复用原通过证据；五份变更文件 ESLint 通过。汇总在 `verification-summary.json`；两测试改前原字节也已保存，SHA256 在 `source-fingerprints.json`。
