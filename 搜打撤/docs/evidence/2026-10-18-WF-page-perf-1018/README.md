## 浏览器与交付边界

当前平台为 Codex 内置浏览器，保持当时窗口大小。5200 复用已有服务；受另一聊天编辑触发 HMR 影响，完整游戏流程改用 `.tmp/page-perf-1018/project/` 纯副本、5318 临时服务和 `game/dev/page-performance-review.html` 内存存档入口。该入口在 `main.js` 前替换当前文档的 local/session Storage，刷新失效，不读取或覆盖既有玩家存档。启动隔离服务曾因受限进程生命周期失败，经审批改用独立 exec 会话运行。

源码核查覆盖表、jsdom/VM 操作计数和当前窗口真实点击分别说明各自范围。浏览器明细与实测结果收在 `browser/`；自然长局、所有随机事件分支、真实拖拽、音乐耳听、GPU/RSS 及 code9 根因仍不由本轮受控对照覆盖。

性能优化及既有完成改动已按老板授权分组提交，完整隔离检查通过。Windows x64 独立 EXE 已生成并按测试版交付；标准构建的末端预算有 5 项失败，原阈值与失败记录保留。提交、封装输入、未纳入范围与验证边界见[收官记录](completion.md)，产物核对见[EXE 交付记录](desktop-exe/README.md)。
