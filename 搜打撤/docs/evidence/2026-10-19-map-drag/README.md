# 地图拖动

已实现直接跟手、松手减速与边缘阻尼回弹。原实现只有位移与硬边界钳位；本次复用已安装的 Motion 13.2 惯性发生器，不新增依赖，不改变地图路线或节点规则。

实现位于 `game/src/core/map-drag-motion.js`、`game/src/core/camera.js` 和 `game/src/game.boot.js`。拖动阈值沿用8px；首次越过阈值时补入从按下点开始的全部位移，之后按屏幕位移/缩放直接更新相机。松手速度取最近100ms；停住超过90ms再松手不续滑。新输入、取景、失焦和覆盖层会中止惯性，减少动态时直接停止。

参数参考 [Motion animate 文档](https://motion.dev/docs/animate) 与 [惯性过渡参数](https://motion.dev/docs/react-transitions)，并核对本地已安装包的实际导出。边界仍采用相机原有范围；边外位移做渐进阻尼，回弹仅发生于释放阶段。
