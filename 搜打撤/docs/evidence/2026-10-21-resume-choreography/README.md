## 实现

- 公共`transition-handoff.js`提供续局呈现占用和resume配置，时长由`motion-presets.js`提供360ms；同一所属操作结束或失败时释放，旧操作不能释放新操作的占用。
- 选档页保留至续局过场接替，不先关闭露出底层；续局不再等待450ms才恢复数据，插画准备与恢复并行。
- 续局插画等待期间静止，不在离场时重播入场；标题160ms淡退，整层360ms淡出，结束收起遮幕。续局不使用旧resume-hold样式，避免遗留退场选择器干扰；节点和战斗的原配置不变。
- 公共呈现占用期间隐藏地图HUD和底栏，抑制其动画；释放前移除层名入场标记，释放后刷新地图控件。恢复数据前重置HUD数值缓存，以恢复值为新基线。
- 标题页右键提示在续局交接开始时移除，避免独立body提示延续到地图。
