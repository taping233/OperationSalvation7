# 成就详情退出修复

## 复现与根因

当前候选源码中详情打开后将页头和主体设为inert，但详情只有内容、没有关闭按钮，内部键盘仅处理Tab。公共overlay的Esc捕获调用_findCancelBtn；当前可用性守卫排除inert中的按钮，因此原先依赖代点页头achBack的关闭路径没有候选。此次lazy修改保留了原关闭机制，没有改变键盘路由；问题是旧详情缺少自己的退出入口，与公共inert过滤组合后暴露。

独立回归使用真实overlayMethods并模拟浏览器inert属性反射，在修复前断言_findCancelBtn命中详情按钮失败（实际undefined），复现无可用取消入口。动画样式装配副作用motion-transitions在该测试中mock；未mock公共取消查找、关闭路由、成就绑定及动效模块。

## 修复

详情新增真实绑定的“收回奖章”按钮，data-gallery-dismiss接入现有closeDetail，data-cancel=true接入公共Esc捕获路由。工具栏sticky保持长详情滚动时可见。独立挂载详情补Esc处理，并保护输入法组合和重复按键。关闭复用原动效及焦点恢复；lazy详情内容与缓存不变，无奖励写操作。未修改公共overlay的inert守卫。

## 验证

3文件15项全部通过：原成就8项、lazy工作量3项、新退出4项。新增覆盖公共取消查找、捕获阶段Esc只关详情、按钮/遮罩回调、来源焦点恢复、缓存节点保留、独立Esc与IME/repeat保护。项目ESLint定向检查源码及改动测试通过。修复前失败、修复后通过均来自相同轻量目录。

真实浏览器尚未复验，交由父任务在新部署验证；本测试不证明实页点击遮罩或最终视觉通过。没有构建、部署、提交或修改共享index。
