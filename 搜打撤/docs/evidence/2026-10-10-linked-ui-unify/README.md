# 主页直连界面通用设计

2026-10-10，老板要求逐项推广此前总结的优秀设计。范围为首页入口及其直连页面，通用实现位于home-linked-interactions.js/css；保留各页主题和入口动作。

1. 点击区域固定：成就、选档、指南和设置/信箱按钮的hover/active/focus不移动外层；选档卡片外层也保持固定。现有奖章、文字和装饰层反馈保留，共用返回键保留窄窗口比例。
2. 返回键统一：指南、成就、设置、信箱、制作名单接入linkedBackHTML，共用archive-back图标、几何和焦点提示；指南/成就采用纸面深色图标。制作名单继续使用原生表单关闭、Esc和原返回生命周期，存档与选人已有archive-back不重复改。
3. 悬停进出：共用视觉属性380ms与平缓起止曲线，双向同一节奏；首页既有700ms保留，减少动态时取消过渡。
4. 局部刷新：指南仅替换正文和分页器，保留页头、章节导航、导航滚动与焦点；重复选择同章不重绘。成就已保留列表阅读锚点，设置已有面板切换，信箱继续只更新记录区。异步信箱读取加原容器身份守卫。
5. 选中标记：成就筛选/陈列按钮、指南章节在颜色之外增加侧边标记，沿用aria-pressed/aria-current；设置已有分类标记和键盘导航，不叠加第二套。
6. 成本与结果：基地现有建设与仓库操作台已经同屏展示持有、成本、结果，本轮复用，不添加泛化说明；活跃基地整改属地不接管。
7. 空态恢复：信箱读取失败增加重新读取，保留原记录；指南缺内容仍有返回入口与重试指引。成就筛选清空与仓库获取入口沿用既有实现。
8. 动效生命周期：文档进入后台时暂停首页与直连页面CSS动画，回前台恢复；成就详情遮罩、制作名单弹窗显示时暂停相应背景氛围。减少动态设置继续生效。
9. 简洁文案：复用此前14处清理，本轮移除指南重复页头说明，保留规则、成本、状态及失败恢复信息。
