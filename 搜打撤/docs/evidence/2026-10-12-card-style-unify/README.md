# 卡牌样式统一与旧规则清理

老板要求新版卡牌统一到全部游戏，并删除旧样式。本轮修改七份 CSS，卡面继续由 `game/css/card-layout-selected.css`、厚涂蔷薇和职业框映射维护。

交易所旧的 `object-fit:contain!important` 覆盖了共用的全幅原画规则，实页计算样式确认原画留黑。删除该规则后，货架、交易台和放大卡牌均使用 `cover`。同时移除旧费用圆牌、灰色描述底板、伤害与币值角标样式，以及商店十字底纹、整备限行、旧仓库隐藏说明、宝箱裁字和旧战术卡面。保留宿主尺寸、页面布局、抽牌/注能/回复/护甲提示与交互。

本轮没有修改其他会话在途的 `base-logistics-trade-v12.css`、交易脚本或卡牌渲染器，没有执行构建、提交或服务操作。
