# 战斗试玩三版迭代

老板授权：自己试玩整改战斗，参考尖塔2源码重写；对照二游迭代数版，删除无用元素与设计。只改 Vite 战斗视图、对应测试/文档，复用当前内置浏览器窗口，不提交、不构建、不删文件。

## 依据与出口

- 尖塔2：[社区反编译架构](https://github.com/Hexpion/Slay-the-spire-2/blob/main/Slay%20the%20Spire%202/ARCHITECTURE.md)与 `NPlayerHand`、`NHandCardHolder`、`NCardPlay`、`NTargetManager`、`NEndTurnButton`。参考稳定牌槽、焦点抬牌、取消选目标及回合输入锁；本作实现独立编写。
- 二游：参考《明日方舟》的边缘操作区、行动点与候选对象靠近；《重返未来：1999》的角色/血条绑定和底部卡牌操作带。参考只决定信息关系，保留本作冬城资产与卡面。图源见后续验证记录。
- V0 实玩：档位01基地正常出征，无，携带群攻/单攻/自指向护甲/状态牌；领取两张职业卡，沿真实地图进入首场两名联邦射手遭遇。当前内置浏览器窗口1603×956，逻辑战场1920×1080。
- V1 精简：删除战斗熟练度、无决策价值的遭遇眉题、常驻操作教程、重复技能说明与环境粒子。保留实际回合、角色数值、意图、能量、卡牌、背包、设置与结束回合。
- V2 结构：手牌不随数量整体缩小；修复底部裁切、悬停与命中区，稳定技能/资源/结束回合位置。
- V3 交互：真实选牌/取消/目标确认/护甲/回合切换/结算，检查对比、遮挡与输入状态；修复复核发现的问题。

## 状态

V1/V2/V3已实现并完成当前窗口普通战试玩，编辑释放、完成未提交。V3复核后角色恢复贴地、血条上置；手牌当前栏消耗后靠拢，卡牌UID、分组及快捷键保持。底部悬停补偿区置于卡牌后方，真实点击不再被透明牌槽截走。费用/目标类型的隐藏重复角标和常驻虚线框一并清退；详情只在当前牌悬停/焦点时露出。

V0原始画面 `v0-battle.png`、V1 `v1-cleanup.png`、V2 `v2-layout.png`、最终V3 `v3-final.png`；V0/V1/V3是同一正常出征入场样本，不同版本靠真实读档恢复。V2拍摄时第一张牌悬停，不能直接把抬牌高度作为版本几何差异。`baseline-*` 与 `iterate_*.py` 是本轮本地中间件，已由本目录 `.gitignore` 排除，不随交付提交；当前源码为最终实现。
