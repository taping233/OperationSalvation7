## 实页覆盖及输入边界

仅使用Codex内置浏览器。当前窗口自然尺寸在工作中由1280×720变为1074×956；没有调用viewport覆盖、外部浏览器或多尺寸扫测。截图保留其实际窗口，未把它们作为受控尺寸A/B比较。

- 设置：分类切换、开关状态、音乐滑块Home/End及减少动态静态选择；临时偏好恢复到正常动态模式。
- 发现：通过既有开发控制台发临时寻宝，实际选目标施放进入3选1。点击、方向键、Tab焦点、详情返回及双击确认已验证；方向键沿原语义改选，Tab仅移动焦点。双击后只获得一张卡，能量和消耗各结算一次。
- 领奖：单领一张后卡面保留；全部收下处理余下两张并回总览，背包2/16→5/16。没有把交易结果当作飞行轨迹或FPS证明。
- 背包：筛选空态及恢复、键盘焦点、详情返回、三区切换；普通模式受控卡面`transition-property`无transform，分区hover无位移；游戏内减少动态时过渡与位移关闭、底板隐藏、静态选择仍可辨认。
- 状态：展示fixture只复制当前快照传给真实渲染器，构造0/1/4/5/8/16项与1/9/10/99数值，不写引擎或存档。最终16/99下随从同屏2项、敌人3项，玩家两行；4→5项高度不跳变。末项可Tab滚入；已选攻击牌后点击状态只显示说明，能量2/2与选中牌保持。
- 生命与顶栏：15次场景读数中，`runTopBar/hpHud/hpText/resHud`各1。生命容器164×64 CSS px、数字30/34且非斜体、4px底轨；所有场景格式和外观一致。真实包扎获得3护甲，实际`b.sts-hp-armor`宽26.3375物理px，未铺满138.25px生命条；之后真实敌方行动使生命30→23，顶部和脚下均23/30。
