# BOSS 开战装备消耗、占位与便携包

老板授权 BOSS 开战自动装配的装备统一消耗并占用装备栏；随后明确不用测试，并要求生成 EXE。

## 当前改动

- 自动装配装备先统一移出手牌、牌库与弃牌区，再执行开战效果，登记本场消耗与墓地；战后沿现有结算进入局内消耗区。
- 自动装配与手动穿戴共用装备上限，默认 2 件，沿用已有上限加成。编组拒绝继续选入超过上限的开战装备，旧编组超限须调整后开战；卡牌不足时按上限内实际可编数量放行。
- 龙巢不走编组，按背包顺序自动装配至上限，超出部分不自动生效、不因此消耗。
- 同步规则与编组页面提示。
