本轮修改六个生产文件，处理五处运行时开销：战斗卡面与提示分别差分、整备卡格增量更新、地图预览只使关联道路失效、静音跳过短音效初始化、已离开角色会话取消资源等待。素材、画质与玩法规则保持原有选择。

以下为真实模块在 Node 24.13/jsdom 与受控后端下的操作证据；不是玩家设备的帧率或实玩耗时。计时采用预热、同输入重置及交替采样，未设墙钟通过阈值，完整较慢样本同样保留。

战斗每次完整保留三次渲染与反馈，未变卡面重建 17→0，500/500 存活节点保留。整备八个独立 fork 场景各 17 对输出严格相等，数量、删除、重排及过滤按当前状态更新。地图 160 组曲线/裁剪/透明度逐数值相等；旧/新目标之外的道路继续复用纹理输入。资源取消不取消共享底层加载，新 owner 仍能接管，迟到资源按所有权卸载。

首开整备没有提速：25 种库存 median 34.393→36.248ms、p95 42.423→47.230ms。战斗 25 卡的进程 CPU 与部分渲染尾延迟也未改善，未删除这些样本或据此声称全部 CPU 指标下降。原先长矩阵的未推进帧队列导致探针 OOM，最终改用独立 fork 并完成 hydration；该失败不作为游戏泄漏证据。

本轮按老板要求没有继续实玩、浏览器操作或原生 EXE GUI 验证。CPU profile、分配采样、显式 GC 后 WeakRef 与 JS heap 用于定位，后端替身的解码/绘制不能证明真实音频、GPU、RSS 或 FPS。模块与夹具边界在各片报告中列明。
