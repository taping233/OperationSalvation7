# 交叉复核

主会话逐项审阅本轮生产差异。Battle 子代理只读复核地图道路缓存与音频/帧资源，Resource 子代理只读复核战斗手牌差分；未发现阻塞缺陷。复核没有改写对方属地。

地图复核确认留白只依赖目标关联端点，路径高亮仍逐帧读取。按复核建议增加清空预览、离屏期间多次目标变化两例，与既有回归共 21 项通过。

战斗复核确认 `.bt-rulehint` 只由本处生成，动态伤害/费用仍使卡面失效，实时 ARIA 和外部属性恢复不被提示缓存跳过。58 项回归、25/28 卡完整出牌的 HTML/状态等价记录均对应最终原字节。

资源复核确认实际 `cancelTextureRecord` 同时设置 cancelled 并 abort，release 清除所有权；共享 URL 新 owner 不受旧 owner 取消影响。成功、失败和取消均移除监听，迟到资源仍按活跃 owner 决定卸载。音频修改保留音乐独立开关、首手势重试及恢复流程。

Battle 子代理另外只读复核整备两文件，未发现阻塞缺陷：整卡内容签名覆盖原位修改并穿透公共卡面身份缓存；数量实时读取；结构、顺序及绑定节点变化使旧视图失效；卡格按 key 队列删除/重排，过滤与旧事件回调守卫保留。首屏增加签名与捕获，不主张打开速度改善。
