# 材质叠层实际生效核查

2026-10-11，Friday / WF-studio-total-1010。

老板反馈材质/光照不明显，怀疑其他样式覆盖。

## 实际证据

当前1280×720内置浏览器读取相纸与档案计算样式及命中来源：图库纸张背景、--paper-shadow和档案background/box-shadow均采用photo-studio-unified.css现行值；外部ak-skin.css虽匹配档案元素，未覆盖最终值。卡纸/按钮/lib-item均overflow:visible，lib-item只有layout style隔离，没有paint裁切；图库仅边界滚动裁切。

不足来自自有叠层：原纸纹上方的渐变色层alpha为0.96/0.98，几乎遮住纸纹；投影参数生效，但暗背景与光照对比不足。不是外部覆盖问题。

## 修订

直接编辑unified.css现行材质规则：纸纹multiply混合、底色与方向高光分开；第一轮纯multiply实页噪点过密，随后增加65%底色调和层以保留纹理并保证阅读。图库/档案与大图纸张同用分层策略。背景增加静态左上暖光，相纸加强接触阴影、边缘厚度与右下投影。原画像素、透明衬底、相机背景、编号与动效时间保留。
