# 选角叶页面按需加载

人物与职业卡池页面现在由轻门面按用户请求装载，标题及基地等待不预取该叶模块。祭坛、火堆、入城补给、撤离恢复仍走原同步 API；游戏、Base 与档位状态没有新增所有者。基地出征切幕等待选角 DOM 实际就绪，未选角存档恢复保持 `loadGame()` 同步返回，额外返回 `classChoiceEntry` Promise 供选档消费，该 Promise 不进入游戏对象或存档。

加载失败保留原入口与 pending run。基地按钮可直接重试；直接开局缺少来源按钮时显示选角重试，重试不重复扣出征卡或初始化对局。Escape、返回标题、换档/换局、来源宿主变化与其他待开页会使旧结果失效；旧人物确认闭包不能在新档扣卡。现有战斗域在玩家已进入选角页时后台准备的行为保留。

- 17 套近邻与真实启动接线测试 222 项通过，含原基地/照相馆交错、读档持久化、祭坛/撤离和选角专属边界
- 最后新增的 DOM 尺寸描述回调可见性守卫与文档更新后，5 套 76 项通过；修改范围定向 ESLint 通过
- 专属源码图断言证明 `main.js` 静态闭包包含轻门面，排除人物/卡池叶实现和 `character-view-motion.js`；结构守卫拒绝把叶页面静态导入或重导出回首屏
- 未执行全量测试或生产 build；本批等待唯一集成构建与平台内置浏览器普通实页验收。源码 gzip 估算不能代替生产入口/首屏字节实测
