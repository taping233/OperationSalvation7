# 代号柒全流程 UI 迭代原则记忆候选

来源：老板在2026-10-13本聊天的直接要求及[二次迭代证据](second-pass.md)、[接班实页](root-live-verify.md)、[下一轮交接](next-root-handoff.md)。本页为稳定经验，现行行为仍以项目docs和源码为准。

## 老板偏好

- 从基地到打通结局的**所有能看到和交互的界面**逐页对照真实二游；模拟真实玩家，敏锐指出bug、难用、难懂、不好看和重复文字。发现明确属地可派Sol子代理实施，主协调负责跨页集成和真实流程。
- 做完一轮源码后，先拿已查看的真实参考图与本作同场景并排再迭代一版；统一验收也是下一轮的找问题起点。不要把“按钮齐全”或定向测试通过说成审美通过；老板否决即返工。
- 控制台可加快到达后段，但构造到场、自动剧本、真实点击/拖牌、刷新读档和自然通关要分开记录。内置浏览器当前窗口固定1920×1080；仅用当前平台内置浏览器。测试页默认静音，新增/重载先核验。
- 沿用已授权范围，勿重问已拍板事项。没有提交、推送、发布、删除或build授权；他人活跃属地先协调，不覆盖共享未提交成果。上下文过长时及时用新主聊天和精确交接文件延续，不重查有效证据。

## 省额度且保质量的顺序

1. 先读最近交接、目标源码、当前占用和真实参考板；已知路径定向查，不重新盘全仓或历史。按页面/文件边界派工，主协调只补跨属地问题。
2. 源码改动后跑直接相关定向反馈；玩家可见变化拿固定1920实页截图和实际输入。CSS解析、Vitest、构造页分别只证明对应层，不替代外观与手感。证据够用即停止重复检查。
3. 长游戏场景使用独立origin、冻结源码、HMR关闭、只读素材junction。不同代理独立端口/档位；端口/PID/会话要登记、身份核实后由创建者停止。老板正在看的页面不复用作构造。
4. 按真人路径先走一条纵向链，再用项目控制台或固定剧本到达其他分支；每个结果说明输入是否真实、是否刷新恢复、是否仅构造。不要把构造首脑击破写成自然通关。

## 本轮踩坑与修法

- 快照同步514文件成功只证明复制时无漂移；后续定向覆盖源文件会使manifest过期，最终交付前重新冻结并记录版本。Windows沙箱可能把Vitest `realpath`、Vite依赖扫描或junction创建拒为EPERM；同命令按审批正常权限重跑，不把未收集测试当失败或通过。
- 浏览器AX可能先于转场稳定帧；首个截图会拍到空立绘、旧页或暗幕。等当前页面稳定后再判断视觉；保存截图时同时写明场景、origin、视口和输入来源。跨聊天tab句柄不可复用。
- 事件节点`data-asset-key`有值仍可能纯黑：`nodeBg`映射和`.node-pg[data-asset-key]`图片CSS需成对接线。接敌、宝箱确认页本轮就漏过一次；真实流程才能发现。
- CSS `flex:0`可把收藏室空态背景压成74px但子元素仍溢出；用`flex:0 0 auto`并在浏览器核对承托和子元素边界。横幅人物皮肤放进统一竖向容器，保留原图完整构图，再用柔化同图背层填补上下空白；不要直接放大裁掉人物。
- 战斗`overflow:hidden`会被点击手牌自动滚动约113px，顶栏滑出；需要`overflow:clip`并实测scrollTop。敌我血条旧CSS的`!important`可能盖新设计；查计算样式，不只看新规则。九叠名称/费用按实际露出宽度排，点击先大卡、显式使用后选目标；真实拖牌需验证释放命中与回手取消。
- 节点收益与选项落在flex壳的直接子元素可能被并排挤压；用明确的纵向摘要容器。奖励一两张时用紧凑容器，仍保留独立领取和出口；终局整理要清楚说明未入库损失，完成按钮按风险分级。
- 控制台“贪心一局”本轮从Agent页点击后无记录/无进度，尚未定位；原始CDP测试剧本曾被浏览器安全策略拒绝，不得绕过或将未跑的剧本记为覆盖。优先普通UI操作，剩余能力按下一聊天当次权限判断。
