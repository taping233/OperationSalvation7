# 第一款有依据的稀有度细化

老板改选第一款为主方案，要求文字继续下移，稀有度区分参考其他游戏优秀设计而非自由添加装饰。本轮只更新审阅预览，不接入正式游戏。

## 来源与改法

- [炉石官方说明](https://hearthstone.blizzard.com/en-us/news/10245930/hearthstone-crafting-in-dust-we-trust)用固定位置的椭圆宝石颜色辨认稀有度。本轮采用单个椭圆切面宝石，颜色仍按本项目稀有度映射；未引入炉石橙色传说规则。
- [SNAP官方升级视觉说明](https://marvelsnap.helpshift.com/hc/en/3-marvel-snap/faq/34-what-does-upgrading-a-card-do/)说明升级会改变边框、名称光泽、动画和额外视觉效果；[官方饰面说明](https://marvelsnap.com/fntyspltlglpg/)包含Foil、Prism、Gold等饰面。本轮借鉴薄亮边、边沿缓慢反光、金属名称和全息饰面，不将其收藏升级等级当成本项目掉落稀有度。

去掉上一轮自加的冠形、角件、侧轨及双宝石，统一第一款全幅结构。古朴素面、稀有蓝亮边、史诗紫亮边和反光、传说金属边及亮面名称、棱彩全息边及镭射饰面。高阶边沿采用transform旋转的遮罩层，减少动态效果时停动画；无性能基线，本轮不声称性能提升。

名称和效果区域底部距离从21px改为10px；效果区最小高度65px改52px，名称行距明确为1.35，进一步向下收拢。费用仍53×53同款徽章、左上浮角，卡名居中，边框1px；无额外攻击、伤害类型或价值栏。预览下方展示实际SNAP与炉石官方图及对应链接，五档同图明确标注只是外观比较。
