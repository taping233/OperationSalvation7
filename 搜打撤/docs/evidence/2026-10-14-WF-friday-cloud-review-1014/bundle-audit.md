# 启动依赖与等字节资产发布审查

本轮做了两项低风险减负：验收剧本改为首次调用时装载；发布时复用 17 份已核验等字节图片的正本。源码美术、动画帧槽、动作顺序和预算阈值均未改动。

本报告只给出源码审查与定向测试证据。真实生产构建、预算结果和内置浏览器验收由主任务统一执行，当前不能宣称预算通过。

## 已实施

### 验收剧本按需装载

`agent.scenes.js` 保留同步清单、同步启动和状态轮询；具体场景驱动迁到 `agent.scenes.runtime.js`，场景名称、标题与默认快进值只在轻量 catalog 维护。启动静态图不再包含剧本实现。

动态装载开始前就占用执行口，装载和执行期间都拒绝第二个场景。装载失败会形成终态失败报告、释放执行口并允许下一次入口重试。`run()` 仍返回 Promise；原有场景断言、快进恢复和错误捕获保留在实现层。

这项改动将轻量场景入口从 26,723 字节降到 4,381 字节，移出启动图 22,342 字节源码。该数字不是压缩后 bundle 的实测收益。

### 只合并发布输出中的等字节图片

`scripts/runtime-asset-aliases.mjs` 每次构建核验候选文件是否存在且逐字节相同。当前命中：

- 五种宝箱的 01/02 帧复用 00 帧、17 帧复用 16 帧，共 15 份，3,317,130 字节
- 常无欲 sprite 的 f000 与 neutral 复用其相同字节的战斗立绘，共 2 份，434,612 字节

`vite.config.js` 将 Vite 静态 URL、复制清单和生成的预热清单指向同一正本。动态动画和 neutral 兜底仍走 `assetUrl()`，仅生产构建注入已核验别名；dev/未构建环境保持源码 URL。相对与根路径前缀、现有查询参数保留，版本参数落在 fragment 之前。

所有原始图片保留。某份图片重画而不再相同，下一次构建就保留它自己的发布路径。宝箱原有 18 个时间槽仍存在，只是等字节时间槽共用 URL。

当前核验可省去 3,751,742 字节发布副本。按源目录重复字节审计推算，残余重复字节为 727,346（约 0.69 MiB）。这只是构建前投影；实际产物还需统一构建核对。

逐项 SHA256 和字节数见 [源码证据](bundle-source-evidence.json)。

## 审查结论与保留边界

审查时启动静态图包含 269 个本地节点，约 2.70 MB 源码。战斗、照相馆、Ink 和 Pixi 已有真实动态边界；仅重新分配 chunk 不能降低真实首屏总 JS。因此本轮没有把启动必需模块藏进未计量的 chunk。

全 CSS 的保守相同规则检查只找到 592 字节可重复项，远不足以解释约 80 KiB gzip 超额。本轮没有执行大面积 CSS 删除或改动样式加载次序。CSS 范围的后续调整另由主任务协调。

审查前图快照见 [静态依赖图](bundle-source-graph.before.json)，只读 Acorn 解析，不包含第三方包的完整闭包。

## 验证

使用项目现有依赖与 Node 22，直接运行定向 Vitest，不调用 pretest、全量测试或 build。

- 8 个测试文件、72 个断言通过：新场景边界、运行时资产别名、URL 别名、Vite chunk、既有场景、影响查询、启动契约、架构边界
- 改动文件 ESLint 通过
- 自有 diff 的 whitespace 检查通过
- 原有 jsdom 场景出现其缺少 Pixi 渲染器/音频 codec 的警告；场景断言通过，这不代表实页渲染或音频验收通过

完整定向输出见 [测试日志](bundle-target-tests.log)。

未核项：真实生产构建、完整预算、内置浏览器首次剧本装载、宝箱动画、常无欲动态帧与静态兜底。本轮未暂存、提交或推送。
