在已核验的等字节资产合并之后，继续只调整两个可选场景的真实加载边界。未把必需启动模块重新分包以规避计量，未改预算、CSS、美术或字体。

## 真实构建核验

主任务的 full-quality-03 实测：重复资源约 0.69 MiB，已通过重复资源预算；package、entry JS、initial JS 与 CSS 预算仍失败。不能将本轮小幅按需拆分描述为已解决所有预算问题。

对这一真实产物执行了只读 Acorn 检查和最小 compiled assetUrl 隔离求值。17 个别名都解析到存在的正本；旧副本文件未发布；别名字面量只出现在字典键中，活跃静态引用为 0。具体产物 hash 与逐项 URL 结果见 [产物别名核验](bundle-output-alias-audit.json)。该核验不替代浏览器图片/动画验收。

## 本轮增量

- Home 的 visual pack 与已经动态加载的 Home scene 一同装载。创建基地 Home 门面不再解析视觉包；原请求序号和 host 连通性检查在使用 visual pack 及挂载前执行，旧请求不会更新新宿主
- 庭院保留同步 HTML 和同步清理函数。首次挂载才加载控制器、雨景与锦鲤实现；期间显示准备状态并禁用未就绪输入。离开或卸载会阻止延迟模块重新挂载，失败给出可见提示并可重新进入重试。热加载后沿用原同步挂载路径
- 原庭院互动、暂停、隐藏页停帧、减少动效、声音手动启用和资源清理实现只迁移到 runtime 文件；交互测试的行为断言保留，首次装载测试改为等待真实动态 import 完成
- CSS 代理的 standalone CSS minifier 已接入 Vite plugin，并给它登记了专属验收映射。本轮 JS 代理未改其压缩实现或样式

初始页面有全量美术后台预热。六项 startup 计数不代表全部网络加载量，本轮没有据此声称首屏低负载或测得加载时延。

最终定向检查为 13 个文件、185 个断言通过；包含庭院/雨景/锦鲤、Home、基地回归、架构/启动、CSS helper、Vite config、脚本登记与验收选择、资产别名。改动文件 ESLint 和 diff whitespace 检查通过。输出见 [定向日志](optional-scenes-target-tests.log)，源文件身份见 [SHA256](optional-scenes-source-hashes.json)。

源码已冻结供主任务统一构建和实页验收。本轮没有执行全量测试或构建。

生成清单不作为人工源码 patch 交付，由接收方在完整资源工作区执行正式构建重生成。当前扫描结果保留在本环境，不能在验收链中恢复成旧值；主任务记录构建时使用的清单 hash。资产别名与正本预热条目由新构建配置自动生成，无需携带本环境的清单 diff。
