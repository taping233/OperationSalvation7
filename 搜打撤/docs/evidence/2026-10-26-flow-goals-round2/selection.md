# 真实选卡入口接线

## 本轮修改

- 背包发现：候选保存提示、容量不足和确认保存失败均原位更新反馈，保留选中与滚动；保存失败恢复源牌与原候选。异步结果按原视图归属处理，已切换页面保持当前内容。取消按实际返回值完成，返回失败可在原选择上重试。
- 安全格交换：选择确认等待保存结果，失败恢复本次交换的原位置并保留候选；对象、卡牌、UID及交换后位置一致时才恢复本次写入。成功后提交一次通知；旧视图或旧局完成时沿用当前页面。取消返回明确成功/失败，支持异步返回，旧局的返回通知结束。普通直接移动及 `refresh:false` 奖励整理继续使用原同步 boolean 合同。
- 战斗发现：同轮在途确认刷新时沿用当前 root；异步 handler 结束后再解释返回值，`undefined` 依据实际票据/页面变化判断是否接受，拒绝后保持可重试。

已满足并继续沿用：三入口的旧局/旧票据检查；安全格容量和候选对象身份复检；领域支付、授予、持久化归属；公共选卡组件的单次提交、异步重绑和键盘行为。

## 当前窗口实页复验

1. 背包使用发现通行证，选中候选后触发容量/保存失败，核对原候选、选中和滚动；原位重试，确认后只获得所选一张。
2. 安全格满时由卡详情进入交换，选中一格；确认等待期间再次确认或取消保持等待。失败后原位置和选中保留；重试成功后交换与回执各一次。
3. 战斗三卡发现选中并确认，在异步等待中刷新同轮呈现，原选择继续等待；拒绝后可重试，新轮次按新票据开始。
4. 等待期间切换页面或局面，再结束旧请求，当前页面和新选择保持连续。
