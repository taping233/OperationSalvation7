老板授权用纸边品质系列与最终职业减饰稿统一替换正式卡面。十三款框映射到paper-1015运行目录：七档品质、五人职业框、无人物纹章的职业素框；素框复用初始纸边图，职业语义由卡牌数据保留。

追加要求已实装：费用由独立上层显示，资源卡不显示费用；传说卡增加低强度金色轮廓呼吸与慢扫光，棱彩原有彩光保留。
