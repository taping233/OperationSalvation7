## 最新修订

老板否定首轮页面后，补给按已实际查看的明日方舟信用交易所重做为单排四商品。名称位于顶栏，卡面居中，持有量位于图下，底部将价格和单一购买动作固定排列；不足原因只在缺币或满仓时显示。删除双货架标题、类别副标签、重复用途说明和固定 ×1 装饰，详情继续由点击卡面进入。

统一系统变量为 `--camp-bg / --camp-ink / --camp-muted / --camp-line / --camp-accent / --camp-dark`，缺省值使用白灰、墨蓝与赤陶红。直角、1px 线条与留白组织内容，赤陶红只用于购买主操作。旧深绿、金色焦点、渐变及大阴影规则已从补给自有 CSS 移除；四件商品保留原数组顺序，价格、购买命令与入库规则沿用现行数据。

庭院同时修正运行时边界：JavaScript 与原 MIT 许可证按 SHA256 核对复制至 `game/src/hub/courtyard-vendor/`，hub.courtyard-v3.js 和测试改从源码目录导入；旧 `game/assets/vendor/base-courtyard/` 保留为来源审核副本，SOURCE.md 已说明运行时路径。庭院现在同时响应系统媒体查询与 `body.reduce-motion` 应用设置，页面打开及运行中切换均立即静态化，关闭设置后恢复单一 RAF；销毁时释放监听该设置的 MutationObserver。

本轮验证：两个主模块语法通过；两个主模块、运行时 vendor 和两个专属测试的 ESLint 通过；定向 Vitest 为 2 文件、8 测试通过（补给 3 项、庭院 5 项），新增应用减少动效开关的初始与动态切换覆盖。自有 diff whitespace 检查通过。未独立运行全项目架构门、build 或提交；根会话负责接入后的架构哨兵及当前窗口实页复核。

## 首轮核对与设计（历史）

当前货架只有穿刺、法杖、口粮、木材四项，价格分别为 6、6、4、4 储备币。卡牌按张占仓库容量；口粮和木材购买后直接计入基地物资，不占卡牌仓库空位。沿用现有购买入口，不改变商品、价格、收益和存档。

原补给页混用侧栏说明、竖向商品列表和缩略战斗卡面，价格、持有量和缺口不能一眼对应。新页改为卡牌与物资两组货架，四件商品的原画、名称、用途、持有量和价签保持固定顺序。查看与购买是两个独立动作；缺币或满仓时仍能打开详情。

第一轮比对以明日方舟采购中心的商品网格、顶部余额和固定价格位置为参考。第二轮查看原神尘辉兑换，把数量与价格进一步靠近商品；删掉本项目没有的折扣、限购、倒计时和推荐角标，保留当前购买真正需要的数值。四件商品留出独立边距，卡牌与物资只作两组陈列，不增加分类页签。轻透明底与阴影承托原画，模糊仅用于货架背板，不作用于图与文字。参考用于信息结构，不复制外部图片。

## 接入接口

`shopV3HTML({ base, cards, art, goods })` 返回完整补给内容；`goods` 传现行 `HUB_SHOP_GOODS`，`cards.all()` 查真实卡牌，`art.cardIcon(card, { low: true })` 取现有缩略原画。导入 `game/css/base-shop-v3.css` 后，在基地独立子页中调用，不再拼 `logisticsTabsHTML` 或旧商店侧栏。

| 元素 | 既有动作契约 |
| --- | --- |
| 卡牌原画 | `shopPreview` + `data-i`（原商品数组索引） |
| 木材、口粮原画 | `rawItem` + `data-kind` |
| 每项购买 | `shopBuy` + `data-i`（原商品数组索引） |
| 仓库空位 | `hubTab` + `data-tab=stash` + `data-view=cards` |
| 扩建入口 | `hubTab` + `data-tab=upgrade` |

没有自己的购买命令、计时器或事件监听，购买后的余额、持有量与缺口依赖既有 `renderHub()` 更新。布局不引入新玩法；独立页返回与购买结果提示由基地壳继续负责。
