# 保险箱动画与奖励领取流程

2026-10-15 老板确认灰白、石墨黑、少量朱红配色，并授权实装；随后要求奖励页先展示宝箱，领取宝箱后再选择卡牌。

现行素材为 `game/assets/scenes/chests/safe-simple-v7/` 的四张 640×640 RGBA 开合帧和独立白光。NAI 草稿经内置 imagegen 重绘为透明素材；内部只展示闪光，不绘具体奖励。五种箱型共用这套开合动作，原箱型的掉落与选取规则保留。来源、完整提示词、SHA256及技术对齐见 `game/art-source/chests/safe-simple-v7/` 的请求和回执。

奖励页停在宝箱，点击“领取宝箱”后播放蓄势、门缝、半开、开门白光与停稳，再进入原选牌/金币领取界面。待领取、已领取正在演出、卡牌领奖分别持久化；已领取演出中读档直接回原卡牌结果，旧快照沿原领奖阶段。点击跳过、减弱动态、队列代次与过期回调保护保留。
