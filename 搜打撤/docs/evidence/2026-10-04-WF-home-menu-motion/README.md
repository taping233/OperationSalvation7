## 实现与覆盖

- `game/src/ui/interface-motion.js`：在公共 UI 实例装配后，以装饰器接入原 `showOverlay/hideOverlay/showScreen/hideScreen`；原页面、点击、返回、存档回调继续由已有实现执行。覆盖全游戏所有走这些公共入口的页面与弹层。
- `game/css/interface-motion.css`：统一缓动和淡入/轻移/收回语言；全屏页约340ms入/200ms出，标准弹层280ms入/200ms出，确认窗220ms入/160ms出，战斗快档180ms入/140ms出，快档位移4px。普通关闭仍由原225/160ms清理计时完成。
- 原 room-view 瞬隐且没有显式immediate的关闭，增加140ms视觉退场，再调用原同步收场；新页面打开会取消这段等待并先完成旧清理，避免迟到的关闭擦掉新页。显式immediate、减少动态效果与原有挂起关闭仍走原即时/取消逻辑。
- 基地同页数据刷新不重复整页入场；只有页签变化重播。战斗同模式高频重绘不重播。竞争的旧整页CSS与根卡片WAAPI停止叠加；卡牌/人物/奖励等对象级特效保留。
- 旧导航斜纹闸门视觉停用，并移除其短期挤压/关闭背景模糊标记，避免与新统一转场再叠加；旧导航控制代码未修改。
- 告别屏与右键留言浮层沿公共屏幕入口接入；普通卡牌放大容器统一淡切及缓动，照片的来源位置/翻转/回收路径与清理计时保留。成就详情用隐藏状态的离散display过渡补成对开合，旧内核按既有hidden行为降级。
- `game/src/ui/home-menu-motion.js`、`game/css/home-menu-motion.css`：主页左右菜单分别退向外侧，返回按25–35ms错峰归位，约半秒收齐；标题/底部工具轻移淡切；静音图标即时轻脉冲，退出先220ms退场再调用原退出按钮，浏览器拒绝关窗时恢复菜单。
- `game/src/ui/title-credits.js`：制作名单使用同款开合；返回按钮、Esc、外侧点击等待约200ms退场后原生close，保留焦点返回。
- 减少动态效果在CSS和JS分支均接入。主页失败/迟到打开有来源序号兜底，减少连续切页遗留状态。公共层仅按界面动作启动，不新增常驻轮询或素材。
