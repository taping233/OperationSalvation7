# 探索演出与本局纪念

老板先授权执行六项候选，随后明确“局部机制暂时不用加进来”。本轮落实特殊遭遇提示、现有送信兑付演出、本局纪念；持物解法、额外挑战与环境条件均未实施。本轮不改卡牌、数值、随机、节点配额及奖励规则，无提交、推送或 build。

## 实现

- 失联配给柜、封存储备库、异常改装台显示各自的简短提示与入场图形；新绑定事件首屏入场，同地点返回/整理背包及读档只显示静态提示。
- 祭坛与首脑迎战页接入同一呈现组件；每局同地点只领取一次入场呈现资格，图形不锁操作。首脑提示不提前抽取或透露尚未确定的首脑。
- 送信沿用现有骰子、免费货位和保存流程，仅加强兑付清单、划去的付款状态及免费标记；神秘箱不提前揭示内容，也不把免费资格当作已领货物。
- 成功/失败纪念从真实回执呈现：有效首探地点按层汇总；最多三条经历读取凭据状态、祭坛、首脑及事件日志；纪念物只取实际入库/安全抢运清单。足迹不是完整移动路线，不推断玩家曾经放弃紧急撤离。不增加奖励或对局存档字段。
- 减少动态效果同时关闭本轮图形和凭据故事面板原有入场位移。
