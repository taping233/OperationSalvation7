老板要求攻击初始帧与原待机相同，攻击首尾也相同。统一版位于 [v3 预览](../../../game/art-source/characters/wu-attack-sprite-20261009/v3/index.html)，[素材说明](../../../game/art-source/characters/wu-attack-sprite-20261009/v3/README.md)记录来源和参数。待机及旧攻击版本未修改，未接入正式战斗。

攻击 `attack-00.png` 和 `attack-07.png` 直接复制已认可的待机 `idle-000.png`。三张 PNG 的 SHA256 均为 `484895aa505493825202539d4b7cfadf7c63c33997633b7940982a6634dbc63f`，字节与 RGBA 像素相同；画布均为 768×512。中间姿态匹配待机高度和脚底位置，两张收势图另修正生成时缩小的比例，避免末段突然变大。

通过：三张端点文件 SHA256/像素相等，全部轮廓留边、可见帧图一致、417 ms 时长、预览脚本语法。Codex 内置浏览器复用既有 5200，当前窗口真实按钮检查三个端点，并等待实际连播进入斩击、随后返回待机；错误日志零。工具不支持读取 canvas.toDataURL，未声称浏览器画布哈希通过，像素相等依据本地文件与帧图验证。

收据列相对路径与 SHA256。超过 1 MB 的图片只留本地，通过本任务目录 `.gitignore` 排除。无新服务、不构建、不提交。
