**硬性环境限制（解读本表全部数据的前提）**

1. **失焦节流**：时间类指标仅 `document.hasFocus()=true` 时有效；本环境实测失焦时 rAF=0、定时器被 Chromium 节流至约 1Hz，失焦数据一律无效（照相馆滚动早前失焦采样测得 [420,1004,997,1000,1000] 即节流伪影，已弃——该值归属勘误见 §⑤ 勘误注）。
2. **rAF 不触发**：本 IAB 环境对静止页面 rAF 不触发（含 active tab），无法直接测帧率；帧率类指标改用**主线程阻塞代理**：4ms 心跳偏差>50ms 计数 + `PerformanceObserver` longtask。

## ③ 关键发现（保守口径，不夸大）

1. **照相馆列表滚动为热点候选**：5 秒滚动期捕获主线程阻塞 ×3（88/138/207ms，median 138ms）+ 2 个 longtask，是本轮唯一明确的可感知卡顿场景（21125px 长列表 / 522px 视口）。
2. **基地页签切换很轻**：15 次切换 median 23.0ms（复核勘误：初稿误记 23.3，系取中位数 off-by-one，排序后第 8 小值为 23.0）、p95 47.1ms；唯一 47.1ms 为首次冷切换，其余 20.9–31.8ms——页签切换不是热点。
3. **地图进入很轻**：124.8ms（**样本 1**）。
4. **战斗进入最重**：1238.7ms（**样本 1**，结束回合按钮可见的构造判据可信但单样本，不可外推）；1.2s 中含敌人生成/牌库洗切，是否可优化留 A4 战斗重做评估。
5. **存疑待复核**：照相馆滚动另有 3 次 ≈993–998ms 心跳偏差，疑似滚动回卷瞬间整列表重排所致；未计入第 1 条结论，待复核后方可定性。
