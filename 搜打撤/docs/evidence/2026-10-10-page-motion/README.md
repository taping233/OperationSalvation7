## 公共实现

`page-motion-profiles.js` 只维护页面识别、展示顺序和区域角色；`surface-motion.js` 管理共享曲线、标题上移8px/导航横移12px/主体轻微收焦/内容上移12px/操作区上移8px，以及130ms内容退场、180ms遮罩退出（原即时关闭窗口用130ms）。入场延迟上限260ms，每块460ms。只操作布局容器，不逐项驱动大型列表。

`interface-motion.js` 识别同类页面重建，避免页头/导航重播；基地首次进入仍走camp-entry，基地切页调用内容编排。页面布局祖先被标记为静止，旧page-in标记移除，避免叠加整页入场；页面布局标记不在动画结束后移除，避免恢复旧动画造成闪动。

业务状态、存档、焦点及实际隐藏仍由原入口处理。战斗快面板、照片放大、主页及独立制作名单原生命周期未重做。现行维护入口更新到docs/development.md。
