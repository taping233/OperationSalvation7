# 基地双向区域切换补齐

老板反馈基地多处切换缺少左右滑动。本轮基于现行导航和局部更新源码实施，沿此前要求不运行测试、lint、类型检查、实页或 build；实际动效待用户验收。

## 改动

- `navigation-motion.js`：基地按房间各自的页面顺序判断方向。交易买入/卖出、后勤卡牌/待复原、收藏室六个子页、人物培养/招式/外观/伙伴/孵化、庭院和设施的已声明子页有独立排序，修正返回方向及未识别子页总从同侧进入的问题。既有公共入场与基地入场共用方向判断，保留各自距离和时长。
- `base-motion-v4.js`：真实点击成对选项时临时记录列表方向，同步局部刷新沿此方向滑入；意图在本次事件后清除。新增基地条目切换入口，复用既有取消旧动画、减少动态偏好及脱离页面守卫。
- `hub.presentation.js`：原位浏览人物、伙伴、设施、交易类别与商品时，依原列表顺序只滑动变化的内容/画面区域。交易类别栏等导航保持原位；商品货架只对列表播放。人物图片准备完成后按方向滑入，培养等正文随人物切换，外观右侧保持静止。无实际浏览选择变化的资源和装备更新不重播这些局部入场。
- `hub.archive-v3.js`：奖励/记录和勋章切换只滑动变化的详情，卡背预览只滑动展示画面；重复内容不重播，装备卡背等状态刷新不带预览滑动。

没有增加交易、存档或动作等待，没有改变原有最新图片请求守卫及重复选择判断。保留已完成的七套皮肤满铺与右侧原位更新。
