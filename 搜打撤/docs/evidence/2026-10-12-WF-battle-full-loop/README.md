# 影潮交锋 · 2分钟完整循环版

老板认可第四版后要求无缝衔接的完整版。已扩成128 BPM、4/4、64小节、120秒的原创完整循环版，保留已确认主主题、14轨配器及第四版鼓贝斯/旋律音强方案。新文件独立交付，正式游戏音乐未替换。

## 编曲

| 时间 | 内容 |
|---|---|
| 0–30秒 | 保留已确认主题与回答，后两小节转向下一段，不采用demo的终止淡出 |
| 30–60秒 | 发展段：前半主线降低八度，随后恢复音区，沿既有动机作句尾变化 |
| 60–75秒 | 八小节收束：伴奏减密度、降低力度，低音维持时间骨架 |
| 75–105秒 | 主主题回归，原轮廓重现，后半包含向上发展的变体 |
| 105–120秒 | 循环过门：最后两小节A7，C♯旋律拾音与A贝斯接回开头Dm |

完整版本由五段编曲构成，未将30秒成品录音复制四遍。原生事件谱与段落、和声、源文件指纹见[score.json](score.json)；可编辑完整LMMS工程为`battle-shadowtide-full-loop.mmp`，默认循环范围64小节。

## 首尾衔接与后期

五组总线各用已安装LMMS 1.2.2/FluidSynth渲染连续两周期，保留第二周期120秒，使开头带有上一周期的原生释放和混响尾音。GeneralUser GS为已有音源，没有新安装、采样参考录音或改全局配置。原音源许可沿用[初稿说明](../2026-10-12-WF-battle-rewrite-demo/README.md)。

分组滤波由上一周期尾部预热；慢速增益采用周期边界，左右早期反射用环形延迟。延续第四版贝斯−0.5dB、底鼓+0.8dB、军鼓/帽音/低打击+2dB的相对调整及轻微慢速补偿。移除demo首尾淡入/淡出，不插入静音，最后2ms仅修正残余端点差异。

第一遍测量发现末尾100ms比开头低约20dB，虽然没有PCM采样跳跃，能量支撑仍显不足。本轮在最后一拍补充A贝斯、底鼓拾音，并延长专用循环过门的C♯音；主主题保持。只重渲染受影响的贝斯、底鼓、主题总线，原军鼓/细节总线复用。

## 产物

- `battle-shadowtide-full-loop.ogg`：160kbps Opus-in-Ogg，解码后精确5,760,000帧，作为循环交付格式。
- `battle-shadowtide-full-loop.wav`：48kHz/24位立体声，精确120秒，循环母带。

- `battle-shadowtide-full-loop.mmp`：64小节原生可编辑工程；后期处理另见增益曲线和mix.py。

复现：在搜打撤运行`python docs/evidence/2026-10-12-WF-battle-full-loop/compose.py`生成工程与五组双周期原生录音，再运行`python docs/evidence/2026-10-12-WF-battle-full-loop/mix.py`生成循环母带、编码、两轮试听并验证。使用现有LMMS、SoundFont、Python和FFmpeg，无游戏构建。

原生双周期中间录音、单周期总线、交付音频仅本地保留，不进Git；项目相对路径、字节数、SHA256及处理方法见[render-report.json](render-report.json)、[compose.py](compose.py)、[mix.py](mix.py)。

## 验证

全部必要检查通过，原始结果在render-report.json：

- 48kHz WAV及OGG解码均严格120.000秒；连续两轮试听严格240.000秒。
- PCM有限值、无削波、无半秒意外静音；OGG真峰值−2.64 dBTP，响度−19.50 LUFS，LRA3.3 LU。
- WAV首尾采样差为0；接缝二阶差0.00110，低于普通相邻采样变化99分位0.04268；OGG解码接缝也通过同类检查。
- 首尾各100ms的RMS差为4.82dB，通过本轮“不得产生巨大能量落差”的内部9dB上限；这一上限是工程检查条件，不是通用音乐审美标准。
- 结尾A7与开头Dm的和声映射核对通过；没有首尾淡出或补零静音。

这些证据覆盖时长、解码、声学端点和能量衔接，不替代实际听辨。连续两轮试听已提供，最终听感仍待老板试听；本会话未声称人工听过。
