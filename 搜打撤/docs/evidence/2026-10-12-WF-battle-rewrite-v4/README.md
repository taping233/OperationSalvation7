# 影潮交锋第四版 · 鼓贝斯与旋律音强平衡

老板要求保留第三版主旋律，调整鼓贝斯与旋律的音强关系，出30秒demo。第四版仅做分轨后期混音；原生工程全部14轨及音符力度保持第三版，未增加、删除或移动任何音符。正式游戏未实装。

## 音强调整

- 贝斯与大提琴从底鼓总线分离，静态降低0.5dB；主题段按0.75秒平均能量作慢速增益补偿，幅度限制±2dB。
- 底鼓单独提高0.8dB，不进入贝斯增益补偿，保留原生瞬态与相对重音。
- 军鼓、帽音与低打击总线提高2dB，既有鼓型及全部音符力度不变。
- 旋律总线按0.65秒平均能量作慢速补偿，幅度限制±1.8dB；其后主题段整体采用0.8秒平均能量、限制±1.3dB的轻微支撑调整。
- 增益补偿只在3.75–15秒及18.75–26.25秒渐入；保留开头、中段收束、终止和最后400ms淡出。既有音色滤波、早期反射与低频居中方案沿用第三版。

补偿是平滑的音频增益变化，不是改写演奏谱。贝斯、旋律及整体的实际曲线分别见[bass-gain-curve.json](bass-gain-curve.json)、[theme-gain-curve.json](theme-gain-curve.json)、[support-gain-curve.json](support-gain-curve.json)。处理公式与顺序见[mix.py](mix.py)。

所有谱面事件字节一致、原生XML音轨一致、新混音有限值、无PCM削波、MP3完整解码、真峰值及响度检查通过。数值证明指定范围的能量起伏减少，不证明听感达到商业成品；本会话没有实际听辨，仍待老板试听。
