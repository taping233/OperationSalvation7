## 教程阅读与应用

已通过内置浏览器核对[原视频](https://www.bilibili.com/video/BV1TeMbzwExw/)标题、作者、简介，并读取播放器加载的自动中文字幕全文（1424 条；本地原件 `.tmp/nai/snow-night-20261015/tutorial-subtitle.json`，相对仓库根）。重点复核 13:02–29:40 提示词、30:31–37:49 参数与导入、38:01–45:25 多人及交互；其他章节含工具箱、氛围转移与辅助工具。未购买付费课件、未安装教程软件。自动字幕的数字与拼写错误不作为接口契约，官方文档交叉核对见现行说明。

采用：简短标签定身份、短自然语言定空间关系；基础词与各角色分工；共享 token 预算；数值权重闭合且不暴力叠加；坐标与文字位置相互呼应。未引入不适合独立进食的施受动作标签，未把模型不认识的原创人物名当作身份标签。氛围参考作为可选能力，当前两张均为纯 NAI 文生图，未上传人设图。

Google 官方 T5 分词数据获取自 `https://huggingface.co/google/t5-v1_1-xxl/resolve/main/spiece.model`，临时保存在 `.tmp/nai/snow-night-20261015/t5-spiece.model`，用已安装 sentencepiece 测算。第一版原始正面计数 352+108+96=556；第二版 250+74+65=389。计数含权重语法原文，与服务端内部解析不保证完全一致；不能据此断言第一版具体在哪个词被截断。第二版留出约 123 token 余量。

## 样本与反馈

第一版：1344×768，NAI 4.5 Full，seed 15102026；[请求](request-v1.json)，[图像回执](image-receipt.json)。老板反馈“效果很差”。本会话观察：轮廓线重、赛璐璐感强，城市雪夜辨识度低、对称双人餐桌缺少宣传图的纵深，无出现蓝腰带等身份偏差。不能把第一版记为审美通过。

第二版：同模型、种子、尺寸与采样参数，提示词总量显著缩短；风格前置并适度加权，改斜向餐桌和前后人物层次，加强暗色城市、积雪屋顶与窗外飞雪。请求与原图另存，不覆盖第一版。

第二版已由官方接口 HTTP 200 返回，1344×768 PNG 校验成功；[图像回执](image-receipt-v2.json)记录原图路径与 SHA256。观察：斜向桌面、人物前后层次、暖色灯与冷暗窗外均已表现；场景更宽，人物相对变小。厚涂宽笔仍弱，细线与材质纹理偏多；雪点近似星点，积雪屋顶不明显，未满足所有画风与城市雪夜目标。无的部分长袖与星月发型仍有偏差。只交付本次提示词迭代样本，不称画风通过或正式游戏宣传图。老板尚未评价第二版。
