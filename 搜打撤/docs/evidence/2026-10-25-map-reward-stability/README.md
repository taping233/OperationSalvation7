## 奖励总览

`game/src/run/chests.js` 接入局部更新，覆盖领金币、重试保存等总览刷新。局部刷新沿用现场滚动位置，不回灌上次从卡牌选择层返回时的旧滚动快照；实际从选择层回总览时仍恢复原位置。原焦点被移除或变为禁用时，只在当前总览版本内恢复到同动作或下一可用入口，使用preventScroll。新增独立总览呈现代次；局部刷新虽然保留根节点，旧异步回调和旧动作闭包仍会失效，不借复用节点放宽原归属守卫。

本轮只改变总览呈现。奖励生成、金币/卡牌发放、容量、领取事务、保存和失败重试规则保持原实现。原逐张领取页已有局部更新，本轮保留。
