## 设置与子页返回

`menu-settings.js` 使用公共 `createOverlayReturn`，退出私有returned标记与按CSS认领数据页刷新的分支。信箱/数据子页每次真实重建通过 `onRender({root,revision,isCurrent})` 回报来源；本次子页刷新后重新接同一来源，旧页或新局接管时结束旧返回。设置完整绑定后才恢复原分类、展开、滚动与来源按钮焦点，原returnTo继续透传真实结果。

`menu-feedback.js`、`menu-data.js` 的入口第三参支持 `{onRender,isCurrent}`；`agent.data.js` 的数据页入口首参支持同形选项，默认独立打开沿用原行为。数据清空刷新通过明确渲染端口回报，退出menu-data的MutationObserver和按同类页样式猜身份。

## 键盘操作设置

`settings-input.js` 在控件可用时处理改键，冲突确认结束后核对请求与当前页面；切页、隐藏或关闭后的旧结果不修改全局键位。取消冲突显示已取消；Tab正常移向下一控件，焦点离开当前改键按钮时结束监听。监听提示与实际状态保持一致，原Input键位计算与存储行为沿用。
