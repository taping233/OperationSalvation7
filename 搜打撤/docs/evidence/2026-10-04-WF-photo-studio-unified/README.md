## 实现方向与改动

- 页头、分类、搜索、三个选择栏、当前选片详情、大图背签采用同一套哑光纸白/深青灰/暖金点缀及清晰细线控件；移除厚重柜框、纹理堆叠与复合光影的外观承托，统一字体、间距和按钮层级。
- 选择栏包括稀有度、人物和排序：原 select/id/value 作为状态端口保留，外观改为馆内统一展开列表。通过既有 input 委托触发过滤，change 继续提供兼容通知；重复选择当前值不重绘。筛选重置同步可见标签和选中状态。
- 控件实现鼠标选择/点击外部收起、方向键/Home/End、Tab离开、Esc先关选项列表；保留输入法组合态守卫，向辅助技术提供目的/当前值/选中项。该键盘和可访问性实现未实页验证，不宣称通过。
- 选片台整理为卡面、费用/类别/稀有度、效果、编号/备注、上一片/下一片及大图入口的顺序；照片以简练纸边承托，夹子和稀有度识别保留。大图照片框、背签和备注输入延续同一语言，仅限照片模式，不影响其他卡牌大图。
- 复用既有过滤/排序/选择/大图/窗口挂载、缩略图、局部预热、有界解码和退场逻辑，没有改图片、卡牌数值或其他页。
