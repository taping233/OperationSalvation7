# 第一首第七版：从开场就有管弦垫底 · 2026-10-05

老板反馈缺垫音、乐器少、应从一开始就有，不让钢琴solo。本轮保留第六版真实延音踏板钢琴，修改和声支撑的进入位置，并增添持续音色层，只交第一首候选。

## 编配

将原来第8–16小节的已认可弦乐／大提琴和声复制到第0–8小节，并抬出开场的表情曲线，使第一拍即有底。旧版第8小节以后的弦乐音符保持不变。钢琴两条冻结录音、原生轨道与踏板处理的XML完全不变。

新加柔弦乐和声垫、中提琴中声部和低音提琴低部，全部从第一拍开始，以每两小节一次的长和声／低音为主；没有加入抢主线的新旋律或碎音序。演奏音轨总数由5到8，乐器类型仍是古典管弦与钢琴，轨数不是好听的证明。新增垫音跟随原有C小调及A/B段和声。

## 真实开场核对

除了全曲，另用LMMS导出了静音两条钢琴后的伴奏，以确认实际音频中有垫底，而不只是MIDI图上有音符：

- 全部8条演奏轨第一段都在beat0；
- 伴奏开头前200ms已有非零声能；
- 前2秒伴奏RMS为−27.20dBFS，约为整混音RMS的29.63%，作为背景支撑；该比值不是占总功率29.63%或审美分数；
- 与第六版整体响度同口径对齐为−15.53LUFS。

这些检查确认开场已有支撑，是否够饱满、是否仍保持主次，以老板试听为准。
