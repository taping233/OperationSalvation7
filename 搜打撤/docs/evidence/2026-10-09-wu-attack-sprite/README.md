# 无攻击 Sprite：参考改版候选

当前成果为[新版预览](../../../game/art-source/characters/wu-attack-sprite-20261009/v2/index.html)与[素材说明](../../../game/art-source/characters/wu-attack-sprite-20261009/README.md)。老板认可待机后令制作攻击，随后否定首版并要求参考别人如何制作攻击帧。本轮据原作者公开示例核对动作，再重做候选；未接入正式战斗、未提交。

## 动作参考与本轮改动

- [Raymond Schlitter / Slynyrd：Pixelblog 9](https://www.slynyrd.com/blog/2018/9/8/pixelblog-9-melee-attacks)：内置浏览器实际查看了剑击 GIF 的站姿、预备、短拖影、命中、惯性、收回与过冲分解。示例拖影停留短，命中停留略长；角色姿势与武器轨迹需要连贯。
- [imonk：Sword Slash Animation](https://itch.io/t/2489691/pixel-tutorial-sword-slash-animation)：原作者描述预备时后倾、转腰及后脚转动，斩击时前倾并抬起后脚跟，收势避免直接跳回待机。文字与插图入口已核对。

首版过度固定双脚，以抬臂换姿态代替完整发力；导出时逐姿态缩放脚距，也削弱了自然重心变化。新版改为同一比例导出，保留前腿承重和后脚转动，以前脚横向位置和整幅脚底基线对齐。八姿态中包括一张主要拖影姿态和命中处的消退剑迹，头发继续简洁垂落。

新版 8 张关键姿态按 10 个 24 fps 时间步播放，约 417 ms；预览另有 900 ms 的待机间隔。部分时间步为明确的预备/命中停留，未宣称 10 张不同原画。源图由内置 imagegen 生成，提示词、源路径及动作参考见新版 `request.json`；参考图未复制进运行素材。

## 验证与边界

十二姿态首版、八姿态新版均完成透明导出与完整轮廓留边检查。新版同一比例、4×2 帧图与独立图片引用、时长求和、脚本语法通过。Codex 内置浏览器复用既有 127.0.0.1:5200，当前窗口真实按钮/键盘检查预备、命中、收势、暂停、进度与单次播放，明暗背景查看完整人物与剑尖；错误日志核对为零。动作自然度与设计认可仍由老板审阅，未验证正式战斗衔接与伤害触发。
