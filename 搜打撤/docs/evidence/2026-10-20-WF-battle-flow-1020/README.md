- 普通战斗携带牌直接入手，另建 99 张独立临时初始攻击。开局和常规回合不自动抽牌；抽牌效果从真实牌库取牌，空库停止，不生成替代牌。临时初始攻击不进入战后随身存档。
- 老板确认弃牌堆、墓地与消耗牌堆为一个「消耗牌堆」，普通、首脑和龙巢均不自动洗回，仅由卡牌效果取回。界面只留一个入口；本场取回与统计共用同一来源，地图消耗区仍按跨战斗存储规则结算。

- 伤害动作读取已加载的实际帧时间线与接触姿势；连击不中途重播同一动作。实页发现异步渲染尚未提交时提前读取反馈队列，新增可取消的提交屏障与回归，由框架聊天迁入其新呈现适配器。
