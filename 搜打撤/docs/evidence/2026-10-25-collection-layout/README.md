## 改动

- 成就、照相馆与预设页头接入公共 `collection-chrome`；返回、标题、分类和内容工具栏各有稳定位置，页面用局部主题变量声明颜色。
- 成就合并重复进度，缩短列表行，把名称、状态、条件放在一起，移除每行可见的重复“查看详情”。待领取/已领取只筛选现有状态。
- 成就详情改为右侧非模态区域；列表、分类、筛选保持可操作，支持上一枚/下一枚。Esc收起详情，页头返回离开页面。切换取消时分开记录请求目标与已呈现奖章，避免快速关闭再开显示旧正文。
- 照相馆标题移到左侧，搜索、稀有度、排序、人物筛选归入同一工具栏；保留原卡面、相片框、纸面详情和放大接线。
- 预设卡片显示名称、人物、同伴和卡牌摘要；编辑默认折叠，资格、容量、缺失、禁带及应用操作持续可见，内部编号仅保留为命令标识。

直接重写原组件定义，删除被替代的成就模态动效、旧页头/筛选规则和预设重复样式，没有在文件末追加纠正层。未删除文件或目录，未更改奖励、存档、卡牌数据或玩家导航入口。
