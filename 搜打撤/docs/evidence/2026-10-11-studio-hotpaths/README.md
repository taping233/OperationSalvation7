# 照相馆专项热路径优化

2026-10-11，Friday / WF-studio-hotpaths-1011，完成未提交。

本轮直接处理选片、深位定位、缩略图挂载到解码、关馆释放的具体开销；没有用减画质、撤动效或移除词条换取性能。

## 路径改动

1. 瓦片壳索引按ID建立：初始网格重建时认领全部已有壳，后续分帧追加的壳增量登记。定位和单卡挂载使用Map，不再反复用选择器搜索整片网格；离窗卸载仍保留壳索引。
2. 筛选结果计算后建立ID到位置的索引，保留第一个同ID的位置口径；详情导航和前后选片直接读取索引，不重复findIndex。索引随筛选重建、关馆清理。
3. 选片只清除上一张的状态，不再扫描全部selected节点。同卡且无强制刷新时直接返回，仍按原请求保留提示音；筛选刷新继续走强制更新。
4. 深位定位只同步补壳到目标。例如队列尚余188张、目标在队列第18张时，只生成18张而不是188张；该数字是算法示例，不是实测。剩余壳继续沿原分帧调度追加；滚动到当前底部仍保留无参全量补齐的兜底。
5. 瓦片观察器已确定处于近窗的图片、真实定位后挂出的图片直接排入解码队列，取消该图片可能已有的二次观察。初始批和其他图片保持原图片观察器；并发上限仍为4，旧会话/离线节点/失效scope检查保留。
6. 关馆释放本页数组、ID/壳/位置索引、搜索文本、筛选/分类缓存与描述渲染器。浏览锚点独立保留，再次进馆按当前卡库重建。
