## 本次处理

第五版左右弦乐、大提琴的音符、音源／音量／声像设置以及三条连续表情曲线逐节点原样保留，序列化指纹在新旧原生工程间完全相同，见 verification.json。整体试听响度另外匹配第五版，故曲子的绝对声压可随共同增益改变，不把“谱和曲线原样”误说为最终混音每个采样点相同。

钢琴这次处理声音本身：通过已安装LMMS的FluidSynth 1.1.6库离线重录原有两条钢琴，以MIDI CC64实际按下／抬起延音踏板，每两拍更新并在换和声前释放；键长与相邻音小量衔接，击键速度降低，轻度高频整理。主钢琴相对原弦乐降低3dB，安静钢琴和声降低4dB。没有用增大混响代替踏板；最终使用与第五版相同的房间处理。

原生SF2播放器源码和[FluidSynth MIDI API](https://www.fluidsynth.org/api/group__midi__messages.html)核对了松键／延音行为。单音同音源对照：松键后1.3–1.8秒，普通键释放RMS为0.0000426，踏板保持为0.003175，尾音相差约37.45dB。这个探针证明实际踏板控制影响了录音，不证明整首主观听感一定更好；上次只提高乐谱时值覆盖率，未处理此发声行为。

钢琴录音随后通过AudioFileProcessor导入原生LMMS与保留的弦乐混音。可编辑MMP保留弦乐与混音；钢琴是冻结录音，修改钢琴音符／踏板需要重跑render.py，脚本引用第五版保存的原始音符事件，记录踏板事件和录音指纹，没有冒称MMP内仍可逐音编辑该录音。
