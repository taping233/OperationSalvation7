# 现行测试梳理与精简

本轮静态扫描 949 个测试文件，并对19个确认存在过期分支、重复执行、手抄旧卡面或无效断言的测试文件实施更新。带日期和旧存档兼容本身不作为删除依据。未删除文件，未修改游戏源码或正式卡库。

## 改动

- M1至M8的正常整批迁移从89次重复执行合并为8次，仍逐卡核对独立规则期望、卡面与保存复读。保留逐卡自定义保护、缺卡、保存失败、重入和版本迁移用例；新增完整目标ID集合校验，防止数据缺失导致循环静默少测。
- M6去掉“能力不支持就自动skip”的临时探测与等待分支。功能退化现在必须失败；移除1个过期等待用例。
- M5原九张候选的测试改读现行真实卡库。刀剑形态、江湖救急-改、扰敌、不朽斩使用正式规则断言，不再拿旧草案的非法参数来证明功能缺失。通用非法输入仍由schema/capability专属用例覆盖。
- M7装备卡面取当前解析数据，独立规则期望继续保留；清除M4已退役深海印记的无效期望。
- A3熔岩爆破断言改查真实手牌中的二次爆炸ID和精确数量，移除“长度>=0”的恒真条件；结构化中毒对照保留，并纠正“数据未迁移”的旧说明。
- 普通事件生命周期测试移除生产端不读取的旧故事假端口与空断言。真实flow保留旧故事数据不受影响的覆盖，以抛错桩阻止旧系列入口复活；独立故事存储与Ink兼容测试保留。删除重复的源码字符串退役断言。
- 5处Canvas桩去掉恒真条件和对应lint压制。
- 核实五张TT12卡均已在正式库后，清空过期缺卡豁免；补正式配置为空及无豁免缺卡必须报过期的断言，同步质量门说明。

## 结果

同一组18文件由398通过、1等待，变为331通过、0跳过：合并67个重复用例，移除1个过期等待。扩展到31个相关文件（包含全部11组迁移、schema/capability、实战、启动、架构及文档守卫）后570项通过，无失败、无跳过。ESLint、文档和差分空白检查通过。
