# 主页音频、恢复与照相馆切幕

2026-10-11，Friday / Codex，会话 01a12b04。老板反馈标题悬停音尖锐、主页 BGM 不自动播放、恢复界面闪帧、左右入场缺少层次，并选择将照相馆过场统一成成就同款。改动完成未提交。

## 改动

- 标题模式的悬停采样增益从 0.12 改为 0.055，以 0.82 倍速和 1200Hz 低通播放；回退提示从 1500Hz 改为 520→430Hz。其他音乐模式的悬停音保持原参数。
- BGM 在请求主页音乐时即加载并尝试播放；保留浏览器音频解锁，捕获首次点击/按键，重试当前播放失败的曲目，避免恢复过程中重复启动。
- 壁纸预览恢复后保留背景，不重播 `homeWake`。右侧控制台比左侧晚 280ms，标题、主操作、收藏、系统及页脚逐项入场，全部结束后才释放恢复标记。
- 照相馆加载期间暂停共用城廓切幕；内容就绪后恢复成就同款的斜切、场景、字牌、档案线条动画，统一 980ms 清理时长。异步准备、取消和图片就绪等待保留。

## 覆盖边界

当前内置浏览器每次刷新仍会限制无交互音频：已实测音乐提前加载、首次点击后开始并在返回主页时持续播放；不能宣称刷新后必然自动出声。未作主观听感评价。无本轮全量测试、生产构建或远端 CI 覆盖。

既有主页、照相馆和共用切幕改动在本轮基础上保留；编辑前源码指纹见 [ui-before.json](ui-before.json)。现行音频说明和开发文档照相馆段已同步。
