# 破甲箭效果修订

老板授权将破甲箭的额外效果由获得 3 点护甲改为破甲。现行效果为：1 费，造成（你的攻击力 - 1）点攻击伤害，再对目标附加 2 回合破甲。回音箭仍为原伤害后自身获得 3 点护甲。破甲时长沿用游戏已有默认值；本次伤害先于破甲结算，后续攻击受破甲影响。

修改 TT10 定版行、M2 规则及定向用例；旧卡库通过独立修订入口更新，不依赖旧 M2 marker 重跑。只处理匹配已知旧卡面的破甲箭，删除旧 armor 字段、替换描述和规则；自定义名称、伤害、护甲、描述、规则及其他卡保持原样。保存失败不原地修改原卡，下次启动可重试。全书由原生成命令更新，M 批矩阵同步本卡。
