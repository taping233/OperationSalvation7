# 画质设置保存反馈一致性

## 已核实问题与当前行为

浏览器拒绝 localStorage 写入时，画质与动画帧率仍即时应用到当前会话。原实现只在当前 DOM 节点写入失败提示，关闭后重开设置会显示内存里的新值，但警告为空，掩盖尚未持久化的状态。原提示“重新打开后可能恢复”也没有区分重开设置与重新加载游戏。

修复仅保存当前会话的失败标志，重开设置继续显示警告；后续任一画质/帧率写入成功后清除。提示明确为“重新加载游戏”。返回保持既有即时应用语义，不新增保存/取消操作，不修改预算、画质档位、调度策略或游戏存档。
