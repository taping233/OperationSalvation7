## 实施与视觉反馈

1. 复用项目专绘transition-photo-v2.webp作为常驻馆内环境：旧相机、木桌、幕布与相纸位于右侧下部；相机在纯文字档案下方可见，左侧压暗以托住照片墙。入馆与馆内共享美术对象。
2. 默认、空态与大图共享房间场景；大图加静态深色遮罩，避免原列表信息与背签重复叠出。
3. 第一轮实页出现背景上缘硬切线和右侧空白相纸亮度抢眼，第二轮增加顶部融合渐变并压暗最右区域。大图同样补顶部融合，最后该渐变微调未另拍。
4. 调整照片接触阴影、方向投影、档案纸边缘/纸纹/色温、顶部玻璃底色、选中外沿强度，保持原画颜色、透明衬底与稀有蓝夹子。
5. 查看入口用铜色纸纹，并用快门符号替换通用箭头；主功能与无障碍名称保持。空态共用快门符号。
6. 实页空态发现重复空档案纸与提示底框，第三处反馈迭代删除这两项；仅左侧居中提示和重置入口，保留场景留白。
