# 首页入口环绕光与选人面板竖带

首页“进入城市 / 成就总览 / 照相馆”各增加一个不接收指针的SVG轮廓光层：主入口暖金、成就浅金绿、照相馆冰蓝。光段沿轮廓慢速循环，悬停/键盘聚焦增强；覆盖页、制作名单、离开首页与只看壁纸时暂停；系统或游戏减少动态效果时只保留静态弱轮廓。按钮布局与点击区域不变。

老板随后提供选人页截图，信息面板出现贯穿上下的竖向深浅色带。截图对应的 `roster-departure-v2.css` 信息面板原为半透明渐变叠加 `backdrop-filter:blur(18px) saturate(1.15)`；本轮改为不透明的连续渐变并关闭该面板背景采样，消除背后分区参与混色的路径。背景采样/叠层是当前推断，未做实页对照，不宣称已证明唯一根因或竖带实页验收通过。没有据此批量移除其他界面的模糊效果。

改动为 `game/src/ui/home-fx.js`、`game/css/home-polish.css`、`game/css/roster-departure-v2.css`。前两份保留之前清理增量。
