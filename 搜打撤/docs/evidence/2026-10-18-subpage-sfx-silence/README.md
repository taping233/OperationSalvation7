# 子页面点击与进入音静音

老板反馈进入界面仍有声音，并要求取消子页面点击音。源码定位到全局按钮pointerdown先播放click、pointerover及部分显式调用播放hover、基地导航另发navigate、选档动画840ms后另发scene。之前仅静音open等样本未覆盖这些路径。

音频入口在主浮层、卡牌详情、留言层及原生对话框打开时跳过通用click/hover；主菜单页面入口及地图背包、保险箱、消耗区入口也跳过自动点击/悬停。navigate设为空样本，选档动画删除场景音定时器，视觉动画与选档操作不变。试听清单与现行说明同步；具体配置见changes.json。

具名奖励、交易、战斗反馈及场景配乐维持原配置。按老板要求未运行测试、构建、浏览器或听感验证，由老板验收。未创建或启停服务，未提交、推送。
