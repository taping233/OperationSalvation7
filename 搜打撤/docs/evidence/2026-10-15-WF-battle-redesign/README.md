# 战斗界面二游重设计（WF-battle-redesign-1015）

老板 2026-10-15 指令：**对比二游重做战斗界面的设计，幅度要大、借鉴要多**。同日
「战斗指挥台」第二版（行动档案重皮肤，纯 CSS）只换了皮没动布局，本轮在设计层面重做。
交付物：本设计稿 + 可交互隔离小样 `game/battle-redesign-demo.html`
（`http://127.0.0.1:5200/battle-redesign-demo.html`，复用主线 Vite，未改任何现行战斗文件）。

## 一、核心判断

现界面的根本问题不是配色，是**信息架构照搬杀戮尖塔 + 三套视觉语言并存**：

1. **回合秩序靠文字**。顶栏写「第 1 回合 · 你的行动」、讯标、意图章、气泡四处重复同一件事，
   二游早就把「谁下一个动」画成空间结构（星铁左缘行动条、阴阳师底部行动条）。
2. **底栏是一个大杂烩**。能量球、战术钮、药水、选中卡预览挤在左角，手牌居中下沉，
   结束回合缩在右侧小钮——主操作没有主操作的样子（七圣召唤/战双的宣示主钮）。
3. **人物没有舞台**。立绘浮在场景图上，无平台、无地面阴影、无景深层次，画面「平」。
4. **打击感缺失**。无伤害数字体系、无受击反馈层、无暴击的仪式感（星铁/绝区零的数字与冲击帧）。
5. **卡牌可打性不说话**。能量够不够要玩家心算（方舟的 cost 点亮是现成答案）。

## 三、新信息架构（1920×1080）

```
┌──────────────────────────────────────────────────────────────┐
│ 作战条(36px)：遭遇名·波次 02/03 │ … │ 余敌 2 │ 设置 投降      │ ← 顶带瘦身，回合/状态移出
├───┬──────────────────────────────────────────────────────────┤
│ 行 │                                                          │
│ 动 │              战 场 舞 台（场景+暗角+景深）                 │
│ 序 │   [我平台·冷青]              [敌1平台·红]  [敌2平台·红]   │
│ 列 │   我方档案(头像+HP pip+护甲)   敌档案签(名+HP+状态行)      │
│ 栏 │                              意图徽章(敌头顶，唯一真源)    │
├───┼──────────────────────────────────────────────────────────┤
│   │ 资源坞        抽堆 │  手牌甲板（扇形×5） │ 弃堆   行动钮塔  │
│   │ 能量核心·注能·药水竖列                  │       结束回合   │
└───┴──────────────────────────────────────────────────────────┘
```

分区要点：

- **左缘行动序列栏**（星铁）：宽 76px，节点=头像圆牌（我=金环、敌=红环）+ 微型意图 glyph；
  当前行动者放大点亮，其余 60% 压暗；顶部回合数。悬停展开 220px 显示名称与意图数值。
  「你的行动/敌方行动」不再用文字广播，由**谁亮着**表达。
- **战场舞台**：场景图 + 两侧电影暗角 + 底部渐晕；平台椭圆 240×64，边缘 1px 亮环，
  平台内 45° 地纹 4% 透明度；立绘立于台上带柔影。敌方档案签浮于头顶右上：名 20px/800、
  HP 条 180px、状态图标行（图标+层数）、意图徽章（平行四边形红底白字「攻击 3」，
  危险型加斜纹缘，下方发丝线锚回单位）。我方档案在舞台左下：64 头像 + 分段 HP pip（方舟）
  + 护甲盾 chip。
- **底部指挥台**（七圣召唤三段）：左**资源坞**（能量核心：青六边形+数字+pip+金瞄准角框；
  注能条：满时头像金态「爆发就绪」；药水竖列纸白）；中**手牌甲板**（FGO 扇形 5 张，
  类型色费用宝石，可打性点亮/熄灭；两侧牌堆章）；右**行动钮塔**（结束回合=斜切金主钮
  25px/800 全场最重；背包/战术次级 chip 竖列）。
- **顶带**：只剩遭遇标识、波次/余敌、设置。状态徽标、arena caption 全部裁撤（信息进左栏）。

## 四、视觉与动效规格

三色纪律沿用 v2：**金=我方主动作、红=敌方/危险、青=能量/资源**，中性石墨蓝面板；
几何家族：动作件左上斜切、信息件对角切角、1px 冷光缘 + 顶封条线。卡牌本体与药水纸白
身份不动（老板定版），状态层（可打性/类型色宝石）加在槽位上不加在卡上。

动效全部状态驱动、零常驻循环、零 filter 动画，`prefers-reduced-motion` 全量降级：

| 时刻 | 表演 | 来源 |
|---|---|---|
| 回合开始 | 发牌 flip-in（错峰 60ms）+ 行动序列重排滑动 | FGO/星铁 |
| 悬停卡 | 抬升+微弧，其余牌退让 0.78 | FGO |
| 选目标 | 候选敌锁定角框金环 + 指向线 | 方舟 lock-on |
| 出牌命中 | 卡飞向目标 → **90ms 冲击帧**（白闪+画面 1.012 顿挫）→ 伤害数字弹出 | 绝区零 |
| 暴击 | 金色 40px 数字 + 「斬」拟声大字（可关） | 绝区零 |
| 连续出牌 | 连击计数 chip ×N，回合结束清零 | 战双 |
| 能量变化 | 核心数字滚动 + pip 填充 | 星铁战技点 |
| 注能满 | 我方头像一次金闪 + 静态金缘「爆发就绪」 | 尼克 |
| 敌方回合 | 左栏敌节点逐个点亮→意图徽章消耗动画 | 星铁 |
| 我方危险(HP≤30%) | 档案一次长脉冲后静态红缘+斜纹 | 方舟 |
