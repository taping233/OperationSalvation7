# 基地旧样式与动效清理

完成未提交。清理共用控件和阅读面板的旧版本残留，沿用现行基地玻璃布局、横向导航与业务动作。

## 改动

- `base-controls-v4.css` 移除通用按钮切角、底部扩展扫线、固定箭头分隔和按压位移，消除旧白底悬停与选中项反色。按钮保留边框、键盘焦点和禁用反馈。
- `base-personnel-v12.css` 将已单独调定的培养入口扫线收回自身作用域，保留520ms悬停与620ms底线过渡；其他基地按钮不再继承。
- `base-rooms-v7.css` 将房间与详情的纸面底色/文字变量改为公共玻璃变量，修正伙伴资料内层白纸变量、孵化材料不足的深棕文字，以及建设金色按钮的浅色文字。
- `base-camp.css` 移除已由公共横向编排接管的旧整页竖向入场。提示条仍有自身反馈。
- `base-motion-v4.js` 移除操作按钮箭头的额外位移动画，保留同页内容切换方向、连续刷新取消与减少动态逻辑；同步已有专测。
