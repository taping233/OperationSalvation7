## 优先修复的实测异常

1. **祭坛领奖后页面卡住（F01）**：献祭三张卡 → 选择传说卡与装备卡 → 骷髅王剑奖励演出结束，旧二选一页面仍在；「离开」和 Esc 无效。正常读档恢复地图，背包从献祭前 16 格变为领奖后 15 格，奖励保存但界面未退出。见 [现场](32-altar-stuck.png)、[页面](32-altar-stuck.txt)、[读档后](33-altar-reload-recovered.txt)。
2. **满包事件吞掉奖励（F02）**：16/16 时进入「满电动力锤」并点收下；直接回地图，节点变为「内容已消耗」，装备筛选中没有闪金之锤。`grantEventCard` 容量失败返回 false，事件 `settle` 分支忽略领取结果并继续结算。见 [实页](17-full-event-missing-reward.png)、[页面](17-full-event-missing-reward.txt)；定位 [事件分支](../../../game/src/run/game.run.flow.js#L821)、[动力锤](../../../game/src/run/game.run.flow.js#L869)、[发卡](../../../game/src/run/game.run.scenes.js#L414)。
3. **招式筛选失效（F03）**：包里有武术、法术，选择「招式」后为空；切回全部能找到金蝉脱壳。视图传 `move`，筛选器判断 `招式`；`supply` 与 `物资` 也存在同类键值不一致，后者本局未构造非空物资筛选验证。见 [实页](22-tactics-filter-empty.png)、[页面](22-tactics-filter-empty.txt)；定位 [按钮值](../../../game/src/hub/game.bag.view2.js#L90)、[筛选条件](../../../game/src/hub/game.bag.js#L566)。
4. **结构化装备主动技能没有按钮（F04）**：射线枪装备后只剩普通名称标签，点击无发动反馈。`equipSkillText` 对已迁移结构化技能返回空；快照只用该返回值生成 `skill`，视图仅在 `skill` 非空时创建发动按钮。见 [装备后页面](18-equipment-active-surface.txt)；定位 [技能文本](../../../game/src/battle/bag/battle.equipment.js#L22)、[快照](../../../game/src/battle/core/battle.engine.js#L303)、[按钮](../../../game/src/battle/view/battle.layers.js#L588)。
5. **注能快捷按钮落在屏幕外（F07）**：1280×720 当前窗口中，「注能1」按钮 y≈801、高≈16，真实点击失败；从大卡使用仍可完成注能。见 [原始几何与点击结果](13-offscreen-infusion.json)。
