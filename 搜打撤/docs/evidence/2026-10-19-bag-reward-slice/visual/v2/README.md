# 背包视觉 v2：矿白导航与石墨卡牌舞台

状态：实现已落，待主会话当前窗口审美复核。老板 2026-10-19 反馈上一版“统一但不好看”，并选择《明日方舟》肉鸽与《终末地》结合的方向；上一版的可用性检查保留，不能视为本轮审美通过。

## 本次决定

参考终末地仓库的明亮导航/标题与透明内容关系，以及肉鸽界面的对象焦点，转成适合本作完整卡面的目录页。主会话查看的[仓库参考](https://img.gamewith.net/img/998631f042c5bb27c16718f1453ff86c.png)只用于版式关系，不照搬其小图标网格。

- 矿白用于细侧栏、当前目录页签和中文标题签；内容舞台保持石墨底。通过大明暗面区分导航、标题、卡牌，不将各区域都包进同一种半透明框。
- 原地图氛围图降为极淡的中性背景；去内容区玻璃外框及每张卡外的圆角色盒，使原纸卡、等级框和卡图成为主要对象。
- 容量数字、实际卡数与容量条在标题右侧成组；筛选使用目录页签，排序/整理仍在右侧独立分组。
- 暖金限于当前区定位、容量及价值焦点；不新增英文编号、警戒线或装饰标签，移除两处重复 DEPOT。
