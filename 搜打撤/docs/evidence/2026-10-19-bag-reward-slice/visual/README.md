# 背包—领奖样板：视觉实施

状态：实现已落，实页结果由本批主报告汇总。仅改背包与领奖的局部样式；没有改卡图、卡面比例、网格列数、场景背景图或动效。

## 本批改动

- 背包：筛选按钮边界、悬停、分区徽章、容量辅文和操作回执使用现行冬日色彩与近直角边界，保留原布局与卡牌大小。
- 领奖：总览和独立领取使用同一冬日 token；主动作/选中使用冷灰蓝，金币与回执数量保留暖金；风险说明常显并保留暖红语义。
- 领取页的规则、容量、已领状态与次动作采用现有 18px 辅文 token；禁用按钮用可读的深底和辅文色表达，不再整体降到四成透明度。
- 标题、按钮和边界沿现行家族；卡宽计算、2:3 卡面、46px 领取动作、116px 预留、卡区滚动及多卡规则未改变。

根标记 `.ui-design-system` 由交互实施同时接入领奖框架与独立领取页，具体 JS 记录见主报告。`card-browser.css` 与 `page-rewards-bag-help.css` 本批未改；背包/领奖目标未使用通用分页，不扩大公共分页影响范围。
