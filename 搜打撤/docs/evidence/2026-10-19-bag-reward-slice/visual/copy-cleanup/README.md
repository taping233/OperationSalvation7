## 搜索后的保留判断

- `beginner-guide-diagrams.js`、菜单帮助和折叠规则里的玩法教学保留：它们是玩家主动打开的帮助，不是主界面重复旁白。
- `game.menu.js` 与留言页的右键留言入口提示保留：该入口无法从普通可见按钮推断。
- `extraction-rewards-view.js`、`achievement-gallery.js`、容器“查看详情”等直接动作标签，以及 aria-label 中的动作/状态保留；动作名称不等于操作教程。
- `settings-audio.js`、命令失败/存档恢复、库存变化等真实错误及恢复方式保留。
- 商店价格、收藏转换、资源单次使用、巢穴规则、祭坛代价、概率与不可逆损失保留；卡牌效果描述和事件叙事未改。
- 城市/层间过渡及开箱阶段的唯一“点击跳过”提示保留：画面没有第二个可见跳过按钮，本批不改全局过渡。
- 设计器机制词条提示与一次性开局日志不纳入高频玩家界面减字，未改工具能力或新手流程。

当前其他负责人属地未编辑：`game.bag.js` 帮助中仍有点格子/拖拽说明，位于主动打开的帮助页；`chests.js` / `chest-opening-art.js` 的解除封存与点击跳过属于当前阶段/唯一跳过入口。已向主会话报告具体位置，由对应负责人判断，不抢写。

编辑前原字节存于 `before/`。既有测试仅同步移除的提示或节点：`sys03-altar-restore-txn`、`photo-zoom-lifecycle`、`blackmarket-card-preview`、`pocket-restore-interface`；其成本、结果、焦点、退出与连续操作断言保留。静态检查与实际文件清单见相邻 `../scale/static-check.json`，本批不另开全量或重复截图。
