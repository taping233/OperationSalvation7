状态：实现与定向检查完成；内置浏览器集中验收由主会话记录在本批 `baseline/`、`final/`。

## 本批改动

- `game/src/ui/reward-scene-view.js`：领奖局部更新保留卡面按钮、图片、横排与纵向滚动容器；更新领取状态、容量、按钮、总览与详情。相同战斗去向保留展开状态，不同奖励快照更新详情。
- `game/src/run/chests.js`：使用局部更新；单张领取后聚焦下一待领取操作，取消放弃回到原入口。后继操作在长横排外时，仅移动奖励自己的滚动容器使操作可见；返回背包/整理前记住长横排位置。追加渲染代次守卫，旧页面闭包在更新后仍然失效。
- `game/src/ui/chest-reward-overview.js` 与独立领奖根节点接入已有 `ui-design-system` 作用域，供视觉线统一冬日角色token。
- `game/dev/bag-reward-slice-review.html` 与 `.js`：生产领奖命令和生产视图的隔离入口，固定六卡、三选一附赠、满包腾位三场景。奖励与背包数据均在内存，不选择/读写玩家档位；完整背包仅复用生产视图和查看/返回，移动与丢弃的fixture适配不构成正式背包行为证明。

背包已有同区拖移原DOM、分区保留与指南返回连续性，本批不重复修改。容量、奖励归属、择一永久放弃、返回保留、授予与保存路径沿用现码；本批未修改全局overlay/motion。
