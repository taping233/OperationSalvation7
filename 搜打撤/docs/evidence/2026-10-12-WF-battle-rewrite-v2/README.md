# 影潮交锋第二版 · 与傀影/水月战斗曲1对比后修订

第二版完成，交付30秒MP3、24位WAV、原生LMMS工程。初稿和两首参考只读，正式游戏音乐未变。对比基于录音测量和可编辑工程检查，没有把自动分析写成人工听辨，也没有完成参考曲旋律的逐音转录。

## 差距与改动

| 项目 | 初稿与参考的可核实差距 | 第二版处理 |
|---|---|---|
| 音色重心 | 初稿2–4kHz能量12.15%，两首参考0–30/30–60秒为1.12–2.64%；谱重心680Hz，参考319–384Hz。初稿较多能量堆在上中频 | 独奏小提琴换弦乐合奏主线；按低音/鼓/主题/细节分4组原生渲染，主题与细节单独滤波，降低上中频负担 |
| 声场 | 初稿左右相关0.985，参考片段0.109–0.504；初稿高度接近单声道 | 调整声部位置，管弦/细节总线加入不同左右早期反射，160Hz以下侧声道高通，保持低音居中 |
| 节奏 | 起音峰计数初稿5.67次/秒，参考4.57–5.47；增加打击密度不能解决差距。原谱拨奏、低音、鼓各自持续填充 | 拨奏与帽音减密度，鼓与贝斯以两小节为单位呼应；底鼓/军鼓/帽音独立轨，句末留停顿，用稀疏低鼓过门 |
| 旋律 | 原谱主线51音，25音短于250ms，仅2音长于500ms；GM独奏音色下短音较多，是旋律容易破碎的创作风险 | 重写为两小节问答，主题重复后变化；缩窄主线音区，增加持续音，内声及铜管在空位回答 |

音色“偏尖”、旋律“容易破碎”属于上述数据和工程结构支持的判断，不能当作已经人工试听证实。对两首参考没有可靠单声部转录，故不声称量出了它们的真实旋律音长、音符数或节奏分轨。

## 同口径复测

录音均按22.05kHz立体声解码，取0–30秒；参考另取30–60秒复核。频谱和包络分析先将单声道RMS归一；这一步是测量归一化，不是播放响度匹配。初稿和二版交付MP3均−19.5 LUFS，可直接比较两版。

| 20–150Hz能量 | 46.0% | 62.1% | 47.5–64.4% |
| 2–4kHz能量 | 12.2% | 4.1% | 1.1–2.6% |

第二版频段与空间分离向参考移动，起音密度进入参考片段范围；上中频仍稍多，段落包络变化比参考片段大。这些差异保留为试听关注项，不把频谱接近当作音色品质、旋律记忆点或融合成功的证明。原始数据、方法和指纹见[comparison.json](comparison.json)、[compare.py](compare.py)。

## 制作与交付

128 BPM、4/4、16小节、PCM严格30秒。14轨：合成贝斯、大提琴、底鼓、军鼓、帽音、低鼓、弦乐合奏、闷音铜管、中提琴、拨奏、电钢琴、竖琴、玻璃点音与弱铺底。3.75秒主题进入，15–18.75秒收束，18.75秒主题返回，最后属和声回主和弦并淡出400ms。

复用已安装LMMS 1.2.2及GeneralUser GS；未新增音源、采样参考录音或安装软件。学习来源与原音源许可沿用[初稿制作记录](../2026-10-12-WF-battle-rewrite-demo/README.md)，本轮依照对比证据调整，不重复网页检索。

- `battle-shadowtide-v2-30s.mp3`：256kbps试听。
- `battle-shadowtide-v2-30s.wav`：48kHz/24位立体声。
- `battle-shadowtide-v2-30s.mmp`：可编辑完整工程；实际主音轨/片段均在工程内。
- `low/beat/theme/detail-native.wav`：LMMS四组原生分轨；对应局部工程/日志保留本地中间文件。
- [score.json](score.json)：原生事件谱；[compose.py](compose.py)：分轨渲染、分组滤波和早期反射、母带增益。

复现：在搜打撤运行`python docs/evidence/2026-10-12-WF-battle-rewrite-v2/compose.py`。已有分轨只重混时加`--remaster`；不会改写第一版或旧工作站配置。完整LMMS工程包含原始配器，交付WAV/MP3另经过脚本中明确的分组后期处理。

第一遍新混音低频占75.4%，超过本轮参考片段范围，作了一次有依据的重混：低音总线−3.74dB，主题恢复部分上中频，调整侧声道。复用四组原生录音，没有再跑相同编曲渲染。
