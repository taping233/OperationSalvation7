# 卡面说明与执行声明同源

本轮在现有整句生成入口增加纯治疗、纯抽牌、治疗后净化自身三类句式；现役覆盖由3张扩大到9张。声明数值变更后，卡面、详情富文本和照相馆搜索展示同一完整句子。条件、目标、时点或操作形状超出已支持范围时，沿用整段审核说明。

## 实际覆盖

| 句式 | 现役卡牌 | 声明数值变化样例 |
| --- | --- | --- |
| 纯治疗道具 | 应急绷带 `starter-emergency-bandage`、金疮药 `tt-jinchuangyao`、斗神酒 `tt3-savior-elixir`、能量饮料 `tt4-woodify` | 生命分别改为18、23、88、10后，整句同步 |
| 纯抽牌 | 圣光之源 `tt7-livingwater` | 抽牌5→7，显示“抽 7 张牌。” |
| 治疗后净化自身 | 治愈 `tt3-holy-water` | 回复5→9，保留“并净化自身”及操作顺序 |
| 治疗后获得护甲（既有） | 包扎 `tt3-bandage` | 生命3→7、护甲3→11 |
| 获得护甲后抽牌（既有） | 坚守 `tt3-hold-fast`、厉兵秣马 `tt7-ironcharge` | 护甲/抽牌分别改为9/2、17/4 |

继续使用 `structured-card-description.js` 与 `displayCardDescription` 的审核文本/卡牌ID入口。为圣光之源补入现行原句的审核入口，原句文字保持不变。道具仅接入独立 `bag.use` 中的单一治疗声明；武术、法术继续限定自身目标、`onPlay` 时点和已审核整句。

数字沿对应执行权威读取：`amountField` 读取卡牌字段；道具 `bag.use` 的显式 `amount` 优先于旧展示字段。定向样例将金疮药声明改为 `amount:14`、旧 `heal:20`，显示14，与道具执行入口一致；`onPlay` 中声明与数值字段冲突时继续保留现有回退。
