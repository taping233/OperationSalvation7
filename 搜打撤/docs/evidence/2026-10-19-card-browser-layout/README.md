## 公共修复

`card-browser.js` 观察 track 宽度，只对正宽度且变化的通知排一次 animation frame；高度变化和重复通知不触发新的分页。零宽度不改浏览位置，已排队后隐藏也不刷新，再显示为正宽度可重新排队。图片加载使用同一合并通道。

改变每页数量时，优先保持正在聚焦的卡片可见，其次保持旧页已选中卡，均没有时以旧页第一张卡为阅读起点。外部搜索框不被夺焦点；已有节点与用户滚动不主动重置。没有 ResizeObserver 时使用 window resize 回退。页面移除后断开尺寸及生命周期观察、移除回退监听并取消待执行帧；旧帧即使到达也不再改 DOM。
