## 两轮迭代

**v1（方舟式分组，已废弃）**：左侧三分区页签 + 中间分组网格（物资→道具→卡牌）+ 右侧常驻详情 + 15 点借鉴标注系统。内置浏览器全链路验证通过；老板判「不好看，杂乱元素太多」。

**v2（绝区零玻璃拟态，现行）**：同文件重写。按老板指定方向：真实场景图（hub-wallpaper.webp）重度模糊作景深背景，全部面板改玻璃拟态（backdrop-blur 26px + 半透明底 + 大圆角 + 弱描边），砍掉标注系统、分组小标题、格内描述文字、虚线说明等杂乱元素。信息层级收敛为：格子只承载「图标 + 名称 + 数量 + 稀有度色晕」，类型/费用/可用态用极轻角标表达，一切文字描述收进右侧常驻详情面板。

## v2 设计要点与借鉴

| 决策 | 来源 |
|---|---|
| 模糊景深背景 + 玻璃拟态面板 | 绝区零（老板指定） |
| 左缘细图标栏切换三承载区，计数作角标 | 绝区零/方舟 仓库导航 |
| 格子仅图标+名称+数量，稀有度用底色晕染 | 绝区零物品格 |
| 右侧常驻详情面板：大图标/稀有度章/描述/操作 | 星穹铁道背包 |
| 分类筛选胶囊行 + 排序/一键整理收成两枚图标钮 | 原神/方舟 |
| 单一金强调色（沿用游戏金），全页无第二强调色 | 本作 10-15 战斗重设计定稿语言 |
| 大标题「背包」+ DEPOT 眉标 | 绝区零排版 |

保留的现版概念：物资/卡牌混占格、安全格押运（格子带「押运」角标）、消耗口袋（去饱和+「已消耗」角标）、道具背包内使用、同名堆叠、珍珠盒扩格（容量条 18/38）。

数据全部为真实条目：卡牌与稀有度取自 `cards-sync.json`，物资取自 `map.json`（木材/口粮/神秘钥匙）。
