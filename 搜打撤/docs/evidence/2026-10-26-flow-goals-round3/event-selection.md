# 事件选择接回实际执行结果

事件多选页由“点选阅读 → 确认 → 执行事件 → 保存与后续页面”组成。此前确认通过再次点击选项转发，无法取得领域动作的 Promise 或失败结果；确认后的界面一直停留在执行状态。

正式节点页现复用 `invokeUiAction` 取得同一动作的实际返回值。事件选择处理器返回 `executeChoice` 的结果，确认等待其完成；返回失败或抛错时保留选择、恢复确认与取消，并在当前页面提示重试。等待期间展示“正在处理…”，Esc清选择及页头退出沿同一在途状态处理。新页面已接管时，旧结果只结束旧会话。

修改范围：`game/src/ui/event-choice-selection.js`、`game/src/run/game.run.scenes.js` 的事件选择接线、`game/src/run/game.run.events.js` 的选择返回值。现有事件抽取、奖励、保存与去重实现沿用。

仅完成实施，未运行测试、lint、构建或实页；由老板统一验收。建议操作入口：事件双选确认、保存失败后重试、等待期间按Esc/页头退出、整理背包后回到原选择。
