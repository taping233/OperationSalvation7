# 第一首第五版：先把钢琴线条说清楚 · 2026-10-05

老板直接听感：第四版太杂乱，特别是钢琴一直断续、不知道在弹什么。最新反馈优先于前轮量化目标，本轮不追求声场／动态／脉冲数字达标，先修复旋律可辨识性，只做第一首候选。

## 修改

重新写一条完整八小节主旋律，前四小节陈述、后四小节回应和落点，以四分／二分音符为主。完整演奏后让同一句在弦乐支撑下再次出现，中段有一条连贯的八小节对比句，最后回收主旋律。速度112降至84 BPM，32小节约91.43秒。钢琴句内音符近连续、重心以级进和小跳为主，只有完整句尾作短呼吸；取消每两小节换碎句、零散起拍、忽然改音区以及奇数小节截断旋律。

配器从10个演奏音轨降到5个：钢琴主线、低音量钢琴和声、左右柔弦乐、大提琴底部支撑。钢琴伴奏每两小节只给一个低音量和弦，取消不断跳动的左手音序；弦乐主要持长和声，取消木管／拨奏／钟琴／打击轮流抢线的安排。没有给钢琴主线套整段音量起落自动化，保留三条背景弦乐／大提琴的缓慢表情曲线。

这是让音乐先有清楚主次，不宣称删轨或简单旋律必然更好。空间与织体更丰富的要求仍保留在后续口味背景中，但不会为满足数字再次打断主线。
