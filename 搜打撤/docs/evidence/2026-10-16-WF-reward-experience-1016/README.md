## 实现结果

- 总览主按钮由本批进度派生：优先已开未领完箱的「继续领取」，其次「打开宝箱」，全部处理后「继续探索」。主按钮和逐箱按钮共用显式点击入口；派生进度不prepare/roll未开箱，原初始化和随机顺序保留。
- 待领计数沿完整箱完成条件，含未领金币及附赠卡；原箱显示实际入包张数，部分领取追加待领，卡牌放弃与金币入账分别描述，不把放弃数当领取数、不报0张成功。短状态预留一行，避免反馈出现时挤动箱区。
- 不可收卡牌与放大卡底部均显示「当前放不下」，整理入口集中底栏；按当前候选能否收取决定整理是否突出，不用满格直接代替实际容量。无可收卡且金币已收时，隐藏空转的全部收下操作。最低估值对比和重复长警告撤下，三选一永久放弃规则与主动放弃确认保留。
- 总览和卡牌弹层统一烟灰玻璃、冷白正文、香槟主动作及细边。弹层只保留返回奖励、箱名和关键选择规则；卡区滚动，工具头、动作与容量脚栏留在容器中。
- 回总览时沿既有initialFocus入口定位下一待领箱或完成按钮，只聚焦，不自动打开。非总览的固定奖励仍保留继续探索、整理、暂离和放弃出口。
