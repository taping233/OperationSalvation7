## 连续蒙皮版的失败与制作流程核对

后续白底增加 `base-chibi-gait.js` 与 `base-chibi-skin.js`，沿现有Pixi能力实现双骨骼腿、足部目标、连续贴图蒙皮；10项状态/运动学测试通过。老板在此版白底截图中指出效果仍然差；颈部块状接缝、颈肩/袖子衔接和整体造型未达到要求，视觉判定失败。尚未完成一整段步态的脚底实页采样和资源释放补验；不把测试通过或几张动起来的截图作为成品通过。源码、原图与既有白底页面保留，不继续在这套素材上堆参数。

根因：先让模型生成八格独立部件，再用任意缩放/坐标重组，没有经过完整Q版基准图与同坐标分层复原检查。素材画面的颈肩结构、透视和轮廓存在不一致；运动学只能改变位置，无法补出缺失或重复的绘画结构。

已核对的官方制作依据：

- [Spine First Steps](https://esotericsoftware.com/spine-first-steps)：完整角色图作为对齐模板；部件的位置、旋转与图层顺序应与模板一致，PSD/Gimp分层导入可保留原位置和顺序。动画先做主要姿势，分段检查后再调整插值和曲线。
- [Mesh weight workflows](https://us.esotericsoftware.com/blog/Mesh-weight-workflows)：通常在固定Setup姿势绑定；按网格用途选择骨骼权重，建立测试动画，从两个极限姿势检查变形，再调整中间权重。
- [Spineboy example](https://en.esotericsoftware.com/spine-examples-spineboy)：髋部与足部目标分别组织；先求腿部IK再处理足部，身体移动不直接拖动落地脚。

本项目的返工顺序应为：完整Q版站姿原画先过造型→从同一画布拆层并补遮挡处→静态组装精确复原原画→固定关节与权重并验极限弯曲→设计步态主要姿势、支撑/摆动脚和曲线→白底逐帧及循环目视通过→运行接入。此为据官方资料整理的项目执行方案，不宣称是鹰角内部生产规范；尚未完成新原画或合格分层稿。
