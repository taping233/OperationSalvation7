# 《霜窗回声》V12 · 织体轮替修订

老板要求继续改首页曲。V11 的第二次主题与返回段更可区分，但 12–60 秒织体移动仍为 0.093，低于此前保存的三首参考样本最低 0.117。本轮保留 V11 的右手主题、左手、单簧管与竖琴乐谱，重新分配持续弦乐、大提琴及前景声部。

## 实际改动

- 右手 52 个主题音的起点、音高、时长和力度不变。A1 的弦乐、大提琴也不变。
- A2 的慢弦乐与大提琴由整段根音转为和弦音的上行回答；单簧管和中提琴隔两小节交替作短句。右手钢琴在回答段平滑退至原增益的 72%，长弦乐退至 56%，底层低音仍持续。
- B 段由竖琴接近前景，钢琴和长弦乐让位；A3 让主题和弦乐回归，并以不同的句尾上行连接循环。混音仍保留 V11 的慢速乐句增益与 120Hz 以下不额外拉宽的声场处理。
- 音源仍是项目已有的 GeneralUser GS/FluidSynth。没有使用参考录音样本、旋律或和弦序列。渲染代码、事件谱、分轨来源和文件指纹见 [render.py](render.py)、[score.json](score.json)、[render-report.json](render-report.json)。
