# 蔷薇外扩包框实装

老板选定稀有度网页第八稿「蔷薇」方案，要求同步所有卡牌和放大界面并删除被替代的旧样式。实现完成未提交，待老板评定；沿用「不用检查，我来评定」的授权边界。

## 接入范围

- `game/css/card-layout-selected.css` 导入 `game/css/card-frames/rose/frames.css`，按现行 `rv*` 标记选择8张静态SVG。五档使用第八稿蔷薇原形；初始、未继承其他等级的衍生和职业沿用基础框及各自标签色。
- `.hs-card::before` 绘制完整外扩框体，含倒角、内槽、右侧及底部厚度、花叶纹章与高阶镶件。SVG画布额外收纳顶部花冠、侧面和描边；放大时随卡宽缩放。
- 所有正式卡牌通过同一共用选择器接入：仓库、战斗手牌、发现、背包、商店、悬停预览、卡牌放大，以及购买/出牌飞行克隆。宿主容器开放框体溢出；格子、手牌与放大容器补外侧空间。
- 保留当前全幅卡面、金蝉脱壳专属构图、稀有度判定、费用修正色与效果文案。照片与照片大图继续使用照相馆装裱规则。
- 审阅网页默认切到第八稿蔷薇，旧稿保留供版本对照。

## 已移除的正式样式

- `card-layout-selected.css`：第六稿银墨饰纹映射与图层、薄框发光阴影、史诗/传说边框扫光及对应动画、棱彩/金光流动光带规则。
- `cards.css`：旧石墨外框的边框/背景/投影/圆角、衍生牌重复内框、旧棱彩宝石光晕、棱彩/金光光带与动画。
- `card-v3.css`：旧光带透明度。
- `winter.css`：放大卡的旧双重投影与金色光晕；放大字号保留。
- `overlays.css`：职业宝箱卡旧黑框皮肤。

清理在已授权编辑的CSS内完成；第六/七稿审阅样式与旧银墨素材是历史对照来源，未删除文件。渲染器保留的旧光带节点由共用样式隐藏，未改他会话活跃占用的 `cards.view.js` 或 `ui.js`。

## 史诗与传说补漏

老板反馈花鸠等史诗牌没有同步。定向读取源码发现，上一轮清理脚本只匹配 `.hs-card::before`，漏掉 `.hs-card:is(.rv3, .rv4)::before`。后者使用更高优先级的旧流光背景与遮罩，覆盖了共用蔷薇框，因此同时影响史诗和传说，包含卡牌放大。

已删除这条旧规则，并补齐制作脚本的匹配范围；所有史诗/传说继续使用现有蔷薇映射，不改卡牌数据或稀有度。沿老板自行评定的约定，未运行浏览器或验收检查。
