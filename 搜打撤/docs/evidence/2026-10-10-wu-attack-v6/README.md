# 无剑长与有效帧修复

老板反馈v5剑长度不稳定、有效帧不足。本版继续沿用当前待机立绘，修复渲染顺序与动作采样。

复现：v5在动作相位0.58至0.947，剑的几何轮廓进入源画布y≥490的脚底重画带；301点采样中111点受影响，最大y约526。渲染器在剑之后清空该区域，因此长度虽在几何计算中固定，显示剑尖仍被裁掉。此前“剑长检查通过”只覆盖几何，没有覆盖这次裁切。

v6先恢复脚底再绘剑，并调整收势手腕角度。601点检查中的最大剑轮廓y为482，全部位于固定带上方，长度保持，画布边界检查通过。导出还逐帧检查实际剑尖位置附近存在可见像素。

v5导出31帧中28张不同，主要前挥只跨两帧。v6提高到60帧/秒、67帧，补中间姿势，将主要挥击扩到约6帧；减少蓄力静止和命中停顿。实际不同帧数及像素检查见资产目录`validation.json`。

只用当前Codex内置浏览器、当前窗口和真实按钮/滑杆查看举剑、前挥、原收势裁剑区间、收回与正常速度播放；页面截图保存到本目录。复用5200，没有新服务、build或提交。候选未接入游戏，老板对新观感尚未确认。
