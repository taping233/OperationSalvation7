# 成就页入场工作量

改动仅覆盖成就陈列室的详情构建。此前开页生成全部26份详情模板，即使没有打开详情也会解析这些模板；现在选中奖章才创建一份详情，重复打开当前奖章复用节点。

## 实测

同一份26项成就数据、无存档、painted画风，使用jsdom解析原版和修改版HTML，统计包括template.content中的元素；返回按钮在两组中一致剔除。明细见 `entry-counts.json`。

- 入场详情模板：26 → 0；模板内元素：494 → 0（另省26个template外壳）。
- 入场奖章SVG构建：53 → 27（26列表 + 1水印）。
- 入场HTML：62,020 → 36,286字节，减少25,734字节，约41.5%。
- 同一奖章打开6次：详情innerHTML写入1次；切换奖章时重新构建且最多保留一份详情树。

这些是DOM构建/解析工作量和字符串字节数，不是帧率、加载时间或网络节省。原模板为惰性模板，不能把移除模板内图片视为减少26次网络请求。
