# 前端旧运行链清退

老板要求继续删除冗余前端代码，并沿用不开游戏实页的要求。本批以当前源码、生成端和全游戏引用为依据，删除已退出运行链的交互、永久隐藏的装饰和无读取方的变量。字节数统一按 UTF-8、LF 统计，测试与生产代码分别计数；不把其他会话的改动计入本批。

## 改动

- 首页：移除首页及资源预览页永久隐藏的旧城市光柱 SVG、动画，移除永久隐藏的场景光层挂载及样式，移除没有生成端的 `akLastTag` 更新块。保留本会话新增的三个入口 `home-orbit` 环绕光。
- 仓库和人物：删除旧折叠筛选查询、展开监听、旧 `warehousePick`、`personCardZoom`、`personPoolPick` 动作。现行卡片浏览器点击和筛选保持原路径。
- 商店：移除旧商店包装、旧购买/预览注册和样式导入；当前页面由 `tradeShopV5HTML`、`bindTradeShopV5` 生成和绑定。
- 战斗：移除没有 CSS 消费者的牌库脉冲/洗入类及其计时器、观察器、全局监听；保留同帧出牌回手抵消和真实飞卡/回合反馈。删除无消费者的血条红闪重排与计时器，以及 `drop-any`、`is-boss`、`battle-won` 挂类残片；胜利输入隔离、提示和动画等待保留。
- 公共样式：移除旧牌堆、旧高级筛选、旧奖励头和设置齿轮规则，清除未使用的 CSS 变量，剪除页面动画中的旧结构查询。保留会改变活分支优先级的两处混合选择器，以及两条 `safe center` 兼容回退。
- 老板逐项确认后删除四个文件：`game/src/ui/settings-transition.js`、`game/src/hub/hub.shop-v3.js`、`game/css/base-shop-v3.css`、`tests/hub-shop-v3.test.js`。旧设置转场无运行引用；旧商店仅有自身测试。原文已保存在本目录 `before/`。

完整范围、前后 SHA256 和字节数见 [changes.json](changes.json)，具体 CSS 条目见 [css-details.json](css-details.json)，同文件条件覆盖及幸存声明见 [context-review.json](context-review.json)，统计见 [summary.json](summary.json)。本批生产代码净减 **32,739 字节**，测试代码另减 **7,964 字节**；CSS 累计净减 **152,686 字节，约 7.78%**（沿用本会话初始 1,963,517 字节基准）。
