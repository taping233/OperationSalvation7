# 事件选项模板对照与第四版

当前交付是独立 `game/event-template.html` 的第四版候选，未接入正式事件页；老板尚未认可本版。场景底图保留，重点是选项美术与布局。

## 第四版现行候选

老板反馈第三版青绿/酒红不符合游戏主题，且不同选项不能共用相同内容图形。查现行VISUAL-BIBLE与secondary-ui-tokens，模板改为石墨标题、冷灰蓝选择与确认，暖金限价值强调，风险保留浅暖红。通用底板经内置imagegen重修为无内容图形版本；引用 `game/dev/assets/event-option-winter-v4.webp`，1437×480 RGBA、58660字节。

两张具象图先经NAI默认V5（种子1382502410/1382502411）与内置精修，均已生成；老板随即明确只要抽象简单虚影，故未将具象图接入页面。最终各选项独立声明 `data-choice-art`，搜寻用叠圆，深入用断裂斜面，原生SVG遮罩为14%透明度，选中后6%。无布料/金属/工具细节；底板不含选项内容。原图与请求保留，不删除候选。

随后老板反馈标题位置偏移。实测标题文本起点y123.75/329.75，而素材深色带更低，故仅将标题视觉位置下移8px，文本起点改为131.75/337.75，未推动说明和按钮。最终图见 [标题校正后](v4-title-fixed.png)，同一1618×956当前窗口目检通过。上移后的叙事位置保留。

此前本版真实选择/Enter确认/结果禁用/重看/Escape通过；标题微调后仅复核位置，不重复业务检查。CSS与脚本解析通过、无横向溢出，未跑Vitest/build/性能采样。[来源回执](asset-v4-receipt.json)与[实际提示词](builtin-v4-prompts.txt)分别标明使用底板及被否定的具象候选；当前虚影由少量原生几何构成，未把SVG宣称为生成模型产物。正式事件/收益/存档不改，无新服务、提交推送，编辑释放。

## 第三版候选（已被老板否定主题与图形内容）

老板明确反馈第二版事件名/简介太低、选项不好看，随后要求直接按方舟复刻并用NAI＋内置生图制作素材。本版以既有「相会」截图为唯一控件结构参考，使用深青窄标题、浅色笔刷信息底和选项内红青圆形确认印记。

NAI默认V5、1344×768、28步、CFG5.5，种子1382502293，一张底稿HTTP200；内置imagegen据底稿及参考精修空白选项底板，再以参考生成空白确认印记。完整字词/参数见 [NAI请求](nai-v3-request.json)、[内置实际提示词](builtin-v3-prompts.txt)；两张运行候选WebP、源文件与SHA256见 [第三版素材回执](asset-v3-receipt.json)。底板的梁柱/硬币是低对比烘焙水印，全部可读文字和勾选按钮仍为DOM。

叙事块从第二版y约752上移至589，约163px；选项以相会右侧约四成画面宽度复刻，不再沿第二版三成窄条。当前窗口1618×956，选项621×174，顶部y118/324，确认按钮146×158。保留两选项与原收益，没有凑三选项或修改场景。

实页真实点击选择、Enter确认、结果叙事/选项禁用、重看恢复、Escape取消通过；CSS与交互脚本解析通过，无横向溢出或浏览器error/warn。见 [初始](v3-initial.png)、[最终选中](v3-selected.png)、[尺寸及检查](v3-browser.json)。共享服务曾清空一次选择，最终证据在确认存在后单独截取。未运行Vitest/build/性能采样，不作性能结论。素材仅用于此独立模板，正式事件组件/资源与存档未改；未提交推送，复用5200无新服务。

参考为项目已存的黑流树海「未涉足之树」整页及「相会」整页（分别在10-11选图与10-12方舟UI参考证据目录）。观察只限这两张静态图，不推断其完整动态和交互规则。
