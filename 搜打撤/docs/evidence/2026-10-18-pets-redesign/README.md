## 生成与验证

NAI 由 `generate.py` 调用现有 `nai_gen` / `nai_guard`，六次均 HTTP 200；1024×1024、V5 Full、28步、CFG5.5，使用共享 v3.4 提示词构建器。方形尺寸为宠物单体用途覆盖，六次均未超过客户端免费像素阈值。执行前核对进程三个代理环境变量均为 `http://127.0.0.1:12450`，Git 未查到代理覆盖；实际成功通道为客户端直连。未改代理或配置。

六份 `*-request.json` 保存完整请求、种子、原图相对路径与 SHA256。内置完整提示词见 `builtin-prompts.json` 与 `builtin-prompts-revisions.json`；首轮使用项目默认双图作画法参考，三只 v2 只用各自 NAI 原图。`finalize.py` 原字节复制内置输出并验证尺寸、RGBA、alpha 极值及哈希，结果见 `receipts.json`；来源绝对路径可用于再次获取。本地 PNG 统一忽略，不进入 Git。

已逐图查看 NAI 和内置输出；三只 v2 的主体结构比首轮接近 NAI，内置生成仍有局部笔触和边缘变化，不宣称逐像素保留。生成阶段未接入运行素材；后续接入和实页验证结果见本页“实装结果”。未 build、未开服务、未提交。
