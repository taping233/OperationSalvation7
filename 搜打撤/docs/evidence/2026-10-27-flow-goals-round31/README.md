# 装备主动可用性同源

本批把装备主动的可用条件、实际发动与装备栏提示归到现有领域查询，修复连弩没有可释放箭牌时仍消耗本场次数。

状态：本批修改完成，编辑释放，保留未提交，持续目标进行中。集中修改，由老板统一验收。

范围：装备领域查询、手牌释放匹配、快照投影及装备栏。魔法锅炉沿退役兼容分支，不新增正式入口；命运钟表的消耗全部手牌不增加最低数量条件。

## 实施结果

- 装备领域提供只读`getEquipSkillAvailability(uid)`，统一`usable/state/why`。规范化、规则支持、主动/被动、次数、忙碌/选择中/待结束回合及初始手牌候选在同一入口查询；实际发动消费该结果，退出分散重复的前置守卫。
- 连弩无匹配非生物箭牌时直接保留本场次数；深红丝袋与自然法杖同样按初始选牌资格判断。`matchesHandReleaseCard`由查询和实际释放共用，初始攻击键、正则名字匹配、非生物边界保持原语义。只检查起手操作，后置抽牌/选牌与消耗全部手牌维持原规则。
- 正式工厂注入真实卡牌查询与待结束回合状态，装备快照携带并冻结可用性；现有签名深遍历该字段，手牌和状态变化继续刷新装备栏。旧预览缺字段时沿原展示回退。
- 装备按钮、禁用、条件原因和ARIA同源，条件不足沿已有禁用样式。此查询只在内部领域/快照使用，没有新增对外动作或存档字段。
