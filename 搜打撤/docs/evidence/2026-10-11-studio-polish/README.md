本轮按三处依赖实施：

1. 导航改为全屏宽度，内侧仍用与主体相同的80px左右边距、7/3分区和108px间距，分类保持按左侧照片区居中。玻璃表面使用低对比渐变与1px渐变下沿。
2. 照片墙、档案说明和选项菜单统一12px原生滚动条，细透明轨道、暖灰渐变滑块，取消滚动按钮；WebKit自定义与其他浏览器原生细条分别处理。翻片文字改为箭头，保留无障碍名称及悬停提示；主按钮缩为“查看照片”。
3. 照相馆入口改为photo-fade：专绘画面保持静止，260ms整层透明淡出，最快140ms开始淡出；取消同一揭幕期间图库通用分层入场的叠加。首屏只等待当前可见照片与预览就绪，最多220ms，不等整库；挂载后先完成ready状态转换，再等待图片，保持取消/关闭契约。图片监听在超时、取消或完成时释放。其他页面原city-cut沿用。

诊断证据：代码显示原入口为620ms全屏斜切横移，目的页同时参与通用分层入场，图片解码也在挂载期启动；这是本轮减负依据，不能直接证明用户设备卡顿只有这一原因。
