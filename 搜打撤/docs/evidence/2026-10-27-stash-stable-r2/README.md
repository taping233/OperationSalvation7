# 入库闪烁续修与按稀有度入库

老板反馈前版仍闪烁，并要求加回按稀有度一键入库。本轮继续保留前述不用测试的要求。

源码定位：保存时原`setSaving`禁用所有带data-act的按钮，包括整批卡面预览；公共控件的disabled样式会变暗，完成后再恢复。同时原局部更新从整个exMain根递归协调，移除运行时注入的动画属性和内联样式。空保存提示也会在点击后新增一行高度。

调整：保存时仅禁用帮助导航，卡面及入库按钮保持视觉；实际操作继续由updating和当前页守卫拒绝重复请求。局部更新仅处理标题计数、提示、仓库操作、卡牌列表与底栏，外壳不参与协调；保留data-surface/data-ui及内联样式，保留已存在卡面和滚动容器。提示行固定预留高度，防止列表上下跳动。帮助按钮在保存结果回写时恢复。

按稀有度入库：提供明确按钮，优先棱彩、传说、史诗、稀有、古朴；其他稀有度排在其后，同级保持原背包顺序，按仓位可分叠入库。复用原selectionFor来源身份和saveCards持久化入口，与按估值/全部入库共用容量选择逻辑。仓满禁用，既有估值入口保留。展示排序和批量排序共享稀有度表。
