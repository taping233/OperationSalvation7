## 第二版（现行）：二游「行动档案」重皮肤

参考语言：星穹铁道式干净深色战斗面板 × 方舟硬朗切角结构 × PGR 式斜切
宣示主钮。三色纪律：**金=我方动作/主操作，红=敌意/危险，青=能量/我方
状态**，其余中性石墨蓝。几何家族：动作件左上斜切（指向敌方），信息件
对角硬切角。

- R0 令牌与深侧晕：`--bx-panel/gold/red/cyan`，战场两侧加电影感暗角。
- R1 顶栏：深色指挥条 + 底缘金色渐变封条（左强右渐隐）、金 kicker、
  26px 表格数字回合、状态徽标切角 chip 按 `data-battle-state` 换色
  （self=金/foe=红/focus=青/warn=琥珀）。
- R2 战场讯标：真实状态=金左缘斜切档案签；我方行动教学态耳语化。
- R3 单位档案牌：对角硬切角面板 + 左缘 3px 身份条（我=青渐变、敌=红
  渐变），名字 22px/800，血条收窄 20px 重上色（我=青、敌=红暖渐变）。
- R4 意图章：平行四边形危险告示（红体红字 24px/800，冻结换青），
  章下 12px 渐隐发丝线锚回单位。
- R5 底部指挥台：连续深色台面 + 2px 顶缘金封条 + 115° 静态斜纹质感。
- R6 能量核心：青辉光六边核（52px 数字带静态辉光）+ 外圈金色瞄准角框
  （lock-on 记号，wrap::before 八段渐变拼角框）。
- R7 战术技能件（猛击等）：左上斜切、青左缘、金费用小签；active 态金环。
- R8 结束回合：斜切宣示主钮（金底墨字 25px/800、字距 .18em），敌 方
  阶段 opacity .42 退让；背包等次级钮金左缘斜切 chip。
- R9 牌堆徽章：对角切角档案章、金数值。
- R10 注能条金左缘档案横条；手牌同名堆叠章金签；悬停聚焦（其余牌
  opacity .78，拖拽不参与）。

硬约束：零常驻循环动画、零 filter 动画（投影/辉光均静态）、过渡只
transform/opacity/色彩；卡牌本体、canvas、药水栏（老板定版纸白）、冻结
battle.css 零接触；prefers-reduced-motion 由既有全局规则兜底。

## 审美判断与对应改动

battle-sts 三段几何（顶栏/战场/手牌带）已成立，本轮不改结构，只修四件事：

1. **底部指挥台基座（C1–C2）**：能量/技能/手牌/战术四簇原来漂在透明渐变上；
   给 `sts-hud` 一条连续暗色台面 + 顶缘金封条（与顶栏底缘金线同族，静态
   opacity .32）；能量徽章收双环内框 + 静态 filter 投影落地，「能量」改
   档案 kicker 字距。
2. **主操作签名（C3–C4）**：结束回合右上硬切角、技能钮左下镜像切角，
   延续 ak 硬切角语言；END TURN 眉题试验后砍除（⅔ 渲染缩放下仅 7 物理像素
   高，读不出反成污点——过程记录保留在 CSS 注释）。
3. **身份语义强调（C5–C6）**：名牌加 2px 身份顶边（我=冷青、敌=暖红，
   computed 核对 1.2px 实际渲染）；攻击意图章加红左缘、冻结换冷青、数字
   表格化；意图章与单位间加 12px 渐隐发丝连接线。
4. **降噪与聚焦（C7–C9）**：玩家行动态（`data-battle-state="self"`）的常驻
   教学条降为耳语级（去底、13px、opacity .48）；其余状态（敌方行动/结算/
   选目标/能量耗尽）维持档案签样式；手牌悬停时其余卡退后一档（`.78`，
   拖拽 aim-lift 不参与），transition 补 opacity 通道；顶栏「状态」与回合间
   加发丝分隔。

## 硬约束遵守
