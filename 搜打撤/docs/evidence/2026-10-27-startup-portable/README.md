## 改动与来源

原便携包在全部解包后才创建 Electron 启动窗，旧启动窗为居中小窗、进度随时间递增。新原生便携入口先显示无边框全屏壁纸和底部进度，再在后台读取资源及解包；资源准备占 0–55%，随后交给独立 Electron 全屏窗，实际 DOM/控制绑定/主页就绪阶段推进至 100%。两个阶段均循环显示六张现有壁纸，游戏初始化失败继续保留重试与退出。

构建使用 HEAD `9336c1df1e567f010cbdc6edbd4b2b40502b1482` 的游戏运行内容，叠加本轮桌面入口修改；未纳入其他会话仍在编辑或归属未确认的未提交游戏改动。独立副本为仓库根 `.tmp/startup-portable-1027/project/`；[快照说明](snapshot.json)、[交付摘要](delivery.json)。未改共享树 build/HMR 产物。

“无档位”沿上次交付含义执行为无预置存档，保留五档正常新建与继续功能。包内无玩家持久数据，发布 profile 为 `codename7-clean-20261027-0e86e8a6c6344138`，实际 EXE 检查使用 Node 模式，不运行游戏 main，不创建此资料目录；交付时仍不存在。旧资料均保留。
