# 事件选牌接入正式组件

本批迁移分支候选/来源选择、异常改装台原卡多选和暗巷赌约奖品预览，统一卡面查看、选择动作、价格及当前节点返回；对应旧事件网格随消费者迁出后退出。

状态：本批修改完成，编辑释放，保留未提交，持续目标进行中。集中修改，由老板统一验收。

分工：6.1-sol/high分别负责分支页、重编/赌局页，以及只读核对后补齐的批量容量；主会话维护现有领奖组件、结果确认与旧样式退出。保留骰子、费用、原卡快照与实际结算，查看与选择分开，暂离与放弃沿原行为。

## 实施结果

- 四个旧事件网格消费者接入现有正式领奖页：分支来源/候选、重编原卡多选、赌局奖品查看。卡面只查看，选择与支付使用独立动作；分支确认仍按2币购买/3币重编/原免费交换执行，赌局奖品不直接领取，投币、点数和保底沿原收据。
- 列表与放大共用动作文字和可用性；正式卡片单元支持选择外观，按钮承担选中语义。页面状态更新复用局部更新、返回位置与焦点；暂离返回与放弃继续分开。
- 删除无消费者的`event-choice-hand/option`和三处覆盖样式分支，以及原选择卡的`picked`样式；火堆仍消费的卡面查看样式保留。
- 补齐原多张重编缺失的容量预检：单张/批量更换共用`canReplaceBagCards`，移除全部源卡后沿正式叠放、物资格与容器扩容投影整批目标。运行时事件命令在换卡前使用该端口，容量不足零换卡/零扣费。
- 结果确认改为等待领域实际返回，进行中统一等待；领域拒绝且原页仍有效时恢复确认与整理背包，原卡、结果和返回入口保留。保存失败已经转到领域重试页时沿其入口继续。更换后的日志或声音独立于已完成的换卡与返回。
- 当前规则与二级界面说明同步实现。

来源代码与相关差异用于集成核对，旧事件网格在运行源码及CSS中已无引用；本批未运行测试、lint、构建、检查脚本或实页验收。没有新增服务、删除文件、暂存、提交或推送。
