- 人物外观：复核上轮保留右侧缩略图、焦点、滚动与固定状态行的实现；继续仅左图切换。
- 照相馆：筛选/排序后选中卡不变时，原位同步预览正文，保留展开状态，不重播或取消无关预览动画；导航按钮继续原位同步。
- 收藏室：记录与勋章详情按源内容缓存，重复选择同一内容不重建详情、不收起已展开内容；筛选后空态仍正常更新。
