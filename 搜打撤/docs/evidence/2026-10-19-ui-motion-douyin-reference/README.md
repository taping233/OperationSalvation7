## 最小样板与完成条件（建议，尚未实施）

只选奖励页一张普通卡与一张高稀有卡，完成同一条链：静置可读 → 悬停/键盘聚焦轻抬 → 选中稳定 → 点击领取 → 成功后背包入口回执。只使用现有 `motion-presets.js` 的 `change:160ms`、`feedback:180ms` 等参数；参数是当前代码值，并非从视频测得。

判断样板是否成立：卡名始终清楚；连续移入移出不跳回旧状态；领取前后能认出同一卡；动效不延迟操作；静止后没有持续漂浮。低动态偏好保留即时颜色/边框反馈。先看这条链是否更清楚，再决定扩展。

## 已核对的接入位置

- `game/src/ui/motion-presets.js`：公共时长与缓动唯一参数来源，现有 change 160ms、feedback 180ms，包含低动态偏好检测。

- `game/src/core/map-drag-motion.js`：现有 Motion 惯性，拖动直接跟手，新输入可取消；此轮只读。
