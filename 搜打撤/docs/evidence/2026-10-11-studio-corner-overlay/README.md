# 大图角饰实际覆盖返修

已实施并在当前Codex内置浏览器1280×720定向视觉复核，完成未提交。未跑全量测试或build。

实页先确认旧修复没有解决视觉问题：ornament的z-index4、图片z-index1已生效，旧覆盖规则清理并非唯一原因。边框图把直轨、木底和四角雕饰一起压进border-image条带；提高层级或扩大图片，只能让边框与图片重叠，不能保证角饰的可见斜面伸到原画内。

本轮将plain/rare/epic/class/prismatic现有SVG中的透明角饰组派生成corner-*.svg，原边轨移除角饰use后派生rails-*.svg，原SVG文件没有改写。大图直轨继续使用border-image，四个独立角饰节点使用原组图形并按角旋转，位于照片前景。史诗/棱彩角饰尺寸为边宽2.2倍，古朴/稀有/职业为3倍，依据图形实际斜面范围设置；不是只拿透明盒子的交叠尺寸判断。传说保留既有栅格装裱，不新增矢量角饰，初始/衍生无独立雕饰组则沿原边框。

图片扩展按纸张内边距与边宽计算，图片内侧位置约为边宽0.7倍，比例和布局补偿沿原图片比例处理。夹子和提示在更高层级，装饰不接收输入。未修改原画或稀有蓝夹子颜色。

视觉反馈：最初1.65倍角饰盒子虽与图片重叠，但可见斜面仍接近原画边缘，已继续调整为上述尺寸。最终史诗和棱彩的可见角饰均压进原画，保存epic.jpg和prismatic.jpg；facts.json记录最终史诗当前窗口与节点几何。两次前景样本均通过本轮视觉反馈，其他档位没有逐档复核，不宣称全矩阵通过。

过程中共享Vite多次热更新使页面回到标题，证据在完整大图状态重新保存并查看，未使用标题页截图作为完成证据。内置浏览器连接更新后复用当前平台的新连接，未换外部浏览器。

源码：ui.js仅四角节点，photo-studio-mounts.css仅材料变量，photo-studio-unified.css仅装饰与图片几何，新增10份小型SVG派生资产。复用5200，无新服务；未提交、推送或发布。
