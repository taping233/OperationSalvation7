## 实施

- 分类计数按卡库数组身份及稀有度/人物/搜索条件缓存。切换分类和排序时复用，不重复扫描全库；重新取卡库后新数组使缓存失效。
- 筛选扫描与分类统计各自在扫描前归一化一次搜索词，替代每张卡重复trim/toLowerCase。两个调用入口均传入本次归一化结果。
- 共用描述渲染器最多缓存128组HTML；键包含当前卡牌ID、实际展示文字和原始大小写的搜索词，原文或搜索变化会重新渲染。超过上限逐条淘汰最早插入结果；新卡库的渲染器独立缓存，保留转义、词条与卡名引用保护。
- 搜索高亮最多缓存16个正则匹配器，复用标题、卡名链接和字段高亮的相同查询。维持原有大小写不敏感匹配及文字转义。
- 陈列区与双斜光重叠的整片循环光改为静态叠层，移除其关键帧及重复暂停/减弱动效规则，减少一个大面积持续动画。双斜光、12粒浮尘、胶片反光仍保留。
- 删除已全局停用背板的重复空态规则、两项未被引用的背景CSS变量；更新当前功能说明。
