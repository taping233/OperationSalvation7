## 实现与三版

| 版本 | 主要改法 | 当前状态 |
| --- | --- | --- |
| A 房间优先 | 全图展示；常驻侧栏；右下整备台；待办下置。电脑、近景椅、壁炉不依赖背景 cover 裁切 | 已用于游戏，待老板验收 |
| B 作业分区 | 左侧房间、右侧暖纸整备台；行动说明集中，背景与操作分区 | 画板候选，共用同一首页组件 |
| C 底部设施栏 | 导航收到底部；房间两侧释放；整备台压成横向短面板 | 画板候选，共用同一首页组件 |

导航七个目的地复用既有 `hubTab`，收藏奖励数量来自现行 Meta；待办分别跳向仓库待复原与收藏奖励。新增 SVG 仅用于导航图标。主动作、待办、常规导航、低频功能按字号、颜色与位置分级；卡牌稀有度和身份色沿原实现。子页标题与统计改为同一阅读节奏。

动效新增短促 hover、箭头与按压反馈，支持减少动态效果；正式页级展开继续沿公共 surface-motion 和 hub.presentation。画板的「重播展开」为独立示意，采用标题、导航、待办、操作区错峰，不代表运行页的实测效果。模式倍率示例按当前 game.session.modes.js 的 1.5 填写，画板不引入运行内核。

展示入口：[三版与真实游戏参考](../../../game/base-design-options.html)。设计画板采用示例库存/奖励数量，不加载存档或交易命令。复用原项目 5200 URL 展示，未创建服务或确认当前监听状态；未操作游戏页面。
