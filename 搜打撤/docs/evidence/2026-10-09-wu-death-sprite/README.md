# 无：死亡倒地 Sprite 候选

老板认可受击后令制作死亡倒地。[预览](../../../game/art-source/characters/wu-death-sprite-20261009/index.html)从同一待机基准开始，失去支撑、屈膝撑地、侧身落地，最后保持躺倒。8 个帧槽含 7 个不同姿态，21 个约 24 fps 时间步共 875 ms；最后两帧复用同一倒地图，不自动回到站立。[素材说明](../../../game/art-source/characters/wu-death-sprite-20261009/README.md)给出配置与复现方法。

首帧 PNG 与认可待机 `idle-000.png` 文件字节/像素相同，SHA256 为 `484895aa505493825202539d4b7cfadf7c63c33997633b7940982a6634dbc63f`。通过：首帧一致、最后两帧一致且不同于待机、最终轮廓水平躺倒、全部轮廓完整留边、可见帧图一致、875 ms 时长、预览脚本语法。倒地形态另以实际图片核对，低轮廓检查不单独替代人工判断。

Codex 内置浏览器复用既有 127.0.0.1:5200，当前窗口真实按钮播放死亡一次，等待到最后“保持倒地”；浅色背景检查完整头发、身体、腿脚与剑。错误日志零。临时标签曾失效，按平台文档重新开内部标签完成验收，没有换外部浏览器。

素材由内置 imagegen 生成关键姿态，再使用已有 Pillow/NumPy/OpenCV 提取、对齐和导出，提示词及源路径在素材 `request.json`。超过 1 MB 的源图/帧图只留本地，获取方式与全部文件 SHA256 见[收据](receipt.json)。未接入正式战斗、不构建、不提交，无新服务；待机、攻击和认可受击动作内容未修改。
