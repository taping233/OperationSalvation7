## 要达到的结果

玩家在每个时刻都能回答：我在哪里、现在该做什么、会付出什么、实际发生了什么、怎么返回。冬境人物与场景有统一的界面承托；卡牌、敌方意图、资源去向和重要操作清楚可辨；选中、命中、领取、损失和退出有连续反馈。画面提升不能以遮挡、等待、卡顿和误操作为代价。

**综合推荐：战斗视觉与演出整体重做，作为第一条完整样板链。** 依据是当前窗口实证裁切、敌方意图断行、只有三人接入且有重复帧、战斗图与认可立绘身份/画风差异。战斗UI、场景、人物战斗图和动作可重新设计；规则与结算逻辑保留，其他页面研究照常推进。老板的补充用于形成这个完整方案，不单独变成一串零散派工。

**不以文档页数、任务数、代码删减量、素材数量或粒子数量评价成果。** 一个问题能靠布局或信息层级解决，就不扩成架构改造。无问题的页面可以研究后原样保留，必须写明证据和理由。

## 执行顺序

1. **A0 全覆盖研究与基线。** 补齐每页的证据；先核对正在进行的 PH1 与选人待机改动。旧证据只在相关源码、素材与环境仍适用时复用。研究结论分为需修、保留、条件实验、冻结或受阻。
2. **A1 可见操作与阅读底线。** 战斗中的裁切/意图问题并入A4整体新布局，避免先修旧皮再重做；其他页面的横向溢出和遮挡可独立修。每处先复现，不把框架整体替换当解法。
3. **A2 视觉依据、出图配方与样板定稿。** 先消除人设页/风格配方中的相互矛盾，再用整备、战斗、战后领取/结算三类不同密度页面建立共同规则；小样落实际容器后审查画面和操作，再并行扩展。
4. **A4战斗优先，A3/A5/A6分域跟进。** 战斗样板先做完整，整备/探索、结算、基地收藏工具的研究可并行；共享卡牌和公共样式由唯一负责人集成。每域研究完成便可实施有证据的任务，不必等所有其他域，但最终研究出口必须覆盖所有现行条目。
5. **A7 性能贯穿。** 改造前取同条件基线，修改后测同一操作；优先热点。过去无头浏览器数据仅作线索，不能当当前内置浏览器成绩。
6. **A8 最小文档整理，A9 全链复核。** 改过期导航和状态；删除候选另列。完成后逐页核对、走完整远征与异常返回链，并交付实际未核项。

步骤详见任务总目录。已授权的研究和改进连续推进；玩法、人设、删除和无法查明的重大取舍带方案问老板，普通实现选择不反复请示。

## 美术决策与控制范围

| 层次 | 本轮要求 |
| --- | --- |
| 构图 | 角色/敌人/卡牌为主要对象；同页一个主要动作，状态和说明退居辅助；先分安全区再装饰 |
| 文字 | 标题、卡名、规则、数字有明确字号角色；关键规则不压缩成小字，不能靠悬停才能找到主要操作 |
| 材质与颜色 | 从认可五图提炼克制的综合色、笔触与局部身份色；UI材质另经参考和样板选择，不能默认现有金属球卡框或金按钮已获认可；危险、选中、稀有度分别表达 |
| 图像 | 五张认可立绘保留；其他素材逐类审查映射、分辨率、裁切、风格和焦点，确需才补图；旧图和提示词来源保留可追溯 |
| 动态 | 选中—目标—结算—反馈—恢复操作形成因果顺序；动效不能延长规则锁或掩盖结算失败；减少动态仍可理解 |
| 跨页 | 同一张卡/物品从列表、详情到结果保持身份；返回到合理来源，不能被共享关闭逻辑送错页面 |

这是一套项目设计约定，不是商业游戏品质已达标的声明。新增装饰必须能说明它改善的焦点、身份或反馈，否则不排期。

## 全覆盖与性能出口

- 当前基线是 110 基本界面＋55 变体，不能把它当永远固定的数量；结合当前入口注册、菜单、弹层与运行可达性重新对账。每个活跃页面都有稳定画面/实际操作证据，或明确的阻塞；源码分析不计视觉完成。
- 同模板可复用布局证据，但每个变体独有的人名、图像、长文案、牌效、满包/禁用条件必须逐项核。故障注入只在本会话可丢弃档；不得覆盖真实存档。
- 性能覆盖冷/热进入、切页、大卡库滚动/筛选、详情开关、地图静止/移动/缩放、战斗出牌/多目标/回合/胜负、粒子与减动态、反复进入退出的资源释放。每页有风险判断；非热点可引用同组件同条件测量，说明共享依据。
- 数值至少带版本/相关输入指纹、窗口、场景数据量、操作、采样方式和冷/热条件。能测则取重复采样的中位/P95与长任务或资源指标；不能测的写未知，不从工具调用耗时推断游戏帧率。
- 不设置脱离设备的虚假“全场景恒定帧率”承诺。超过本项目既有预算或同条件出现可重复退化才定位；任何大于测量噪声的退化须解释，优化后回跑受影响场景。
- 当前平台内置浏览器、当前窗口；不启动外部 Edge/CDP/headless 取代。支持的性能能力不可用时记录缺口，继续其他工作，不安装新工具或修改全局配置绕过。
