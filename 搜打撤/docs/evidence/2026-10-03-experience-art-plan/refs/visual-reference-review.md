## 1. Griftlands：战斗目标与操作层

- 官方来源：[Klei 游戏页](https://www.klei.com/games/griftlands)
- [已观察原图](https://assets.klei.com/f/259446/2662x1440/55280044c0/3-fight1.jpg/m/fit-in/1200x700/filters:quality(70))
- 截面：酒馆战斗、底部手牌、我方两人、右侧怪物群、选中目标与指向线。
- 构图：左右敌我占中上部，底部为持续操作带。手牌位于中下方；行动点在左下，结束回合在右下。牌与目标有明确空间关系。
- 文字层级：生命数值贴近对应角色，攻击意图在目标上方，费用在卡片左上角。状态事实不混入大段背景叙事。
- 图像框与明暗：场景褐灰且压暗，角色轮廓独立；底部青色 UI 带与画面分区。可用手牌绿边、目标粉色描边/箭头与青色指向轨迹共同出现。
- 可借：把来源、目标、预期后果连在一条视觉链上；持续数值紧贴对象；明确手牌操作区，避免各浮层争抢中央空间。
- 不能照抄：本图同时使用多种高亮颜色且小字偏细；我方应先建立颜色语义并给文字/图标冗余，不能整屏套绿边。其人物数量与循环卡组语义不直接迁移。

## 2. Hades：认可立绘如何成为页面焦点

- 官方来源：[Supergiant 游戏页](https://www.supergiantgames.com/games/hades/)
- [已观察原图](https://images.ctfassets.net/5owu3y35gz1g/73cqOl2QleftNZSwhHmYXO/28627035cb39453e3c46c81300e088bc/hades_09-dec-2019_06.jpg?w=1920&q=80)
- 截面：Athena 对话；官网仍展示的 2019 年早期画面，不代表当前版本全貌。
- 构图：大型半身人物占左下，文字面板向右延展；人物允许出框，面板避让面部和关键轮廓。场景保留但退居背景。
- 文字层级：角色名在独立深色铭牌，身份是更小次级行，正文在浅色低纹理大面板中。纹样停留在边框和少量装饰区。
- 图像框与明暗：人物亮部、浅色文字底与深环境形成明确层次；画面有丰富笔触，但文字区域不承接背景噪声。
- 可借：五张已获认可立绘应作为风格与人物焦点基准；由布局为它们留出完整轮廓和呼吸空间。人物、身份、正文、操作四层各有职责。
- 不能照抄：不直接搬希腊纹样、角色、字体或对话框比例；该图只能支持人物与文字分层，不能冒充祝福选择、收藏或结算页的实见证据。

## 3. Darkest Dungeon：整备与升级

- 官方来源：[Red Hook 截图库](https://www.darkestdungeon.com/darkest-dungeon/media/?cat=screenshots)
- [已观察 Guild 原图](https://img2.storyblok.com/fit-in/1536x768/filters:format(webp)/f/127947/1920x1080/043452ad8f/ss-24.png)
- 构图：左侧场所插画、中间当前人物与升级矩阵、右侧角色列表；底部统一资源栏。大插画负责气氛，密集操作集中在规则区域。
- 文字层级：场所名、选中人物名、职业与说明、技能行、价格各有固定位置；角色列表一行承载一名角色的同类信息。
- 图像框与明暗：背景与插画大面积低明度，当前操作矩阵以金色节点、图标、锁和数字建立差异。
- 可借：整备明确“当前对象—可改项—成本—资源总量”；列表和详情分离，避免每张卡同时塞入全量信息；锁定态有锁形状，不只变灰。
- 不能照抄：其细字、低明度与高密度不应成为我方可读性目标；不能只凭亮色节点判定已解锁、可买、已购买的精确语义。

## 出图逻辑建议：先基准和用途，再风格词

1. 将五张获认可立绘列为唯一已确认视觉基准，先由本轮立绘审查提取可核验属性：线条、明暗分组、饱和度、材质频率、轮廓、比例、留白；本参考研究没有代替该审查。
2. 每类资产先规定用途与落位：人物出框范围、背景文字安全区、物品缩略尺度、卡图焦点、横竖比。页面结构与字体用代码保证，避免把文字/按钮/UI 整体生成进位图。
3. 提示词写成“共同基准 + 资产用途 + 主体/动作 + 构图/安全区 + 光色与材质 + 禁止项”。不能靠堆多个游戏名来建立风格一致性。
4. 先做少量代表样本并放回真实界面：人物旁的背景、卡面、物品图各一类；确认与五立绘协调、缩小仍可读，再扩批。保留旧素材和生图脚本，不做大规模换图先行。
5. 验收同时看原图与实际落位：面部不被裁、关键轮廓不被控件覆盖、文字面低纹理、不同状态不只靠颜色、素材尺寸/格式符合性能预算。参考作品只提供构图原则，不替代老板对样张的判断。
