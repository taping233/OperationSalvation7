### 待机提示词

以参考图片中的角色为唯一主体，制作二维手绘游戏战斗待机动画。人物全身、手持长剑和马尾始终完整在画面内，保持参考图朝向、脸型、服装、颜色、剑长及画风。固定镜头、固定构图、固定人物尺度。双脚固定在原位，身体轻微自然呼吸，肩部、衣摆和马尾有小幅连贯运动，持剑手稳定。动作从参考姿态开始，平稳回到相同姿态，适合无缝循环。背景为均匀纯色，与人物轮廓颜色明显区分。不要镜头移动、缩放、转身、走路、攻击、闪光、文字、阴影地面或新增物件；不要改变脸和剑的形状，不增加写实材质与细碎纹理。

### 接入标准

- 逐帧检查身份、手部和剑形；不能只依据首尾图认定中间帧合格。
- 抽帧后透明背景无残色；头顶、剑尖、马尾和脚底不裁切。
- 画布、人物尺度和脚底锚点稳定；待机末帧至首帧无可见跳变。
- 以原视频时间维护帧时长；缩短攻击时须保留起手、命中与收势。
- 通过候选目检后再接入；玩家可见变化在当前平台内置浏览器、当前窗口验收。
