# 普通面板与区域目标过渡

状态：两轮实施已完成，父会话最终14文件119项定向通过；第二轮实页因工具不可用待验，见 [最终验证](../verification.md)。下文保留各阶段交接记录，“待验证”指当时状态；子代理未自行运行测试、构建或浏览器验收。

`game/src/ui/surface-motion.js` 通过公共 `target-motion.js` 驱动普通遮罩、面板和区域的可重定向外观。保留 `surfaceMotion`、`surfacePhase`、`surfaceLayout` 等数据契约；实际隐藏、路由、焦点和退出时长仍由调用方负责。首页、基地与 preparation/departure 专属编排沿用现有路径。

新目标交给公共层从当前显示态续接。关闭准备调用不重播已有入场；离场反转会移除首入错峰，避免等待上一轮。`clearSurface(root, { preserveVisual: true })` 允许保留外壳当前态，供 show 分支替换内容时使用；默认清理及隐藏、卸载、低动态偏好中断恢复本层持有的原始内联样式。数据阶段保留，但本层持有节点的旧 CSS 关键帧被内联 animation 覆盖，避免两套动画争用相同节点。

背包以既有 rail/head/board 等区域承接，奖励以奖励区承接。未知布局的大列表以整个容器承接，不对前八张卡单独进场。

第一轮打磨已实施，待主会话集中验证：普通目标路径的透明度统一由根层持有，面板和区域只做位移、缩放。入场与配对退场都避免根层、面板、内容三重透明度相乘。既有已规划页面首入时保持根层不透明的约定继续保留，内容通过区域位移展开；关闭时只由根层淡出。原生 surface 兼任 panel 时合并为同一目标，保留一份透明度。共享时长、首页与基地及整备专属路径未调整。

第二轮窄复核：只读核对 surface、target、interface 接线及实际 overlay 内容替换方式，未运行测试、浏览器或构建。普通/profile 互切继续共用根层 opacity 目标；公共层仅首建状态使用 from，同目标去重，不重复种子或追加动画。真正隐藏、节点移除及低动态中断由生命周期恢复公共层持有的 opacity/transform，再恢复本层保存的内联 animation。

复核发现并按主会话授权修正了一个具体关闭准备问题：同页 contentRefresh 会替换内容 DOM 而不播入场；随后关闭时，interface 先 enterSurface(restart:false)，新区域首次登记原先仍从首入偏移取种子，再立即转向退出。背包新区域因此会先跳到 x=24；contentOnly 未参加首入的标题/导航也会在关闭时首次使用入场偏移。修正只利用现有 uiClosing/uiMotionScreen 关闭标记，让关闭准备中新发现的节点从中性目标登记且 delay=0，再交 leaveSurface 驱动退出。已有节点保留当前显示态，不改时长与现有责任边界。
