## 第一轮打磨（主会话已集中验证）

卡牌聚焦边缘改为读取现行卡面 `--paper-wash`、`--paper-pigment`，无材质变量时读取背包 `--tint`，不另建稀有度配色表。退出聚焦保留同一色相并收透明；键盘焦点使用 2px 薄边，鼠标聚焦使用 1px。新增材质优先级与反转同色相断言，低动态断言同步为当前材质色。

连续领取刷新 footer 时，在同一合法奖励场景内重新寻找可见背包锚点，现有来源克隆朝新锚点继续收束。重新定位仍使用原完成期限，不延迟发放；旧路段取消回调通过版本号失效，避免误删新路段。已出现的入口薄边也可跟随替换后的锚点。离开场景、关闭浮层与切换模式保留清理边界。新增断言检查来源克隆身份不变、落点更新、旧路段取消不销毁当前克隆及关闭清理。

已从 `bag-pane-view.syncAttributes` 确证：同区刷新原先会移除运行时 `data-card-state-motion`，并用渲染字符串覆盖含动效值的 style。最小修复仅对带该标记的 bag tile 将标记、`transform`、`outline-color` 合入待同步节点，其余业务属性仍按新渲染同步，`--tint` 与 `--glow` 可正常更新；未改 `reconcileTools`。新增 `tests/bag-pane-retained.test.js` 断言保留抬升与边缘、更新材质、删除失效业务属性，并确认标记移除后恢复普通属性同步。

## 第二轮打磨（依据第一轮实页，实施完成待集中验证）

保留材质色边缘、6px 轻抬与 1.02 缩放。聚焦使用公共 `change` 160ms，回中性改用 `cardReturn` 120ms；领取使用公共 `acquire` 340ms 与 `travel` 曲线，来源缩略卡在末端保留 .12 透明度。落点光改为 160ms、起始 .65 透明度、终态 1.035 缩放，减轻拖尾。

同一背包入口的连续落点共用一个薄光节点，并移交清理归属，不叠加亮框。复用节点由公共目标动效维持当前渐隐状态，不重新点亮；旧回执回调只能清理旧归属。没有修改发放、领取按钮或焦点时序。

飞行与落点光的有限生命周期内捕获 scroll 并监听 resize；同一帧多个事件合并成一次端点计算，支持目标 DOM 未替换但位置变化。重新收束始终使用原完成期限，不重置 340ms；静止时不递归申请动画帧。销毁会解绑两个监听并取消尚未执行的帧。DOM 刷新也核对端点盒变化，继续沿既有坐标换算与合法场景边界清理。
