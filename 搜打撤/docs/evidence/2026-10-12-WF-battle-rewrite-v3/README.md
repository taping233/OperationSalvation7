# 影潮交锋第三版 · 固定主题与返回

老板确认量化判断后要求继续修改。第三版只改主旋律：以两短一长起头的固定节奏轮廓，增加级进，让首次两小节主题与返回保持相同音高、起音及音长；中间改变句尾与和声回应。其余13轨、第二版鼓型、配器和后期方案保持原样，正式游戏未实装。

## 改动与证据

主线第3–4小节首次陈述，第11–12小节返回；使用D–E–F起头，再跳到A并回落，回答句F–E–D收束。第5–8小节变化发展，15–18.75秒保留原有收束，第13–14小节采用上移变体，末段沿属和声回主音。返回时只增加音符力度，帮助识别同一主题。

| 定向指标 | 第二版 | 第三版 |
|---|---:|---:|
| 鼓组音符数 | 124 | 124 |
| 鼓组律动一致指数（16格/小节） | 85.0/100 | 85.0/100 |

| 主线平均绝对音程 | 2.77半音 | 2.51半音 |
| 两小节主题返回的音高/起音/音长联合匹配率 | 57.1% | 100% |
| 主线音符数 | 40 | 52 |
| 主线音长中位数 | 439ms | 332ms |
| 主线短于250ms音符数 | 1 | 15 |

短音增加用于固定动机的起头和句尾拾音，没有继续以“音越长越好”为目标。主题返回匹配率按16分音符网格量化、忽略力度：它证明指定片段一致，不是经过验证的记忆点评分。鼓组指标沿用[MusPy律动一致性定义](https://muspy.readthedocs.io/en/latest/doc/metrics.html)，仅对核心鼓轨以16格/小节计算；也不是好听度总分。

指标与断言见[evaluation.json](evaluation.json)、[evaluate.py](evaluate.py)。13轨原生XML逐轨核对不变，证据见[backing-preservation.json](backing-preservation.json)；本轮没有人工听辨，不声称统计改善已经证明旋律更好听。量化方法与参考背景沿[第二版记录](../2026-10-12-WF-battle-rewrite-v2/README.md)。
