## 源码对照与调整

只读对照来源为 `D:/素材/杀戮尖塔2源码/sts2-decompiled/`，不是官方公开源码仓库；未修改该目录，未复制其素材。

## 光效

只在 `#overlay .battle-stage` 下增强临时/变形状态。临时牌青色、变形牌紫色、双状态双色，沿实际纸边叠加近光与柔光，保留原状态标签、正文和卡图。修正原状态滤镜会被后面的纸边默认滤镜覆盖的问题；光效通过原纸边滤镜入口取战斗状态变量，不增加矩形选择框或命中层。传说、棱彩的稀有度光晕参数恢复原值。减少动态保留静态状态光。

只读预览入口 `/dev/battle-glow-review.html` 使用生产 `cardHTML` 及固定展示状态，不连接战斗引擎或存档，可切换战斗增强和减少动态。截图在同一当前窗口、相同冰刺卡面、减少动态开启下采集：[原强度](state-default.png)、[战斗增强](state-battle-enhanced.png)。固定展示状态不证明真实临时牌的生命周期或变形结算。
