## 学习资料与标准索引

| 编号 | 原始来源 | 本计划采用的内容 | 边界 |
| --- | --- | --- | --- |
| G1 | [NN/g：十项可用性原则](https://www.nngroup.com/articles/ten-usability-heuristics/) | 状态可见、术语/行为一致、错误预防、减少记忆负担 | 通用检查方法，不规定某款游戏的美术风格 |
| G2 | [NN/g：渐进披露](https://www.nngroup.com/articles/progressive-disclosure/) | 高频决策留首层，进阶内容按需展开 | 核心消耗/风险不能被藏到次级页 |
| G3 | [NN/g：动效的用途](https://www.nngroup.com/articles/animation-purpose-ux/) | 状态变化、反馈、对象关系和导航关系 | 用途明确再添加，不以动效数量评价完成度 |
| G4 | [NN/g：动效时长与运动特征](https://www.nngroup.com/articles/animation-duration/) | 时长与距离/复杂度相关；普通UI100–500ms的研究区间 | 是实验起点，不是二游实测值；战斗与剧情演出另行采样 |
| G5 | [Microsoft XAG101：文字显示](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/101) | 字形高度、间距、最终显示和可读性；PC1080p默认18px字形高度参考 | 字形body height不等于CSS font-size，需考虑本项目缩放 |
| G6 | [Microsoft XAG102：对比度](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/102) | 重要标准字号文字4.5:1；大号3:1；禁用文字3:1 | 按最终背景检查；不是对当前游戏的达标声明 |
| G7 | [Microsoft XAG117：视觉干扰与运动设置](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117) | 非必要动态可停止/减弱，阅读层保持稳定 | 核心玩法运动与辅助界面运动区分处理 |
| G8 | [W3C WCAG2.2：非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast) | 识别控件与状态必需的图形，适用时与相邻颜色3:1 | 并非每一条装饰边或每两个非相邻状态都必须互比3:1 |
| G9 | [W3C WCAG2.2：目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) | Web指针目标24×24 CSS px或足够间距等例外 | CSS像素、缩放后命中区域和图片像素不能混算 |
| G10 | [Riot开发者：游戏视觉清晰度](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/) | 主辨识特征与朝向、信息/演出重要性的层级、减少视觉噪声、跨场景辨识 | 借鉴方法；不搬用竞技MOBA的命中框、伤害或皮肤规则 |
