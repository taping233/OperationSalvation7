# 项目约束

## 按任务接手（Codex / ZCode 共用）

- 单问直接答；需查证时只读相关资料。小改先核对 Git 与目标归属，再按 `搜打撤/docs/README.md` 路由读取必要上下文。
- 跨域、长任务或接班按序核对：① `git status --short` + `git log -5`；②留言（如可读，记录内置浏览器与来源地址，不可读记未核验）；③按需检索当前平台记忆；④ `docs/PARALLEL-REGISTRY.md`；⑤ `docs/PENDING.md`；⑥ `docs/README.md` 路由。
- `cd 搜打撤 && npm run handoff` 可完成 Git/热点/活账机械简报；只补它未覆盖的步骤，不重复跑同一检查。记忆入口、事实分层与收官口径见 `搜打撤/docs/README.md`「双端工作流」。
- 流程工具统一入口为 `搜打撤/docs/WORKFLOW-TOOLS.md`：开工先查已有实现，记忆路径可用 `npm run memory:discover` 只读发现；验证优先用 workflow verify 留证，混树暂存先 staged --plan，不绕过依赖或 index 守卫。
- 同会话复用有效证据；目标文件内容、工作区/属地、任务范围或相关环境变化时重新核对，不把历史记录当当前事实。

## 流程登记（09-29 起）

- 改共享文件/开长任务（工作树/端口服务/后台进程）前，先登记 `搜打撤/docs/PARALLEL-REGISTRY.md`，收官销账；发现无主改动只记录勿动。
- 产生确需老板决策/处置的事项即时登记 `搜打撤/docs/PENDING.md`；普通 backlog 归路线图，已授权实施不重新请示；拍板结果回写来源。
- 验收证据入 `搜打撤/docs/evidence/<日期>-<任务>/`，不散放。
- 端口约定：主线 Vite 5200、隔离副本 53xx、产物 preview 8139；记录工作目录/端口/PID/会话，收官只停本会话创建且身份确认的进程，再复核端口；无主进程勿杀。
- 派工（老板点名时）按 `搜打撤/docs/PARALLEL-DISPATCH-PLAYBOOK.md` 执行。
- 小额免登（09-29 深夜起）：纯说明类小修——注释或 .md 文档 ≤10 行、不碰代码/数据/共享台账、当次会话内收官——可免热点登记，提交信息注明改动即可；拿不准是否够小，一律照常登记。

- 只开发 `搜打撤` Vite；Godot/Unity/EXE 冻结。文件超 300 行先 `rg` 再读片段。
- 改前查 `git status --short`、`git log -1`、并行归属；其他会话有未提交改动时不覆盖共享文件、不 build、不顺手提交。只看相关 diff 或 `--stat`。
- 接手开发/判断交付从 `搜打撤/README.md` 按需导航，核对实时工作区；历史交接非当前事实。交付变化仅更新自有现行记录，注明时间、HEAD/远端差异、证据、未核实项；共享记录占用则另记。
- 默认定向验证；A 档删除三证据与 B 档全套沿用老板拍板口径，详细矩阵见 `搜打撤/docs/quality-gates.md`；纯工程文档验链接/事实，不触发游戏全量。公共架构或代码收尾落库前跑全量（默认并行）；生成成功非完整验收；勿手改 `cards-sync.json`。
- 浏览器操作/游戏验收仅用当前平台内置浏览器（Codex 或 ZCode），只验当前窗口，多尺寸须明确要求；不可用就记录阻塞，不改用外部 Edge/CDP/headless。`page-snapshot.mjs` 仅导入/对比内置浏览器采集的证据，不自动驱动浏览器；来源与真实输入范围须分别核验。
- 顺带发现先做范围内最便宜的非破坏性实验；10 分钟内未定性即停止深挖，需求归 backlog、决策归 PENDING；HEAD 对比优先另读或隔离副本，不擅自回滚共享现场。
- 只改要求范围；能查证的先查，玩法决策查不明再问。任何删除先列具体路径获同意，清单已获批且范围未变沿用授权；回滚、提交、推送、发布、外部写入须明确指示。禁用 `git clean`/`git checkout` 清理；任务完成不自动提交。
