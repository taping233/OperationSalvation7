本轮修改及源码依据：

- 地图路线裁剪的两端各有12轮二分采样，原每轮经 `mapTravelPoint` 重新构造同方向曲线控制点，裁剪完成还另构造一次正向曲线。现正反方向各构造一次，采样传入已有曲线；单次裁剪的控制点构造从25次变为2次。这是源码调用次数，未测量CPU耗时。二分次数、方向、插值公式及道路最终截取方式保持原实现；其他三参数调用继续自行准备曲线。
- 地图节点名称及状态在同一帧经常重复，原每次绘制都调用Canvas测宽。现按字体和文字在当前 `drawIcons` 内共享宽度，标题/状态沿原字体、补边和取整逻辑；下一帧重建缓存，不跨字体加载或实时文字变化复用旧结果。
- 页面活动观察原每次刷新做两次全页遮挡查询，且每次断开重订全部遮挡属性观察。现一次发现结果同时用于订阅及当前阻挡判断，仅节点集合变化时重接；仍逐次检查离场、隐藏、inert、确认层退场和加载层退场状态。
- 大列表属性变化通知检查媒体/循环动画归属时，原逐条复制Set为数组再查找。现直接遍历，找到相关成员即结束；媒体播放恢复、减少动效和页面生命周期仍沿原逻辑。
