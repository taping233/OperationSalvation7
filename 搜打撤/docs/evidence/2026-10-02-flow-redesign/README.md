## 结果

- 日常路径统一为按目标、主动作、定向反馈、按授权收官；QUICKSTART 和导航只指路，WORKFLOW-TOOLS 维护实际流程，quality-gates 维护验证口径。
- REGISTRY 分编辑、完成未提交归属、已落库待移行和已释放；PENDING 分有效待决与已决。接手和 impact 共用分类，默认简报低噪音，详情保留审计，不自动处置他人行。
- 普通门和隔离门共用冻结 Git 视图的选择，不再因删除/改名统一全量；scripts-only 在两入口同判。
- 新冻结报告可经 `--reuse` / `GATE_RECEIPT` 严格复用；失败、中断、skip、改写、相关输入/依赖/环境变化拒绝。工作树 verify 报告仍是候选；旧报告不补造冻结证明。无关文档、状态和素材变化不影响代码证明，相关文档必须共同验收。
- ship 默认预览，排除在途、待决目录、中间产物和证据大件；锁 HEAD/index、源内容/mtime、REGISTRY/PENDING/task 筛选依据。按共同验收范围分组，相关文档随代码；`--only` 不夹带后续组，组间核对 index 内容，失败保留现场。
- 档案原文哈希和替代入口必须有效，历史 source 可以合法退役；文档检查与测试共用链接、档案、源码域表、规则预算契约。
