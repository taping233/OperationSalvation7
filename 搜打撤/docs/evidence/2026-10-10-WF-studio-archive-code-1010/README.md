# 照相馆档案主题：代码复核迭代

老板要求“自己从代码层面检查迭代一版”。本轮执行源码审查、修正和定向代码检查；未操作浏览器，未新增服务或运行构建。完成未提交，实际画面仍待用户验收。

## 发现与修正

| 代码问题 | 修正 |
| --- | --- |
| 旧 `expedition-library.css` 的字体规则带 important，网格名称新字体及大图标题子 span 会被覆盖 | 网格和大图标题/子 span 明确使用同一衬线变量，并按目标作用域覆盖原规则 |
| 搜索伪元素保留旧圆环及柄，同时 unified 规则又写入新搜索字符 | 保留一套字符图标，清除旧圆环/柄，按输入框中线定位 |
| 右侧长内容沿用旧 flex 高度与外层滚动，照片、说明和导航在压缩时缺少明确边界 | 标题固定，预览区独立滚动；照片与纸签不参与压缩，统一六像素横向安全留边 |
| 三列信息继承居中对齐，值换行时纸签高度和标签位置可能不同 | 三列拉伸等高，内部从同一顶部基线排列；编号不换行，标题、按钮和说明允许长文本换行 |
| 分类标记只在初始和筛选时更新，布局变化后可能停在旧位置 | 新增页签尺寸观察，兼容窗口事件；整页重建和关页释放观察器及监听，忽略已排队的销毁后回调 |
| 暗底结果计数和暖纸传说文字使用旧墨色 | 计数改为浅墨、传说改为深金；源码色值计算对比从 2.62→6.46、3.45→4.95。该数字不代表实际截图/透明叠加/缩放验收 |
| 照片墙纸签与放大背签各自写死字体/纸色，信息字段分组不一致 | 共享档案主题变量，大图也按三列字段排列 |
