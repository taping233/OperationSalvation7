# 默认画风九图融合

2026-10-20，老板上传九张插画，直接要求“把这些融进现有的默认画风里”。本轮在现行双图块面厚涂基础上融合画法，正式规则与可复用提示词只维护在[游戏默认画风](../../production/art/ART-STYLE-V1.md)。

## 来源与提取

九图按本次发送顺序逐字节保存为本目录 `reference-01.jpg` 至 `reference-09.jpg`；[原件清单](references.json)记录原文件名、来源绝对路径、保留相对路径、尺寸、字节数与 SHA256。01 大于 1MB，由本目录 .gitignore 排除，留本地；其余原件单文件均小于 1MB。异机缺失原件时，从老板本次上传的同名附件获取并按清单核对哈希。

以下是助手对参考画法的观察及本次提取，不代表老板另行认可过生成样图。

| 图 | 主要观察 | 融入方向 |
| --- | --- | --- |
| 01 | 蓝紫与暖褐呼应，弧形发束、深浅叠色和细轮廓相接 | 冷暖色片与清透眼睛；保留发束及衣料结构 |
| 02 | 绿橙点睛、综合色大面、宽袖折面与轮廓留白 | 鲜色集中；宽阔衣面和局部折面形成密度差 |
| 03 | 深衣服仍有多级灰紫，眼睑和手势清楚 | 暗色可读、脸手优先、线与色块共同塑形 |
| 04 | 橙红主色、头发断续切笔、衣褶宽笔覆色 | 饱和色也保留综合色层次，笔触顺形且有长短 |
| 05 | 明亮发色配深衣与浅布，视线、手势和衣摆相连 | 材质与明暗分组清楚，动势服务人物表达 |
| 06 | 灰白与高纯红反差，硬边色块配局部细线和排线 | 点睛色集中，排线仅作局部材质手段 |
| 07 | 蓝灰与紫灰叠色，西装大面安静，脸眼更细 | 彩色灰、选择性细化与有轻重的轮廓 |
| 08 | 暖褐与灰紫协调，暖肤色完整，衣料切面较活泼 | 肤面比衣面柔和，保留必要投影与清楚神态 |
| 09 | 红褐与灰白大组，斗篷宽笔叠压，发梢与衣缘有动势 | 大笔覆色、局部露底感与强弱边缘；成图仍保持完整主体 |

融合保留旧双图认可的发束、衣褶折面与层叠密度，再加入九图的线色关系、冷暖叠色和脸眼表现。参考中的角色身份、兽耳、角、光环、服装、半身裁切、白底、签名与水印不成为默认内容。没有设置机械混合比例，也没有将某张图的配色固定为全局色板。
