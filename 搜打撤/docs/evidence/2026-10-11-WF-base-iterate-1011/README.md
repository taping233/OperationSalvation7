# 基地与收藏室迭代交付

本轮继承“审阅基地与二级界面设计”的有效上下文，按最新指示完成可审阅实现，未提交。壁纸按原对话最后要求暂缓，不再制作或接入。

## 最终结构

- 收藏室只陈列当前档永久收藏记录；未收藏的角色招式与仓库持有牌不混入。普通收藏与已消耗归档的职业/能力卡都保留，退役记录仍显示原名，不伪造卡面和可用操作。
- 收藏奖励是独立次级页面，成就、卡背、故事同样从轻量入口进入。返回按钮与真实Esc回收藏室；卡背解锁目标正确进入并选中成就。奖励计算和领取沿原有规则：职业/能力卡里程碑与普通收藏展示范围分别保持现行语义。
- 培养页集中加成、熟练度与一个选择卡牌入口；仓库筛选收进浮层，保留容量和扩建入口并直接选中基地仓库；扩建材料/费用只在确认区出现一次。补给减少重复边框和容量旁路。
- 基地按钮采用切角、固定箭头区、焦点/按压/禁用反馈；翻页、筛选和弹出工具区使用可中断的短动画，页级入场继续沿公共来源。没有性能A/B或呈现帧率结论。
