# 补给布局减法

状态：自有补给布局已完成定向验证，购买按钮已挂共同控件契约，待根会话创建/加载 base-controls-v4 和当前窗口复核。本轮没有修改 home、warehouse、personnel、facilities、archive 源码或共享 CSS。

## 已实施

补给页主动作是购买所需商品；四件商品保持现行数组顺序、价格、持有量、缺币计算、预览与购买命令。商品外框、名称分隔线和价签底块已移除，卡面保留作为实物身份的轻框。拉开列间距，减少卡面内缩，让名称、卡图、持有量、价格与购买形成一条短路径。

购买按钮增加 `base-command base-command-primary`，内部为 `base-command-label` 文字和 `base-command-arrow` 箭头（aria-hidden）。删除补给独有的色面、尺寸、hover/active/disabled/focus 皮肤，价格仍独立固定排列，按钮禁用条件与 aria-label 保留。共同 CSS 由根会话创建/加载，本子任务未新增配色或第二套控件规则。商品预览的局部图片缩放移除，首次入场和 hover 由根共同 motion 绑定；没有局部动画 JS。

常态移出仓库容量与扩建旁路；卡牌仓库满时才显示“整理仓库 / 扩建”出口。满仓原因集中显示一次，卡牌仍禁购，口粮与木材仍可购买。每件商品的缺币缺口继续就近显示；商品图在买不起时仍可打开详情。
