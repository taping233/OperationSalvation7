# 四首配乐草稿精修

老板授权保留四首为草稿，并继续改进此前指出的编曲问题。本轮输出四首30秒候选及独立试听页；正式音乐映射、原音频及之前候选均未改动。沿用老板“不要验证，直接给我听”的要求，没有浏览器验收或测试循环，不声称人工听辨通过。

本轮使用声部级谱面重排和分轨渲染，未在原整体混音上增加声部。首页、探索、战斗以原有旋律为身份；商店以《灯下交易》新曲为基础。现有游戏谱例研究证据见前两轮 references.json；本轮不再下载参考曲或复制外部旋律。

| 曲目 | 改进方式 |
|---|---|
| 霜窗回声 | 保留原双手版右手钢琴录音，重新写左侧支撑、下行大提琴、和声悬留与解决；去掉多组独立回应。无鼓组或电子脉冲。 |
| 灰线行军 | 保留原旋律音高走向，钢琴和单簧管分段轮流主导；短吉他动机反复与变形，中段减少声部，颤音琴只标记少数句尾。 |
| 黑脉交锋 | 保留原弦乐旋律音符；圆号只在应答段接主线，大提琴与底鼓共用重音，定音鼓仅在过渡出现。 |
| 灯下交易 | 保留新写的短动机；删掉铜管与钢琴句尾重叠的插话，缩减吉他和弦，重新写连贯低音线，修正收束时低音重新返回属音的问题。 |

新增演奏控制包括小幅句间偏移、力度区分、持续木管/弓弦的CC11起伏、钢琴踏板与分组空间。持续声部适当减少250–650Hz能量，为主旋律留空间。这些是实现的制作调整，不是听感评分；音源仍为现有GeneralUser-GS，商业录音级音色不能据此保证。

独立页面 `/music-refinement-demo.html` 提供四首播放器、下载和上一轮入口；同时仅播放一首。每首30秒，短淡出保留为草稿结尾，尚未制作完整游戏循环。
