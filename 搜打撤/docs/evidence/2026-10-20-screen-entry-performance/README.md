- 600张卡片构造DOM：照片页17→1次查询、节点页14→1、无匹配18→1；是API调用计数，不代表一次物理遍历或真实FPS。

- 假时钟确认资源已就绪时两帧后揭示；冷图和背景仍需完成，懒图不解码。没有把16ms模拟帧换算成真实设备收益。
