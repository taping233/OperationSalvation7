## 动画实现

- 一级/普通二级使用分区错峰、方向切换，动画作用在信息容器而非逐张卡牌。连续切换取消旧内容动画。
- 人物档案/外观/卡池保留人物节点，切卡池时人物区域缩小、切回恢复；通过旧新几何差值处理人物展示区域移动与缩放。资料局部淡入，换人单独反馈。
- 代码采用本项目自定时长：一级240ms、普通二级160ms、区域错峰20ms，人物资料200ms、人物展示占比调整280ms、换人260ms。这些不是参考游戏的实测时序。
- 沿用减少动态效果分支；未采样完整运动轨迹、帧率或内存，实际效果待老板验收。

## 参考与来源

复用[独立审核](../2026-10-10-WF-base-design-audit-1010/README.md)中本轮已重新打开的12项真实材料：星铁背包/模拟宇宙准备、1999角色属性/名册/着装/商店/提升反馈/图鉴入口、方舟设施、原神成就、绝区零角色和列表录屏。

参考包含早期版本；绝区零角色录屏只抽帧查看至约50秒，60秒后登录阻断；通用列表短片未测精确时序。实施借鉴内容组织、对象焦点与反馈方式，不能据参考链接宣称已经达到对应商业游戏质量。

六伙伴没有现成专属立绘，当前新增的是统一矢量徽章，不是已生成六幅二次元立绘。人物与卡牌图像沿用现有资源，没有重绘或修改素材台账。
