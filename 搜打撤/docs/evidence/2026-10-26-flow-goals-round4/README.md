## 普通使用的共同入口

`bag-item-use.js` 统一源牌消耗、在途归属、保存结果、失败恢复、随机计划与成功呈现；`bag-item-effects.js` 处理治疗、复原、直接获取及旧快照兼容效果。`bag-legacy-use.js`保留兼容识别和效果映射，结构化普通使用也接同一执行入口，退出旧的两套消费/保存/演出代码。已完成的发现选择流程沿用。

生命与物资继续由 `game.session.death.js` 的 `heal`、`game.session.bag.js` 的 `addItem` 计算，新增可选 `deferFeedback` 端口交出原有反馈；默认调用沿用原行为。共同使用流程在保存成功后播放捕获本次数值的日志、音效和刷新，失败恢复本次源牌、治疗、复原、获得卡牌或物资。`game.store.types.d.ts`同步两个可选端口，保留上一批丢弃的实际完成合同。

`useStructuredBagRule`继续同步返回是否已接管，新增可选 `onComplete` 传实际boolean/Promise，`createLegacyBagUse`与详情使用动作透传结果；详情关闭与演出归属在成功后交接。旧“将在M1实装”提示改为当前背包可用性描述。
