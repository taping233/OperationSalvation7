# 新手指南插图稿

这组图片用于分页新手指南，均为原创 SVG 机制示意图，不是实页截图。统一画布 `560×360`，以冬日深青灰为底色、暖金强调选择，绿色表示已走节点；图内只留短标签，较长解释交给旁边的指南 UI。

## 插图

- `prepare.svg`：仓库选牌 → 整理行囊 → 带上宠物 → 出发。
- `map.svg`：突出相邻可达关系；已走为绿、当前可去为金、未接通为灰，另示战斗、火堆和箱子节点。
- `battle.svg`：玩家出牌、费用符号、目标指向及随后读取敌方意图；牌面和费用图形仅作示意，不代表具体牌或平衡值。
- `loot.svg`：从奖励中选一份，放入普通背包或宠物安全格；安全格以独立金边区域标明保护关系。
- `extract.svg`：第三层紧急出口献祭 3 张卡；第四层祭坛 → 首脑 → 终点。
- `growth.svg`：战利品回仓库、材料使用、行囊/宠物成长并进入下一轮。

素材路径均在 `game/assets/ui/beginner-guide/`。文件由 SVG 基本形状和简单路径构成，没有外部字体、图片或滤镜，也未改既有素材、图标或 manifest。

## 依据与边界

机制依据：`docs/rules.md` 的对局地图、紧急撤离、第四层流程、宠物安全格、仓库与背包条目。插图刻意不写易误导的伤害值，也不介绍尚未确认实装的研究所。

按本轮要求未运行测试、lint、解析器、渲染、浏览器或 build；插图只完成源码制作，尚未做实际页面展示核验。
