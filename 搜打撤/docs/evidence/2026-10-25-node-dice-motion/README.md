## 改动

- 事件短幕停留从 280ms 调为 520ms，退出改为 420ms 淡出；交易短幕从 240ms 调为 460ms，同样淡出。
- 通用准备短幕从 160ms 调为 360ms，不再在页面就绪入口强制覆盖成 160ms。带短幕的交接至少淡出 420ms，等待与 CSS 时间一致。
- 节点短幕整层增加 240ms 淡入，覆盖底色一起渐入；交接克隆、继续对局和减少动态效果不重复进入。
- 事件六面骰改为六个真实立体点面，1250ms 腾空翻滚、落地回弹和跟随阴影。最终朝向对应已保存点数；非六面事件使用数字骰，保持原点数范围。
- 原随机流、支付、结果保存、确认领取和离开重入逻辑保留。减少动态效果直接呈现保存结果。
