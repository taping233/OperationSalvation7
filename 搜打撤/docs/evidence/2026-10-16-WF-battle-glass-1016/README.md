- 战斗专属重复名称条的DOM与CSS已撤下，卡面印刷名称保留。人物上方继续不显示姓名；攻击力不再使用大面积黑底。

- 拖牌以单条输入合帧更新直接跟随最新指针，起拖保留抓点与当前姿态，越过原出牌线后继续跟手；取消时从末帧平滑归位，支持再次抓取。拖牌及后代临时不命中，overlay继续捕获指针；原敌人/自己/空地与HUD屏蔽逻辑保留。
