## 实现

- 右侧从整块错位纸板改为分段纸签：标题/编号、三列费用/类别/稀有度、效果说明独立成块；照片与全部纸签共用左右边线。借鉴已查看的《1999》实机中暖纸信息块、细分隔和橙色按钮端块。
- 馆藏与当前选片统一 19px 衬线标题、数字小标、文字基线；使用 8px 间距基准，整理相片间距、标签留白、编号数字与导航列宽。网格名称单行省略，完整名称仍在按钮可访问名称和右侧档案标题中。
- 背景改为中性的石墨灰，减少上一版偏绿黄的色调；沿用低对比材质与原有相框、夹子和稀有度。
- 主按钮改为暖白文字块加赭橙箭头端块，翻片按钮减弱；右侧不再重复叠加小标签底框。
- 放大背签同步纸色、标题、编号、字段、输入框和退出按钮颜色；未改变照片 420ms 动效或备注交互。
