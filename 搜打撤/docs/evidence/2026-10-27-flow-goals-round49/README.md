# 自动出牌续接与承伤资格

批量自动施放等待当前牌的完整选择链，再继续剩余牌；回合承伤预估与实际敌方攻击共用随从承伤资格。

状态：源码修改完成，接入原结算入口；保留未提交，由老板统一验收。

- 自动批次保存初始真实 UID、战斗 token 与会话 generation，逐张重读手牌和有效卡面。快意恩仇等牌产生强制支付时，后续自动牌等待支付及其后续选择完成，避免先消耗支付候选或覆盖当前选择。旧战斗批次在查询或推进时释放。
- 手牌释放沿用同一批次入口，每张附带的抽牌等待本张子选择完成。动作队列、强制支付、选牌、发现、抉择与目标选择分别沿用原执行机制；目标与注能取消也进入统一收尾。回合交接等待剩余批次，无交互的自动行动继续等待原动作队列。
- `battle.enemy-plan.js`提供共享承伤随从选择：存活、有数值、生命大于零且未潜行，按原随从顺序取首个。正式敌方攻击与预估共同读取；预估保留独立生命副本，模拟阵亡后及时排除。只有潜行随从在场时，预估不再把它算作替玩家挡伤害的目标。
- 延迟效果片只读追踪现有下一回合零费、普通/额外回合延迟结算及保存口径，本批保留既有规则。
