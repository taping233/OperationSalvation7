## 仓库与待复原

`hub.warehouse.js`沿用现有收藏浏览与懒构图，材料使用只更新当前卡格数量、资源及空堆状态，保留查询、筛选、滚动与焦点；耗尽时优先转向附近可用卡格。材料详情部分使用保持当前详情和焦点，耗尽后回到仓库安全位置，回执采用领域返回的实际qty/total/label。
