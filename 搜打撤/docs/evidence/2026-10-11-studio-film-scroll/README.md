# 照相馆胶片导轨滚动条

实现完成未提交，待用户验收。沿“不用检测”要求，没有实页或测试/build，没有本轮最终截图。

照片墙使用低对比的双侧胶片齿孔与细导轨；滑块采用暖铜渐变、侧面反光和两道握槽，悬停提亮、按下加深，呼应照片装裱与夹子。资料阅读区和筛选菜单复用铜扣滑块，不复制齿孔，避免干扰正文。其他浏览器保留暖铜原生细条回退。

尺寸保持12px逻辑宽度、透明拖动边缘与原生滚轮/键盘/拖动；照片墙此前向右24px位置与列宽补偿不变。不增加持续动画、图片资产、文字或额外操作按钮，不使用假的DOM滚动进度。

这是基于本项目照相馆主题的设计选择，并非复制1999或其他二游的具体滚动条。仅修改现行photo-studio-unified.css中的已有滚动条规则；不新建覆盖样式文件，无新服务，不提交。
