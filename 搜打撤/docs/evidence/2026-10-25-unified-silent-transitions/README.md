## “只有展示，没有演出”的实现处理

旧等待类会将整幅插画及子层暂停在首姿；部分入口又在目标准备好后立刻移除图层，实际只剩短暂展示。现在：

1. 素材解码完成后，公共 `prepareSilentFilm` 记录本次起播时刻，开始独立图层动作。
2. 目标准备可以继续保持不透明遮幕，但不会把已准备好的图层永久暂停。
3. 正常结束等待当前演出的剩余时长，再走单次淡出；点击跳过仍可缩短演出。
4. 读档保留原恢复握手；桌面启动仅在宿主进入播放状态后启动动作，避免后台准备阶段提前播完。
5. 目标页面继承的过场副本标记为完成姿态，避免复制节点后重播。

这些是源码实现说明，未以实机验收证明本批全部入口已经通过。
