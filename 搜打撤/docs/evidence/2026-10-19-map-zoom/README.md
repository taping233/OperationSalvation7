# 地图同步缩放与留白

**当前状态：缩放方案已按老板要求撤回。** 以下原实施记录仅作历史。已恢复图标/文字/道路/当前位置的原绘制比例、原手动倍率上限2.45及固定1.12倍滚轮输入；额外80px有限留白和节点区域拖动边界保留。恢复后相机、拖动、道路、渲染资源生命周期及启动指针5文件46项通过。当前无内置浏览器工具，实页未验；未提交。

老板要求再留一些拖动空间，并明确反馈缩放时节点没有同步缩放、会叠在一起。

根因是节点位置按相机倍率变化，但renderer以反向倍率补偿图标、迷雾剪影、文字、道路与当前位置标记；状态条还抵消了图标细节缩小。图形和节点间距的比例因此随倍率改变。

本轮移除上述反向缩放补偿。图标、名称、状态、道路与箭头、编号、当前位置标记及其锚点偏移跟随同一个镜头变换；保留节点主次区别和揭示动效。名称不再因缩小倍率被单独隐藏；迷雾仍不显示类型/名称。实际文字点击边界按绘制变换回写，图标点击半径计入画布比例。

拖动边缘比上一轮增加80px余量（1280px画布基准，按窗口宽度等比，最多可用轴长12%），仍限制在节点区域附近。手动倍率上限从2.45统一为探索定位使用的3.4，修复从自动高倍率继续放大反向缩小；滚轮按实际delta幅度及单位换算，纯横向和无效输入不改变缩放。
