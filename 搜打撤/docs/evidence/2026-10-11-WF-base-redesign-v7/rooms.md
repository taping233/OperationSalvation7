# v7 基地完整房间画布

状态：待用户验收。老板明确要求继续改美术与 UI，并沿用“不检测、不测试”；本片只完成 CSS 实现，未运行检测、测试、build 或浏览器验收。

## 本片实现

- 文件：`game/css/base-rooms-v7.css`。由主线在旧基地样式之后加载；只在 `#hubMain.base-frame-v7.base-subpage` 生效。
- 实际房间根：`.warehouse-v3`、`.personnel-v2`、`.trade-v5`、`.hub-archive-v3`、`.facilities-v2`。画布变量只落在含以上根节点的 `.hub-page`；不影响庭院、照相馆、选人与地图。
- 大标题与次级跳转沿一条底细线对齐，工具条与被浏览内容相邻。开放浏览区使用中性灰/低饱和灰绿，正文暖白，阅读及结算集中到单一暖纸区。
- 仓库、人物招式和卡牌收藏共享宽货架节奏；移除外层盒子底色与厚边，卡名和数量分开；卡牌本身、品质与原画保持原数据与资源。
- 仓库支持主线提供独立 `.warehouse-categories-v7` 分类节点后，转换为约 16% 左分类加中央宽货架；分类只用开放文字、细竖线与字色，不另加厚容器。原 details 分类仍能使用，新增独立分类时隐藏重复的内部分类条。
- 人物和伙伴横向名册释放主体画幅，人物立绘与阅读纸形成两个大区。招式页也移走常驻纵向名册，宽内容成为主要画布。
- 交易保持目录、原画、名称和结算连续；商品用开放陈列，结算用大阅读纸。购入/出售事件和 2.6 秒确认逻辑不变。
- 收藏成就和卡背用宽陈列加独立阅读区；见闻由侧栏目录改为顶部段落索引，正文铺成完整阅读纸。
- 扩建保留设施数据与命令，设施用开放大陈列，容量和费用读在右侧纸面。
- 橙铜只用于主动作、关键读数；细线与明度表达当前选中。交互反馈仅短过渡与卡片抬起，并处理减少动态偏好。

## 参考及证据边界

主线指定以《重返未来：1999》和《少女前线 2：追放》的完整空间与大画幅为框架方向。本片补充读取了以下材料：

- [《少女前线 2：追放》「静默突触」官方公告](https://gf2.sunborngame.com/NewsInfo?id=2044&typeId=3)：公告明确优化整备室衣装档案直达成员库对应人形衣装界面的跳转。本片据此把人物外观、招式、伙伴保留为页级跳转，不再新建小弹窗。
- [少前 2 三测仓库完整展示](https://www.bilibili.com/video/BV1cX4y1j77x/)：页面内容确认素材为三测仓库演示，可继续收集为 UI 参考。当前工具读取的是视频页面文本，未观看画面；没有据此声称复刻其布局或动效。
- [GFL2 Main Screen](https://iopwiki.com/index.php?mobileaction=toggle_view_mobile&title=GFL2_Main_Screen)：作为导航参考补充，文中列出交易室、仓库、成员库与整备室独立入口，并描述任一子菜单回主菜单。本片借鉴独立房间和短返回路径；页面不是项目行为依据。
- [《重返未来：1999》指南中的仓库材料](https://note.com/takeyori/n/n26c937d0cfdc)：主线参考代理提供该文中的[仓库截图](https://assets.st-note.com/production/uploads/images/220854821/picture_pc_8a9f6307dc53697cf0b2d00d6487154d.png?width=1200)，并给出左分类约 16% 加中央宽网格的观察。本片沿该观察增加独立左分类结构支持；文章说明截图为 2025 年 10 月游戏界面，本片没有把它当作当前版本事实。

本片版式是上述页级跳转方向与本项目现有 DOM 的实施推导。未下载或接入外部游戏原画。未改 `camp-card-actions`、仓库特写 footer、全局卡面、原卡稀有度或玩法数据。

## 主线接入点与待看效果

主线须让基地根使用 `base-frame-v7`，加载 `base-rooms-v7.css`。该文件放在 `base-cohesion-v5.css`、`base-panel-layout.css` 等旧规则之后。
