## 边界与结构

原始静态链为 `main.js → game.session.js → ui/game.menu.js`，其中整份选档、指南、成就、设置、留言和离开面板及独占渲染依赖在标题前解析。现在轻壳保留同步标题、标题统计、右键位置快照和退出行为；面板经一次动态导入 `game.menu.pages.js` 创建页工厂，注入原有会话端口与标题回调。没有静态导入会话的反穿，也没有 idle 菜单预取。

原 32 个函数实现中 29 个逐字搬移。选档和设置两处取消仲裁仅增加排除自身 `menu` owner，防止真实冷挂载被自己的页面初始化取消；退出增加先取消迟到页面，再沿原有同步保存/退出行为执行。实现未复制页面代码、未改概率/存档格式/统计/预算，未移除功能。

首个面板请求提供共享载入层及 `aria-busy`。相同真实按钮点击合并，忽略 DOM 自带 MouseEvent；不同请求最后意图优先。Escape、标题、换档/换局、来源 DOM/显隐或 Base 归属变化、其他页面入口会取消或废弃迟到结果。失败保留来源并提供重试提示；下一次点击重新导入。已到达模块与页工厂复用，热入口直接执行原页面函数。
