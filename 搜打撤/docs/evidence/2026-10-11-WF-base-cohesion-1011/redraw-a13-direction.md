# A13修改方向与判定条件

本轮先确定方向，再重绘和对照。主要参照继续采用少前2艾莫个人空间，集中处理A12灰褐色调单一、材质偏写实、排列像陈列室的问题。保留A12相机纵深、左侧大近景椅和斜向扶手、宽桌尺度、沿墙储物和右侧起居关系。

## 本轮实际修改

| 部位 | 修改方向 | 画后判定 |
| --- | --- | --- |
| 墙面、柜体与桌面 | 墙面石灰灰绿，柜体灰青，桌面暖白；阴影蓝灰，室内中间调更可读。桌灯与壁炉承担小范围暖光 | 缩小看仍能区分墙、柜、桌与布料色相；没有全局黄染或整屋泛蓝 |
| 近椅、外套 | 保留大椅轮廓和扶手透视，压掉密织纹；外套改纯色灰蓝，以少量折面表现松弛搭挂 | 近椅作为大形框景，不凭密纹理抢焦点；没有迷彩、臂章或新装饰 |
| 地面、金属 | 地面用哑光色面和少数必要透视接缝；金属只在受光转角保留局部窄高光 | 不出现镜面地板、统一亮边、遍布碎噪点或磨损纹理 |
| 工作组 | 工作椅稍拉出斜转，地图/档案夹/终端/任务灯围绕操作范围，水杯落在手边；删桌面小箱与椅下独立箱 | 工作面可用，膝部与通道不被箱子堵住；画面最清晰的细节集中在工作组 |
| 储物、饮水 | 两只同制式箱留在靠墙储物下层；供水为紧凑一体模块，热饮集中一处 | 使用关系明确，保持箱具规格与颜色一致，无新一排杂物 |
| 起居 | 寝具和枕头少量错位，以几组大褶皱表现使用状态；现代炉与床之间继续保留实体隔挡与净空 | 有生活状态，床具仍合人尺度，取暖不贴近布料 |
| 室外 | 保留低对比冬季城市背景，少量灰蓝建筑大形和雪色，无山树/道路/窗格细节 | 外景只交代地点，清晰度和局部对比低于工作面 |

颜色是物件固有色与照明关系的方向，不对生成图承诺逐像素色值。画风以选择性边缘、概括明暗和局部细化为主；保持物件结构与透视可读，避免用统一模糊模拟画法。

只读审稿后补充：抬中间调仍保留窗最亮、近椅最暗，桌面和床品承光，柜体与地面退后；色相区分服从同一窗光。远处轮廓、板缝和暗部边缘收掉，椅子与工作组选择性清晰；大色面保留少量叠色笔触，避免光滑填色加连续描边。

## 执行顺序

先复看A12与真实参考、记录本方向；只读代理核对有无遗漏；生成一张针对性重绘；根与代理实际看图，对照上表确认哪些改动落实。只有明显违背本方案时再做局部修正，不按固定次数反复出图。

本轮先完成画稿和实际对照。候选未定稿时不替换游戏运行背景；游戏源码、交易逻辑与照相馆属地不动。
