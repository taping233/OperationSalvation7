# 画风锁定与本轮边界

老板最新反馈：复杂度够；配色和光线不如原参考；当前太真实，画风须锁定与参考一致。因此保留A14/A15空间与物件数量，本轮仅重绘画法、配色和光照，不再增加家具、零件或新的布置组。

主要参照锁定[少前2艾莫个人空间](https://iopwiki.com/wiki/File:BG_None_PersonalLounge_01.png)。A15仅作空间轮廓和物件位置来源，不保留它的摄影式表面。目标为二维手绘游戏背景：选择性线条、分层色面、柔和过渡与局部受光笔触；材质通过明暗和边缘变化表达，不靠织物纤维、微磨损和强镜面反光。不改成古代水彩、厚灰纸或模型照片。

光色优先学习原参考的关系：左窗中性偏暖日光作为主要光，室内冷灰/灰绿暗部填光；桌面和床品承光，任务灯/炉火局部衰减。此前阴天设置是会话设计选择，老板最新要求学习原图光色后可调整为冬季薄云日光，不受旧提示词限制；外面仍是积雪和低对比城市。墙面灰绿/灰白、设备石墨绿、布料蓝灰与少量土黄/赭橙、纸面暖白应实际区分，避免全屋灰褐和多个橙灯染色。

画后只检查三件事：是否明显从摄影材质转为绘制色面；中间色色相是否比A15丰富并接近主参考；亮暗和反光是否由已知光源解释。真实透视保留，表面细节密度降低。未做到的项目据实际图片记录，不因为写进提示词就视为完成。
