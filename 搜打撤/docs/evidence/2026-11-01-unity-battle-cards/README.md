## 精简与消耗

删除旧黑暗形态增加发现候选的状态和分支、未消费的成长卡缓存、保险柜条件改写及发现页重复赋值。发现结算和火球批次分别共用一个执行入口。火球奖励池每批过滤一次；自动卡面按实际变化更新、复用一个展示根节点；演出空闲时提前返回。名字牌缓存布局几何，悬停回调只创建一次。没有新增每帧扫描卡库或构造卡面；本轮未测量帧率或内存收益。

## 旧卡读取边界

旧存档会携带完整卡牌定义，因此仅修改目录不能更新已经持有的卡牌。本轮采用共同读取入口对8张已知旧标准卡作精确指纹匹配，只升级本轮改动字段；保留图片和备注。带变体或关键属性、规则与旧标准不一致的卡牌保留原定义，自定义定义库直接读取不参与升级。若嵌套实体与旧标准卡的完整属性和规则完全相同且没有来源标记，读取时无法区分其是否为刻意复制的自定义卡。没有按ID覆盖所有旧实体，没有保留旧黑暗运行别名，也未扩建通用存档兼容框架。
