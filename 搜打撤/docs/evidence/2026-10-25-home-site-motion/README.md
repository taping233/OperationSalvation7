# 首页交互与动态整改

老板要求将本轮官网代码拆解先用于首页。仅改首页自身的4份源码，沿用现行公共动效组件，其他页面与城市入口的业务流程不变。

## 已实施

- 首页先出现标识，再展开主入口、收藏入口、系统入口和底部辅助操作。首次按钮动效560ms，入口延迟80–450ms；返回按钮动效380ms，原有顺序延迟缩到40%，先返回之前选中的入口。只看壁纸后恢复界面的横向位移从120px收至32px，底部从56px收至16px，缩短恢复顺序。
- 普通入口等被点按钮的退场完成再进入目的地，复用 `completeSurfaceMotion` 的事件、超时兜底和取消机制；Esc取消释放等待，制作名单关闭也复用该组件。城市已有的档位入场继续由原入口处理。
- 主按钮保留600ms进入、800ms归位的4px文字位移；底部工具文字轻抬2px，点击区域固定。取消按下时玻璃底层的横移，普通按钮悬停采用低透明亮面，不再叠加近乎实心的黑色渐变。保留现行透明底部按钮。
- `home-fx.js` 和 `home-menu-motion.js` 通过模块依赖加载自己的样式，去掉挂载后再追加样式链接的时序。
- 首页通过 `data-home-ambient` 统一管理环境动效。隐藏、页面被覆盖、打开制作名单、进入加载状态、离开首页、只看壁纸和减少动态偏好时，暂停明确列出的背景装饰；有限的按钮退场不在暂停列表里。暂停时取消待处理视差帧并归中，现行时钟随首页可交互状态启停，动态偏好变化即时同步。
- 清除已 `display:none` 且无其他现行引用的3套环绕线SVG挂载与对应样式；合并分散重复的环境暂停规则。未删除文件。
