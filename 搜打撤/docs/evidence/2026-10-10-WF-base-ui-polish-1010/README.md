# 基地二游参考迭代：浏览与动效衔接

2026-10-10 · Friday（Codex） · WF-base-ui-polish-1010

本轮继续复用上一轮真实参考，围绕对象浏览、分类、费用、阅读位置和返回反馈更新源码。实施已接入，实际画面与动画待老板验收；未运行测试或浏览器。

## 本轮改动

- 人物卡池新增按实际招式类型生成的分类标签；分类与搜索、归档状态共同筛选。费用从卡牌现有cost字段展示，含0费与无费用，不改变费用规则。
- 搜索、归档状态与类型分类收为固定工具区；键盘滚动预留实际工具区高度，避免把选中卡滚到固定筛选区后面。分类/清除条件同步选中招式和常驻详情。
- 卡池、仓库、待复原网格支持方向键及Home/End浏览，自动聚焦并选中只读对象；整备网格只移动焦点，带入/移出继续沿既有明确动作。
- 卡池放大显式提供原网格对象作为来源；仓库、待复原、卡池选中变化只给阅读区短反馈，资源操作按钮不随阅读区移动。
- 仓库对同一张卡打开/取消确认时保留阅读滚动位置；基地内页切换记住卡牌/人物资料阅读位置，按档位、页面、卡牌区分，仅会话内保留，缓存最多64项，不写存档。
- 二级切换依据内容顺序决定进/退方向；人物展示比例变化先采集当前可见几何，再取消旧动画，从当前画面位置继续，而非先跳到旧布局终点。
- 换人物/皮肤增加单张旧图过渡层，等待新图载入后交接；连续换图用序列标记拒绝旧载入回调，清理旧层。对象名称在图层上方保持可见。
- 整备剩余/已选数量和容量仅在数值实际变化时反馈；减少动态效果时跳过，保持卡牌节点与原选择规则。职业卡提示统一为归档培养/出售。

## 对照依据

复用[此前独立审核](../2026-10-10-WF-base-design-audit-1010/README.md)中的实看材料：星铁背包的稳定网格与常驻详情、1999角色/着装与名册的对象身份和分类关系、绝区零录屏中按子页改变展示重心的片段，以及原神成就的稳定目标/状态位置。

这些材料包含早期版本；绝区零角色录屏只抽帧看过约16–50秒，60秒后登录阻断，列表短片未测完整时序。本轮没有重新打开当前游戏画面；动画时长与几何方案是本项目的实现选择，不能当作参考游戏事实或实测通过。
