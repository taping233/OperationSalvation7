## 工具自测（本目录 snap-final-a/b，同树两轮）
- 结果：**失败 0 处 / info 11 处 / 退出码 0**（info 全部为商店随机货与图标加载序，符合设计）。
- 自测过程抓出并修复 4 处工具缺陷：①CDP 目标宽松匹配抓到 chrome-extension 页面（改严格匹配 about:blank/http）②报告后 ws 句柄吊住事件循环不退出（确定性 exit）③同名 key 元素被 Map 折叠交叉误比（分桶+父容器类结构定位）④照相馆瓦片高度未收敛即拍（高度稳定门）。
