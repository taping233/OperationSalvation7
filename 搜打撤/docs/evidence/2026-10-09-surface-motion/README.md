# 全界面公共进入退出模块

老板要求将首页进入/退出动画同步到所有界面，并让后续只改公共模块即可调整。

已新增 `game/src/ui/surface-motion.js`，集中维护动画时长、缓动、方向与关键帧；`interface-motion.js` 自动在公共弹层和屏幕入口挂载。首页保留左右分组、点击项先返回、点击项放大退场与距离错峰；其他页面使用同一横向分块语言。首页背景视差、灯光与装饰仍归首页美术模块。

普通界面进入 500ms，块间错峰 35ms（最大105ms），退出180ms；快速界面进入180ms、退出110ms。现有隐藏时序仍由原入口管理：标准225ms、战斗轻面板160ms、房间140ms、独立屏幕240ms、制作名单210ms；修改退出时长时须保持在对应收尾窗口内。减少动态效果同时兼容游戏设置与系统偏好。

同一基地页刷新保持当前动画相位，切换页签翻转相位重播。重开时先取消旧退出计时并完成旧清理，再显示新页面，防止新页面被旧收尾清空。内容动画只挂到最多8个布局区域，不逐卡创建动画循环。公共样式优先级覆盖首页路由和基地主题的整页入口规则，不改其他会话基地源码或美术文件。
