## 本轮实现

- `game.menu.js`：进基地时保留选档容器到同步换页；继续对局保留原有关闭和转场流程。
- `camp-entry.js`：生成无交互的短暂选档副本，移除副本 ID 和动作属性、设 inert/aria-hidden；选中档案短暂突出后退场；780ms 后释放副本和入场标记，关闭或刷新时提前清理。
- `camp-entry.css`：基地背景直接承接；人物轻微移入收焦，页头与导航短幅错峰，行动档案按信息顺序显露，主按钮最后落位。动画不阻塞业务执行，减少动态设置下跳过。
- `interface-motion.js`：基地首次进入走专用内容编排，不叠加通用整层淡入/滑动；保留已有基地刷新分支。更新 `docs/development.md` 的动效入口说明。

保留工作树中既有 `game.menu.js` 与 `interface-motion.js` 修改。没有编辑其他会话的基地、仓库文件，没有新开服务、build 或提交。未覆盖：修改后外观、进基地/返回/快速切页/减少动态的运行结果；继续对局转场尚未重做。
