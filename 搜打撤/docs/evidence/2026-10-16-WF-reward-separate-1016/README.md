# 金币与物资箱分开奖励

2026-10-16，老板要求「给的奖励，金币和物资箱要分开」。已实现，完成未提交；编辑占用释放，无新服务。

金币集中显示在奖励总览左栏，点击「收下金币」独立领取。物资箱在右侧单独开启，只处理卡牌；收牌、全部收下、关闭卡牌层、确认放弃卡牌均不自动领币。物资箱计数只统计未处理完卡牌的箱子，金币与卡牌都处理完才能继续探索。金币领取沿用各箱 coinsReceived，允许未开箱先领金币并保存恢复。

多箱沿原有时机确定内容，总览不提前抽取后续箱；后续箱确定的金币加入独立待领金额。固定补给继续沿原卡牌页流程。本轮保留所有已有未提交与暂存改动，不提交、不 build、不修改存档现场。
