# 无刚性剑、变速与模糊残影

老板反馈剑长仍不稳定，并要求变速与模糊残影。本版沿当前待机立绘制作，旧候选保留。

检查旧源码确认三条绘制路径：原待机位移场包含剑，攻击剑图做颜色筛选，攻击首尾直接绘整张待机。v7统一为干净身体加同一独立剑层，保留剑刃完整像素，所有姿势仅做刚性平移旋转。此前几何不变与剑尖存在检查不足以证明跨绘制路径的外观一致。

时间曲线安排慢蓄力、约100毫秒加速斩击、短停顿、缓收势。挥击阶段叠加带模糊的前臂及剑历史姿势，实剑不模糊。73帧、60帧/秒、约1.22秒，实际不同帧与像素检查以资产目录`validation.json`为准。

601点护手到剑尖测量约320.34源像素，误差为浮点精度，画布边界通过。当前Codex内置浏览器窗口通过真实控件查看待机、举剑、挥击、收势，开关残影与剑长对照。截图留于本目录；导出进一步检查新待机首尾、脚底固定、逐帧剑尖可见与不同帧数。这些检查不代替老板对动作观感的判断。
