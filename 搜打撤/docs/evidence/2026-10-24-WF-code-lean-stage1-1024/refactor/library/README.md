# 照相馆结构重写

已将冻结的制作/导入实现替换为当前只读契约的兼容边界，并统一照片页筛选端口与壳批追加。两运行文件共减少 4005 个 Acorn 非注释 token、25172 个 LF 规范化 UTF-8 字节、361 行。新增默认回归 3044 字节、736 token 单列，不计入运行收益。

修改边界原 14474 token，现 10469，减少 27.7%。以全部 14 个照相馆模块及直接依赖 card-browser 两文件计算，原 24162、现 20157，减少 16.6%；没有把局部比例写成完整子系统比例。新增 helper 成本已经扣除，没有压行、删注释或搬同量逻辑到 JSON。

## 当前契约与实现

- `game.cardslib.common.js` 生产常量 `CARD_DESIGNER_WRITES_ENABLED = false`，且现行注释明确冻结制作/导入/增删改入口。原 designer 草稿、编辑表单、机制词条、保存与导入逻辑受此常量阻断，当前没有可达写界面。重写后的 factory 保留四个旧入口：制作/导入回照相馆、关闭走原关闭回调、导出保持原 JSON/剪贴板/下载与返回行为。旧入口的返回值继续为 undefined。
- 照片页的四个写 action 名称及会话守卫保留，回调继续无效果；开发者展开工具、导出、普通查看与备注编辑均保留。未启用或更改任何卡库数据写入口。
- 统一的筛选字段映射同时用于表单同步和输入派发，保留搜索组合输入、120ms 防抖、稀有度扫光、分类计数与排序刷新。
- 空闲分帧追加和同步定位补壳共用一个追加步骤；原 15 个初始卡面、64 个首窗壳、每帧 60 个余壳、目标定位只补至目标、旧代回调失效、IntersectionObserver 窗口挂卸均保持。
- 未改轻门面异步取消、图片就绪闸、图片预热/缩略图策略、解码并发、运动控制、照片探针或 FPS 开关。

这次以当前冻结写功能的产品契约为边界；若未来重新启用制作坊写功能，应作为独立功能重新实现，而不是切换原 false 常量。
