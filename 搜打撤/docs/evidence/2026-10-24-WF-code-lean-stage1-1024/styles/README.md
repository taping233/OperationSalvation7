本轮只合并同一父条件中相邻、声明逐项相同的规则块，并提取两处共性：选档装饰的背景/filter 提入原有 before/after 共同规则；冬夜主题五张存档插画共享 image/size，五个 position 单独保留。没有跨文件移除覆盖，没有删除动态选择器、关键帧、媒体条件、前缀或注释。不同现代选择器支持条件的规则不混组。

- `changes.json`：每个受影响文件的冻结前后 SHA256、行数、原始/规范化字节、规则/声明数与完整操作选择器。
- `validation.json`：语法、静态等价、定向测试及未核实项；完整临时测试输出保留在清单所列缓存路径。
- `reduce-css.mjs`：本轮一次性归一程序，只接受冻结原文输入，不能对改后结果重复运行。
- `verify-css.mjs`：独立读取冻结原文和改后源码，展开逗号选择器，比较每个属性的选择器/值/important 顺序；@规则及其各次出现均为硬边界，另核对所有注释逐字保留。两处声明提取另外检查原规则属性集合，确认重排仅跨过互不重置的属性。该程序依赖本轮本地冻结缓存。
