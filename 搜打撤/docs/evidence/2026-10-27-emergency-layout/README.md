# 紧急撤离页面排版

老板要求同步修改紧急撤离相关 UI、排版与页面设计。

撤离事件页复用正式插画事件布局、选项确认与公共底栏。新增专用展示模块 `game/src/ui/emergency-exit-view.js`，左侧为简短叙事、启动代价3张、当前普通背包可献祭数量及不足数量，随身币提醒放在说明区；右侧两项行动与确认，底栏为返回地图和整理背包。停用信标展示沿同一页面结构。背景沿现有撤离场景，使用灰青色与黄铜色强调。

撤离献祭页单独展示准备标题、确认后果与实时已选/3计数；卡牌区独立滚动、底部操作保留，“献祭并撤离”和“返回撤离点”使用明确动作文案。继续复用既有献祭选卡、确认数量和结算入口。专用样式只命中撤离页面，其他祭坛献祭保持原展示。

范围：`game/src/run/game.run.altar.js`、新增 `game/src/ui/emergency-exit-view.js`、`game/css/emergency-exit.css`。保留其他会话已有增量，未修改公共事件组件。
