# 《灯下交易》V3 · 商店轻快版

老板反馈 V2 节奏太慢、不够轻松，要求继续分析不足并修改。本轮保留钢琴短动机，将速度从 96 提到 112 BPM；铜管回答改为单簧管，重写低音与和声支撑，把吉他回答移到较高音区，增加少量颤音琴与轻刷声。60 秒循环版已接入商店映射，V2 文件保留供对照。

## 可复现来源

谱面与渲染脚本见 [score.json](score.json)、[compose.py](compose.py)，导出文件及 SHA256 见 [render-report.json](render-report.json)。沿用项目已有 GeneralUser GS / FluidSynth 音源；参考录音只用于分析编配，没有导入参考样本或音符。大于 1MB 的 WAV、MP3 留在本地证据目录，不进入 Git；可运行 `python docs/evidence/2026-10-13-WF-shop-music-v3/compose.py` 重新获得。

## 定向检查

[evaluation.json](evaluation.json) 使用同一方法分析 V2、V3 和本地《商人坎诺特》参考的前 30 秒。V3 相对 V2 的算法起音由 2.53 升至 2.80 次/秒，侧向声能由 9.8% 降至 6.8%，频谱织体移动由 0.626 降至 0.312。算法不同于 V2 历史报告，数值不可跨报告直接比较；这些指标也不能代替听感判断。

V3 WAV 为 48kHz 双声道，时长严格 60 秒，采样峰值 0.6004；首尾采样差为 0，首尾 100 毫秒 RMS 差为 −4.22 dB，最安静半秒约 −28.11 dBFS。OGG 完整解码通过。运行文件 `game/assets/music-demo/05-shop-lamplight-deal-v3.ogg` 为 773,257 字节，SHA256 `da97724e9a53a6f8b21b19d17e19349415ef9911ef6f59d7844afa4007d7d91f`，与制作文件一致。工程数据不能证明主观循环自然或更轻松，待老板试听判断。
