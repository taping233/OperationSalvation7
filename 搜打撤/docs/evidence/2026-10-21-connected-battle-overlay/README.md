# 连续保留战斗场景候选（待整合与实页验证）

规则、设置及同类战斗二级页通过现有 showOverlay 生命周期更换所属兄弟层，不重新挂接当前战斗场景。背景在入口设置 inert/aria-hidden，新内容的资源就绪、音效、首焦点和动画判定不读取背景内容。返回恢复原控件焦点。普通页面仍完整替换正文；同步钩子开启新页面、新战斗或更换渲染拥有者时，旧事务不能覆盖新现场，已离场场景仅由仍拥有它的旧事务移除。

本候选的直接依据是 v31 正式浏览器返回规则/设置时外层同步区间较大，以及已倒下敌人短暂再次淡出。连续连接避免场景移除这一已识别机制，但 CSS 动画连续性和实机收益仍待正式环境验证，不能用 jsdom 计时或节点计数代替。
