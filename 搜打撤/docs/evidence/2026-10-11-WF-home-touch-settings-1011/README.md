## 写入的实现

- 悬停360ms、移开480ms、按压220ms，采用更平缓的曲线；盘面、文字、光斑、箭头与序号在主页内使用同一反馈节奏。底部工具外层固定，内部材质与图形承担抬升，避免点击范围随悬停来回移动。
- 主页退场由本地样式接管为560ms，距离错峰上限仍为90ms。旧共用surface层的180ms覆盖不再控制主页这段动作。点选按钮先轻压再少量展开，图标用320ms亮度反馈；业务入口在退场后回放一次，避免下一页立即盖住退场。设置闸片在退场后段开始覆盖。连续点击在当前进退期间拦截，失败入口仍由已有回返机制承接。
- “恢复界面”：左控制台由-120px、右控制台由+120px飞入，900ms，右侧延后160ms；页脚由左、状态条由右较短距离跟进。条目在该模式下不另叠入场，整块玻璃与按钮一起到位。两套动画名支持再次恢复；再次隐藏时取消恢复状态与收束计时。减少动态效果沿原静态路径。
- 设置：用生成的双幅闸片420ms合拢，遮挡完整后才调用原设置入口；稍停100ms，再以760ms向左右揭开。设置返回按钮复用闸片，遮挡后调用原closeSettings，再等待260ms承接既有关闭清理。Esc在闸片播放期间可跳至既有业务动作，1900ms兜底清除闸片；减少动态效果直接保留原动作。设置控件、存储及危险操作未改。此次专属入场接主页设置入口，返回接设置返回按钮；普通设置Esc关闭保留既有路径。

这些是源码实施说明，最新可见动作与连续输入效果未验收；不能据此声称卡顿已实测消除。
