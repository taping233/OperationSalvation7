## 使用口径

- **D1**：官方开发者/发行页或开发者提交的商店介绍经 web 读取。只能证明描述中的机制；不等于亲玩、完整复盘或已知玩家效果。
- **D2**：补读具名作者文章、访谈、开发日志的明确章节；设计实验是本库推论，未实施。每款的读取范围在 records.json 中。
- 全部 **未实际玩、未验证画面/音效、未下载或运行代码、未复制素材**。Agent 栏都是对代号柒的观察协议建议，本轮没有证明这些第三方游戏提供 Agent API。
- `reference-only` 是本库使用限制，不是开放版权许可。官方免费阅读、可下载新闻素材或允许录视频都不意味着资产可用于本游戏。
- FTL / Into the Breach / Slay the Spire / Darkest Dungeon 已有 GDC 索引，本轮只补横向机制比较，避免重复读取全文。
- 选择按机制相关性与一手资料质量；不使用销量、商店评分、奖项证明质量。未核的失败政策、解锁条件和信息呈现显式留白。
