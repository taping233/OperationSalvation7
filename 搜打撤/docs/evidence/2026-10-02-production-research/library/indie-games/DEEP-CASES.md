# 六个深读案例与设计实验

2026-10-02；[比较矩阵](README.md) · [全部记录](records.json)

这些是具名作者资料的定向深读，不是亲玩评测。作者事实、研究推论和代号柒待验证假设分别标识。下面的实验均**未实施**，不授权修改玩法、缩减层数或增加系统。只写原生短摘要，不转载原文/图/音乐。六例不包含既有库正补读的 Slay the Spire GDC 全文。

## 共同实验口径

项目文档基线：四层相邻节点、单向深入；普通持有牌使用后入消耗口袋、火堆可复原；首脑战是单独的循环牌库且无撤离按钮；安全格提供失败抢运；收藏会消耗仓库卡并换熟练度。实施前须核对当前代码，不据文档推断页面已达标。

以下字段是**拟议观测项，不是已经存在的接口承诺**：种子、版本、职业、局外解锁/熟练度、携入卡实例、背包/安全格/消耗口袋/墓地变化、节点已知信息、行动理由、资源收支和结束原因。UI与Agent只获得玩家可知信息；隐藏事件/未揭节点可在终局审计中记因果，不能进入即时策略观察。

探索性比较可先用同一批固定种子、相同职业和局外基线做配对，分开新手/熟练用户。Agent用于验证因果与资源行为，不能证明人类易读、音效氛围或可理解性。人为理解任务需在当前平台内置浏览器、当前窗口执行；本轮没有实页结果。样本量、完成时间、缺失数据和中断局必须记录，不把少量探索当显著性结论。

## 1. Cogmind：终局要解释行为，音效文字要守住同等情报

**作者事实。** Josh Ge 的 [Morgue Files](https://www.gridsagegames.com/blog/2015/10/morgue-files/) 中 Cogmind Score Sheets / Format / Additional Post-Mortem Features 解释了行为统计、峰值构型、常用物品和终局输出。死亡时的装备可能已失去，单看最终状态不足以解释之前的选择。作者也讨论人读输出和易解析记录之间的权衡。

[Audio Accessibility Features for Roguelikes](https://www.gridsagegames.com/blog/2020/06/audio-accessibility-features-roguelikes/) 的 Challenges / Options / General Audio Settings 讨论了把声音转为可视信息时避免额外提供精确距离，筛选有策略价值的信息、减少重复，并分开调整界面/玩法/物件/环境音量。正文读到实现限制；没有观看嵌入视频或检视演示像素。

**研究推论。** 卡牌库存会因战斗消耗而变形，结算应保留关键决策和状态拐点；音效的冗余文本应提高获取机会，而不是扩大信息权限。

**本项目假设与实验。** 给同一局制作一个结算草案：带回净额、关键损失原因、进入第三层时的资源截面、最后一次可撤离选择；与现有结算截图/观察输出比较。先从真实跑局记录生成草案，不先增日志墙。另选一个已知战斗事件，核对声效、文字和Agent观察是否传达同一事件类型。

**指标。** 玩家能否说出首要损失原因/下一次改变一项选择；解释时长；净资产核算与存档变化一致率；日志能否按事件重算卡牌去向；静音与有声条件下关键事件识别情况。Agent只核事件对齐与重算，不评价听感。

**失败/反例。** 摘要增加阅读时间却不能解释决策；峰值卡量只是库存膨胀，不能代表优势；声音文字或Agent暴露未知敌人/事件；终局日志原因错归于最后一击。遇到这些结果应缩减摘要或修正事实模型，不能补更多指标掩盖失败。

**不可照搬。** 不复制Cogmind巨大数据表、终端美术或所有音效；它的部件更换并非本项目职业成长。

## 2. Cultist Simulator：过滤永远无效的动作，保留发现空间

**作者事实。** Alexis Kennedy 的 [The Labyrinth Under the Skin](https://weatherfactory.biz/the-labyrinth-under-the-skin/) 正文描述展会玩家反复尝试无效组合。最终引入基本属性类别过滤，减少绝不会成立的投入，并提示动作期待的物件类型；没有改成直接显示全部正确组合，因为组合可能需第二张卡才能成立。这是2018年设计过程，不能视为2026每个交互都满足该规则。

**研究推论。** “未知事件会发生什么”和“这个动作为什么不合法”是两个问题。前者可保留悬念，后者如果不解释，容易浪费策略时间。

**本项目假设与实验。** 选普通战斗的一个受限出牌场景和基地的一个容量受限操作，制作三态信息草案：当前可用、条件不足且原因明确、根本不适用。用现有规则下的情境问答比较，保留事件奖励/隐藏组合本身。先核各状态属于玩家可知范围。

**指标。** 无效动作次数 / 总尝试；第一次正确操作所需时间；玩家能否说出限制原因；误以为牌会永久消失/可循环的回答；Agent非法动作返回原因与UI提示一致性。

**失败/反例。** 高亮引导变成机械扫描，玩家不理解原因；“可能成立”被误读为当前可用；提示泄露未发现奖励；新手虽点击更快却更常做错误资源选择。减少无效点击不能单独证明玩法变好。

**不可照搬。** 不复制神秘文本与有意隐晦的全部配方；搜打撤财产风险要求清楚告知确定性规则。

## 3. Dicey Dungeons：同一资源直觉上做职业差异，音效服务主题

**作者事实。** [The Reunion Reunion](https://distractionware.com/blog/2022/07/) 是Terry Cavanagh与美术/音乐/程序/写作团队的具名回顾。本轮读月归档的起源、组队、声音主题和末尾规则变体讨论。骰子是从Dream Quest类构筑中尝试差异的核心；音乐/声音从随机抽取的感受发展到游戏秀主题。Terry解释六面骰有助于维持概率直觉，Reunion则专门尝试打破不成文规则；硬币变体表达能力有限，开发并不轻松。

**研究推论。** 内容扩展可以改变怎样处理同一种资源，而不必引入更多读不懂的资源类型。声音应强化规则事件与世界主题的一致性。

**本项目假设与实验。** 选两种已存在职业，在相同携入卡价值和局外基线下，比较它们如何决定“现在消费/保留去火堆复原/带回收藏”。暂不创设新职业。给地图深入、用牌入消耗口袋、成功回基地这三个阶段建立声音事件草案，逐项注明需要强调的动作意义，再试听已有声效而非下载参考音乐。

**指标。** 职业之间资源分配/路线选择差异；共享卡被使用与保留的比例及原因；新手对消耗状态/复原机会的辨认；声音事件与文字/动画时点的对齐情况。按技能组比较，不能只比较总胜率。

**失败/反例。** 两职业只有数值大小差异；一种职业在所有条件下都更值得囤牌；新增反馈只制造噪声、覆盖敌方时点；概率/状态符号需要额外说明才明白。此时先修资源转换/信息，不把新增卡数量当改进。

**不可照搬。** 游戏秀音色、骰子角色和硬币新机制不适合直接复制；主题关联是方法，不是素材许可。

## 4. Backpack Hero：奖励取用限制与明确顺序，收束发生在决定之后

**作者事实。** Thejaspel 的 [Version 2 Hotfix 2](https://thejaspel.itch.io/backpack-hero/devlog/347904/backpack-hero-version-2-hotfix-2) 写明早期从12层压到9层，因为多数局的胜负在9层已定。这是作者当时的判断，非实验数据或现行规则证明。[Archery Update](https://thejaspel.itch.io/backpack-hero/devlog/361238/backpack-hero-archery-update) 写明增加奖励候选但每场最多取三件、被动按位置顺序触发、调整重排时机和重物落下音效。[1.0公告](https://thejaspel.itch.io/backpack-hero/devlog/636026/backpack-hero-10-is-available-now) 确认故事模式上线；后续城镇/音乐计划不能当完成事实。

**研究推论。** 更丰富的奖励候选若没有明确取用成本，就可能只增加库存管理；胜負已经决定后的重复步骤会削弱终局收束。

**本项目假设与实验。** 不改四层，先从配对跑局观察“最后一次会改变撤离/打法的有意义选择”到结局之间的节点数和时长。给现有奖励/满包/首脑后归库做一份静态草案，显示候选价值、取用上限、容量和舍弃后果；同时核对同回合词条触发顺序能否解释。

**指标。** 尾段新增策略选择次数；最后关键选择后的无选择时长；奖励比较/整理用时；因满包误弃卡次数；触发顺序解释正确率；首脑前/后分别记，不把无撤离首脑和普通探索混算。

**失败/反例。** 末段虽无新卡但仍有紧张战术，缩短会丢失高潮；限制取卡只减少回收净额而不改变选择；顺序说明比实际逻辑更简单导致误导；整理本身是玩家乐趣。不能从作者9层结论推出本项目应少一层。

**不可照搬。** 空间相邻协同和现有同名堆叠格语义不同；要先证明容量取舍问题，才讨论新的背包机制。

## 5. Ring of Pain：去掉空走廊，保留局部决策与可预见后果

**作者事实。** [开发团队AMA](https://www.reddit.com/r/NintendoSwitch/comments/jsi9x8/) 中身份列表和Simon Boxer / sboxle的具名回答解释：原型从去掉空走廊、让遭遇来到面前出发，整体体验应让机制/美术/音乐/叙事共同作用。本轮读取这些回答及结局屏、属性选择回答，不把玩家评论当规则证据。2020年回答“考虑保存结局历史”是计划，不能宣称已上线。[官方介绍](https://store.steampowered.com/app/998740/Ring_of_Pain/) 写明可见选择后果、敌方动作预告、环形移动与两条终局；[开发公告](https://steamcommunity.com/app/998740/announcements/) 支持后来的Item Sets选择功能。

**研究推论。** 地图价值取决于相邻选择是否可辨；信息可压缩，但风险类型、可见后果和不同结局的意义不能压没。

**本项目假设与实验。** 选一个已到达地图窗口的相邻节点选择，制作并排的局部选择草案：已知类型、明确固定成本、可达方向、规则上的不可返回、撤离条件。只显示当前玩家已经知道的信息。与现有地图说明比较；回看步骤仅区分导航/信息查询/策略选择，不先删移动或动画。

**指标。** 玩家能否在行动前解释为什么选这个节点；方向/单向规则误解；查询次数和决策时间；深入与撤离选择的资源差异；终局能否对应此前选择。Agent比较只核合法方向、成本与已知信息一致。

**失败/反例。** 更少点击使探索没有空间感；预览变成精确收益列表而削弱搜刮悬念；只标收益让风险不可读；结局提示只是装饰文本。此时调整信息层次，不以删节点证明效率。

**不可照搬。** 环形动态相遇和四层单向节点拓扑不同；阴暗插画/角色/诗句不可复制。

## 6. Citizen Sleeper：先看有限行动预算，再安排机会成本

**作者事实。** [具名开发者访谈](https://www.gamedeveloper.com/business/how-citizen-sleeper-was-inspired-by-tabletop-rpgs-and-gig-work) 中Gareth Damian Martin说明：每日开始就掷出当天骰子，表现一个人清楚当天能力限度、再面对任务的感觉。骰/进度时钟借鉴桌面RPG，允许带代价的成功；统一交互系统能覆盖不同叙事情境。[发行页](https://www.fellowtraveller.games/citizen-sleeper) 也确认Dice / Clocks / Drives。本轮读相关问答，不将本作关系剧情当作搜打撤局外经济。

**研究推论。** 玩家理解可用行动预算后，更容易把成功和损失联系起来。代价不是只有死亡，活着回来也可能错失补给/消耗核心卡。

**本项目假设与实验。** 在已知的普通战斗前与第三层撤离决策点，设计一个资源草案：当前生命、可用持有卡、消耗口袋、可复原机会是否已知、撤离固定成本及安全格范围。比较纯胜负摘要和“成功但净资源下降”的摘要。未知节点内容保持未知，不承诺一定存在火堆。

**指标。** 玩家能否预估一个行动后的可用牌/净带回方向；活着撤离但净亏损的占比及原因；为终局保牌导致普通战斗损伤的次数；地图与战斗阶段资源读法是否一致；Agent事件流能否重算资源预算。

**失败/反例。** 预算表太长，玩家只看生命；永久成长让亏损感被掩盖；摘要用零售价格误代真实机会成本；“可复原”提示误导为本局必定能遇到火堆。此时缩到当前确定资源和明确条件，不引入新生存计时条。

**不可照搬。** 本作日循环、生存药物和关系叙事不是撤离回仓循环；不能以相似资源限制证明需要永久衰减或新任务系统。

## 后续取证顺序

先核卡牌去向与结算净额、合法性原因、相邻节点已知信息这三类事实一致性，再进行人类理解与声音体验比较。六例中，Cogmind/Cultist Simulator/Ring of Pain最适合先做低成本草案；Backpack Hero的节奏和Citizen Sleeper的预算需要真实跑局基线。Dicey Dungeons用于检验职业资源差异，不能替代职业平衡实验。

本库未声称已发现代号柒哪处必然有问题。没有实页与跑局证据时，结论止于研究假设；现行状态、占用和待老板决策事项由父会话按项目docs登记，本子库不新增玩法拍板。
