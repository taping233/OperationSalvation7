# 每界面美术批注入口

双击 `index.html` 可本地查阅，截图与批注左右并列，支持分类、关键词和基本页实图/源码筛选。变体放在各父页下可展开；图片原位引用，没有复制、编辑、服务或外部依赖。

- `ANNOTATIONS.md`：逐页与逐变体完整文字、原图、独立游戏对照及证据边界。
- `annotations.json`：与 coverage 最终目录对账的机器记录，每个基本页和变体有自己的 ID。
- `source-evidence.json`：各定义的定向源片段、SHA、入口与状态边界；不能作为实际画面。
- `validation.json`：ID/字段/文件链接及模拟 DOM 的静态搜索检查，不是浏览器视觉验收。

H 是前会话历史8图；B 是本研究已有正常首层；A 是已有四层辅助（不能写自然通关）；N 是主会话本轮新采，正常UI与正式守卫导航按 captures.json 分开。本代理通过 view_image 逐张读取，不操作游戏。初始过渡帧保留，稳定外观以 stable 图为准；尚无 stable 的页不据淡入判可读性失败。只审实际当前窗口；658×764不是主动多尺寸。

独立游戏对照引用 `../visual-comparators/`。S1 是参考代理亲见官方静态图；D1 仅作者/官方设计文字。STS官方6.57秒循环由主会话观看，三个有效可见帧由本代理亲读；仅战斗/目标/详情四项标M1-limited，不能证明详情进退动画。其余参考动效M0，本项目动态全部M0，不比较节奏、打击感、流畅性。早期裁切失配的sts-motion-0..3不作证。源码层记录写的是独立审查条件，不是已见外观缺陷。建议未实施，游戏、存档、安装、build和Git均未改。

生成：`node build-annotations.cjs`；静态验证：`node validate.cjs`（在本目录运行）。参考矩阵更新后可重生成；不得将未经亲读的新图自动标为 reviewed。
