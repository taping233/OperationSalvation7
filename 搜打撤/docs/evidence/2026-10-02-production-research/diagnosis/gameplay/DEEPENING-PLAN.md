# 现有 5336 实页四层推进：最短操作方案

2026-10-02；此轮只读定向核对现有工具，未操作浏览器、存档或源码。老板已授权控制台辅助完成；本计划把正常策略推进、开发辅助和构造场景分别留证，不把自动脚本名称当通关结论。

## 直接可用：游戏自己的开发者控制台

当前档01已在首层稳定地图，继续同一 5336 页面，先保留当前页面/档号/层号/HP/行动/来源截图或AX。

1. 页面获得焦点后以工具支持的真实键盘操作按 **Ctrl+L**，打开游戏内“开发者控制台”。`game/src/game.boot.js:143-155` 直接绑定此快捷键，不依赖开发者模式。若平台把快捷键截给地址栏，不能改用evaluate合成键盘事件；可检查现有页面快捷入口或明确记录平台限制。
2. 点 **Agent** 页签。查看快进开关；“贪心一局（快进）”只是按钮名称，`runWith` 没有自动 `setTurbo(true)`，要快进须明确点“快进：关”切为开。
3. 点 **贪心一局（快进）** 后，**立即点底部“关闭（Esc / Ctrl+L）”**回到地图；两个已观察的按钮可在同次工具调用依次真实点击，以缩短竞态窗口。不要用Ctrl+L作为Agent页关闭：快捷键的“控制台已开”检测依赖调试页才有的 `#devcSearch`，Agent页可能重新打开调试页。启动函数不自动关面板，且策略未排除devc动作；不可把控制台留在前台给贪心乱选。
4. 短间隔观察实际页面变化，先让现成Agent承担重复普通战/节点动作。不要另起Agent或同时点战斗。需要接管时重新开控制台→Agent→**停止**，等待当前步收口；若按钮状态未刷新，切换页签再回Agent。自动跑局最多3000步/30分钟，不能把超时/停止/死亡当完成。
5. 到第三层、第四层前后及时留页；**本次目标是第四层首脑，不接受第三层紧急撤离当终点**。greedy会按策略考虑撤离，不能保证通过第四层。策略停滞或转向三层撤离时停止并人工选择继续深入，后续沿相邻节点正常过门。

这条UI路径调用 `SDT.Agent.autoRun` 的同一正常动作层，不是跳节点。源码对应 `game/src/agent/agent.console.js:21-33,45-49,78-82`。UI仅提供greedy/random/LLM，**没有strategic按钮或JS命令输入框**；不应为了使用strategic填入LLM配置或修改代码。

**真实副作用：** 正常自动推进会消耗卡牌/资源、战斗受伤、选择奖励并正常写当前档。该按钮传 `resetSlots:true`（`:24`）；策略在选档页会优先newSlot/overwriteSlot（`game/src/agent/agent.policy.js:807-811`），所以看到选档页必须停止接管，不能放任它改其他档。启动期间仍有控制台动作竞态，需用实页确认已经回地图/战斗；若发生异常点选，记录实际结果，不宣称纯正常策略。

## 确保完成原图路线：现有调试UI辅助

若贪心无法可靠继续，停止Agent后沿当前真实地图推进。老板授权的辅助可从轻到重使用并逐次记账：

- 地图时：Ctrl+L→调试→“回满血”；必要时“+50币”、指定卡名搜索后发牌，补足续航/祭坛三牌。修改会写本局存档；不能称原始平衡通关。来源 `game/src/run/game.run.dev.js:109-117,139-142`。
- 战斗时：同一调试页提供“能量回满”“生命回满”“冰冻敌人×2回合”“全体10伤”“直接胜利”。可用于跳过重复普通战；首脑优先保留正常编组、开战和至少一轮机制观察，确需直接胜利则明确标“首脑战结果由调试产生”。来源 `game.run.dev.js:119-122`。
- 关闭调试面板会调用战斗 `refreshView()` 恢复真实战斗页（`:168-171`）；不需要JS操作。

保留**正常过层→第四层祭坛支付/奖励→第四层首脑入口及编组→首脑战→击破奖励→相邻终局撤离点→整理→结束→基地**链路。回血/发牌/直接胜利是辅助；沿地图到终局仍可验证流程可达和真实页面，不能证明战斗平衡或纯策略可通关。

## 不要混用的工具

- `scripts/iab-drive.mjs:2-17,28-42` 明确仅限ZCode `node_repl`，依赖 `ZCODE_PLUGIN_ROOT/CLAUDE_PLUGIN_ROOT`、ZCode browser-client，并主要通过evaluate合成事件。**不是Codex当前内置浏览器驱动，禁止照抄此调用或改为外部浏览器/CDP。**
- 本轮Codex浏览器evaluate文档限定只读，因此这里只把 `SDT.Agent.observe()` 等只读快照视为可能的辅助读取；不得用evaluate启动autoRun、scenes、act、setTurbo、写game或合成点击。只有当前工具实际暴露可写console入口且文档允许，才可以考虑下述API。此次工具元数据检索未找到单独可调用的浏览器JS console写入口；现成游戏开发UI是已确认路径。
- `game/tools/agent-batch.mjs:1-15` 是Node/jsdom非渲染批跑，初始化自己的环境/存储；不是当前5336页面，不能完成本次实页四层目标，不运行。
- 标题“节点测试”的BOSS/祭坛按钮（`game/index.html:273-287`）调用 `devJumpNode`，有活动局会复用当前局，不保证不写档（`game.run.dev.js:48-75`）。强制BOSS固定选首脑表第一个、自动编组（`:17-31`），绕过真实祭坛与正常首脑入口。只能单独标注“构造节点验收”，不能代替原图四层通过。

## API参考仅供合法可写console存在时，不是当前Codex evaluate调用方案

```js
// 在有文档许可的可写console中，才可启动；保留当前局，防止选档覆写。
SDT.Agent.setTurbo(true);
SDT.Agent.autoRun({
  decide: SDT.Agent.policies.strategic({ resetSlots: false }),
  driver: 'assisted-four-layer-review',
  maxSteps: 3000,
  runTimeoutMs: 300000
});
// 需要人工接管时：SDT.Agent.stopRun()
```

该策略仍可能在第三层撤离，必须监看与接管，并不保证首脑通关。正常API方案也会写当前档，不能把“未直接改存档”写成“未写档”。

`scenes.start('fullrun')` 更不能作为成功捷径：`game/src/agent/agent.scenes.js:77-96` 的 `ensureTestRun()` **有活动局时直接复用**，没有时构造500HP/指定人物/跳教学测试局；`:428-449` 使用strategic，pass只要求自然撤离或死亡、无单步异常与记录增加。**fullrun.pass=true ≠ 四层通关。** `scenes.run('boss')`也是构造节点，不证明走过四层。
