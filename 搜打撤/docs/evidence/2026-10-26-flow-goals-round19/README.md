- `runHubOperation`依据既有命令的实际返回值判定保存，统一页内等待/成功/失败提示；成功提示、声音/日志和刷新分别处理，保存完成后继续返回true，来源已离开时不再更新旧页。原各入口的保存与呈现混合链退出。
