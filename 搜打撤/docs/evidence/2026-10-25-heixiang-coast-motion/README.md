# 离岸半日实装与换肤区域稳定

将老板确认的「离岸半日」内置重绘修疤痕版导入黑像皮肤列表；来源、完整画布、哈希和默认图保护见同目录 `skin-import.json`。人物外观与选人大图使用满铺裁切，横向焦点 58%，与既有两款分开维护。
