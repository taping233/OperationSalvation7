# 照相馆模糊查询与地图寻路修正

2026-10-25，老板要求继续优化性能、照相馆支持模糊查询，并修正有时无法前往可达节点的问题。沿本会话要求，不运行测试、lint、类型检查、实页或构建。

## 照相馆

新增 `collection-search.js`：统一NFKC全半角、大小写及标点，按空白编译去重关键词。各词需同时匹配，词间不限定顺序；单词先尝试连续包含，否则按字符先后查找非连续匹配。例如“火术”可匹配“火焰法术”，“抽牌 伤害”可查询同时包含两项内容的文本。这里描述的是实现语义，没有声称实际卡库中存在上述名称或已执行用例。

`createCollectionModel` 将匹配器放在本次投影的卡牌循环之外，规范化搜索文本按候选惰性生成并在当前数据代复用；替换数据时清缓存。不额外创建全库搜索副本，不引入依赖或每卡正则构造。照相馆输入提示同步为模糊搜索及空格分词；原高亮仍标注连续的原始查询文字，非连续结果不保证整词高亮。

## 寻路依据与修改

- 前往按钮原依赖打开预览时保存的 `moveTarget`；预览后状态变化可让详情的实时寻路显示可达，而旧标记仍为空。现确认以当前预览为目的地重新查路线；实际 `moveTo` 仍保留自己的事务与路线守卫。
- 多段中途通行原只接受blank或已消耗节点，entrance不属于可消耗类型，领完补给的入口因此仍阻断路线。现把入口作为普通通行类型，前置未领取补给条件继续阻止自动穿过；门/祭坛/首脑等原特殊边界不变。
- 地图绘制及命中在seen为空时沿旧档全可见兼容，旧多段寻路却把所有seen/visited为空节点判成未知。现对空迷雾记录使用同一可见兼容；有迷雾记录时仍不能跨越未知中途节点或选择未知远端目标。
- 点击命中原只把相邻点作为可达优先级，并有依赖bestLegal相等的选取分支；多段可达点与相邻点重叠时可能选错，非优先模式也可能跳过合法候选。现只收集实际图标/文字命中，按距离排序，再由近至远查询完整路线，第一个可达点即返回；无可达点时返回最近命中供原不可达提示。当前地点仍可重新进入，不扩大命中半径或迷雾交互范围。
- 键盘相邻点的旧缓存只比较next数组引用，无法反映原地边变化。现按调用读取当前边，用本次节点索引查找并去重，未领取入口补给时不提供前往候选；没有跨调用拓扑/奖励缓存。
