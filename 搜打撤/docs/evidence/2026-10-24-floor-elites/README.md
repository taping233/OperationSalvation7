# 二至四层普通战固定精英

九种精英已按老板给定的攻血与能力接入。二层起普通遭遇先按既有编组抽总人数，再替换一个位置为本层精英；每层三种等概率，普通战奖励沿原路径。总数为1时仅有精英。原第三、四层概率刷单体巨兽的分支从普通遭遇表移除；巨兽模板与其独立奖励代码保留。事件与首脑战不经此替换。现行规则见 [rules](../../rules.md)。

友方均指怪物阵营；过客光环在死亡/离场时移除；逃兵失血能致死并继续触发死亡事件；复活不算死亡，清尸不重复派发。铁皮单段伤害与中毒均限4，破甲/真实伤害克制。邪教徒阻止新增攻击/法伤祝福，不移除已有强化；假药按每次成功附加诅咒回2，受禁疗与生命上限限制；狙击手独存立即破隐。现有潜行通则仍适用。
