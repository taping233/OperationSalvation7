- 战斗：轻击/重击/施法/连击分别使用 130/240/200/90ms 基础前摇；按已计算的段数与伤害选择，不重新掷随机数。重击及实际高伤/暴击保留停顿，普通连击不逐击冻结。命中贴图大小与反冲区分，原元素音效沿用。配置在 `game/src/battle/view/battle.attack-profiles.js`，结构化与兼容文本伤害入口都传递实际段数/伤害。
