# 老板点选32项音效替换

老板从当前音效审听页导出32个触发场景的更换清单。本轮按这32个事件ID接入23份新WAV，未点选的74个事件定义保留，按钮/确认/奖励三样与音乐未改。选择范围见 `before.json` 的selection，逐项前后映射见 [mapping.json](mapping.json)。

来源为OtoLogic的Assorted SE05极简现代UI、Cyber16成对开合，以及効果音ラボ的场景/战斗声音；没有使用先前被否定的Sonniss样本，也没有整体接入B组。OtoLogic的官方ZIP由内置浏览器领取，効果音ラボ文件从官方页面列出的匿名下载链接取得，均使用当前代理。原页面快照/素材清单、ZIP和MP3留在 `sources/`；获取与加工脚本为 [prepare.py](prepare.py)，23份原件/运行件的路径、SHA256、许可和参数见 [receipt.json](receipt.json)。

界面收放、保险箱与弃牌采用短界面素材；状态、格挡及元素法术分别选音，场景转换不复用胜利/金币提示。运行件最长0.75秒，剪除开头静音，轻度变速、高通/低通，响度只衰减不提升，4ms淡入与40ms淡出。常规运行增益0.65、场景转换0.55，原护盾420ms上限、总线处理和并发策略保留；这些参数是制作选择，尚未经老板听感验收。

OtoLogic采用CC BY 4.0，发布时保留署名、许可链接和修改说明；効果音ラボ允许商业游戏与修改，不允许将音效作为素材另行分发或用于AI训练。本轮仅作游戏运行及本机私有审听，不对外发布素材包或音效介绍视频。游戏鸣谢、运行目录 `SOURCES.md`、资产清单、旧试听JSON和当前审听页来源信息同步更新。音频、MP3和ZIP不进Git，只保留来源与指纹。

入口仍为 <http://127.0.0.1:5200/sfx-review.html>，E编号不变，可沿用原勾选查看新声音；S编号随去重结果变化。浏览器勾选与备注没有被清除。

按老板“不用验证，我来验证”的要求，没有运行测试、build、浏览器或耳听验收；安装脚本只在写入前核对选择ID、捕获映射和共享文件基线，避免覆盖范围外内容。不启停或认领5200服务，不提交、推送或发布。
