# 钢琴连贯、战斗收敛与探索还原

老板反馈战斗太吵、首页钢琴不连贯，并要求《灰线行军》换回最初版本。本轮只生成首页/战斗新候选与新的四首试听页；探索和商店直接引用既有音频，正式游戏音乐映射仍未改动。

## 修改

- 首页：保持上轮钢琴主题与真实采样，改成相邻触键之间约65ms的连奏重叠；同键重弹约15ms间隔，真实句界约85ms呼吸。减小触键力度跳变，在±6dB内校正采样攻击能量；释放尾音从约0.42秒延长到0.85秒，避免和声交界干断。
- 战斗：删去一半鼓镲细分、部分吉他短音、部分Crash与过门Tom；事件数494降为374。降低鼓、吉他、FM主线相对增益，失真吉他换成较轻的过载音源，高频分量收低；最终整体额外降低4dB。
- 探索：试听页直接使用 `game/assets/music-demo/02-explore-ashline.ogg`，即老板第一次试听的《灰线行军》，完整音频而非重新编曲或截取。指纹与原接入来源见 render-report.json。
- 商店：原样引用 `docs/evidence/2026-10-09-WF-shop-remake/shop-lamplight-deal-30s.mp3`。

新首页相邻主旋律触键最大间隙从0.674秒降至0.085秒；该指标只描述琴键时间衔接，不能代替连贯听感判断。相邻不同键采用短重叠，句界仍保留呼吸，不以持续堆积延音替代分句。

钢琴素材：Salamander Grand Piano V3 — Alexander Holm，CC BY 3.0，来自 sfzinstruments/SalamanderGrandPiano。素材仍在 `.tmp/salamander-title-1009/`，未安装新软件；本轮获取/复用记录见 piano-samples.json，原素材署名和实现边界沿上一轮。
