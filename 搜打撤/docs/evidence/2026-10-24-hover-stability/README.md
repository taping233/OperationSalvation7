# 跨页面悬停稳定性修正

老板要求寻找并修复首页之外的同类问题。源码检查定位到82条会移动可点击外层的悬停声明；它们是同类风险来源，不代表82个已经实页复现的缺陷。

## 已修改

- 在30份CSS中移除76条外层悬停transform/translate声明，覆盖公共按钮、返回、选档、人物入口、基地、卡池、商店、事件、营火、背包与奖励等现行及兼容样式。保留同规则的颜色、边框、阴影和其他反馈。商店返回键仍从基础规则保留translateY(-50%)定位。准确来源及前后指纹见[变更清单](changes.json)。
- Kimi正在编辑的run-experience.css未直接修改；其中6处外层hover位移由public-controls.css中的窄范围translate规则归零，不改变布局或按下反馈。
- 背包、奖励卡面的card-state-motion不再移动/缩放可点击外层，使用边框与轻微光晕表达当前浏览状态；业务拥有的领取、丢弃与选中状态保留。
- 全局悬停音：pointerout在同一按钮内部跨子节点时不再清空去重目标。
- 词条/动作说明：在同一触发元素内部移动时不再重复调用显示路径。
- 角色卡池：同一卡面跨子元素不重置预览计时；已显示的同一预览不重复创建DOM或重播预览动效；离开卡池网格后取消尚未执行的切换。
- 固定槽位里的战斗手牌内部抬升、伪元素装饰位移、已领取卡牌飞行动画不在外层悬停移除范围。

原始源码候选见[candidates.json](candidates.json)，本次CSS修改前的自有备份在`.tmp/hover-stability/before/`。同类样式中的部分旧规则可能已被后续样式覆盖，本次同时收敛来源，避免后续入口重新落到旧位移。

## 验证边界

按老板要求只做源码查找和修改，没有运行测试、lint、浏览器、全量、资产审计或build；实际悬停不闪烁的结论尚未实页验证。保留全部其他会话增量，无服务、提交、推送。
