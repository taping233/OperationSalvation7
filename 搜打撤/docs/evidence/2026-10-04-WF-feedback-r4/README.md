# 照相馆性能与退出留言（2026-10-04，待老板验收）

老板要求优化照相馆性能并处理新留言。代码只读当前内置浏览器 `http://127.0.0.1:5200` 的 `sdt-suggestions-v1`，比上一轮新增1条：「退出照相馆缺少动画」，原文在 feedback.json。沿用老板“不测试、直接修改”的明确要求。

## 已实施

- **装配**：瓦片观察器只在网格切换时重建，每批新增壳只增量注册；真实挂载的子树传给预热接口，不再每批重新扫描、观察整库。保留15张首批瓦片、64个近窗壳、后续分帧追加、缩略图与键盘深定位。
- **缓存与旧任务**：同一卡对象的瓦片HTML缓存复用，牌库刷新时更新、关馆时释放；网格 generation 使旧 rAF/observer 回调失效。悬停预览保持90ms去抖，并在筛选、重绘、关闭时取消待执行回调，避免迟到预览作用于新页面。
- **图片**：预热支持指定 roots，当前会话最多4路并发解码，近视口才赋 src；同一图片/源地址不重复排队。预览有独立合法 scope，不能误按“必须位于网格”过滤掉。重置断开观察器、清空队列，旧完成回调不推进新会话。
- **入口**：加载来源快照改用 DOM 节点身份与原有请求/状态检查，避免序列化整页 innerHTML；显式切页时中止旧加载、释放残留 Promise 与遮罩，保留旧请求不能覆盖新页面的守卫。
- **退出**：只给关馆时的整页容器补0.2s淡出、10px下移与轻微收回；内部照片仍禁动画，避免数百张照片重新播放入场。动画仍沿既有225ms关闭收尾；减少动态效果下禁用新增动画，未改玩家偏好。

主会话负责轻门面和退出CSS；两名Luna分别负责 page.js 与 art-warm.js。渲染机制说明在 render.md；实现完整范围为 game.cardslib.page.js、game.cardslib.art-warm.js、game.cardslib.js、photo-studio-craft.css。其它未提交增量及卡面、资产登记清单保留。
