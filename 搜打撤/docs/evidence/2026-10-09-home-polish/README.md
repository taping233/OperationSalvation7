# 首页美学加动效（2026-10-09）

范围：标题页 `#title`。新增 `game/css/home-polish.css`、`game/src/ui/home-fx.js`，`title-credits.js` 加一行 import；未改 `title-p0.css` / `index.html`。

## 改动
- 氛围：壁纸 48s 缓慢漂移加鼠标视差；顶部冷光呼吸；雪层透明度 .32→.62；扫描线降到 .34 并在角色区域淡出；左侧压暗减轻。
- 字标：保持原 PNG，仅有柔光托底、6 颗星光、轻微浮动、字下金线画出；斜光已按老板要求删除。
- 玫瑰花瓣：8 片，从角色周围区域飘落，呼应手中的红玫瑰。
- 菜单：悬停改为内部层滑动、按钮外框不动（修复边缘悬停抖动）；悬停加光标跟随光斑；右侧列表收紧（单项 66px、间距 11px）、边框改 1px 发丝线、填充加深；主按钮由信号黄改为金色渐变并带周期扫光；英文副标 11→12px 并提亮，「进入城市」副标改 ENTER THE CITY，「照相馆」改 PHOTO STUDIO。
- 顶部横幅：由同句重复 6 遍的滚动条改为单行标签加一条从左画出的细线。
- 主按钮箭头：只在悬停或聚焦时右移，不再常驻抖动。
- 入场编排：壁纸先从暗处亮起，字标随后落定，右侧菜单自上而下依次到位，底部工具最后出现。
- 点击反馈：板与小工具按下时压暗。悬停与点击音效沿用 sound.js 的全局委托，未另加。
- 群像壁纸：降饱和并整体偏冷，红橙压成深酒红，与冷色界面一致。
- 稳定性：`#title` 改 `overflow: clip`。原为 hidden，聚焦或点击定位会把它滚走（实测 scrollLeft 303、scrollTop 170，整页错位）。
- 第三轮（老板令「晃动再轻、改动放开、更高级」）：壁纸漂移幅度约减半且周期拉长到 72s，视差、字标浮动、花瓣摆动、颗粒抖动、悬停位移均下调；新增 home-layers 层：右侧斜切暗板（斜边描线绘入加金色短线）、四角角标、巨幅描边 CODE NAME 7（180s 缓慢滑过，人物区域遮罩）、左侧竖排字与刻度尺游标、顶部体积光束、菜单编号 01–07、悬停扫光与字距呼吸、次级菜单自右侧擦入。
- 电影感：地面薄雾缓慢横移、胶片颗粒（overlay、低透明度）、四角暗角。
- 细节：右上状态读数（本地时钟、版本）；壁纸切换钮移到「只看壁纸」旁；预热提示在 0/0 时隐藏。
- 安全：页面被覆盖时暂停新增动画；reduce-motion 与 prefers-reduced-motion 下关闭动画并隐藏花瓣、星光、扫光。
