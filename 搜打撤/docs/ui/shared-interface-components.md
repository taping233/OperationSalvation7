# 公共界面组件

公共层统一普通界面的按钮状态、玻璃确认框、区域切换、资源就绪和可见性；页面继续声明自己的内容、布局、主题与业务操作。接入记录见[首轮实施记录](../evidence/2026-10-25-interface-components/README.md)、[覆盖补齐记录](../evidence/2026-10-25-interface-coverage-fix/README.md)和[演出与资源闭环记录](../evidence/2026-10-25-frontend-gap-close/README.md)。这些批次未运行实页验收。

## 材质与控件

普通界面的字级与操作语义由 `secondary-ui-tokens.css` 的 `--interface-*` 变量维护。页面标题30、对象名26、正文22、控件20、辅助信息18、注释16、强调数值24，均为既有设计画布像素；当前接入收藏页头、成就、照相馆操作区、预设、设置及确认/留言。照片原画、卡面内部排版和其他业务页面不自动套用这套字级。

显式 `.ui-control[data-ui-action]` 在 `public-controls.css` 中区分 `primary`、`secondary`、`quiet` 和 `danger`。主要操作为浅冷色实底，次级为低对比描边，轻操作透明，危险操作为红色；调用方只声明角色，局部样式保留尺寸与布局，不再另写主按钮配色。确认框保持取消在前及初始焦点，危险确认在后；留言表单按返回、保存排列，原事件标识保留。选中使用冷色标记，预设就绪用绿、待处理用琥珀色，金色仍可表达奖励/稀有度或页面材质。记录见[操作与字色层级](../evidence/2026-10-25-interface-hierarchy/README.md)。

收藏页面的稳定身份、分类导航和内容工具栏由 `collection-chrome.js` / `collection-chrome.css` 维护，当前接入成就、照相馆与预设页头。`collectionHeaderHTML` 接收标题及可信的返回/分类/工具片段，`collectionToolbarHTML` 将搜索、筛选与结果置于相邻区域；主题通过局部变量声明，照片纸面与奖章原图保留。

成就详情是列表旁的非模态区域，选中与筛选保持可操作，上一枚/下一枚只切换详情正文；关闭或新选择取消旧切换，已实际呈现的奖章身份与请求目标分别记录。Esc优先收起详情，页头返回直接离开成就页。待领取与已领取筛选仅投影现有状态，不触发领取。`decision-summary.js` / `decision-summary.css` 将预设资格、容量、缺失与禁带事实置于应用入口旁，编辑折叠不隐藏决策事实；当前预设页仅有控制器入口，未新增玩家导航入口。实现及验证见[收藏界面结构整理](../evidence/2026-10-25-collection-layout/README.md)。

`game/css/public-controls.css` 唯一维护普通按钮的基础外观、状态反馈与显式文字层运动；`interface-components.css` 维护中性玻璃确认框和留言表单。`confirmAction` 使用 `.ui-dialog-panel`；公共浮层入口为玻璃确认内容添加同一类，原来的焦点陷阱、背景隔离、取消与动作执行继续由既有所有者负责。退出视觉壳的完成与业务动作分开。

设置与信箱的公共页壳、正文层级和操作按钮由 `page-settings.css` 维护，分类导航、设置行及开关由 `settings-navigation.css` 维护；旧双列布局、旧勾选框和私有逐行入场已移除。设置折叠区使用 `settings-extra-*` 稳定标识，返回时分别恢复展开、滚动与来源按钮焦点。指南保留纸面主题；它与设置的选中填充使用公共底板提供的变量，已测量后让出填充，减少动态时使用原静态选中态，不通过高优先级规则压住两套底色。实施及验证见[来源整理记录](../evidence/2026-10-25-interface-source-rewrite/README.md)。

`dialog-surface.js` 的 `bindDialogSurface` 供确认框、右键留言表单和研究所通关演出共用焦点循环、背景输入隔离、Esc所有权与返回焦点。`input-isolation.js` 按所有者累计隔离，释放时仍有其他所有者的元素保持隔离；原已隔离而不属于此机制的元素不接管。`screen-owner` 暂时跳过被隔离的所有者，覆盖解除后继续参与输入仲裁；返回焦点也检查当前输入所有者。特写退场只释放自己的隔离权，并核对来源页版本与当前焦点。

留言表单通过 `showScreen` / `hideScreen` 接入公共开合；来源页已变化时只关闭留言，不恢复旧游戏状态或旧焦点。普通留言临时挂在 `body`；制作名单等原生弹窗打开时挂在其内部，隐藏完成后回到原位置。公共层级变量为 `--layer-cinematic`（9500）、`--layer-feedback`（11000）、`--layer-confirmation`（12000），保证留言与确认框在通关演出上方。

普通浮层内的 `.ui-control`、`.ov-btn`、`.mini-btn`、`.settings-tab`、`.bg-nav-item`、`.bg-page-button` 和 `.archive-back` 共用悬停、按下、焦点反馈。快档战斗浮层保留原来的控件反馈。文字需要轻移时，在按钮内显式使用 `.ui-control-label`；点击外层保持固定，不自动重包富文本或图标。选中状态沿用 `aria-selected`、`aria-pressed`、`aria-current` 与各页既有标记；`.ui-control` 提供按下/当前项的边缘标记，危险状态仍有独立色彩。

`selection-state-motion` 的移动底板接入背包分区/筛选、设置分类、指南章节及成就的获得状态/陈列视图。底板只接管选中填充与阴影，文字、边框、点击位置和业务标记由原控件持有；指南保留石墨底与金色边，成就沿用各自深色底板与圆角。完成测量后才隐藏静态选中填充，减少动态时隐藏移动底板并保留原状态样式。成就分类的专用框、照相馆专用页签线不重复接管。

所有新增时长继续由 `motion-presets.js` 输出 CSS token：悬停进入/退出、按下、区域退场与区域进入分别使用 `hoverIn`、`hoverOut`、`press`、`regionExit`、`regionSwap`。首页保留已确认的缓慢悬停参数。减少动态偏好取消文字位移和进入/退出运动。

运行中开启减少动态时，公共 `target-motion` 立即应用当前目标，并以完成结果结算原等待；切页、卸载或新目标接管仍按取消结算，二者不混用。`home-linked-interactions` 同时监听系统偏好和本地开关：已登记的有限原生动画直接完成，持续循环暂停；偏好恢复时只接续由该机制暂停的循环，已完成的入场不重播。后台暂停与减少动态的暂停所有权分别保留，关闭/分离元素清理后不复活。

## 区域切换

`region-transition.js` 的 `transitionRegion(root, update, options)` 用于同一页面内的内容导航。`root` 是保留的正文容器，导航留在容器外；`update` 同步更新本次内容。`direction` 决定水平位移方向，`isCurrent` 补充页面有效性，`signal` 支持外部取消，`prepare(signal)` 可连接有截止时间的资源等待。

顺序是旧正文退场、更新内容、可选资源准备、新正文入场。新请求取消该容器的旧请求；退出浮层或替换页面时沿 `createPageSurfaceLifetime` 取消。结束和取消都会恢复该组件接管的样式、输入与忙碌状态。动画完成有超时兜底，业务提交不放入此视觉更新回调。

可选 `enterGroups: string[]` 按明确选择器声明入场顺序。资源准备后只对这些不重叠的内容组分别入场，容器自身不再叠加第二次入场淡入；最多8组，组间35毫秒，累计间隔最多105毫秒。取消、被新请求接管或结束时恢复分组样式；减少动态时直接呈现终态。未声明或未匹配分组时沿用单区域入场，不按行数自动拉长列表动画。指南翻章顺序为标题、插图、正文；收藏详情顺序为卡面、信息；分页、导航与操作数据刷新不因此重播整页。

当前接入设置分类、指南翻页和留言信箱列表更新。设置保留每个分类的阅读位置；指南保留页头、章节导航、正文容器以及每章正文滚动位置，分页器随章节替换。信箱读取、错误/重试、完成标记和删除后的列表更新都经过同一容器；保留滚动，焦点对象移除后转到同条或邻近记录的可用操作。异步恢复焦点检查请求版本与页面有效性，用户已主动移动焦点时保留用户选择。首次整页入场继续沿 `surface-motion` 与 `page-motion-profiles`。

指南翻到首章或末章使来源翻页按钮禁用时，焦点转到当前章节按钮。异步翻页期间单独记录实际聚焦和指针选择，自动落回body不当作用户改选；用户已操作别处、页面过期/关闭或被隔离时不抢回焦点。临时监听在完成和取消路径均释放。

信箱容器声明 `data-region-managed`，由公共层接管直接子项的有限入场，避免每次替换列表又叠加旧逐行动画。返回状态的身份匹配忽略临时动效阶段，不把进入/退出阶段当作元素身份。

`mountCollectionView` 的可选详情区复用 `transitionRegion`：选择状态即时同步，保留导航、列表及详情容器，只对变化正文退场、替换、准备和进入；图片等待最多600毫秒。相同内容不重建或重播，连续选择取消旧详情请求，返回原内容也会取消在途替换。初次同步或显式不播放时直接更新；不叠加调用方的详情刷新动画。当前可选详情适配器接入收藏室，其他仅列表适配器不因此增加详情过渡。

信箱按每页20条挂载记录，先待处理后已完成，分页保留完整数据和总数；全部导出仍包含所有记录。换页回到列表顶部，完成/删除更新保留原阅读位置并修复失效焦点。

设置从留言信箱或跑局数据返回时恢复当前分类、每分类阅读位置、展开项与可用焦点，并沿用最初进入设置时的退出状态。子页面返回检查对局/档位、当前页面与一次性返回状态；数据页自身刷新允许继续返回，离开时直接接回设置页，不先启动一次浮层关闭。

## 可见性与持续效果

`surface-activity.js` 提供 `watchSurfaceActivity(root, options)`：观察保留容器及其祖先的可见性、输入隔离、关闭状态，以及确认框/加载层和浏览器生命周期。额外的原生弹窗可通过 `extraRoots` 观察；`isActive` 增加页面特有条件。回调与计时器可以订阅活动状态；结束使用时调用 `dispose()`。

`manageSurfaceActivity(root)` 暂停不可用容器内正在播放的音视频和无限循环动画，恢复时只接续本控制器暂停、仍在该容器中且来源未变化的媒体。有限入场/退场继续由原动效所有者完成。减少动态偏好也暂停已接管的循环，偏好恢复后可接续。声明为 `data-ui-ambient` 的装饰还能使用公共暂停样式。

容器内部的隐藏、隔离、折叠、影响已登记媒体/循环的类变化，以及新加入媒体也会同步。隐藏子面板中的新播放请求会被暂停；更换媒体源不继承旧的播放恢复。观察忽略动效内联样式，普通选卡类变化不枚举整页动画；已有原生循环在真实暂停边界登记，CSS循环通过 `animationstart` 登记。

公共浮层按 `ovBody` 容器复用活动观察，容器内部更新由既有观察接续，关闭或更换容器时释放。首页环境状态复用同一观察能力，并保留只看壁纸、离开首页、制作名单等额外条件。

庭院通过 `watchSurfaceActivity` 直接联动自己的Canvas帧循环和WebAudio雨声：隐藏、被模态隔离或进入后台时暂停；恢复时保留手动暂停开关。离开或替换庭院会释放观察、帧请求和音频资源。

研究所通关演出在被留言/确认框隔离或进入后台时暂停打字，恢复后接续；Enter/空格只在演出拥有输入且目标不是表单控件时翻页。减少动态偏好直接显示完整字幕并取消视觉运动。

## 资源与返回上下文

页面准备继续沿 `runPageLoading`、`waitPageVisual` 与资源共享器，按同一挂载页和订阅者的取消/截止时间工作。默认只等待首屏代表图片，不等待长列表全部加载。必需的图片可显式标记 `data-visual-critical`，该图片会参加准备并转为 eager；一次仍有数量上限。指南位图插图和留言信箱空态插图已使用此标记；信箱局部更新在准备后入场。

图片实际失败标记 `data-visual-state="unavailable"`，保留原图框和可访问替代文字；取消等待不会把图片标为失败，也不会修改下一页。页面关闭后的旧准备不能揭开新页面。

照相馆缩略图保留近视口加载、最多4个活动任务；每次准备以2500毫秒为截止，失败/超时后延迟350毫秒尝试一次，总计最多2次。完成、失败、超时都会释放队列位置，关闭/筛选重绘清理旧任务与重试；实际解码无法中止时，完成记录先释放旧DOM引用。两次自动尝试仍失败时，照片目录出现一处“重新加载”入口。共用收藏/仓库卡牌浏览也使用 `list-image-recovery.js` 提供局部恢复；入口位于卡牌按钮外，一次手动尝试最多并发4张、每张等待最多6000毫秒，失败后允许再次手动尝试，不刷新整页或追加缓存参数。换来源、卸载卡片和关闭页面使旧恢复失效，成功后移除提示；关键图与原图恢复见下节。

临时页面返回使用 `overlay-return-state.js` 保存稳定身份下的滚动、展开状态与焦点。`captureOverlayReturnState(root, focusTarget, {readContext})` 可由页面提供分类/筛选/选中等普通值；`restoreOverlayReturnState(root, snapshot, {applyContext})` 先应用该上下文，再恢复展开/滚动/焦点。具有明确id的目标不再因入场、选中等class变化而漏匹配；标签、类别/卡牌等来源数据和唯一匹配仍须一致，歧义、禁用和隐藏目标跳过。适配器不存旧DOM、回调或游戏数据，不写存档；设置导航已接入分类与各分类滚动，其他筛选页面仍由自己的所有者持有状态。

角色卡池按2026-10-25老板确认的策略维护本次选人会话的浏览上下文：同一人物从卡池返回选人再打开时，保留类型筛选、页码、选中预览、滚动与焦点；切换人物清空该上下文，换回原人物也从默认开始。不写入游戏存档。对应回归与实页边界见[图片与返回连续性记录](../evidence/2026-10-25-image-return-continuity/README.md)。

## 图片失败与局部恢复

`visual-resource-recovery.js` 的 `createVisualResourceRecovery({host, source, apply, label, isCurrent, floating})` 用于图片探针：调用 `load()` 开始，准备以6000毫秒为截止；失败或超时才出现局部提示和“重新加载”，重复点击不会叠加请求，成功后撤去提示。保留已有画面、不加全页遮罩、不刷新页面、不添加随机缓存参数；关闭/换页/来源变化使旧请求失效，`dispose()` 清理观察、计时器与探针引用。样式独立放在 `visual-resource-recovery.css`，随模块静态引入。

庭院背景与照相馆原图升级使用同一恢复组件。前者保留现有底色与可用交互，后者保留当前预览。当前模块只负责图片，不替代音乐/音效既有恢复入口。

显式 `data-visual-critical` 图片在公共准备时登记 `watchCriticalImageRecovery`；图片自身的load/error及6000毫秒截止独立于页面揭幕等待。揭幕结束取消等待后，晚到的真实失败仍能提示，晚到成功会收起提示。替换图片源、关闭或卸载后清理；指南位图和信箱空态图已经过此入口。普通卡面长列表保持原有懒加载/有限重试，未自动为每张图添加按钮。

人物换图使用 `visual-image-preparation.js` 的 `prepareVisualImages(root, {signal, timeout})` 准备一组已挂载或离屏图片，默认2500毫秒截止，返回 `ready` / `unavailable` / `cancelled`。离屏懒加载转为eager；取消、截止和失败清理监听、定时器与可清空解码记录，不因等待取消误标新来源。`character-view-motion` 在成功后才替换旧立绘，失败/超时保留旧图并用 `createVisualRecoveryNotice` 提供就地重试；新选择取消旧请求，离开页面释放未完成准备与提示。减少动态也保留资源准备，只跳过视觉运动；皮肤内层交叠、旧图布局快照、`--skin-focus` 与待机进度连续沿用。

## 人物导航的最新意图

`latest-page-motion.js` 的 `createLatestPageMotion({getRoot, isCurrent})` 保留一个退场时钟和一个目标回调。同一页退场期间的新导航替换目标，不延长退场；完成事件或有上限的UI时钟提交最后目标。取消/卸载/关闭会释放动画、时钟和目标引用，旧回调不进入新页面。

选人页接入该控制器：退场中点击合法人物会取消旧导航，并即时响应新人物选择；最终出发确认仍保留原业务守卫，不把确认动作加入导航队列。

## 过渡属性边界

基础控件样式显式声明颜色、边框、阴影、透明度、滤镜或既有按下变换，不使用 `transition: all` 把尺寸、间距、布局一起接管。按钮原有反馈时长保留；渐变图像的切换仍沿CSS本身的插值能力，公共层不补额外遮罩。此轮收窄范围为 `base.css`、`cards.css`、`hub.css`、`overlays.css`、`scenes.css`、`winter.css` 中19处原有声明；不以此宣称全站实页已验收。

## 插画节点

事件、火堆、入城说明和宝箱开启选项使用 `illustrated-node.js` / `illustrated-node.css` 的公共阅读布局：左侧标题叙事、右侧操作选项、同一滚动与页脚边界。选项底板使用已确认的石墨标题带与灰白笔刷，冷灰蓝表示选择，金色用于价值，淡暖红表示代价；选项右侧由语义对应的简洁 SVG 虚影留白。

`illustratedChoiceHTML` 生成操作项，`decorateIllustratedChoices` 保留事件原动作与禁用条件，`illustratedNodeLayout` 组合叙事、内容和页脚。`event-choice-selection.js` 仅处理多项事件的阅读选择：选中项内显示唯一确认键，再点同一项或 Esc 取消；单项事件与火堆继续直接执行原动作。开箱后、战斗后的卡牌奖励和入城补给领取保持独立奖励布局，不接入此组件。独立预览 `game/event-template.html` 直接调用正式组件，不维护第二套设计样式。实施与验收见[插画节点实装记录](../evidence/2026-10-25-illustrated-nodes/README.md)。
