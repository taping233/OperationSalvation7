# 局内商店的浏览连续性

从货架打开收购台，再按「返回商店」，会回到离开前的货架滚动位置，保留商品详情及其完整规则展开状态，焦点回到原操作入口。出售后的金币与背包变化照常保留，不恢复旧交易数据。

从收购台打开背包整理，再返回收购台，会保留收购规则的展开状态、浏览位置与入口焦点。之后返回货架仍沿用本次进入收购台前的位置。

这些浏览状态只属于当前商店会话，不写入存档；换店或离店后作废。延迟恢复只作用于仍显示的原返回页面，不抢占之后打开的页面。

代码与定向测试证据见 [返回连续性验收](../evidence/2026-10-20-shop-return-continuity/README.md)。当前内置浏览器实页尚未验收。
