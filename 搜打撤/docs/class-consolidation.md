# 职业整合定版表（2026-09-05）

原 11 职业（刺客 / 剑客 / 术士 / 法师 / 牧师 / 授印者 / 降临者 / 召唤师 / 守卫 / 游侠 / 战士）
整合为 **5 职业**，每职业 **10-12 张职业卡**，另配 1-3 张英雄卡。

> **不同职业不互通**：每张职业卡带 `cls` 字段，`classPool(职业)` 严格按职业隔离；
> 职业卡稀有度统一为「职业」并锁定随机/发现获取（`unrandom`），只能经职业卡池发放
> （开局选职业 / 火堆 30% / 事件）。英雄卡与衍生牌同样绑定 `cls`，随所属职业流转。

## 七、实机卡库迁移说明（ensureClassConsolidation）

游戏启动时自动执行一次（标记 `sdt-cards-cc2-seeded`，v2 覆盖 v1 已迁移过的卡库），对现有卡库做如下处理：

1. **按 id 改归属**：上表 36 张带原 id 的职业卡直接改 `cls`，并统一为职业卡形态
   （稀有度「职业」+ `unrandom`）；其中 9 张按定版更名（快意恩仇 / 剑仙形态 / 噬血术 /
   急行军 / 法师锦囊 / 永恒绽放 / 爆燃火球 / 三重火球 / 星陨之力）。
2. **英雄与衍生牌**：11 张英雄卡与 8 张衍生牌只改 `cls`（稀有度不变）；
   修罗/雷修斯/关云长/妲莉薇特同步定版更名；妲莉薇特的描述按定版重写。
3. **按卡名收编**：设计者在制作坊自建的职业卡（盗宝 / 花瓣法阵 / 千变万化 / 厄运 /
   黑暗形态 / 充能火球 / 火焰形态 / 致命射线 / 风暴火球）按卡名找到后改归属，
   **不覆盖已写的效果文本**；江湖救急只收编「职业」稀有度版本，普通版保持原样。
4. **补种新增卡**：整合新增卡（不变应万变 / 厉兵秣马 / 恶魔之力 / 圣光之源 / 法力补给
   等 cc- 前缀卡）缺失时自动补入；v2 会撤下 v1 曾补种的占位英雄「九尾焚天·妲」
   （cc-heroda），由「邪渊主宰·妲莉薇特」顶替。
5. **退役与兜底**：退役表中的卡去掉 `cls`（保留在图鉴与制作坊）；任何残留旧职业名的
   归属一并清除，保证「不同职业不互通」。

其他同步改动：

- **职业熟练度**（meta.js）：同名职业直接沿用；侠客取 刺客/剑客/游侠 中熟练度最高的一份
  （惰性迁移，旧数据保留可回滚）。
- **职业发放**（randomClassCard）：开局/火堆/事件的随机职业卡只从「职业」稀有度卡中取，
  不再可能随机发出英雄卡或衍生牌。
- **彩色令牌**（heroOf）：改为在所属职业的英雄卡中随机发 1 张（如侠客三英雄任取其一）。
- **立绘**（art.js）：侠客沿用剑客立绘；旧职业名映射保留供老存档兼容。
- **选角故事**（game.run.js CLASS_STORY）：更新为 5 职业版本。
- 中途对局如仍选着旧职业：该职业不再出现在选角页，卡池发放会安全空转，重开一局即可。
