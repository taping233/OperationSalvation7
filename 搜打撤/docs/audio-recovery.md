# 音乐加载失败与恢复

设置页的音频分类显示音乐播放、加载中、静音与失败状态。当前场景音乐加载失败时提供「重试加载音乐」，每次点击只重试当前失败曲目一次；正常播放与加载中的曲目不重新创建或重播。加载成功后按钮隐藏；再次失败后可再次手动重试。

场景切换时，下一首加载失败会继续保留上一首，直到新曲目实际开始播放才淡出旧曲。普通点击、音量变化和状态同步不会反复下载失败文件。关闭再开启音乐仍按原有规则恢复当前场景。

浏览器自动播放限制仍由现有播放器在真实输入或解锁后恢复，与网络加载失败的手动重试分开。全局静音、关闭音乐、后台页面及诊断禁播期间不发起手动加载。设置页监听在关闭或替换页面时释放，不增加轮询。
