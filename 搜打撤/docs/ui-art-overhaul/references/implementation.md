# 计划、实现与素材生产

## 1. 制定能直接执行的计划

不要只列“优化字体、提升美术、增强动效”。每一项必须能分配文件、选择素材方式并验收。

推荐实施顺序：

1. 修复页面/图片/字体加载与严重布局问题，确认真实入口。
2. 整理主次和功能区：标题、搜索/筛选、内容区、预览、返回。
3. 固定字体、颜色角色、间距、控件尺寸和状态；恢复用户要求保留的特色。
4. 做三种代表对象：普通、高阶、特殊分类，走完列表—选中—详情—返回。
5. 扩展等级和材质，制作必要素材，覆盖空态、长文案、窄屏。
6. 整理进入/退出和切换动效，检查性能和完整观看链。

步骤可按问题调整。例如已有成熟布局，只缺材质，就不重排整个页面。

工作单必须写出“通过条件”。例如：

```text
任务 A07：统一退出按钮
依据：用户要求与封面一致，颜色可调整。
先读：封面按钮 DOM/SVG、计算规则、移动端覆盖。
改动：目标页复用同一图标路径、58×58按钮盒、24×24图标与窄屏缩放。
保留：目标页原有退出事件、Esc、可访问名称。
范围：目标页标记和限定作用域样式；不改封面与全局按钮。
通过：尺寸/图形一致，位于指定角落，无遮挡，点击与键盘仍可退出。
注意：数字仅为这个实例；新项目必须读取实际封面值。
```

## 2. 文件与并行任务所有权

开工前看当前仓库状态和最近提交，确认目标文件是否有别的任务写入；历史交接只能作快照。已经核实的上下文不重复扫描。

- 只在用户或当前适用规则授权多代理时派工。不能为了显得忙而委派一项等待结果期间没有独立工作的任务。
- 可拆为：布局/标记、独立美术资产、主代理整合样式与实际复核。性能审查可以只读。
- 每个写文件只有一名负责人；明确可写、只读、禁止碰的路径。
- CSS、共享 UI 和入口 HTML 容易冲突，尽量由同一人整合。不要多代理同时往同一 CSS 末尾堆覆盖。
- 子代理报告只说明其产出与自查。主代理不得把报告当成最终实际视觉证据。
- 用户指定小模型时才采用相应模型；没指定就遵守环境的代理规则，不擅自切模型或改配置。

## 3. 把规则落在稳定实现里

### 作用域

为目标界面设置明确根类或组件边界。例如照片展示模式才使用照片框，不影响共用卡牌组件在战斗、背包中的样式。

新增规则前先查：旧主题覆盖、CSS 加载顺序、断点、伪元素、`!important`、内联样式以及共享组件调用方。源文件里的值不是最终生效值。

### 状态与身份

- 将等级/类别映射集中管理，列表、预览、弹层共享映射。
- 稀有度颜色与选中状态分开管理。选中轮廓不能把所有框染成一种色。
- 尽量局部更新选中对象，避免每次点击重建全库 DOM、丢焦点和滚动位置。
- 随机纸张角度/磨损使用稳定 ID 派生，不能每次渲染抖动。
- 不能为 UI 方便而改卡牌等级、数值、排序语义或存档规则。

### 材质与空间

- 相纸至少区分：原画、可见纸边/底签、纸层侧面、接触阴影、离面投影。
- 微纹理放在纸面背景；文本和原画保持清晰。不要对整个照片容器套噪声滤镜。
- 木/金属框需要实体底、内外沿和角部连接；只有几条描边通常仍像线框。
- 高阶角雕在缩略尺寸仍应有可辨的“大形”；把几十条细线压成两像素不是细节。
- 主光方向和阴影距离应一致。厚度靠近物件，投影离物件；二者不是同一种黑色粗边。
- 容器边角、分隔线和扣件应解释结构。没有功能/材质理由的装饰优先删减，但删除须遵守项目授权边界。

### 观看连续性

至少走通：进入 → 搜索/筛选 → 浏览 → 选中 → 预览 → 放大 → 操作详情 → 收回 → 返回。

同一对象的框式、夹子、名字颜色在各处保持身份；随尺寸调整工艺尺度，不在大图里突然给所有物品统一金框。

进退动效应成对，优先 `transform` 与 `opacity`。要处理快速连续点击、来源已滚出视野、筛选导致来源消失、图片刚加载、窗口尺寸变化和减少动态效果偏好。无法回到来源时使用一致的淡出兜底，不跳到页面角落。

“点击照片外退出”需要明确排除照片本身、备注输入、按钮、链接、术语交互等区域；同时让布局间隙和外部提示能关闭。不要用一个粗暴的全局点击监听破坏备注编辑。

## 4. 素材选择：不要事事生成，也不要事事画渐变

| 需求 | 优先方式 | 选择理由 |
|---|---|---|
| 间距、对齐、尺寸、状态、基本投影 | CSS/组件布局 | 可维护、适配稳定，不需要图片 |
| 简洁图标、几何护角、矢量分隔装饰 | 现有图标/SVG | 缩放清晰，易统一线宽 |
| 纸纤维、皮革、木纹、手绘浮雕、复杂装饰框 | 真实位图素材或图像生成 | 需要具体笔触、材质细节和不规则形体 |
| 已有可编辑的 SVG 需要换形 | 修改原生 SVG | 不把确定性矢量工作转成随机生成 |
| 仅少数原画构图/质量不合格 | 按具体图片单独修订 | 不授权批量重绘人设或全部卡面 |

使用当前环境可用的图像工具/技能和项目指定通道。用户明确授权的新通道优先于旧偏好；不得假设所有项目都可调用某服务。

本次项目曾先用 SVG 建结构，再用手绘位图提高关键框的精细度。它是一种可选路线，不表示所有界面都必须先做粗糙占位图。

## 5. 生成前写素材规格单

每个素材至少定义：用途、实际显示尺寸、外形比例、透明区域、角件范围、拉伸区域、材质、光向、字体/主体禁入区、文件格式需求、文件预算、使用位置。

先生成一件代表素材，检查接入效果后再扩展成套。不要生成一整张带文字的界面图，然后把它作为可交互 UI 背景硬贴。

### 可复制的边框提示词

```text
用途：游戏收藏界面的生产用九宫格边框素材，不是界面概念图。
构图：正视、无透视、单一闭合矩形框，输出方形画布。
透明：中心和框外为真实透明 alpha，不画棋盘格或黑色背景。
结构：外侧约【比例】为框体；四角装饰完整位于【角区比例】以内；
      四边中段保持笔直安静，便于横向/纵向拉伸；不要在中段放会变形的花纹。
材质：【产品已确认的材料组合】，有明确实体底、压边和接榫。
工艺：【低/中/高阶指定工艺】；高光来自【方向】，暗部保留层次。
风格：【产品笔触与写实程度】，细节集中边缘，不侵占中心照片与文字。
不包含：文字、数字、标志、无关徽章、额外夹子、整页UI、人物、环境、强发光。
输出：一张独立可接入素材，保留透明通道。
```

实际比例根据容器确定，不把一个项目的 `slice=230` 或 `18px` 当通用标准。

### 可复制的纹理提示词

```text
用途：【相纸/皮革/木材】表面微纹理，用于文字背后的低对比底层。
正视均匀表面，细致但低对比，色调【色调】，尺度【纤维/纹理颗粒大小】。
若需重复铺贴：四边可自然衔接，无明显中心亮斑、方向性投影和独特大污点。
不含文字、边框、物体、图标、折角、强划痕或可辨重复图案。
```

### 可复制的局部修订提示词

```text
目标图是编辑对象，其余图片仅为风格参考。
仅修改【具体区域/工艺】；保留【轮廓、透明区、主体、光向、比例、颜色语义】。
问题是【可见症状】，改为【可观察结果】。
不重新设计整个对象，不新增文字/人物/图标。
```

提示词写具体材料与结构，不堆“最高级、AAA、超级精美”等无法验收的形容词。只有要修改输出时才发起新一轮生成，每轮只改变导致失败的关键变量。

## 6. 从生成结果到真实接入

1. 按工具要求检查生成结果，不假设中心透明；错误包括假棋盘格、发黑底、透视、边缘被裁和拼图式多资产。
2. 获取真实输出文件；先保存到项目许可的资源目录，使用语义化版本文件名。不要引用只存在于生成工具私有目录的文件。
3. 保留原始输出，替换现有资产、删除旧版和清理临时文件均遵守项目授权。无必要不改已有被别处引用的文件。
4. 位图框测量实际角件边界，确定九宫格切片，中央不填充；背景纹理单独放一层。需要实体面板时才使用中心填充。
5. 确定边宽、纸内边距和图片区域预算；低阶/高阶比较时明确允许哪些几何差异，避免边框盖住原画。
6. 静态纹理使用可复用小图；根据实际显示尺寸和 DPR 选择资源分辨率。允许的常规编码/压缩按工具规则处理，保留 alpha，不擅自用不受支持的图片编辑方式绕过图像工具。
7. 接入真实 CSS/组件，检查 URL 基准、大小写、版本参数、静态目录和生产打包路径。
8. 在框的预览页看到素材不是最终接入。列表、预览、弹层必须都沿实际数据展示；但用户接管验收后不要继续浏览器检查。
9. 记录：资源路径、生成通道、最终提示词、素材职责、引用文件、切片/尺寸约定及待检查项。

## 7. 资源失效的排查顺序

先区分：所有图片失效、某一资源族失效、单张损坏、请求成功但被 CSS 隐藏。

1. 所有图都失效：先检查页面/资源请求是否连得上服务，监听端口与进程是否存在。不要先重绘图片或更改清单。
2. 连接被拒绝且服务确已停止：按项目方式恢复服务，保留用户页面，不强制刷新。使用能持续运行的托管/后台方式，遵守系统工具规则。
3. 404：比对磁盘路径、URL、相对目录、大小写和清单；HTTP 200 也要确认返回的是图片，而非 SPA 回退 HTML。
4. 文件可读而解码失败：确认实际格式、文件完整性和透明通道，避免只看扩展名。
5. 图片请求正常但不可见：检查尺寸、display/visibility/opacity、层级、遮罩、背景覆盖、懒加载根节点和旧主题覆盖。
6. 只修确认的原因。全站资源故障时不要先修改通用图片错误处理；别把服务重启说成素材被修复。

项目说明里写清服务生命周期与启动方式；不能承诺后台服务永远在线。
