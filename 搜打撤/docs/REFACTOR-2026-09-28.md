## 实施原则

- 规则/纯数据 → 领域状态与命令 → 应用流程 → 视图与浏览器装配，避免领域模块创建 DOM、依赖启动顺序。
- 保持存档 schema、卡牌 ID、随机流和公开接口；需要迁移时先明确契约和回归证据。
- 使用已有 JavaScript + JSDoc + TypeScript 工具逐步严格化，不用 `any`、`@ts-ignore` 或空接口伪造类型覆盖。
- 模块拆分须减少实际依赖或独立状态职责，不以文件数量作为成果；软编码用于真实共享规则，不引入通用配置平台。
- 不覆盖未认领文件，不删除临时或旧文件，不安装依赖；现有检查失败先定位原因，不绕过提交门禁。
