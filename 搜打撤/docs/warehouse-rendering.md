# 仓库卡面构造

仓库与待复原页保留连续滚动网格。所有库存堆叠的按钮、数量、保护标记和卡面占位槽一次建立；复杂卡面仅在当前可见区域及上下各 600px 的邻屏内构造。进入页面和修改筛选时立即补齐当前窗口，后续滚动由 `IntersectionObserver` 补齐。

卡槽沿用现有卡框宽高比和网格尺寸，不替换按钮、不回收已构造卡面、不分页。选择、筛选、快捷键、滚动位置以及待复原业务继续走原仓库逻辑。键盘焦点进入未构造的按钮时立即补卡，因此 Home/End、方向键和 Tab 不依赖观察回调时序。

补卡时按当前库存稳定堆键重新定位卡牌，不保存旧库存索引或卡牌快照。找不到对应堆叠时不向旧按钮填入其他卡。每个卡面在当前页面只构造一次；库存事务触发的整页刷新重新建立本页状态。

观察器只服务当前页面和存档。离页时释放观察器，过期回调不再写 DOM。没有 `IntersectionObserver` 的环境按当前筛选一次补齐卡面，保持浏览功能。

实现：`game/src/hub/hub.warehouse.js`。回归：`tests/warehouse-art-window.test.js`。受控成本对照与未核边界见 [2026-10-20 验证记录](evidence/2026-10-20-warehouse-window/README.md)。
