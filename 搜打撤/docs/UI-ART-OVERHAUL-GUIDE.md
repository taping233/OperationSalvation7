# 界面美术彻底整改：使用入口

这份指南把照相馆整改中可复用的经验整理成 `ui-art-overhaul` 技能。适用于游戏/应用的现有界面，可以提供参考图，也可以由模型从产品已有风格建立基准；不固定使用木框、纸纹或任何具体画风。

## 直接给模型的任务

```text
使用 $ui-art-overhaul，彻底整改【目标界面】的美术与UI。
参考图有则使用，没有则从产品已有风格建立基准。
先诊断清晰度、满足感、统一性，再按计划实现并生成接入所需素材。
保持已有功能与明确保留的特色，持续复核修改，直到标准满足。
同时检查文字清晰度、跨页面连续性和渲染性能。
```

用户自行验收时追加：`我来验收，不要操作我的页面或运行验收流程；实现后列出待验收项。`

“持续”指授权会话内不断完成下一项并闭合反馈，不代表无视用户停止、不受限制调用工具，或保证会话结束后自动继续。

## 经验的适用边界

- 明确要求必须保留：例如夹子造型、等级文字色、原战斗/背包卡牌表现，不能在“统一风格”时删掉。
- 参考成熟作品应借鉴层级、物件感、材质和工艺关系，不以增加装饰数量或照搬界面作为标准。
- 美术、功能与性能分别取证；测试通过或生成成功不自动等于画面达标。
- 自动验收默认按问题闭环推进；用户接管验收后立即遵守，不继续操作现场。
- 本指南已经进行结构与内部链接检查；未据此启动另一轮游戏整改或小模型端到端执行，效果仍需实际使用验证。
