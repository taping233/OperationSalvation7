# 人设库（character-bible）

五角色文字人设 + 标准参考图的唯一权威出处。出图、写作、剧情、卡面对齐一律以本库为准。

## 口径铁律

- 人设以选人界面为准：角色数据源 `game/src/characters.js`（id / 名字 / 职业），立绘 `game/assets/portraits/full/`。
- 旧 Danbooru 人设文字已于 2026-09-09 全部删除，**禁止引用或恢复**。
- 每个角色一页，页面分两块：**外观锚点**（美术出图用）+ **性格与背景**（剧情写作用）。
- 标注「待定稿」的字段 = 老板尚未提供素材，任何人不得擅自推断填充；老板改稿后及时回写本库。
