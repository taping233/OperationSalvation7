# 音频系统说明

`game/src/audio/sound.js` 是 Vite 版音频入口，公开 `SDT.Sound` 接口：`sfx(name[, opts])` 播放短音效，`music(mode)` 切换标题、探索和战斗音乐，音量及静音设置独立控制。进入主页即加载并尝试播放音乐；浏览器限制自动播放时，首次点击或按键恢复 AudioContext 并续播。播放器在音频解锁后重试播放失败的当前曲目，静音、隐藏页面和离场曲目仍受原有开关控制。

原创场景配乐由 `SceneMusicPlayer` 按需加载独立 Howl 实例，只使用四首：《霜窗回声》织体轮替修订版、初版《灰线行军》、战斗《影潮交锋》120秒无缝循环修订版、商店《灯下交易》60秒循环修订版。首页、基地及成功/失败结算复用标题曲；探索、营火、事件、祭坛、撤离复用探索曲；普通战斗与全部首脑共用战斗曲；商店使用商店曲。下一曲加载期间保留旧曲；就绪后旧曲淡出500ms、新曲淡入650ms，带代次保护并释放离场曲目。关闭音乐、全局静音和页面隐藏立即卸载当前及待播放音轨；音量滑条与战斗 ducking（45%）同步当前曲目。

曲目映射由 `sound.music.catalog.js` 的 `MUSIC_TRACKS` 维护，文件在 `game/assets/music-demo/`；临时卡牌/背包浮层保留节点所属曲目，离开节点恢复模式曲。独立试听页为 `game/music-demo.html`，与游戏使用同一份四首映射。标题曲来源与运行指纹见[首页配乐二轮精修记录](evidence/2026-10-13-WF-title-music-v12/README.md)，商店曲来源见[商店配乐轻快版记录](evidence/2026-10-13-WF-shop-music-v3/README.md)，初版探索来源见[四首接入记录](evidence/2026-10-09-WF-four-bgm-install/README.md)，战斗曲来源与运行指纹见[完整战斗曲接入记录](evidence/2026-10-12-WF-battle-bgm-install/README.md)。旧音频文件仅停用，历史文件和草稿仍保留。

短音效优先使用 `assets/sfx/battle` 采样池，缺少素材或解码未完成时使用 WebAudio 合成音。新战斗 cue：`cardSelect`、`discard`、`burn`、`kill`、`danger`、`energyUp`、`energyDown`、`shieldUp`、`shieldBreak`、`phase`、`rarePlay`、`curseEnd`。其中 `phase` 支持 `{ side: 'foe'|'self' }`；选牌、弃牌、护盾增加和击杀使用新增 CC0 采样，其余使用短合成音。护盾增加采样以较低增益播放，截短至 420ms 并淡出；护盾增加 cue 有 220ms 冷却。

音频入口重复初始化时先销毁旧 `SDT.Sound`；Vite 热更新释放当前播放器、淡出定时器和音效 AudioContext，并移除该实例的输入及可见性监听。曲目映射保持初版标题曲。此生命周期修订尚未做运行验证。

主页菜单悬停采样使用较低增益、0.82 倍速与 1200Hz 低通；素材未就绪时使用 520→430Hz 的柔和短音。

高频操作和装饰音按事件冷却；45ms 内超过四个声音时，后续低优先级操作声会被抑制，战斗结果和危险提示仍可播放。合成音与采样共享 SFX 总线和 Master 软限幅器（阈值 -6dB、比例 12:1）。采样峰值归一化至约 95%，各 cue 再按独立增益混合。

音乐来源固定为这四首文件配乐，设置保留音乐开关和音量；旧存档中的冬境声景来源偏好不再启用。`setMusicSource` 兼容接口只选择当前文件配乐。冬境声景代码和历史音乐文件保留；音频入口不再导入或创建冬境声景，首脑战和压力接口也不启动旧合成层。

文件在Web Audio通道解码失败时，播放器对同一加载请求只回退一次浏览器媒体通道；两次都失败才报告加载错误。HTTP等网络错误直接报告，不切通道。回退加载同样遵守静音、隐藏和场景切换的释放规则，旧加载回调不能启动已离场音轨。
