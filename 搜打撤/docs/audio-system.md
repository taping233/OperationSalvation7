# 音频系统说明

`game/src/audio/sound.js` 是 Vite 版音频入口，公开 `SDT.Sound` 接口：`sfx(name[, opts])` 播放短音效，`music(mode)` 切换标题、探索和战斗音乐，音量及静音设置独立控制。进入主页即加载并尝试播放音乐；浏览器限制自动播放时，首次点击或按键恢复 AudioContext 并续播。播放器在音频解锁后重试播放失败的当前曲目，静音、隐藏页面和离场曲目仍受原有开关控制。

原创场景配乐由 `SceneMusicPlayer` 按需加载独立 HTML5 媒体 Howl 实例（显式 `backend: html5`，不走整曲 WebAudio 解码），只使用四首：《霜窗回声》织体轮替修订版、初版《灰线行军》、战斗《影潮交锋》120秒无缝循环修订版、商店《灯下交易》60秒循环修订版。首页、基地及成功/失败结算复用标题曲；探索、营火、事件、祭坛、撤离复用探索曲；普通战斗与全部首脑共用战斗曲；商店使用商店曲。下一曲加载或等待播放解锁期间保留旧曲；收到下一曲真实 play 回调后旧曲淡出500ms、新曲淡入650ms，带代次保护并释放离场曲目。关闭音乐、全局静音和页面隐藏立即卸载当前及待播放音轨；音量滑条与战斗 ducking（45%）同步当前曲目。

曲目映射由 `sound.music.catalog.js` 的 `MUSIC_TRACKS` 维护，文件在 `game/assets/music-demo/`；临时卡牌/背包浮层保留节点所属曲目，离开节点恢复模式曲。独立试听页为 `game/music-demo.html`，与游戏使用同一份四首映射。标题曲来源与运行指纹见[首页配乐二轮精修记录](evidence/2026-10-13-WF-title-music-v12/README.md)，商店曲来源见[商店配乐轻快版记录](evidence/2026-10-13-WF-shop-music-v3/README.md)，初版探索来源见[四首接入记录](evidence/2026-10-09-WF-four-bgm-install/README.md)，战斗曲来源与运行指纹见[完整战斗曲接入记录](evidence/2026-10-12-WF-battle-bgm-install/README.md)。旧音频文件仅停用，历史文件和草稿仍保留。

全部运行短音效由 `sound.samples.catalog.js` 的106个明确事件及 `phase` 双方别名维护，`sound.samples.player.js` 只播放已解码文件。其中打开界面、打开保险箱、关闭界面、进入祭坛、门扉、商店、撤离点、诅咒结束、冰霜攻击、治疗恢复和界面导航11项已取消音效，以空files列表和零增益表示，不加载或创建音源；对应游戏行为保留。按钮/选择、确认、奖励等38个触发继续使用 `game/assets/sfx/original-ui-1018/` 的V2点击、V2确认与V3奖励A；三样为项目独立设计，没有第三方音频采样。对应常规增益0.65、悬停/导航0.08，SFX基准1.5不变。

最新第二轮点选15项中，10项按老板后续要求取消音效，另外5项使用 `game/assets/sfx/selected15-r2-1018/` 的5个短音源，覆盖能量/增益降低、格挡、诅咒和卡牌恢复效果。卡牌恢复效果与治疗恢复分别配置，前者保留声音。来源为Kenney Interface/Impact Sounds（CC0）与効果音ラボ，未使用本轮被否定的旧源。沿用这些触发的运行增益，原件只做短片段、轻度变速/滤波、仅衰减配平和淡入淡出。另按后续要求取消界面导航声；其余90个事件定义保持，包括前轮已保留的17项、原创38项及Mixkit35项；音乐未改。本次4项取消见[静音调整记录](evidence/2026-10-18-sfx-four-silence/README.md)。此前处理、来源和前后映射见[第二轮15项记录](evidence/2026-10-18-selected15-sfx-r2/README.md)，前轮记录保留在[点选32项接入记录](evidence/2026-10-18-selected32-sfx/README.md)。

子页面打开时（主浮层、卡牌详情、留言层及原生对话框），统一跳过通用click与hover，包括页面内显式请求的悬停音。主菜单页面入口和地图背包/保险箱/消耗区入口也不播放自动点击与悬停音，避免在打开页面前先响。界面导航样本已静音；选档动画不再延后播放场景音。奖励、交易、战斗等具名反馈保持各自配置。修正原因与覆盖边界见[子页面静音记录](evidence/2026-10-18-subpage-sfx-silence/README.md)。

制作名单不展示音效署名；作者、许可及修改说明保留在各素材目录SOURCES.md。仍在使用的OtoLogic素材按CC BY 4.0保留来源说明，効果音ラボ按其免费商用许可使用。旧音频不删除，新旧音频均不进Git；方舟原录音未进入当前映射。

旧试听入口 `game/sfx-audition.html?set=web` 的清单已同步当前映射，优先列出本轮15项；11个静音项显示「已取消音效」，连续试听跳过这些项。此页不包含游戏总线滤波/限幅与并发。老板要求自行验证，本轮不运行测试、构建、浏览器验收或游戏内听感验证。

当前配置逐项审听入口为 `game/sfx-review.html`，直接导入运行映射，提供音源去重和全部触发场景两种视图。静音项保留在清单并显示「已取消音效」，不发起播放请求；有声项可选择对应场景音量及文件版本。各项可标记「要更换」、写备注、复制清单；标记仅保存在本浏览器独立的 `sdt-sfx-review-v1` 项，不修改游戏设置或映射。E编号及已有勾选/备注保持；S编号随音源去重结果变化。单音试听沿用事件增益/变速/滤波/截断和现行总线参数，不复现游戏并发、音乐或动态战斗参数。未整体接入先前B组候选。
