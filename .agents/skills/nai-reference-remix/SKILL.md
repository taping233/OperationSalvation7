# 参考图换人出图

项目入口：仓库内 `搜打撤/tools/NAI-PROMPTS.md`；具体组合规则统一维护在 `搜打撤/docs/production/art/NAI-PROMPTING.md` 的「参考图换人标准流程」。先读该段，再按需读指定人物现行页与认可图。

- 参考图提供构图、动作、场景与光色；我们的现行人物提供身份；我们的现行 NAI 配方提供画师串与画法。当次明确指示优先。
- 服装、帽子等可更换造型先从身份层剥离，再按场景重新设计。配饰可以保留，须区分参考配饰与目标人物的身份饰物；不把原人物发色、眼色、兽耳等身份特征带入。
- 已明确的人物与偏好沿用，无需重复确认；人物无法确定时只问角色。默认一张候选，不自动接入游戏。
- 默认横版使用免费档 **1344×768、不超过28步**；参考图更大或要求沿用原图配置时也不自动升为付费尺寸，只有老板明确指定大图/其他尺寸才覆盖。客户端与项目手册维护实际参数。
- 读取或设计流程本身不等于出图授权；老板要求出图或执行时走项目现有 `nai_gen` / `nai_guard`，不绕开失败与冷却护栏。
